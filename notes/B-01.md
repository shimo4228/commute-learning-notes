# B-01 確率とは何か

## 本編の要点

- 確率には、繰り返しの中の割合（頻度）と、証拠に支えられた信念の度合いという二つの顔がある。ハッキング（1975）はこれが17世紀半ばの成立時からの二重性だと論じた
- 頻度説（フォン・ミーゼス 1928）は確率を世界の側に置けるが、一回きりの出来事と参照クラスの問題に弱い
- 主観説（ラムジー 1926執筆、1931刊、デ・フィネッティ）は信念を賭けで測る。値は自由だが、ダッチブック論証により確率の決まりを守る整合性が求められる
- コルモゴロフ（1933）の公理は計算の決まりを定めるだけで、確率が何であるかは言わない。複数の解釈が同じ公理を満たす
- ハーイェク（2007）は参照クラスの問題がほぼすべての解釈に及ぶと論じ、条件付き確率を基本とみなすことを提案した。条件の選び方の悩みは残る

## 対話で出た論点

- 降水確率で傘を選ぶ人は、頻度を一回きりの信念に移しかえている。これ自体は直接推論と呼ばれるまっとうな手続きで、ライヘンバッハは信頼できる統計のある範囲で一番狭い参照クラスを使えとした。危ういのは移しかえの継ぎ目が見えないとき。誰が選んだ参照クラスか、手元にそれより細かい情報がないかを確かめずに済ませてしまう
- LLM判定器の0.7は継ぎ目がほぼ見えない例。学習データのどの集まりの頻度を借りたかが外から分からないまま、その一件への信念として読まれる。要領の格差率は、どの集まりと比べたかを明示して継ぎ目を見えるようにする工夫と読める
- ブラックスワン（タレブ 2007）には二つの問題が重なる。一つは仕組みが変わらないまま裾が重い場合（果ての国）。極限はあっても有限の記録からは推せず、中心極限定理も使えない。もう一つは出来事が条件そのものを作り変える場合。集団の前提が崩れ、参照クラスがある日を境に消える（二匹目の子猫の例、ラッセルの鶏）
- 主観説は一回きりの出来事にも信念を与えられるが、その信念の良し悪しを繰り返しで確かめられない。カーネマンとクラインの二条件（規則性とフィードバック）が両方欠けた場所にブラックスワンはある
- 観想的エージェントは憲法を自ら修正するたびに、それ以前の記録が半分別の列のものになる。日々条件が変わるので較正のしようがなく、evalを作れない。さらにその手前に、望ましい振る舞いが定義されていないという問題がある。較正には当たり外れの基準が要るので、順番としては構成概念の不在が先
- 主観説は信念の中身を決めず、組み合わせの整合性だけを問う。evalに移すと、望ましさは定義しないまま、その時点の憲法と振る舞い、修正提案と述べた理由が噛み合っているかだけを見る方向がある。比較判断（どちらがよりそれらしいか）も目標を固定しない。どちらもグッドハートに比較的強いが、一貫して妙な方向へ進むものは止められない
- 望ましい行動を定義しないのは著者の子どもの頃からの特性でもある。本人の感覚では「定義したくない」より「定義できない」に近い。方向づけを欠いて生きてきたわけではないが、価値に盲目になれず、どこか覚めてしまう。何かを決め切って覚悟を決められない臆病さによるのではないか、という自己理解もある
- 定義できないが方向はある、というのはポランニーの暗黙知の形に重なる。方向は選んだり退けたりする振る舞いの中に現れる
- ベイズでは信念の度合いと行動の決定は別の段階。0.7の信念のまま傘を持つかどうかは決めるしかなく、決めたあとも信念は0.7のままでよい。信念を0や1に置くと更新できなくなる（リンドリーのいうクロムウェルの指針）。「決め切れない」には、信念を1にしきれないこと（更新の余地を残す態度）と、信念が1でないまま行動を選ぶことへのためらいが混ざっているかもしれない。憲法を確定させずに修正を提案し続けるエージェントは前者を形にしたもので、それでも毎回何かの行動は選んでいる


## 概念表

| 概念 | 一言で |
|---|---|
| 頻度説 | 確率を、繰り返し試行での相対頻度の極限とみなす立場 |
| 主観説 | 確率を、ある人の信念の度合いとみなす立場 |
| 参照クラスの問題 | どの集まりで頻度を数えるかで確率が変わり、選び方が決まらないこと |
| 整合性 | 必ず損をする賭けの組を組まれない信念の持ち方 |
| ダッチブック論証 | 確率の決まりを破る信念は必敗の賭けを許す、という論証 |
| コルモゴロフの公理 | 非負、全体が1、排反なら足せる、という計算の決まり |
| 確率の二重性 | 偶然の傾向と認識上の確からしさという二つの面 |
| 直接推論 | 参照クラスの頻度を、その一件への信念に移すこと |
| 果ての国 | ごくまれな桁違いの値が全体を決めてしまう世界（タレブ） |
| 非定常 | 出来事が生成の条件そのものを変え、過去の記録が同じ列でなくなること |
| 整合性によるeval | 望ましさを定義せず、組み合わせの破れだけを見る評価 |
| クロムウェルの指針 | 信念を0や1に置かず、更新の余地を残せという指針 |
| 信念と決定の区別 | 信念の度合いが中間でも、行動はどちらかに決めるしかないこと |

## 復習用の問い

1. 降水確率70%を、頻度の読み方と信念の読み方でそれぞれ言い直せるか
2. 参照クラスの問題を、今日とは別の日常の例で示せるか
3. 「雨」に0.6、「雨でない」に0.6の信念を持つ人が必ず損をする仕組みを、金額で説明できるか
4. コルモゴロフの公理が確率の意味を決めないとは、どういうことか
5. ハーイェクが条件付き確率を基本にしようと提案したのはなぜか
6. 言語モデルの単語の確率に、頻度と信念の二つの顔はどう現れているか
7. ブラックスワンに重なっている二つの問題は何で、頻度説にとってより根が深いのはどちらか
8. 信念の度合いと行動の決定を分けると、「決め切れない」はどう二つに分かれるか

## 開いたままの問い

- 自分で憲法を修正し続けるエージェントで、修正の前の評価の頻度をどこまで持ち越してよいか。憲法の版ごとを参照クラスとみなすのか、修正の過程そのものを較正の対象にするのか（→B-14 較正、A-15 直観はいつ信頼できるか）
- 望ましい振る舞いを定義しないまま、整合性と比較判断だけで eval はどこまで組めるか。一貫して妙な方向へ進むことを、何で見つけるのか（→A-18 比較判断、A-20 統合回）
- 「定義できないが方向はある」の方向は、どこに現れていて、どう記録できるか（→A-11 ポランニーの暗黙知、A-12 コリンズの三分類）
- 決め切れないことは、信念を1にしきれない態度なのか、信念が1でないまま選ぶことへのためらいなのか。エージェントの設計に映っているのはどちらか（→B-19 能動的推論、知るための行動と得るための行動）
- 裾の重い世界では有限の記録が平均を語らない。エージェントの振る舞いの記録にも、ごくまれな桁違いの出来事が全体を決める性質はあるか（→B-06 中心極限定理）
