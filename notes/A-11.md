# A-11 ポランニーの暗黙知

## 本編の要点

- ポランニー（1966年『The Tacit Dimension』、同年の論文「暗黙の推論の論理」）は、私たちは語れる以上のことを知っている、という事実から始めた。顔の見分け、自転車、症例や標本の見分けの芯は、教える側も言い切れず、学ぶ人が自分で見つけ、言えないまま知る
- 暗黙知には二つの気づき方がある。近い側の手がかりには従属的に（それを頼りに先へ向かう形で）、遠い側の意味には焦点的に気づく。杖の衝撃が杖の先の感じに変わる、言葉の音が透き通って意味が前に出る。従属的な手がかりは、注意を向ければはっきり分かるものでもよい
- 手がかりから意味へ向かう関係は長続きするが、注意を手がかりの側へ引き戻すとひどく損なわれる（言葉を音として繰り返す、ピアノで指を見る）。ただし意味は粘り強く、中に入り込むことと外から眺めることを交互にすると意味を育てうる、とも書いている
- 言葉や式にした知（明示的な知）は、暗黙のうちに理解され当てはめられることに頼る。すべての知は暗黙か、暗黙の知に根を張る。教本の中身は運転の中に沈んで働き続ける（中に住まう）
- 「言えない」をどこまで強く読むかは割れている。ガスコインとソーントン（2013年）は、場面から切り離した規則には書き下せないが、その場で示しながらなら言い表せる、と論じた
- 講義の整理として、前回の媒介評価プロトコルは、観点を切り離して付ける段（外から眺める段）と最後の全体の判断（中に入る段）を交互に置いた手順とも読める

## 概念表

| 概念 | 一言で |
|---|---|
| 暗黙知 | 語れる以上のことを知っていること。言えないまま見つけ、持てる知 |
| 従属的な気づき | それを頼りに別のものへ向かっているあいだの、手がかりへの気づき |
| 焦点的な気づき | 注意が向かっている先、手がかりがまとまった意味への気づき |
| 手がかりに目を移すと意味が崩れる | 注意を意味から手がかりの側へ引き戻すと、手がかりから意味へ向かう関係が損なわれること |
| 明示的な知は暗黙の知に根を張る | 言葉や式にした知も、暗黙のうちに理解され当てはめられて初めて働くこと |
| 中に住まう | 道具や言葉や規則を内側に取り込み、それを通して先へ向かうようになること |

## 開いたままの問い

- 今日の引っかかり。「よい」と見た出力について、何で見分けたのかを言葉にした手がかりの並びから、「よい出力」が分けられない一つのまとまりか、一つの言葉に複数のものが入っているのかを決める手がかりは得られるか（A-05 から。→A-12、A-20）
- 禅の「動きの中では手がかりに止まるな」と、観察の瞑想の「止まって手がかりを見れば、まとまりの作られ方が見える」は、ポランニーの中に入り込むことと外から眺めることの往復の両端と読めるか（応答の側の読みで、著者はまだ答えていない）。熟達者の技能の段階と、注意の向け方の訓練がどう重なるか（→A-13、A-14、Attention Not Self）
- 言えない見分けでも、当たり外れを外から数えれば見分ける力の大きさは測れる（またぐ一問の尤度比9倍）。言えるかどうかと当たるかどうかを別々に見るとき、直観を信頼してよい条件はどこから来るか（→A-15）
- 媒介評価プロトコル（A-10）を、観点を切り離して付ける段（外から眺める）と最後の全体の判断（中に入る）を交互に置いた手順と読む講義の整理は、ポランニーの「手がかりに目を移すと意味が崩れる」とどこまで両立するか（→A-17、A-20）
