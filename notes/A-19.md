# A-19 LLMを評価者として測定論で見る

## 本編の要点

- 位置の偏りは、判定が答えの中身でなく置かれた場所に左右されること。同じ順の繰り返しでは見えず、置き場所を入れ替えて初めて見える。Zheng ほか（2023年）では、入れ替えても同じ判定を保ったのは GPT-4 で65%、Claude-v1 で24%ほど。両方の順で同じほうが勝ったときだけ勝ちとし、食い違えば引き分けにする対処が示された。Shi ほか（2025年）は、出来の差が小さい組ほど偏りが強いと報告した
- 冗長さの偏りは、中身の良し悪しと関係なく長い答えを選びやすいこと。長さは中身と一緒に動きやすいので、中身をそろえたまま言い換えで水増しした組で確かめる。Zheng ほかでは、水増しした答えを良しとしたのは Claude-v1 と GPT-3.5 で9割あまり、GPT-4 で1割に満たなかった
- 判定器の妥当性は、中身を保つ変更で動かないこと（不変）と、中身を変える小さな変更で動くこと（感度）を組で見る。Chen ほか（2026年、未査読）では、不変が95%ほどなのに感度は32%ほどだった。第6回の二つの円で言い直せる（この講義の整理）
- 人の判定との一致は基準関連の証拠で、支えるのは判定器の判定を「人ならこう判定する」という予想として読むことまで。良さと読むには、人の判定が良さを捉えていることが別に要る（第4回の基準の問題）
- 一致の度合いは課題や基準にした人の専門の深さで大きく変わる（Bavaresco ほか、2025年）。人の判定が表面で決まる部分があれば、判定器との一致も表面での一致かもしれない

## 概念表

| 概念 | 一言で |
|---|---|
| 判定器 | 答えの良し悪しを判定する LLM（この講義での呼び方） |
| 位置の偏り | 判定が答えの中身でなく置かれた場所に左右されること。置き場所を入れ替えて確かめる |
| 冗長さの偏り | 中身と関係なく長い答えを選びやすいこと。中身をそろえて長さだけを変えた組で確かめる |
| 不変と感度 | 中身を保つ変更では動かず、中身を変える小さな変更では動くこと。二つを組で見る |
| 人との一致が支えるもの | 人の判定との一致は「人ならこう判定する」という予想を支える。良さは別に確かめる |
| 比をつなぐ（比較判断の法則を目盛りなしで） | 選ばれた割合を「勝ち対負け」の比に直して比どうしを掛け、最後に割合へ戻す。割合のままでは掛けない（A-18 の法則の言い直し。対話） |

## 復習用の問い

1. 判定器に、曲 a と曲 b を聞き比べさせます。一回目は a を先に、二回目は b を先に置いて聞かせたところ、二回とも先に置いたほうの曲を選びました。判定器が選んだ曲は、一回目と二回目で同じでしょうか。1 同じ、2 違う（答え　2。一回目は a、二回目は b。位置の偏り。置き場所に引かれた判定は、入れ替えると選ぶ中身が変わる。11/27 の小問1は「二回とも先に置いた写真」と場所で書き、二回で別の写真を指すことが読み取りにくかった）
2. 判定器に、曲を二つずつ50組聞き比べさせます。どの組も、一回目と二回目で置き場所を入れ替えます。二回とも同じ曲を選んだのが30組、二回とも先に置いたほうを選んだのが18組、二回とも後に置いたほうを選んだのが2組でした。二回で選んだ曲が変わったのは何組でしょうか（答え　20組。先に寄った組も後に寄った組も、二回で違う曲を選んでいる。出すたびに数を変える）
3. 判定器が、散歩の道案内の文を二つ比べて、いつも長いほうを選びます。長さに引かれているかを確かめるのに使える組はどちらでしょうか。1 同じ道順を言い換えて二倍に書き足した文と元の文、2 寄り道の店まで書き足した文と元の文（答え　1。冗長さの偏り。中身をそろえて表面だけを変える）
4. 料理の写真を判定器に採点させます。同じ写真を何度見せても同じ点が返ります。けれども、焦げた一品が写り込んだ写真でも点が変わりません。この判定器に足りないのはどちらでしょうか。1 中身を保つ変更で動かないこと、2 中身を変える変更で動くこと（答え　2。不変と感度の、感度の側）
5. 見方。旅行の写真のコンテストで、判定器の選び方が人の選び方と、人どうしよりよく一致しました。ここから言えるのはどちらでしょうか。1 判定器は写真の良さを人より見分けている、2 判定器は人がどちらを選ぶかをよく当てている（答え　2。人との一致が支えるのは「人ならこう選ぶ」という予想まで。基準の問題）
6. 判定器を人の判定との一致で確かめるとき、確かめないまま正しいことにしているのは何でしょうか。短い一文で（答え　人の判定が良さを捉えていること。基準の問題を判定器に当てはめた形）
