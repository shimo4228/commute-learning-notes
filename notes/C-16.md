# C-16 辞書は記述か規範か

## 本編の要点

- 辞書の記述主義は、人々が言葉を実際にどう使っているかを、用例を集めて写すのが辞書の仕事だとする。トレンチは1857年、言語学協会での発表で、辞書は言葉の目録で、作る人は歴史家であって批評家ではないと述べ、のちのオックスフォード英語辞典のきっかけになった。見坊豪紀（1914〜1992）は『三省堂国語辞典』のために140万枚を超える用例カードを残し、「世間ずれ」の新しい意味（世間とずれている）の実例を6年以上探して1974年の雑誌記事に見つけた
- 写すといっても、すべては写せない。一度しか聞かなかった言い間違いまで書くか、どんな説明を添えるかは、書き留める人が選ぶ
- 辞書の規範主義は、正しい使い方を示し乱れを防ぐのが辞書の仕事だとする。ジョンソンは1747年の計画書で英語を固定することを大きな目的の一つに挙げたが、1755年の序文では、辞書で言葉を腐らせずに保てると思うのは笑われてよいと書き、それでも変化を遅らせるために手を尽くすと書いた。定めることのよしあしには、第14回の但し書き（誰が、どの範囲で、何のために）が付く（この講義の整理）
- 見坊は、辞書はことばを写す「鏡」であり、ことばを正す「鑑」でもあると書き、かがみはまず鏡であることによって鑑になりうるとした。カーザン（2014年の講演）は、辞書を作る人は使われ方を写そうとしながら、人々が使い方を尋ねに来ることも知っている、と述べた
- 「くだけた言い方」のような注意書きも、写す側の選び方として付けられるが、読む人には手本として届く。手本として読まれたものは、また使われ方に戻っていくことがある（使う、選んで写す、手本にして使う、の輪）

## 概念表

| 概念 | 一言で |
|---|---|
| 辞書の記述主義 | 言葉の実際の使われ方を、用例を集めて写すのが辞書の仕事だとする考え |
| 用例 | 言葉が実際に使われた例。写す辞書が新しい意味を書き入れる証拠になる |
| 辞書の規範主義 | 正しい使い方を示し、乱れを防ぐのが辞書の仕事だとする考え |
| 写す側の選び方 | 何を載せ、どんな説明や注意書きを添えるかを、書き留める人が選ぶこと |
| 鏡と鑑 | 使われ方を写す鏡であることによって、読む人が手本にする鑑になりうる、という見坊の見方 |
| 写したものが手本として読まれる | 写すつもりで載せたものが、読む人の側で使ってよいという許しや規準として働くこと |
| 歴史的原理に基づく辞書 | 意味ごとに日付つきの用例を古い順に並べる作り。オックスフォード英語辞典のもとの名前（対話） |
| 版ごとの写し | 版を重ねる辞書の一つ一つの版は、一つの時点の使われ方の写しで、並べると変化の層が見える（対話） |
| 語の説明と使い方の分布 | モデルが述べる語の説明と、その語を文の中で使うときの確率の置き方は別のもので、ずれうる（対話、応答の整理） |
| 見えにくい固定 | 調整の段階で入る「こう答えるのが望ましい」という選び方。どこで誰が定めたかが見えにくい（対話、応答の整理） |
