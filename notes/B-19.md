# B-19 能動的推論

## 本編の要点

- 行動を選ぶときは、そのあとに何が見えるかがまだ分からないので、行動の案 π ごとに、見えそうな観測の予想 q(o|π) で平均した量を使う。それが期待自由エネルギー G で、まだ起きていない観測について F に似た量を前もって見積もるために作られた
- 好みを観測の確率 p(o|C) として書くと、行動ごとに好みの驚きの平均 Σ q(o|π) × log2(1 ÷ p(o|C)) が数えられる。小さいほど得るための行動として良い。猫の世界では、袋を振るが1.5ビット、押し入れをのぞくが2ビット
- 情報利得は、行動の前の居場所の読めなさから、行動のあとに残る読めなさを予想で平均したものを引いた数で、B-13 の相互情報量と同じ手順。のぞくは1ビット、振るは0ビット。フリストンら（2015年）は、知ることの値打ちが隠れた状態と観測の相互情報量に等しいことを示した
- G ＝ 好みの驚きの平均 − 情報利得 で、小さい行動ほど選ばれる。1回目はのぞく（1ビット）が振る（1.5ビット）より小さく、居場所が分かると、のぞくは2ビットになって振るほうが選ばれる。知るための項がどこから来るかは割れている（スミスらの2022年の手引きと、ミリッジらの2021年の論文）
- 好みが平らなら、好みの驚きの平均はどの行動でも同じで、行動を分けるのは情報利得だけになる。知ることが尽きると、G はどの行動にも同じ値を返す

## 概念表

| 概念 | 一言で |
|---|---|
| 行動の案 π | 方針（policy）。π は policy の p にあたるギリシア文字 |
| 予想 q(o\|π) | 行動 π をとったときに、観測 o が何回に1回見えそうか。前回までの推測 q(s) とは別 |
| 好み p(o\|C) | 何を見たいかを観測の確率で書いたもの。見たいものほど大きな確率を置く |
| 好みの驚きの平均 | 好みの驚き log2(1 ÷ p(o\|C)) を予想で平均した数。得るための項 |
| 情報利得 | 行動の前の読めなさ − 行動のあとに残る読めなさの平均。知るための項で、相互情報量と同じ手順 |
| 期待自由エネルギー G | 好みの驚きの平均 − 情報利得。小さい行動ほど選ばれる |
| 平らな好み | どの観測にも同じ確率を置く好み。行動を分けるのは情報利得だけになる |
| 好みの鋭さ | 見たいものと見たくないものの確率の差が大きいこと。効果の薄い行動でも好みの驚きの平均の差が大きく開き、情報利得を押しのける（講義のあとの対話。執着と重ねるのは講義の読み） |
| KL と相互情報量の関係 | KL は左と右に何を置くかを決めていない式。相互情報量は、左に組の本当の出方、右に同じ記録から作った掛け算の出方（色の割合 × 言葉の割合）を置いた KL に付けた名前。ふつうの KL では右の q は外から来る（復習モードの対話） |
| 相互情報量の型 | X は知りたいが直接は見えないもの、Y は見える手がかり。Y を見ると X の見当がどれだけつくようになるか（復習モードの対話） |
| 代わりの分布 q の実際の姿 | 事後分布を出すのが重すぎるときに持つ、扱いやすい形に限った仮の見立て。その形の中で F をいちばん小さくするものを探す（復習モードの対話） |

## 復習用の問い

1. 計算。好みの驚きは、猫がひざに来れば1ビット、何もなければ2ビットです。袋を振ると、猫が4回に1回ひざに来て、来なければ何もないとします。袋を振ったときの好みの驚きの平均は何ビットでしょうか。答え　1.75ビット（4分の1 × 1 ＋ 4分の3 × 2）。重みを付けずに平均すると1.5
2. 計算。猫は押し入れかベランダにいて、推測は半々で、居場所の読めなさは1ビットです。押し入れの電気は2回に1回切れています。ついているときにのぞけば居場所が決まり、切れているときは暗くて何も分かりません。押し入れをのぞく行動の、猫の居場所についての情報利得は何ビットでしょうか。答え　0.5ビット（残る読めなさは、ついているとき0、暗いとき1ビット。平均は2分の1 × 0 ＋ 2分の1 × 1 で0.5。1 − 0.5）。11/28 の小問2は観測を三通り（姿、空、暗い）で書き、まとめ方を示されるまで手が付かなかったので、ついているか切れているかの二通りで書く
3. 計算。袋を振る行動は、好みの驚きの平均が1.5ビット、情報利得が0ビットです。押し入れをのぞく行動は、好みの驚きの平均が2ビット、情報利得が0.25ビットです。G が小さいほうの行動を選ぶとき、選ばれるのはどちらでしょうか。1 袋を振る、2 押し入れをのぞく。答え　1（振る1.5、のぞく1.75）
4. 見方（名前の形）。期待自由エネルギー G は、何から何を引いた数でしょうか。答え　好みの驚きの平均から、情報利得を引いた数
5. 見方。何が見えても同じくらいでよいという平らな好みの飼い主が、猫の居場所をまだ知りません。行動どうしの G の差を生むのはどちらでしょうか。1 好みの驚きの平均、2 情報利得。答え　2（好みの驚きの平均はどの行動でも同じ数）
6. 見方（11/28 の復習モードの対話から）。相互情報量を KL として読むとき、左には色と言葉の組の本当の出方を置きます。右に置くのは何の出方でしょうか。短い一文で。答え　色の割合と言葉の割合を掛けた出方（色によって言い方が変わらないとしたときの組の出方。同じ記録から作る）
