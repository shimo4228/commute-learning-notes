# B-06 正規分布と中心極限定理

## 本編の要点

- 正規分布は左右対称で山が一つの連続分布で、平均（山の位置）と標準偏差（山の幅）の二つで形が決まる。山の線は密度で、範囲の下の面積が確率。平均から標準偏差一つぶんにおよそ68%、二つぶんに95%、三つぶんに99.7%が入る（きゅうり、平均20センチ、標準偏差2センチ）。ちょうど正規分布に従う量はまずなく、よくできた近似の形
- 中心極限定理は、独立な量をたくさん足し合わせると、もとの一つ一つの分布の形によらず、合計や平均の分布が正規分布に近づくこと。硬貨のすごろく（表2マス、裏0マス）で、1回は山のない二本の棒、4回で 1、4、6、4、1 と山が現れる。真ん中の合計にたどり着く出方の組み合わせが多いから。ド・モアブル（1733年）が硬貨の表の回数で見つけ、ラプラス（1810年）が独立な誤差の和へ広げた
- 釣鐘型があちこちに現れる理由の一つの説明は、ハーゲンの、観測の誤差は小さな独立な誤差の合計だという仮説。どこまで通用するかは割れていて、19世紀の終わりには生物や社会のデータに非対称な分布が多く見つかった。足し合わせとして読める量かは量ごとに確かめる
- 独立なものを n 個平均すると、平均の標準偏差（標準誤差）は1個のときの √n 分の1になる。散らばりを半分にするには4倍の数が要る。ずれが全部は打ち消し合わないから。すべての回に共通するずれ（塩のついたスプーン、目盛りのずれた巻尺）は打ち消す相手がなく、何回平均しても残る。独立が中心極限定理の条件の一つ目
- 条件の二つ目は分散が有限であること。裾の重い分布（ワープのあるすごろく）では、一回の桁違いの出来事が平均全体を決め、回数を増やしてもさらに大きな一回が出て平均が跳ぶ。コーシー分布は何個平均しても散らばりが1個のときと変わらない。B-01 の果ての国で中心極限定理が使えないのはこの崩れ方

## 概念表

| 概念 | 一言の説明 |
|---|---|
| 正規分布 | 左右対称で山が一つの連続分布。平均と標準偏差で形が決まる |
| 68%と95%の目安 | 平均から標準偏差一つぶんにおよそ68%、二つぶんに95%が入る |
| 中心極限定理 | 独立な量をたくさん足すと、もとの形によらず合計や平均が正規分布に近づく |
| 組み合わせの数 | n 個から k 個を選ぶ選び方の数。4C2＝6。パスカルの三角形の隣どうしを足しても出る |
| 標準誤差 | n 個の平均の標準偏差。1個のときの √n 分の1 |
| 共通のずれ | すべての回に同じ向きに乗るずれ。平均しても縮まない |
| 裾の重い分布 | 桁違いの値が無視できない頻度で出る分布。分散や平均が定まらず、中心極限定理が使えないことがある |
| 裾の減り方 | 軽い裾は大きさが少し増えるだけで急に珍しくなり、重い裾は大きさが10倍になってようやく10倍珍しくなる |
| コーシー分布 | 何個平均しても平均の散らばりが1個のときと変わらない分布 |
| 標準偏差を物差しにする | 正規分布の目安は標準偏差いくつぶんで書かれ、山ごとの標準偏差を一目盛りとして読み替える |
| 範囲の重なり | 左端は二つの左端の大きい方、右端は二つの右端の小さい方。長さは右端から左端を引く |
