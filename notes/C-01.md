# C-01 概念工学とは何か

## 本編の要点

- 概念工学は、概念や言葉の意味を記述するだけでなく、評価し、欠陥があれば改良する営み。カペレン『Fixing Language』（2018）が主題として一冊にまとめた
- バージェスとプランケット（2013）は、どの概念を使うべきかという規範的な問いを「概念の倫理」と呼んだ。「倫理」は道徳に限らず、認識上や実用上の「べき」を含む
- 概念の欠陥には、曖昧さ、内部の矛盾、説明に役立たない、人を見えなくしたり傷つけたりする、といった型がある（大盛り、無償労働、ペットロスの例）
- プランケットとサンデルのメタ言語的交渉。事実では一致したまま、言葉の使い方を実演によって持ちかけ合う争い（eスポーツ、ラドローの競走馬の例）。言葉の争いでも、制度や敬意が結びつくので交渉する価値がある
- 直せるのかという問いが残る。話題の連続性（→C-07）、実装の制御の欠如（カペレンは見通せずほぼ手の内にないとしつつ試みは続けるべきとする、→C-08）、何を直しているのか（頭の中の概念か、言葉の公共の意味か）でも説が割れている

## 対話で出た論点

- 大乗の立場からは、概念を立てて良し悪しを論じ作り直す概念工学は戯論としてすぐに退けられる。だからこそ重要だ、というのが著者の受け止め
- 二諦から見ると、言説によらなければ勝義は説けない（『中論』第24章）。言説を捨てられない以上、どの言説を使うかを選ぶ問いは残る。概念工学を勝義の主張としてでなく、言説の中でどの仮設がよりよく働くかを問う営みと読めば、中観とぶつからないかもしれない。空性を因って施設されたものと言い直すくだりは、言葉が依存して立てられたものという概念工学の前提に近い
- 仏教自体が概念を設計してきた伝統でもある。アビダルマの法の一覧、唯識の阿頼耶識は、目的のために設計された概念と見られる。聞き手に合わせてどの概念を差し出すかを選ぶ方便は、そのまま概念の倫理の問い
- アッタカヴァッガは争いの根を見解をつかむことに置く。メタ言語的交渉で言い張るときにつかんでいるのは、事実よりも自分の使い方のほう。概念工学は使い方を意識に上らせて争いの構造を見えやすくするが、執着を減らすのか、「正しい概念」への新しい執着を生むのかは両方ありうる
- AIをめぐる「理解」「エージェント」「意図」は、誰かが意図して作り直さなければ声の大きい使い方が既定値になる。戯論と知りつつ定義語を作るのは、既定値に任せきりにしないための言説の側の手当てと見られる
- B-01 の「定義できない」とのつながり。定義できない感覚は勝義の側の手触りで、定義語の公開は言説の側の仕事、と分ける見方を出した。著者の実感に合うかは未確認
- 2026-11-03 の B-03 の復習で著者が欠陥の型を忘れていたので、型ごとに詳しく説明し直した。曖昧すぎる（大盛り。直し方は精密化で C-02 の厳密性。ただし「塩少々」のように曖昧さが判断を預ける役をすることもある）。内部の矛盾（嘘つきのパラドックス。シャープ『Replacing Truth』2013 は真理を不整合な概念とみて二つの概念への置き換えを提案、賛否あり。直し方は置き換えや分割）。説明の役に立たない（日常の「虫」、C-02 の鯨。実り豊かさの不足で、直し方は分け直し、→C-12）。見えなくする・傷つける（無償労働は意味の拡張で直した例。フリッカー『Epistemic Injustice』2007 の解釈的不正義は、共有の言葉が欠けて本人も経験を理解しにくい状態で、ペットロスはその穏やかな形。直し方は新語。蔑みを運ぶ語もこの型）
- 型ごとに直し方が違い、同じ概念でも目的によって十分にも欠陥にもなる。欠陥は概念と目的の組み合わせに現れる

## 概念表

| 概念 | 一言で |
|---|---|
| 概念工学 | 概念や言葉の意味を評価し、改良する営み |
| 概念の倫理 | どの概念を使うべきかという規範的な問いの総称 |
| 概念分析 | すでにある概念を正確に書き出す伝統的な方法 |
| 解明（カルナップ） | 曖昧な日常の概念を精密な概念に置き換える手続き |
| 概念の欠陥 | 曖昧、矛盾、説明に役立たない、人を見えなくする、などの不具合 |
| メタ言語的交渉 | 事実では一致したまま、言葉の使い方を争うこと |
| 話題の連続性 | 意味を変えても同じ話をしていると言えるかという問題 |
| 実装の問題 | 改良した意味を共同体にどう広めるか、そもそも制御できるか |
| 戯論 | 分別が分別を生んで広がる概念の働き。中観では寂まるべきもの |
| 言説の仮設 | 依存して立てられた名。二諦の言説の側で働く言葉 |
| 方便としての概念設計 | 聞き手と目的に合わせてどの概念を差し出すかを選ぶこと |
| 不整合な概念 | 構成する決まりの組そのものが矛盾を生む概念（シャープは真理をその例とした） |
| 解釈的不正義 | 共有の言葉が欠けて、自分の経験を言い表せず理解しにくい状態（フリッカー） |

## 復習用の問い

1. 概念工学は、伝統的な概念分析と何の向きが違うか
2. 「概念の倫理」の「倫理」が道徳に限らないとは、どういうことか
3. メタ言語的交渉を、今日とは別の日常の例で示せるか。そこには何が賭けられているか
4. 概念の欠陥の型を三つ挙げ、それぞれ身近な例を言えるか
5. 二諦から見て、概念工学が中観とぶつからない読み方はどういうものか
6. 方便が「概念の倫理」の問いでもあるとは、どういうことか

## 開いたままの問い

- 定義できない感覚を勝義の側の手触り、定義語の公開を言説の側の仕事と分ける見方は、著者の実感に合っているか（→C-19 自分の概念を点検する演習）
- 概念工学は執着を減らすのか、「正しい概念」への新しい執着を生むのか。見解をつかまずに概念を設計することはできるか（→C-14 概念の倫理、C-20 統合回）
- 方便としての概念設計は、聞き手ごとに概念を変えることを許す。それは話題の連続性の問題とどう折り合うか（→C-07 話題の連続性）
- AIの用語が声の大きい使い方で既定値になっていくとき、個人の研究者の定義語はどこまで既定値に抗えるか（→C-08 実装の問題、C-17 AIが概念を割る、C-18 用語を作る技術）
