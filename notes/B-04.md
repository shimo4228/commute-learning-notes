# B-04 基準率の無視

## 本編の要点

- 基準率は集まりの中のもともとの割合で、事前確率に当たる。有病率1%、陽性になる割合が病気で9割、病気でなくて1割の検査なら、陽性のうち本当に病気なのは1000人中 9÷108 でおよそ0.08（事前オッズ1対99 × 尤度比9 = 1対11）。外れの陽性が多いのは、病気でない人の数が圧倒的に多いから
- キャッセルズら（1978）はハーバード大学医学部の教育病院で60人に、有病率1000人に1人、偽陽性5%の検査の陽性の意味を尋ねた。正答（約2%）は11人、もっとも多い答えは95%（27人）
- 基準率の無視は、事前オッズを黙って1対1に置いて尤度だけで事後を決めること。P(陽性|病気) と P(病気|陽性) の取り違えで、B-02 の条件の逆転と同じ根
- カーネマンとトヴェルスキーの技術者と弁護士の問題。基準率30%と70%で答えがほとんど変わらない。紹介文なしなら基準率どおりに答え、役に立たない紹介文（尤度比1）を見せると0.5前後に寄る。タクシーの問題（緑85%、目撃の正しさ80%、正答約0.41、典型的な答え0.8）では、基準率を原因の話として示すと使われやすくなる（トヴェルスキーとカーネマン 1980）が、追試では差が出ないこともある
- 評価は割れている。ギーゲレンツァーらは自然頻度で示せば正答が大きく増えるとし（1995、婦人科医160人の2007年の報告）、ケーラー（1996）は無視は言われるほど一貫せず、実際の場面ではどの基準率を使うべきか自体があいまいだと論じた（B-01 の参照クラスの問題）
- 較正された判定器の数字には較正した集まりの基準率が入っている。当たりの少ない集まりへ移すと、同じ合図でも当たりの見込みはずっと下がる

## 概念表

| 概念 | 一言で |
|---|---|
| 基準率 | 集まりの中のもともとの割合。事前確率に当たる |
| 基準率の無視 | 基準率を見落とし、証拠の当たり具合だけで事後を決めてしまう傾向 |
| 偽陽性 | 病気でないのに陽性と出ること。数の多い側の小さな割合が、陽性の多くを占めうる |
| 事前を1対1に置く誤り | 基準率の無視をオッズで言い直したもの |
| 役に立たない証拠の効果 | 尤度比1の手がかりを見せられると、正しく使えていた基準率まで消えること |
| 原因としての基準率 | 割合が原因の話として読めると、その一件の情報として使われやすくなること |
| 自然頻度での示し方 | 人数で書くと、数の多い側の外れが目に入り、無視が減る |
| 基準率の選び方の問題 | 実際の場面では、どの集まりの割合を事前に置くべきかが判断になること |
| 証拠を重ねることと読み方を確かめること | 同じ証拠を何度見ても尤度比の違いは残る。証拠のあとの結果を確かめると尤度比がそろう |
| 本当のゼロ | その量がまったくないことを指すゼロ。あれば比率尺度、なければ間隔尺度どまり |
| A系列とB系列 | 今を基準に付け替わる過去・現在・未来と、動かない前後の関係（マクタガート 1908） |
| 時間の尺度の水準 | 西暦の日付は間隔、経過時間は比率、B系列は順序の構造 |
| 独立の二つの使い方 | 証拠と仮説の独立（尤度比1で動かない）と、証拠どうしの独立（尤度比を掛け直せる） |
| 尤度と事後の一致 | P(陽性|病気) と P(病気|陽性) が一致するのは事前が1対1のときだけ |
| 三つの割合の分母 | 基準率は全体、尤度は仮説の側、事後は手がかりの出た側を分母にとる |
| 珍しいものの原則 | 珍しいものを見たと思ったら、まず似たふつうのものを疑う。独立な証拠が重なれば越えられる |
