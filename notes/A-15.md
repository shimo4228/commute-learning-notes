# A-15 直観はいつ信頼できるか

## 本編の要点

- カーネマンとクラインは2004年に話し合いを始め、2009年に共同論文「Conditions for Intuitive Expertise. A Failure to Disagree」を出した。副題はカーネマンが推し、クラインはのちに、実際にはしょっちゅう割れていたので少し誤解を招くと書いた（2024年）。熟練者の直観をいつ当てにしてよいかでは、二人とも条件しだいに着いた。前回の出来ばえの主張に、その経験がどんな場で積まれたものなら、という条件を足したもの、と読める（この講義の読み）
- 一つ目の条件は、外から特定できる手がかりと、その後に起きることや打ち手の結果とのあいだに安定したつながりがある場であること（論文の high-validity。この講義では規則性の高い場と呼ぶ）。手がかりは本人が言えなくても原理の上で特定できればよい。つながりは確率的でもよく（ポーカー）、規則性の無い場でもたまたま続けて当たる人は出て、腕があると思い込みやすい
- 二つ目の条件は、長い練習と、速くて紛れのない手応え。手応えは外から返る当たり外れの知らせで、自分の「うまくいった」という感じは含めない。手応えが遅く、まばらで、あいまいな場では、年数が増えても腕は育ちにくい
- 本人には直観の出どころを見分ける内側の印が無い。技能から来た直観も近道から来た直観も同じ手触りで浮かび（バットとボール）、自信の強さは情報の質より辻褄で決まりやすい。だから確かさは、場の規則性と学ぶ機会という外から確かめられる二つで見積もる
- 同じ人や同じ専門の中でも、熟練した課題とそうでない課題が入り混じる（fractionated expertise。この講義ではまだらな熟練と訳す）。確かな課題で育った自信が隣の課題に持ち越されるのが困りどころ。クラインは変だと気づく力に、カーネマンは別の目的への持ち越しに目を向け、論文はどちらも退けず、課題が違えば規則も違う、とまとめた

## 概念表

| 概念 | 一言で |
|---|---|
| 規則性の高い場 | 外から特定できる手がかりと結果のあいだに、確率的でも安定したつながりがある場（論文の high-validity、この講義の訳） |
| 学ぶ機会と手応え | 長い練習と、外から速く紛れなく返る当たり外れの知らせ。直観の腕が育つ二つ目の条件 |
| 手応え | 外から返る当たり外れの知らせ（feedback）。自分の「うまくいった」という感じは含めない |
| 内側の印が無い | 技能から来た直観も近道から来た直観も、同じ手触りで浮かぶこと |
| 自信と辻褄 | 自信の強さは、情報の質より情報どうしの辻褄で決まりやすい。重なった薄い根拠でも自信は強くなる |
| 外から見積もる | 直観の確かさを、本人の感じでなく、場の規則性と学ぶ機会の二つで調べること |
| まだらな熟練 | 同じ人の中で、熟練した課題とそうでない課題が入り混じること（fractionated expertise、この講義の訳） |
| たまたまの連勝 | 規則性の無い場でも続けて当たる人は出て、腕があると思い込み自信を持ちすぎやすい |
| 妥当性の錯覚 | 当たりの記録が見立てとほとんど結びつかないと知っても、強い確信が減らないこと（カーネマンの名づけ。本文から外し、対話で紹介） |
| 意地の悪い学びの場 | 手応えが遅い、偏っている、見立てそのものが当たりを作ってしまう場（ホガース。第2節の裏側として対話で紹介） |

## 復習用の問い

1. 二つの趣味があります。一つは将棋で、指した手と勝ち負けのつながりは、運に左右されても長い目で見れば安定しています。もう一つはおみくじで、引いた時刻と出る吉凶は結びついていません。手がかりと結果のあいだに安定したつながりがあるのはどちらでしょうか。1 将棋、2 おみくじ。答え　1（規則性の高い場）
2. 二人が毎日カレーを作っています。一人は作るたびに家族の食べ残しの量を確かめ、どの皿が残ったかを見ます。もう一人は「今日もおいしくできた」という自分の感じだけで終えます。何年かのちに、家族の好みに合う味つけを見分ける舌が育ちやすいのはどちらでしょうか。1 食べ残しを確かめる人、2 自分の感じだけで終える人。答え　1（手応えは外から返る知らせ）
3. 年に一度の家族旅行の行き先を、十五年選んできた人がいます。よかったかは旅から帰って分かります。この人の行き先選びに、これまで返ってきた当たり外れの知らせは何回でしょうか。数で答えてください。答え　15（年数より、返ってきた知らせの数と質）
4. 公園の売店で、パンとジュースが合わせて300円です。パンはジュースより200円高い。ジュースはいくらでしょうか。数で答えてください。答え　50円（すぐ浮かぶのは100円で、それならパンは300円、合わせて400円になる。技能から来た直観と同じ手触りで浮かぶ）
5. 毎日パンを焼く人は、焼き色の見立てがいつも確かです。年に一度しか作らない誕生日のケーキで、この人が「このスポンジは中まで焼けている」と自信たっぷりに言いました。この言葉について言えるのはどちらでしょうか。1 パンの焼き色の見立てと同じくらい当てになる、2 パンの焼き色の見立てほどは当てにならない。答え　2（まだらな熟練）
6. 二人の友人が、別々の登山道を勧めてくれました。一人は自信たっぷりに、もう一人は控えめに言いました。どちらの勧めを当てにするかを決めるのに、よいやり方はどちらでしょうか。1 二人の自信の強さを比べる、2 それぞれが、その山で道の当たり外れが返ってくる経験をどれだけ積んできたかを見る。答え　2（外から見積もる）
