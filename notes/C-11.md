# C-11 本質的に論争的な概念

## 本編の要点

- ギャリー（1956年「本質的に論争的な概念」）は、正しい使い方が、使う人たちのあいだでの正しい使い方をめぐる終わりのない争いを避けがたく含む概念を、本質的に論争的な概念と呼んだ。言葉の争い（C-10 のリス）と違い、意味の違いが見えたあとも、どの側も自分の側の働きこそ正しいと言い続ける
- 五つの条件。ほめる語であること、達成の内側が込み入っていて価値は全体に付くこと、部分の重みづけでいくつもの描き方が成り立つこと、状況で形が変わる開いたものであること、どの側も互いの基準を知ったうえで自分の使い方を守ること（攻めにも守りにも使う）。例は作り物の大会（点数も審判もなく、試合は終わらない）。生きた例は芸術、民主主義、社会正義、宗教に従って生きること
- 二つの別の概念を一つの紛らわしい語が覆っているだけの混乱と分けるために、ギャリーは二つの条件を足した。争うすべての側が権威を認めるもとの手本から来ていること、側どうしの競い合いが手本の達成を保ち育てているともっともらしく言えること。擁護は極めて条件つきで、手本の条件はのちの議論で強く疑われた
- 自分に相手がいると知ること（低い段）と、争いがその営みの本質に属すると認めること（一段上の認識）は違う。一段上の認識は、退けている使い方を自分の使い方への終わらない批判の材料と認めることを含み、論拠の質が上がると期待できる
- 暗い側として、説得の望みが消えると相手を締め出したい気持ちに置き換わるかもしれない。ギャリーはこれを論理的な帰結でなく起こりうる成り行きとした。強い形の論争性は相対主義に行き着くという批判もあり、評価は割れている

## 概念表

| 概念 | 一言で |
|---|---|
| 本質的に論争的な概念 | 正しい使い方が、その使い方をめぐる終わりのない争いを避けがたく含む概念 |
| ほめる語 | 価値ある達成をほめる語。ギャリーの一つ目の条件 |
| いくつもの描き方 | 込み入った達成の部分のどれを重く見るかで、描き方が分かれること |
| 開いた概念 | 状況が変わるとよいとされる形も変わり、その変わり方を前もって決められないこと |
| 攻めにも守りにも使う | どの側も自分の使い方が争われていると知り、相手の基準をいくらか分かったうえで自分の使い方を守ること |
| 手本 | 争うすべての側が権威を認め、それぞれがまねて自分なりに変えてきたもとの達成 |
| 競い合いが手本を生かす | 側どうしの絶え間ない競い合いが、手本の達成を保ち育てているともっともらしく言えること |
| 一段上の認識 | 争いがその営みの本質に属すると認め、相手の使い方を自分の使い方への批判の材料として扱うこと |
| 暗い側 | 説得の望みが消えたあと、相手を締め出したい気持ちに置き換わる成り行き |
