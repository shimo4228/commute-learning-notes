# A-05 メシックの統一的妥当性論

## 本編の要点

- メシック（1989）は妥当性を、点数にもとづく推論と行動の適切さを証拠と理論がどれだけ支えるかについての総合的な評価的判断とした。妥当性の持ち主は道具でなく点の解釈と使い方で、二択でなく程度。同じ歩数でも、体を動かした量と読むか散歩の楽しさと読むかで当たり具合が変わる
- 三つの入口は三種類の妥当性でなく、一つの構成概念妥当性を支える違う種類の証拠になる。ギオンの批判した「一つの証拠で済ませる」扱いが成り立たなくなる。この見方は測定の標準的な指針に取り入れられ主流になった
- 解釈を危うくする二つのずれ。構成概念の過少代表（狭すぎて大事な面を取りこぼす）と構成概念に無関係な分散（余計なものが混ざって点数が動く）。どちらもなくせず小さくするのが目標（ピアノの審査の例）。A-04 の内容の欠けと方法の分散に対応。1995年に証拠を六つの側面に整理
- 結果的妥当性。点数の解釈と使用がもたらす意図した結果と意図しない結果も妥当性の材料にする。ただし悪い結果が妥当性の問題になるのは、過少代表や無関係な分散にさかのぼれるとき（速さだけ見る進級試験で表情の練習が痩せる例）。言語試験の波及効果。A-03 の課税評価の話は結果的妥当性を信頼性の側から言い直した形
- どこまでを妥当性と呼ぶかは割れている。ポパム（1997）は結果への関心は正しいが妥当性に入れるのは誤りとし、ボースブームら（2004）は性質が存在しその違いが結果の違いを生むときに妥当という狭い定義で道具の性質に戻した。ケイン（2013）は解釈と使い方の主張を書き出して一つずつ確かめる論証の手順を示した。この争いは「妥当性」という言葉をめぐるメタ言語的交渉（C-01）の一例

## 対話で出た論点

- 著者の受け止め。三つの講義を並行していて、それぞれに妥当性のような概念があるので混ざる。地図を出した。テーマAの信頼性と妥当性は測ったものの問い（揺れないか、当たっているか）、テーマCのカルナップの四条件は概念の作り直しの問い（うまく作り直せたか）、テーマBの尤度や事前は証拠の読み方の道具（どれだけ動かすか）。C-04 の直観の問いは、Aの物差しを哲学者の直観に当てたもの
- 復習の1（A-04 の三つの入口）への著者の答えは、カルナップの四条件（厳密性、類似性、実り豊かさ、単純性）。問いとはずれたが、四条件の名前は四つとも正解で、同じ日の総復習で抜けた類似性と実り豊かさが出た。三つの入口は思い出せなかった（内容的、基準関連、構成概念。三つ目は法則論的ネットワークの予想が指標で当たるか）
- 復習の2（C-03 のザグゼブスキー）は著者が忘れていた。不運で理由と真の筋を切り幸運で真を戻す二段の手順を、止まった時計で示した。真を保証する条件を足すと真の条件と一つになる
- 著者の頼みで、復習の2問を形を変えて出し直した。練習1（散歩の楽しさスコアを三つの入口で確かめる）の著者の答えで、三つの名前はすべて正解。内容的妥当性は「楽しさという観点が散歩に妥当か（玄妙さとの比較）」としたがずれていて、構成概念の選び方に近い。内容的妥当性はスコアの材料が楽しさの全体を偏りなく拾っているか（歩数と速さだけなら景色、発見、会話が抜ける。過少代表を中身の側から見る）と直した。構成概念妥当性は散歩の時間とは関係し、厨房に怒鳴り込むこととは関係しないという予想の網で、形は正解。関係しないはずの側は紛らわしい相手（歩数との揃いすぎ）ほど確かめの力が強いと補った。基準関連妥当性は散歩の継続で正解（予測的）。玄妙さのスコアが怒鳴り込みを予測するなら、それとしては妥当でも散歩の楽しさとしては妥当でないという指摘は、メシックの解釈に付く妥当性を言い当てている。基準の問題（継続が楽しさの答えか）も補った
- 練習2として、録音の声と、偶然隣の部屋にいた友人の例で、ザグゼブスキーの不運と幸運の位置と、因果の条件を足しても反例がなくならない理由を尋ねた
- 練習2の著者の答え。不運は録音がたまたま流れたこと、幸運は友人が偶然黙って本を読んでいたことで正解。因果の条件については「真であるという条件を足すのと同義になりトートロジーになる」。こちらの問いが不正確だった（因果の条件は事実がなければ原因になれないので真を含み、不運と幸運の手順はそのまま使えない）と認め、著者の答えはザグゼブスキーの論法のもう一方の側（真を保証する条件を足すと二つが一つになる）を捉えていると講評。トートロジーまではいかず、真の条件が余分になり重さが因果の条件に乗る、と直した。その因果の条件も張りぼての納屋（本物の納屋から因果的に生じた信念でも、環境に運が入る）で反例を受けた
- 著者の頼みで、真を保証する条件を足すと一つになり、しかも環境の運にさらされる、という流れを細かく説明した。(1) 四つ目の条件Xが真を保証しないなら不運と幸運の手順で反例、保証するなら真はXに吸収され余分になり、知識＝信念＋X で「Xとは何か」がそのまま残る（当選が保証されたくじの例え）。(2) 因果の条件を張りぼての納屋で一歩ずつ追った。本物の納屋→光→目→信念は切れておらず条件を満たすが、首の向きが少し違えば張りぼてから同じ像と同じ信念ができて偽になる。止まった時計や録音は実際の流れの中が切れ、納屋は流れが完全につながっていて運は起きなかった可能性の側にある（環境の運）。因果の条件は実際の流れしか点検しないので素通りする。(3) その後の安全性の条件（少し違っていたら偽なら知識でない）にも反例があり議論は続く。確認として、止まった時計の信念は3時という事実から因果的に生じたかを尋ねた
- 著者の問い。ゲティアの議論にベイズを導入するとどうなるか（確認の問いの前に）
- 応答（見立てを含む）。(1) ベイズだけではゲティアは見えない。動く時計と止まった時計で本人の手元は同じなので事後確率も同じ。ベイズの合理性は手元の材料で決まる内在主義。(2) 尤度比を本人が思っている値と世界での実際の値に分ける。止まった時計は P(3時を指す|3時)=P(3時を指す|3時でない)=1 で実際の尤度比1、見分ける力のない証拠（日の出、ラッセルの鶏と同じ）。張りぼての村では P(納屋に見える|納屋でない) が大きく尤度比が1に近づき、同じ見分け方でも環境で実際の尤度比が変わる。これが環境の運の正体と読め、B-03 の判定器を別の集まりに移す話と同じ。(3) 知識は実際の尤度比も大きく、ゲティアは本人の尤度比は大きいが実際は1に近いのにたまたま当たった場合。「おかげで」のつながりの言い換え。ノージック（1981）の感受性（Pが偽なら信じなかった）は尤度比の分母が小さいこと。本人の尤度比は内在主義の正当化、実際の尤度比は外在主義の信頼性にほぼ対応。(4) 解けはしない。実際の尤度比をどの範囲で数えるか（村か県か）で判定が変わり、信頼性主義の一般性の問題、B-03 の参照クラスの問題として残る。ウィリアムソン（2000）の証拠は知っていることという主張は、ベイズとゲティアの関係を逆から組み直した立場。C-03 の理由のずれた当たりの分類器は二つの尤度比がずれた状態で、当たりだけを見る評価では見えない
- 著者の問い。つまりベイズは正当化の説明メカニズムを与えるだけで、問題の構造には寄与しないのか
- 応答。そのまま入れただけならそのとおりで、内在主義の正当化の精密な書き直しにすぎない。ただ尤度比を本人と実際に分けると、治さないが場所を指す寄与が二つある。(1) 理由の筋の中の運（止まった時計）と環境の運（納屋）が、本人の見積もりと実際の見分ける力のずれという一つの形にまとまる。(2) 残る問題が知識の定義から参照クラスの選び方に移り、何を争えばよいかがはっきりする。さらにクレイグにつなぐと、実際の尤度比は見えないので、知識という概念は「この人の証拠は実際の尤度比も大きい」という見えないものに付ける印と読める。ベイズはゲティアを解かないが、知識という概念が何を印づけるためにあるかを書き出す道具になる（一つの読み方）
- 著者の受け止め。「知っている」が非常にあやふやな概念に見えてきた。複合概念すぎるのではないか。真だけでも死ぬほど議論できるのに
- 応答。三つの応じ方。(1) 部品もそれぞれ底なし（真は対応説、整合説、収縮説、シャープの不整合な概念。信念、正当化も割れている）。(2) 複合に見えるのは分け方のせいかもしれない。ウィリアムソン（2000）の知識は分解できないという立場では、信念は知識になりそこねたかもしれない状態として知識から説明される。判断はふだん苦もなく下せて文化をまたいでもおおむね揃う（マシェリーら）ので、難しいのは使うことより部品に分けて定義すること。C-03 の「論理式では組めない、LLM的」と同じ描写。(3) 一語に複数の概念（C-12）。日本語の「知っている」は事実、やり方、面識を含み、ライル（1949）の knowing that と knowing how。ゲティアは一つ目だけを扱う。やり方の知は A-11、A-13 の主題で、土地評価の熟練者の感覚はこちらに近い。「よい出力」が分解できない一つのまとまりか、一語に複数が入っているかで、ホリスティックな評価の根拠になるか割るべきかが逆を指す
- 著者の問い。ガネーリや LLM のように注意を基盤にしてゲティア問題の説明を組み上げられるか
- 応答（ガネーリの発想を借りた組み立て）。ガネーリ『Attention, Not Self』（2017）第二部は熟達に導かれた注意は知識に十分とし、注意は本性上実在するものに定まるとする。ゲティア事例そのものの扱いは確かめられなかった。(1) 注意が定まった対象と信念を真にしている対象を分けると、止まった時計（針と時刻）、録音の声、陽炎と水、硬貨十枚はすべて両者が別で、真は注意の届かないところから入る。「おかげで」は「注意が定まった当のものが信念を真にしている」と言い直せる。(2) 張りぼての納屋では注意の対象と真にする対象が一致するので注意の条件だけでは知識になってしまう。熟達の部分（奥行きや側面にも向かう注意）が効き、注意の向きが元のゲティアを、注意の見分ける力が納屋（実際の尤度比、一般性の問題）を説明する二部品に分かれる。徳認識論（成功が能力のおかげ）との関係も書評で指摘されている。(3) LLM では正解に効いた手がかりと答えを真にする内容が別の場合がゲティア型の当たり（草原の牛）。アトリビューショングラフは原理的にこれを調べる道具になりうる（→D-14）。トランスフォーマーの注意と人の注意は別物かもしれず、注意の重みが説明になるかはジェインとウォレス（2019）とウィーグリーフとピンター（2019）で割れている。(4) Attention Not Self と同じく、知識でも「誰が知っているか」を「注意がどこに定まり何を見分けているか」に置き換えられそう。前半は自己なしで説明できるが、後半の見分ける力は環境と注意が育った歴史に頼り、熟達がどんな手応えのもとで育つかという C-04 の調律師の問いに戻る
- 止まった時計の確認（信念は3時という事実から因果的に生じたか）は著者が答えずに本文へ進んだので答えを示した。生じていない。針はずっと前に止まり、今が3時であることは針の位置の原因でなく、最初の矢印が切れている。因果の条件で外せるのは時計で、外せないのは流れが最後までつながる納屋
- 本文の節1（統一的妥当性論）と小問1（猫の体重を餌の量と読むか満足と読むか）を出した。練習1の玄妙さの指摘がこの節の考えそのものと添えた
- 小問1（猫の体重を餌の量と読むか満足と読むか）への著者の答え。餌の量とは相関するので妥当性は高い、満足は補助的な妥当性だが食欲の問題とも解釈できるので必ずしも妥当でない、「体重計は妥当」には点数をどう解釈するかの視点がない。三点とも正解。「補助的な妥当性」は、妥当性は種類でなく度合いなので「程度が低い」と整えた。「食欲」は節2の無関係な分散への入口。節2と小問2（料理教室の時間内の一品）を出した
- 小問2（時間内に一品の修了試験）への著者の答え。手間のかからないものでも成立するので過少代表、タイマーが壊れて早く進むなら無関係な分散。一つ目は正解。二つ目は方向は合っていて、壊れ方で置き場が変わると絞った。でたらめに揺れるなら測定誤差（信頼性の側）、全台が同じだけ速ければ手の速さという別の性質が合否を左右して無関係な分散、一部の台だけなら台の運で無関係な分散。メシックが主に念頭に置いたのは毎回同じ向きに点数を動かすもの（道具への慣れ、緊張への強さ、手の速さ）。節3（結果的妥当性）と小問3（歩数の健康ポイント）を出した
- 小問3（歩数の健康ポイント）への著者の答え。歩数を稼ぐため歩幅を短くしピッチを上げるかもしれず、その癖が体に悪影響を与えうる。変化の例は正解。妥当性の問題になるのは、変化が歩数が健康の一部しか拾わない過少代表にさかのぼれるからと補った
- 著者が思い出した例。Meta の社内でトークン数をリーダーボードにしたら、成果をおざなりにトークン消費だけをハックする人が出た。検索で確かめた。2026年4月の報道で、社員が作った「Claudeonomics」がトークン消費で順位づけし、エージェントを何時間も動かしっぱなしにして稼ぐ人が出たと報じられ、数日で取り下げ。6月の報道では CTO のボスワースがトークン消費だけでは成果を測れないという趣旨を書いたとされる（数字は報道で食い違い、公式発表なし）。メシックで読むと、トークン数を「AIをどれだけ役立てたか」と読んで順位づけに使ったことが中心。過少代表（量の一部）と無関係な分散（空回し）で、結果が解釈のずれにさかのぼれる典型。グッドハートの形でもある（→A-06）
- 節4（妥当性をどこまで広げるか）と小問4（登園の体温）を出した
- 小問4（登園の体温）への著者の答え。メシックでは体温を病気の印と読んで使うことの妥当性が問われ、ボースブームでは決まりの作り方の問題。置き場所は正解。ただ両者の力点が分からないとして、極端な譬えを頼まれた
- 極端な例を逆向きに二つ。(1) 完璧な物差しで身長順に晩ごはんを決める。ボースブームらは身長が実在し目盛りを生むので物差しは妥当、困りごとは家の決まり（倫理）。メシックは身長→晩ごはんの読みと使いを支える証拠がなく使い方の妥当性はゼロ。(2) 何も測らない運気メーター（でたらめな数）を、でたらめと承知でおやつのくじに使う。ボースブームらは運気が実在しないので測定として妥当でない。メシックは「公平なくじ」と読んで使っているので妥当。判定が逆になる。力点は、ボースブームらが性質→目盛りの因果の矢印だけを見て目盛りのあとを測定の外に出す（科学が実験で確かめられる問いに絞る）、メシックが目盛り→解釈→使い方の連なりを見て使う人の責任まで入れる。包丁がよく切れるかと、この包丁でこう切るのが適切か。利点は、ボースブームらは何を確かめればよいかがはっきりし道具と決まりを分けて直せ言葉の膨張を防ぐ、メシックは道具が正確だったと逃げられない（Meta のトークン数はトークンの測定としては妥当でも、役立て度と読んで順位づけた問題が測定論の視野に入る）
- 今日の引っかかり（ベンチマークへの違和感をメシックで言い直すと解釈と使い方の側か、ケインの主張の書き出しはルーブリックとどこが似てどこが違うか）と参考文献を出して講義を終えた。全4節を消化
- 著者の頼みで、今日の論点（C-04 と A-05）を本編と対話の要の概念に分けて表にまとめて見せた
- 著者の問い。物事を勉強して再利用可能にするのは、結局はその論が提示する術語概念をきっちり理解して自分も当てはめられるようになることではないか
- 応答。大筋で同意し、Meta の件を自分で過少代表と無関係な分散で読めたことを支えに挙げた（スケンプの関係的な理解）。補いを三つ。(1) 理解と当てはめのあいだに境目の見分けがあり、入る例、入らない例、紛らわしい例で育つ（三つの入口の名前は出たのに内容的妥当性の当てはめがずれた、四条件は出たのに別の問いに答えた。→A-16）。(2) 術語は世界の切り方を運び、何を見えるようにし何を見えにくくするかの感覚まで含めて持つ（メシックとボースブーム）。(3) 術語にならない部分（オッズの階段の絵、手で追った計算、三つの物差しの地図）があり、ライルのやり方の知の側。術語は取っ手で中身がついてこないことがある。研究ハブの定義語に裏返すと、読む人が再利用できるには何を一緒に渡すか（→C-18、C-19）
- 著者の頼み。全体の中のどこを議論しているか分からなくなってきたので、AからCの関係図と各領域の議論を図で示してほしい。見取り図のページを作った（非公開の Artifact）。三角形の中央に核心の問い（要領とホリスティックな感覚をどう結びつけるか）、辺ごとの橋渡しの概念（AとBは判断の揺れと当たりを数で扱う、AとCは測ることと概念を作ることの地続き、BとCは確率も知識も作り直された概念）、第2期のDへの橋、各テーマの20回を区切りに分けた進み具合、テーマをまたぐ糸（正解ラベルのない評価、証拠の見分ける力、どの集まりで数えるか、一つの言葉に二つのもの、熟達と外からの手応え）。今日の C-04 と A-05 は「判断が当たっているとは何で、何で確かめられるのか」の両側にいると位置づけた
- 著者の意向。見取り図の「テーマをまたいで出てくる糸」を、ある程度の段階でまとまったエッセイにしたい。書く段では zenn-content の writing-ecosystem に渡し、中心命題はインタビューで決め、原稿と計画は zenn-content に置き、個人的な話はそのつど認めたものだけを持ち出すと確認した。材料の厚さの見立て。正解ラベルのない評価が最も厚いが A-15、A-17、A-19、A-20 が先にあり答えの側が薄い。証拠の見分ける力は今日育ったが二つの尤度比の見方は対話で出した読み方で、先行議論の調査が要る。熟達と外からの手応えは土地評価の材料で個性が出しやすく、A-13 と A-15 のあとが書きどき
- 著者の着想。LLM活用は作業範囲を今まで到達不可能だった範囲にスケールさせ、エンジニアがコンテンツマーケティングをしたり、さらに経営的な視点が要るようになる。専門外に踏み出すと「何がいいのか分からない」状態になり評価が難しくなる。これをどう考えるかも面白い

## 概念表

| 概念 | 一言で |
|---|---|
| 統一的妥当性論 | 妥当性を、点数の解釈と使い方がどれだけ支えられているかの一つの総合的判断とみる見方（メシック） |
| 解釈と使い方の妥当性 | 妥当なのは道具でなく「この点をこう読んでこう使う」という主張 |
| 程度としての妥当性 | 妥当性は二択でなく、証拠が増えれば強まり反する証拠で弱まる |
| 構成概念の過少代表 | 測り方が狭すぎて、構成概念の大事な面を取りこぼすこと |
| 構成概念に無関係な分散 | ほかの性質や測り方の癖で、点数が構成概念と関係なく動くこと |
| 結果的妥当性 | 点数の使用がもたらす結果も妥当性の判断に含めること |
| 波及効果 | 試験が教え方や学び方に及ぼす影響 |
| 狭い妥当性（ボースブームら） | 性質が存在し、その違いが測定結果の違いを生むなら妥当、という道具の性質としての定義 |
| 環境の運 | 理由と真の筋の中でなく、まわりの環境に入り込む運（張りぼての納屋）。真を含む条件も免れない |
| 条件の吸収 | 真を保証する条件を足すと、真の条件がそこに吸収されて余分になり、その条件の中身の問題だけが残ること |
| 安全性 | 少し違っていたら偽になっていた信念は知識でない、という条件 |
| 本人の尤度比と実際の尤度比 | 本人が見積もる証拠の見分ける力と、その場の仕組みでの実際の見分ける力。ゲティアはこの二つのずれ |
| 感受性（ノージック） | Pが偽だったらPと信じなかっただろう、という条件。尤度比の分母が小さいことに当たる |
| 一般性の問題 | 信頼性や実際の尤度比を、どの範囲の状況で数えるかで判定が変わる問題 |
| 事実の知とやり方の知 | 何かであると知っていることと、どうやるかを知っていること（ライル） |
| 注意の対象と真にする対象 | 注意が定まったものと、信念を真にしているものが別なら、真は注意の外から入った運になる |
| 熟達に導かれた注意（ガネーリ） | 熟達に導かれた注意は知識に十分、注意は本性上実在するものに定まるという主張 |
| 因果の矢印と使い方の連なり | ボースブームらは性質→目盛りだけを、メシックは目盛り→解釈→使い方までを妥当性と見る |
| 論証にもとづく妥当性確認（ケイン） | 解釈と使い方の主張を書き出し、一つずつもっともらしさを確かめる手順 |

## 復習用の問い

1. メシックは、妥当性の持ち主を何だとしたか。「この道具は妥当だ」という言い方に何が足りないか
2. 構成概念の過少代表と、構成概念に無関係な分散の違いを、日常の例で言えるか
3. 結果的妥当性で、悪い結果がいつでも妥当性を下げるわけではないのはなぜか
4. 三つの入口は、メシックの見方ではどういう位置づけになるか
5. ボースブームらの狭い定義とメシックの広い見方では、点数の使い方で起きた困りごとはどこに置かれるか
6. ケインの論証の手順は、メシックの見方を何のために組み直したものか

## 開いたままの問い

- LLM の判定器や評価対象の出力で、本人の尤度比と実際の尤度比のずれをどう見るか。データの集まりを変えて当たりが崩れるかを見るのは、実際の尤度比を別の参照クラスで数え直すことか（→A-19 LLMを評価者として、B-14 較正、D-11 プロービング）
- 知識という概念が実際の尤度比の大きさに付ける印なら、評価やエージェントの設計で同じ役をする印は何か。判定器の確信度は本人の尤度比しか表さないのか（→C-14 概念の倫理、A-19、B-16 言語モデルの確率）
- 「よい出力」は分解できない一つのまとまりか、一語に複数のものが入っているのか。前者ならホリスティックな評価の根拠に、後者なら割るべきという逆の方向を指す（→A-08 全体的評価と分析的評価、A-11 ポランニーの暗黙知、C-12 概念の分割、A-20 統合回）
- 知識を「注意が定まった当のものが信念を真にしている、かつその注意が環境に照らして見分ける力を持つ」と組み立てるとき、後半の見分ける力（熟達）はどんな手応えのもとで育つのか。観想的エージェントの注意には、それを育てる手応えがあるか（→A-13 ドレイファス、A-15 直観はいつ信頼できるか、D-14 アトリビューショングラフ、D-20 統合回）
- ベンチマークへの違和感は、点数そのものより「能力が上がった」と読む解釈と開発の向きを決める使い方の側にあるか。ケインの主張の書き出しと点検は、ルーブリックとどこまで似ていてどこが違うか（今日の引っかかり。→A-06 グッドハート、A-08 全体的評価と分析的評価、A-19、A-20 統合回）
- 妥当性を因果の矢印に絞るか、使い方の責任まで広げるかを、自分の eval ではどちらで使っているか。判定器の判定が正確でも、その判定で何を決めているかの点検はどこにあるか（→A-19、C-14 概念の倫理）
- 自分の定義語を読む人が再利用できるようになるには、定義に加えて何（境目の事例、切り方の外への目配り、絵や手順）を一緒に渡せばよいか（→C-18 用語を作る技術、C-19 自分の概念を点検する演習）
- エッセイにする糸をどれにするか、いくつを束ねるか。候補は正解ラベルのない評価、証拠の見分ける力（二つの尤度比の見方に先行議論があるかを調べる）、熟達と外からの手応え（→A-13、A-15、A-20 統合回のあとに zenn-content で）
- LLM で手の届く範囲が専門の外に広がるとき、評価する目をどう追いつかせるか。使い方による割り振り、外の基準の借用、専門家の事例での目合わせ、目的を先に置いた基準づくりのどれがどこで効くか（エッセイの糸の候補。→A-06、A-12 コリンズ、A-15、A-17、A-19、A-20 統合回）
