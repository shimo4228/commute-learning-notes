# B-02 条件付き確率

## 本編の要点

- 条件付き確率 P(A|B) は、世界を B に狭めてから A を数える操作。P(A|B) = P(A かつ B) ÷ P(B)。P(B) が0なら定まらない
- P(A|B) と P(B|A) は分子が同じでも分母が違い、一般に値が違う（猫と餌皿の例で 0.8 と約0.67）。取り違えは条件の逆転と呼ばれる
- P(A|B) が P(A) と等しいとき A と B は独立。掛け算の形 P(A かつ B) = P(B) × P(A|B) は次回のベイズの定理の足場
- ギーゲレンツァーとホフラーゲ（1995）は、割合より「何人のうち何人」の自然頻度で示すと正しい推論が増えることを示した。効く理由（進化的な説明か、入れ子の見えやすさか）は割れている
- シンプソンのパラドックス。分けるとどちらでもAが上なのに、まとめるとBが上になる（自転車のルートと天気、1973年のバークレーの入試をビッケルら1975が分析）。どの条件で分けるべきかはデータの外の因果の見立てで決まる

## 対話で出た論点

- 復習（参照クラス）への著者の答え。飼っている動物が朝ごはんを完食する確率は毎日でみると3割ほどだが、前日の夜ごはんを残した日に限ると9割。「空腹なのか」という見立てつき。全体と条件付きで値が変わる例として的確。残る論点は、一日が複数の集まりに属するとき（夜を残した、かつ寒い朝、など）どれを使うか、絞るほど数える日が減ること、そして「空腹だから」という因果の見立てが、どの条件で分けるべきかを決めている点（本文のシンプソンの節につながる）
- 小問への著者の答え。替え玉を頼むにはこの店のラーメンを頼む必要があるので、P(この店のラーメン|替え玉) は10割、という指摘。こちらの用意した答え（ほかの店の替え玉まで数えて6割）は問いの文から無理のある読み方で、著者の読みが正しい。替え玉の客がラーメン客に含まれるとき、一方の向きは9割、逆向きは10割になる。B が A に含まれるなら P(A|B) は1、という条件の逆転のいちばん単純な形。lessons/B-02.md の答え合わせも訂正した
- 著者の受け止め。ホリスティックな判断は、シンプソンのような誤りも感覚の中にすっぽり含んでしまうので、厳密さに欠けるかもしれない
- 一つの作品をその場で丸ごと判断するだけなら足し合わせがないので、この形の誤りは直接には起きない。入り込むのは印象が積み重なるところ。見た課題の配分が偏ったまま「Bの方がよい気がする」が育つのは、感覚の中のシンプソン
- ルーブリックの合計も配分つきの足し算なので、分ける条件を決めていなければ同じく逆転する。厳密さは形式の違いからは出てこない
- 厳密さは比べ方の設計に置ける。同じ課題に対するAとBの出力を並べる一対比較は、条件で分けることが手続きに組み込まれ、配分の偏りが入らない（→A-18）
- 土地評価の要領も、事例と比べる前に事情補正、時点修正、地域要因や個別的要因の比較で条件をそろえる手順を細かく定め、そろえたあとの最後の見立てを評価者に残している。要領の多くは、感覚を縛るより、感覚が比べる相手の条件をそろえるために使われている、という読み
- 著者の補足。自分のホリスティックは逆向きでもある。強いモデルにはルーブリックでなくホリスティックを勧めている。さきの自分の説明はシステム1的だったが、強いモデルは内部推論でシステム2をしており、さきのような分析も済ませたうえで結論を出しているのだから、わざわざ数字に折り畳む必要がない
- ホリスティックには二つの向きがある。人間の感覚の判断（システム1寄り）と、推論するモデルの結論を点数に折り畳まずに受け取る設計。後者は、条件づけを含む推論を点数に変換すると条件が落ち、点数が目標化する、という点で筋が通る。小さな較正済み判定器を外して大きなモデルに戻した経験とも合う
- ただし確かめどころが三つ残る。シンプソンは多くの課題の判定を集めて比べる段階、つまりモデルの外で起きるので、課題の配分と突き合わせ方は設計者の仕事。書き出された推論が結論を生んだ過程を忠実に映しているかは疑われており（→D-17）、並び順の入れ替えなどで確かめる対象にした方が安全。推論するモデルにも位置、長さ、自己優遇の偏りが残る（→A-19）。システム1と2の区別を言語モデルに当てはめてよいか自体も未決
- 言い直すと、判断はモデルの推論に任せて点数に折り畳まず、比べ方の設計と、推論が結論を支えているかの点検を人の側に残す
- 著者の claude-harness の llm-as-judge スキルを読んだ。二値の確認を証拠として集め、列挙型の結論を一つだけ出し、点数に集計しない。決定的な No はそれだけで結論を決める。不合格寄りの結論には反証の問いを作って当て、直したあとは同じ問いで一度だけ再判定する。決定的に確かめられること（パス、フラグ、URL）はコードが判断の前に無条件で確かめる
- 学習との重なり。決定的な No は埋め合わせの前提を退ける（A-01）。二値の確認は弱い操作主義で、質の定義でなく証拠の位置に置かれ、すき間を消さない（A-02）。同じ問いで再判定する規律は、道具を固定して変化を見る認識の反復の手つき（A-02 チャン）。判断の前の存在確認は「条件をそろえる部分はコード、見立ては列挙型の結論」という切り分けで、要領の事情補正と評点の関係と同型。さきの開いたままの問いに著者がすでに出していた答えと読める
- 手当てが薄いところ。同じ項目を二度判定して結論が一致するかという再現性の測定がない（→A-03 信頼性）。一対比較がなく、モデルどうしを比べる段階のシンプソンには向いていない。確認の問いが検証しやすさで選ばれる以上、ホリスティックな結論が確認済みのことに引っ張られる街灯のおそれがある（BinEval 自身も主観的な質での分解の弱さを認める）。反証の問いも同じ判定者が作り答えるので、主観的な部分を外から確かめる仕組みはない
- 観想的エージェントへの示唆。結論の列挙型を「次に何をするか」と一対一にする設計なら、望ましさを定義せずに人の側の次の行動を結論にできる（憲法の修正案に「採る / 話し合う / 戻す」）。「よい」の代わりに「次に何をするか」を定義することで、B-01 の構成概念の不在を迂回できるかもしれない

## 概念表

| 概念 | 一言で |
|---|---|
| 条件付き確率 | ある条件に世界を狭めたうえでの確率 |
| 条件の逆転 | P(A|B) と P(B|A) を取り違える誤り |
| 包含のときの条件付き確率 | B が A に含まれるなら P(A|B) は1。逆向きの P(B|A) は1とは限らない |
| 感覚の中のシンプソン | 偏った配分の経験が積み重なって、印象の順位が逆転すること |
| 条件をそろえた比較 | 同じ課題で並べて比べ、配分の偏りを手続きで消すこと |
| 二つの向きのホリスティック | 人間の感覚の判断と、推論するモデルの結論を点数に折り畳まない設計 |
| 推論の忠実性 | 書き出された推論が、結論を生んだ過程を実際に映しているかどうか |
| 決定的な No | 一つの欠陥がそれだけで結論を決め、平均で薄められないこと |
| 行動に対応する結論 | 結論の選択肢を次の行動と一対一にし、「よい」の定義を迂回すること |
| 独立 | 条件を付けても確率が変わらない関係 |
| 賭博者の誤り | 独立な試行で「そろそろ逆が出る」と思い込むこと |
| 掛け算の形 | P(A かつ B) = P(B) × P(A|B) |
| 自然頻度 | 全体の数を決めて「何人のうち何人」と枝分かれさせる示し方 |
| シンプソンのパラドックス | 分けたときとまとめたときで、比べた結果が逆になる現象 |

## 復習用の問い

1. 条件付き確率の「狭めてから数える」を、日常の例で説明できるか
2. 30日のうち餌皿が空の日10日、そのうち鳴いた日8日、空でない20日のうち鳴いた日4日のとき、P(鳴く|空) と P(空|鳴く) はそれぞれいくつか
3. 五回続けて表が出たあとの表の確率は、独立ならいくつか。なぜそう思いにくいのか
4. 割合の話を自然頻度に書き直すと、なぜ取り違えに気づきやすくなるのか
5. シンプソンのパラドックスが起きる仕掛けを、数値例で説明できるか
6. 分けた数字とまとめた数字のどちらを使うべきかは、何で決まるか

## 開いたままの問い

- 要領のうち「比べる条件をそろえる部分」と「最後の見立てに任せる部分」は、どれくらいの割合か。自分の eval では、条件をそろえる部分を何が担っているか（→A-17 アンカー事例、A-18 比較判断、A-20 統合回）
- 印象が積み重なって育つ感覚の中のシンプソンを、ホリスティックな判断の側からどう見つけるか（→A-10 ノイズ、A-15 直観はいつ信頼できるか）
- 自分の eval で、モデルの結論は文章か選択肢か。推論が結論を本当に支えていることを、いま何で確かめているか（→A-19 LLMを評価者として測定論で見る、D-17 思考の連鎖は本当の思考か）
- llm-as-judge に、同じ項目を二度判定して結論の一致を見る手順や、並び順を入れ替える一対比較を足すべきか。足すなら結論の列挙型とどう両立させるか（→A-03 信頼性、A-18 比較判断）
- 観想的エージェントの憲法修正案に「採る / 話し合う / 戻す」のような行動の列挙型を当てたとき、望ましさを定義しないまま判定は成り立つか（→A-20 統合回、C-19 自分の概念を点検する演習）
