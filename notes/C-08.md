# C-08 実装の問題

## 本編の要点

- 実装の問題は、直した意味を言葉の共同体にどう広めるのかという問い。前回の、意味の変化を許す探究で決め直した語を、変えたことを伝えずに外へ持ち出すと行き違いが起きる、という話を受ける
- カペレン（2020年の章、2018年の『Fixing Language』の要約）。外在主義でも内在主義でも、意味の変化の舵は話し手の手の内にない。規模を比べると、家の中（娘のアイス）なら考えは効き、住む通りの減速帯では効き目が小さくばらばらで見通せず、遠い都市の犯罪ではほとんど効かない。語の意味の変化は大きい側にある。だからやめよではなく、やるなら思い違いなしにやる
- スターケン（2020）の言語的介入。メタ言語的交渉がその場の会話での使い方を争うのに対し、介入は共同体全体でこの先も新しい意味を持つことを目指す。語をすでに新しい意味を持つかのように使うと伝わり損ねが起き、聞き手が立ち止まり使い方を考え直し新しい意味をつかむ（変容をもたらす伝達の乱れ）。誤解させたまま、冗談と受け取られる、真面目に受け取られなくなる、という危うさがあり、話し手の意図が先の会話と共同体に向いていると見て擁護した。孫が祖母の庭仕事を「トレーニング」と呼ぶ例
- トマソン（2021）。制度は自分の範囲の中では語を定義し直すことをわりあい簡単にできる。外まで根づくかは、日常の使い方という競争相手がいるかと、決め直しがそれから離れすぎていないかで変わる。会社を法の上の「人」とした例は、日常の「人」は変わらず専門の意味が一つ加わっただけで、法の上の立場を変える目的は果たした。ボードゲームの大会の「初心者」（競争相手あり）と「くじ組みの部」（競争相手なし）
- 講義の整理として、法を動かせるほどの力を持つ側でも日常の語の意味までは握れず、力が届いたのは制度の範囲の中の扱いだった、と読んだ（C-07 の対話の、どの語りが通るかを勢いのある側が決めるのでは、という見方を受けて）

- 復習3（C-05 問い3）。著者「そんな話したっけ？」。C-05 第2節のニレとブナと言語的分業を示した。C-01 と C-05 の主役級の語が二つとも思い出されなかったので、両ノートの next_recall に近い期日を足した

## 概念表

| 概念 | 一言の説明 |
|---|---|
| 実装の問題 | 直した意味を言葉の共同体にどう広めるのかという問い |
| 制御の欠如 | 意味の変化の舵を話し手が握れないこと（カペレン） |
| 規模の比べ方 | 家の中、住む通り、遠い都市と、規模が大きいほど考えの効き目が小さく見通せなくなるという並び |
| 言語的介入 | 語が共同体全体でこの先も新しい意味を持つようにする試み（スターケン） |
| 変容をもたらす伝達の乱れ | 伝わり損ねが聞き手を立ち止まらせ、使い方を考え直させ、新しい意味をつかませる過程 |
| 下からと上からの広め方 | 話し手の使い方から広める道と、権限を持つ制度が定義を決める道 |
| 制度の範囲の中の定義 | 制度が自分の範囲で語を定義し直すこと。外に根づくかは別の話 |
| 競争相手 | 制度の定義と張り合う、同じ語の日常の使い方 |

## 復習用の問い

1. カペレンの規模の並び（家の中、住む通り、遠い都市）で、語の意味を変える試みはどこに置かれるか。それでも試みる意味があるとカペレンが言うのはなぜか
2. メタ言語的交渉と言語的介入は、目指す範囲がどう違うか。日常の例で一組言えるか
3. わざと新しい意味で語を使うと、なぜ広まる助けになりうるのか。どうなると危うい結果になるか
4. 制度が自分の範囲で決めた定義が、外の言葉にまで根づきやすいのはどんなときか。根づきにくい例と根づきやすい例を一つずつ言えるか
5. 一人の人に、日常の意味と制度の定義を両方当てて、分かれるところを示せるか
