# A-07 グッドハートの四類型

## 本編の要点

- ガラブラント（2017）の短い文章と、マンハイムとガラブラントの論文（2018）は、指標が押されて崩れる仕組みを回帰的、極端、因果的、敵対的の四つに分けた。この講義では、選ぶだけで起きる二つと、世界に手を入れて起きる二つにまとめて眺めた
- 回帰的　指標は目標に外れが足されたもの。上位を選ぶと外れの上振れも一緒に選ばれ、選んだものの目標は期待より少し低くなる。避けられないが、でたらめに選ぶよりは良い。外れ方の違う二つ目の手がかりが手当てになる
- 極端　指標と目標の関係はふだんの範囲で観察されたもので、指標が極端な値をとる世界では関係そのものが変わる（糖度のいちばん高い桃が熟れすぎている）。手当ては観察した範囲を出ない程度に選ぶこと
- 因果的　指標と目標がまわり道でつながっているとき、指標に直接手を入れると道筋が切れる（荷物を軽くするために雨具を置いていく）。選ぶだけなら起きない
- 敵対的　別の目的を持つ相手が指標を学び、自分の目的と指標を結びつける（おすわりとおやつ）。相手は前の三つの型の手をどれでも使う
- この講義の整理として、選ぶ二つは見るのをやめれば困りごとが消えるグッドハートの側に、手を入れる二つは世界に変化が残るキャンベルの側に寄ると読んだ。論文自体はキャンベルの法則を敵対的の一つの場合に置いている

- 応答。(1) 人の評価者も現地調査を外に委ねて届いたものから判断しているので、LLM と同じ位置で、入力の違いは解消済み。評価の測定の面で残る違いは押され方だけ。(3) 三つを一列に並べたのは混ぜすぎだったと認めた。今の役割の決め方を講義の言葉で読んだ（見立て）。LLM は評価者でなく検索の位置にあり、評価の数を出さないのでグッドハートの圧がかかる指標にならない。検索対象外を返さない制限は出してよい範囲を先に限る形で、極端の手当て（観察した範囲を出ない）と同じ向き。能力では評価者に入れるのに、責任の引き受けが社会で成り立たないので役割をそこで止めている。役割の境目を決めているのは能力でなく責任。AAP で人の引き受けを必須にするなら、自律の範囲の縁は引き受ける人がどこまで見張れるかで決まり、その見張りが押される場所になるかが四類型とつながる（今日の引っかかりへ）

- 著者の考え「結局 LLM がタスクをこなすかどうかは能力の話ではない。社会設計の話だ」。応答（見立てを含む）。要領そのものが社会設計の産物で、一人の評価者の判断を公の課税の基礎として受け入れさせる仕組み。だから測定の道具立て（揺れ、当たり、押されたときの崩れ方）は社会設計の外でなく、任せた判断を確かめる部品。社会が判断を任せるには、揺れず当たっていると確かめる手立てと、外れたときの引き受けの取り決めの二つが要り、人の評価者には要領と資格と組織がそれを用意している。LLM に任せるなら、問いは「何ができるか」から「要領と資格と組織にあたるものを何で作るか」へ移る。前半は測定の側（A-17〜A-20）、後半は責任の側（AAP）。能力の問いが消えたのでなく、この分野では能力は足りていて、いま効いている制約が社会設計の側にある、と返した

- 著者の考え「今の社会通念では、自分が考えて手を動かしていない判断の責任を負えるのかという話になる。現場責任者はそれをしてきたので LLM に変わるだけとも言えるが、前提として LLM は最低限の責任能力を一切持たないという社会通念の問題になる」。応答（見立てを含む）。責任者が部下の判断を引き受けられる支えを三つに分けた。(1) 部下も一部を引き受ける（理由を答える、注意や処分を受ける。責任は分かれて持たれる）、(2) 責任者は選んで見張ったことに責任を負う、(3) 部下の振る舞いが読めるので見張りが成り立つ。通念が引っかかるのは主に(1)。さらに(1)を、理由を答える（LLM もある程度できるが、答えた理由が実際の判断の道筋と一致する保証はない→テーマD）、報いを受ける（できない）、改める（作り手やシステムの側で起きる）に分けた。先行する議論としてマティアス（2004）の責任の隙間（学習する機械の振る舞いは作り手や使い手にも予測しきれず、誰にも責任を帰せない隙間が広がる。自律兵器の議論で広く参照。埋め方や隙間の有無は割れている）。テーマCの言葉では、責任という概念が三つを一つに束ねているので LLM はどれも満たさないとみなされる。分ければ担える部分と人が引き受ける部分を別々に設計できるかもしれない（→C-12 概念の分割、C-17 AI が概念を割る）。AAP で人の引き受けを必須にするのは、束のうち報いを受ける部分を人に残す設計と読めるかもしれない

- 著者の判断「マティアスの論文は AAP に関連付け済みだが、三つの整理（責任者が部下の判断を引き受ける支え、理由を答える・報いを受ける・改めるの束）は AAP にまだ無い視点で AAP を深める。RFC 化するか、RFC が無ければ Issue にしておいて」。AAP のリポジトリに RFC の仕組みが無かったので Issue にした（shimo4228/agent-attribution-practice#3）。AAP の thesis.md はマティアスとサントーニ・デ・シオとメカッチ（2021、四つの隙間）を既に引いているので、Issue では、彼らが帰属の側の隙間を分類するのに対し、こちらは委ねられる側が担えるものを分類する、と軸の違いで位置づけた。四つの隙間との対応づけは確かめが要る読みとして書いた。土地評価の業務の話は Issue に入れていない

## 概念表

| 概念 | 一言で |
|---|---|
| 平均への回帰 | 極端な値で選んだものが、次には平均の側へ戻ること。回帰は元は「戻る」の意味（ゴルトン） |
| 回帰的グッドハート | 指標の高いものを選ぶと外れの上振れも選ばれ、選んだものの目標が期待より低めになること |
| 極端グッドハート | 指標が極端な値をとる領域では、ふだんの範囲で観察した指標と目標の関係が崩れること |
| 因果的グッドハート | 指標を上げようと世界に手を入れると、指標と目標をつなぐ道筋が切れること |
| 敵対的グッドハート | 別の目的を持つ相手が指標を学び、自分の目的と指標をそろえるように動くこと |
| 選ぶか手を入れるか | 回帰的と極端は選ぶだけで起き、因果的と敵対的は世界に手を入れて起きる、というこの講義のまとめ方 |
| 外れ方の違う二つ目の手がかり | 一つの指標の外れを選んでしまうことへの手当て（別の日にもう一度試食する） |
| キャンベルの法則の二つの半分 | 前半は数そのものが偽られる圧、後半は数が正直でも見張る営みが形を変えること。後半だけがグッドハートに無い |
| 記録を正直にしたら残るか | 偽りを封じても残る困りごとがキャンベル後半、という見分けの問い（この講義の整理） |
| 責任の隙間 | 学習する機械の振る舞いは作り手や使い手にも予測しきれず、誰にも責任を帰せない隙間が広がるという問題（マティアス 2004） |
| 責任の束 | 理由を答える、報いを受ける、改めるの三つ。通念の責任はこれを束ねて持つ（この講義の整理） |
| 任せるための二つの部品 | 判断が揺れず当たっていると確かめる手立てと、外れたときの引き受けの取り決め。人の評価者には要領と資格と組織がこれを用意している |
| 数を出さない役割 | 評価の数を出さず検索や手がかりの供給にとどまる役割。指標にならないので押されない（著者の土地評価での RAG 検索補助） |
| コブラ効果 | 報酬に応じて、相手が目標を通らずに指標を上げる道を自分で作ること |

## 開いたままの問い

- 責任を、理由を答える、報いを受ける、改めるの三つに分けたとき、LLM が担える部分と人が引き受けなければならない部分を別々に設計できるか。社会通念の「LLM には責任能力がない」は、束ねたままの概念から来ているか（→C-12、C-17、テーマD、AAP。記事の素材になりうる）
- LLM に評価を任せるために、人の評価者にとっての要領と資格と組織にあたるものを何で作るか。確かめる手立て（測定の側）と引き受けの取り決め（責任の側）は、どちらが先に要るか（→A-17〜A-20、AAP、記事の素材になりうる）
- LLM に要領と評価システムの権限を渡せば人と同じにできる、という著者の見立て。入力の違いは委託調査で解消済み（著者）、責任は評価と別の領域（著者）。評価の面で残るのは押され方の違い。揺れ、人との一致、極端な土地の三つで確かめられるか（→A-19、A-20）
- 役割の境目を能力でなく責任で決める。AAP で人の引き受けを必須にするとき、自律の縁は引き受ける人がどこまで見張れるかで決まる。その見張りは四類型のどれで押されるか（→A-19、A-20、AAP）
- 評価の分野ごとに、路線価にあたる錨（外の目盛りへのつなぎ止め）は何か、例外規定はどんな事例から育つか。そこに LLM を評価者として入れたとき、要領を当てはめる人と比べて何が同じで何が違うか（LLM を分野として切らない、という著者の指摘で直した。→A-17、A-19、A-20）
- 要領は揺れを縛り、外の目盛りにつなぎ、使える範囲を限る。ホリスティックな判断は、要領が範囲を限ったところで始まるという見立ては、実務と合うか。要領の定める「手順で評価しがたい土地」の扱いは実際どうなっているか（著者に確かめる。→A-13、A-16、A-20）
- 今日の引っかかり。観想的エージェントが修正案を選ぶ判断の好みを学べるほど力を持ったとき、責任帰属の設計（AAP）が捉えにくくなるのは四類型のどれか（→A-19、A-20）
- LLM の eval で平均を取っても、多くのモデルや設定からいちばんを選べば回帰的な上振れが残り、同じ向きのずれは縮まない。自分の eval で、選ぶ段階に二つ目の外れ方の違う手がかりを置けるか（→A-17、A-19、B-14）
- グッドハートとキャンベルの区別は A-06 から二回続けて揺れた。振り分けを自分からしない、向きを逆に取る。キャンベル前半（偽り）と後半（営みの変形）の三層の見方で次は通るか。A-08 以降の復習で、偽りの封じられた場面（正直な記録なのに営みが崩れる）を出して確かめる
