# C-18 用語を作る技術

## 本編の要点

- 今日の三つの節は、作った考えを言葉にして人に渡す三か所（名前、例、広まり）に当たる（この講義の整理）。研究ハブで新しい定義語を出すとき、名前を選ぶ、例を添える、どこで誰に使ってもらうかを考える場面で使う。いま出ている定義語の点検は C-19
- 名前に見立てを入れない。ファラデー（1834年）は、引きつけの見立てを運ぶ「極」の代わりに、二人の友人と相談して、電流が入る面と出る面を地球の東と西に結び、アノードとカソードと呼んだ。見方が変わっても誤った見方を支えない、と書いた。ただし東と西の決め方には、地球の磁気が電流によるなら、という彼自身が「もし」を付けた仮定が入っていた。見立てをまったく持たない名前は作りにくく、できるのは決着していない見立てから名前を遠ざけ、動かない目印に結ぶところまで（この講義の読み）
- 例は散らして添える。シューとテネンバウム（2007年）の実験では、おもちゃの犬を一つ指して「フェップ」と教えると広く当てはめられ、同じ種類の犬を三つ指すとその種類にしか当てはめられなくなった。例を、言葉を知る人が当てはまる物から選んで見せたもの、と読むから、という説明。説明は割れている（見せ方しだいで消えるという報告と、確かめ直して残ったという報告）。定義に入れたくない特徴は例ごとに変え、入れたい特徴だけをどの例にも残す（作る側への読み替えはこの講義の整理）
- 言葉が広まるとき。メトカーフ（2002年）は定着を左右しそうな条件の一つに、使う人と場面がばらけていることを挙げた。ヴュルシンガー（2021年）は投稿サイトの99の英語の新語で、使われた回数が似ていても広がり方が違い、一つの密な集まりにとどまる語と、記者の集まりから外へ広がった語があることを示した
- 広まると意味は作った人の手を離れる（第8回の制御の欠如）。パース（1905年）は、広く使われて意味の動いた「プラグマティズム」を手放し、最初の意味を言い表すために「プラグマティシズム」を作り、誘拐されないくらい醜いので安全だ、と書いた。どこで誰に使ってもらうかを選ぶことは、どこまで手放すかを選ぶことでもある（この講義の整理）

## 概念表

| 概念 | 一言で |
|---|---|
| 見立てを入れない名前 | まだ決着していない見立てを名前に入れず、見立てが変わっても動かない目印に名前を結ぶ付け方 |
| 例の散らばり | 読む人は例を作った人が選んだものとして読むので、例がそろって持つ特徴は意味の一部と受け取られやすい |
| 大きさの原理 | 例がそろって小さな種類に入るほど、狭い意味の尤度が例ごとに掛け算で大きくなる（シューとテネンバウムの説明） |
| 使う人と場面の広がり | 新しい言葉が集まりの外へ広まるかは、使われる回数より、いろいろな人がいろいろな場面で使うかに左右されやすい |
| 手放すこと | 言葉が広まるほど、意味は使う人の側で動き、作った人の手を離れる |

## 開いたままの問い
