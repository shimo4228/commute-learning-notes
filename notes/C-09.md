# C-09 チャーマーズの整理

## 本編の要点

- チャーマーズ（2020年の論文「概念工学とは何か、そして何であるべきか」）は、工学の定義になぞらえて、概念工学を概念を設計し、実装し、評価する営みとした。分析は概念分析と紛らわしいので評価に、作るは実装に替えた
- 設計は定義や推論の役目や手本の事例を与えること、評価はその概念が役目をどれだけよく果たすかを確かめること（概念の倫理の仕事。テーマAの測ることとは別）、実装は自分で使い他人にも使ってもらうこと。いちばん難しいのは実装、とくに他人に使ってもらう手順。使い方を十分広く変えればたいてい意味もついてくる、とチャーマーズは見る（カペレンとは割れている）
- 新規設計（直す相手の無い新しい概念を作る）と再設計（古い概念を直すか置き換える）。置き換えのために作った新しい概念は再設計に数える（古い橋のそばに架ける新しい橋）。カペレンの『Fixing Language』（2018）は直す仕事に絞り、チャーマーズは作ることも含めるべきとした。多元主義から、古い概念も残して新しく作るほうが実りの多いことが多いと見る
- 同じ語の設計（古い語に新しい意味を当てる）と別の語の設計（違う語を当てる）は、概念の軸とは別の言葉の軸。理論の上では言葉の違いだが、語への連想があるので実際の違いは大きい
- 古い語は役目と重みを運ぶ（結婚とシビルユニオン）が、紛らわしく広めにくい。新しい語は覚えてもらう手間がかかるが、ストローソンの心配に「そう、別の話題だ」と答えられる。クラークとチャーマーズ（1998）は e-信念でなく信念の語を当てた

## 対話で出た論点

- 日本時間の夜8時半ごろ、時間帯の外で始まったので試し実行として届け、復習の1の答えのあとで記録するかを尋ねた。著者が「記録する」を選び、本番と同じ書き込みにした
- 復習の1（C-08 から、近所の川べりで弁当を食べることを誰にでもいつも「遠足」と呼ぶ友人）。「3」（制度の範囲の中の定義）と答えた。答えは2の言語的介入。講評では、「家族にも友だちにも」と書いたので友人の周りが一つの範囲のように読めたかもしれない、と問いの書き方を挙げ、決める力があるかどうかで分けた
- 著者「言語的介入なんか学習したかな？メタ言語的学習と合わせてきっちり理解させて」。言語的介入は C-08 の第2節（孫が祖母の庭仕事を「トレーニング」と呼び続けた例）、メタ言語的交渉は C-01 で出て C-08 の復習で一度思い出した、と答え、名前が場面と結びついていないので一つずつ積み直した。見立て　理解の側が主。名前そのものが記憶に残っておらず、C-08 の復習でもメタ言語的交渉が思い出されなかった。三つの名前を選択肢に並べ、名前から場面を思い出させる形だったことは出題の側の要素
- 段1 メタ言語的交渉（直感、プランケットとサンデルの名づけ、カップ麺にお湯を注いだのは「料理」か）。練習1（牛乳だけ飲んだ弟の「朝ごはんは食べた」）は「2」で正解
- 段2 言語的介入（スターケンの、変容をもたらす伝達の乱れと危うさ、ベランダの鉢植えの水やりを誰にでも「畑仕事」と呼ぶ友人）。練習2（公園の池を誰と話すときも「湖」と呼ぶ友人が目指すもの）は正解（答えの文は記録に残っていない）
- 段3 見分け（目印を一行ずつ。交渉は事実で一致したままその場の相手と、介入はふだんと違うと知ったうえで誰にでもこの先ずっと）。練習3（高さ300メートルの丘を「山」と呼ぶかの帰り道の言い合い）は「1」で正解。練習4（残り物の夕飯を一年「創作料理」と呼び続ける友人と、ある晩の妹との言い合い）は「2」で正解。介入の途中でその場の交渉が一度起きる場面も読み分けた。範囲（その場の相手か、この先の皆か）を場面から読んで選べたので、二つの区別は通ったものとした
- 復習の2（A-02 から、料理教室が「うまさとは採点表の点数のことだ」と決めたとき、満点のカレーを家族がまずいと言ったら、採点表が測り損ねたと言えるか）。正解（答えの文は記録に残っていない）。すき間を消すと測定が間違えられなくなる、と A-02 に結んだ
- 復習の3（A-07 から、猫のごはんを急に半分にして体重は減ったが元気がなくなった）。「2」（極端）と答えた。答えは3の因果的。見立て　出題の側。「急に半分」がふだんの言葉の「極端」と重なって見えた。極端の型は指標が観察してきた範囲を外れて関係そのものが変わること、と分け、紛らわしい言葉を外して場面を変えた版（ベランダの鉢植えで、土の表面だけを霧吹きで湿らせ、根まで水が届かない）を出し直したら「3」で正解
- 著者「他の語の意味も教えて」。四つの型を、選ぶだけで起きる二つ（回帰的、極端）と、世界に手を入れて起きる二つ（因果的、敵対的）に分けて並べた。回帰的は食べ歩き番組で一回の試食の点がいちばん高かったラーメン屋（手当ては外れ方の違う二つ目の手がかり）、極端は糖度のいちばん高い桃と自転車のタイヤの空気の入れすぎ、因果的は A-07 の旅の荷物、敵対的は犬がおやつ欲しさに言われなくてもおすわりをする例
- 著者「続きを」で本文へ。節1（設計、評価、実装）の小問1（耳弾きで上達が見やすくなったかの確かめ）は「2」評価で正解、小問2（教室の仲間に使ってほしいとき、一人で終えられない段）は「3」実装で正解
- 節2（新規設計と再設計）の小問3（「一位」をやめて「一番ゴール」と呼ぶ）は「2」再設計で正解、小問4（「一位」を残して別の呼び方も作る）は「1」新規設計で正解
- 節3（同じ語か別の語か）の小問5（週三回の運動の数えにそのまま乗るやり方）は正解（答えの文は記録に残っていない）、小問6（「それは運動じゃない」と言われて「そう、別のものだ」と答えやすいやり方）は「2」で正解。今日の引っかかりと参考文献を出して講義を終えた。残った節なし
- 講義のあと、著者「イマイチ意義がわからないんだけど、概念工学の。意識とアクセス意識の例は意義を感じるけど、どんなユースケースを想定するしているんだろう？学者の狭いコミュニティーに影響を与えることを目指してるのか？それとも社会的地位を活かして社会にインパクトを与えようとしてるのか？結局実装の部分にメソッドを与えれていないのではないか？」。見立てはおおむね当たっていて、チャーマーズ自身も実装に方法を与えられていないことをほぼ認めている、と答えた。使い道は二つの層。一つは学問の中で考える道具を作り直す層（カルナップの解明、拡張された心の「信念」、スーパーヴィーニエンス、固定指示子、ブロックのアクセス意識）で、概念の大事さはそれで言える主張の大事さから来る、議論を進めることが狙い。もう一つは社会の概念に手を入れる層（ハスランガーの「女性」や「人種」、フリッカーの認識的不正義、セクシュアル・ハラスメントという言葉ができる前の場面）で、社会への影響が狙いだが、学者が意図して広めた成功例とは見にくい。社会的地位を使って広めることは、チャーマーズは方法として語っていない。実装の方法はほぼ無いのが分野の現状で、手がかりは「どこでなら効きやすいか」の目安（新しい語を作る、範囲を狭める、下から使い続ける）にとどまり、これを弱みと見る批判は文献にもある。それでも、三つの段はそれぞれ単独で大事で、評価だけで値打ちがあり、自分がその概念で考えるようになることも考えを変える。講義の当てはめとして（著者の設計を確かめたものではない、と断った）、エージェントの憲法やシステムプロンプトや AKC の文書の中はトマソンの制度の範囲に近く、設計した人が語の使い方を決められ、エージェントはそれに従って動く。研究ハブの定義語も、新しい語を小さな範囲で使う形に近い
- 教案の梯子を使った場面はない（教案の予備の問いは介入の危うさと制度の範囲の中の定義だった）。メタ言語的交渉と言語的介入の段1から段3、A-07 の出し直しと四つの型の並べは、その場で作った

## 概念表

| 概念 | 一言で |
|---|---|
| 設計、評価、実装 | チャーマーズが概念工学を分けた三つの段 |
| 実装の三つの手順 | 自分で使う、他人に使ってもらう、使われたあと意味と指示が正しくなる |
| 新規設計 | 直す相手の無い新しい概念を作ること |
| 再設計 | 古い概念を直すか置き換えること。置き換えのための新しい概念も含む |
| 同じ語の設計 | 古い語に新しい意味を当てること |
| 別の語の設計 | 概念に違う語を当てること。前に語を付けて連続を少し残す手もある |
| 多元主義（チャーマーズ） | 古い概念を捨てずに、新しい概念と両方を持つ考え |
| 概念工学の二つの層 | 学問の中で考える道具を作り直す層（議論を進める）と、社会の概念に手を入れる層（社会に効く） |
| 実装の目安 | 方法でなく、どこでなら効きやすいかの手がかり。新しい語を作る、範囲を狭める、下から使い続ける |

## 復習用の問い

1. 家族が、夕飯の残りを次の日の弁当に回す日を「回し弁の日」と呼ぶことにし、紙に意味を書いて冷蔵庫に貼りました。一か月後、家族の誰もがその言葉を使うようになったかを見ています。テーマC（概念工学）のチャーマーズの三つの段のうち、家族が見ているのはどの段の進み具合でしょうか。1 設計、2 評価、3 実装、から番号で一つ選んでください。答え　実装
2. 家族で、これまで「おやつ」は甘いお菓子のことでした。「おやつ」と言うのをやめ、その代わりに、午後に食べる果物や芋も含めて「三時のもの」と呼ぶことにしました。テーマC（概念工学）のチャーマーズの区別で、この呼び方を作ったことは、新規設計と再設計のどちらに数えられるでしょうか。1 新規設計、2 再設計、から番号で一つ選んでください。答え　再設計（新しい語だが、狙いは「おやつ」の置き換え）
3. 家の決まりに「犬の散歩は一日二回」とあります。庭で犬とボール遊びをする時間も数えたいとき、「散歩」の意味を広げて入れるやり方と、「庭遊び」という新しい言葉で別に記録するやり方があります。「それは散歩じゃない」と言われたとき、「そう、別のものだ」と答えやすいのはどちらでしょうか。1 「散歩」を広げる、2 「庭遊び」を作る、から番号で一つ選んでください。答え　「庭遊び」を作る（別の語の設計）
4. 家族ですごろくを遊ぶとき、一番先にゴールした人を「一位」と呼んでいます。「一位」をそのまま残し、それとは別に、途中で一番多く止まったマスの色で「赤の人」「青の人」と呼ぶ呼び方も作りました。テーマC（概念工学）のチャーマーズの区別で、これは新規設計と再設計のどちらに近いでしょうか。1 新規設計、2 再設計、から番号で一つ選んでください。答え　新規設計
5. 友人が、自分で作った言葉を、仲間内で何度か使ってもらえたものの、ほかの人には広がりませんでした。チャーマーズの三つの段のうち、友人がつまずいたのはどれでしょうか。1 設計、2 評価、3 実装、から番号で一つ選んでください。答え　実装（他人に使ってもらう手順）

## 開いたままの問い

- メタ言語的交渉と言語的介入は、段を踏めば場面から範囲（その場の相手か、この先の皆か）を読んで選べた。ただ、名前そのものは記憶に残っていなかった。日をおいて、名前を選択肢に並べた場面の問いで一往復ずつ確かめる。C-10 の言葉の争いはメタ言語的交渉と隣り合うので、そこで名前と場面をもう一度結ぶ（→C-10）
- 概念工学の意義と、実装の方法が無いこと。学問の中の道具作りの層と、社会の概念に手を入れる層の、どちらで実装が効くか。エージェントの憲法や AKC の文書の中は制度の範囲に近く、設計者が語の使い方を決められる。そこでは実装の問題は消えるのか、エージェントが語をどう読むかのずれという別の形で戻るのか（→C-14、C-17、C-18、C-20）
- 今日の引っかかり。著者の定義語の一つ一つは、古い概念を直したものと、新しく作った概念に古い語や近い語を当てたものの、どちらに近いか（→C-19）
- A-07 のグッドハートの「極端」が、ふだんの言葉の「極端」（激しい手の入れ方）に引かれて選ばれた。場面に程度の強い言葉を書かない（テーマAへ）
