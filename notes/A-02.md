# A-02 見えないものを測る

## 本編の要点

- ブリッジマン（『現代物理学の論理』1927）は、概念とは操作の集まりと同じものだとした。背景は相対性理論の「同時」の考え直し。長さも手続きが違えば厳密には別の概念とみなす
- この考えは心理学で教義として広まった（ボーリング 1923「知能とはテストが測るもの」の趣旨、スティーヴンス 1935）。ブリッジマン本人の意図とはずれていたという見方が有力
- すき間を消すと、概念が増えすぎる（水銀とアルコールの温度計）、測定が間違えられなくなる（妥当性を問えない、グッドハートの入口）、改良ができなくなる
- 反対に、手続きと結びつかない構成概念は当たり外れを言えない（「隠れた才能」）
- クロンバックとミール（1955）は、構成概念をほかの概念や観察とのつながりの網（法則論的ネットワーク）に位置づけ、網の予想が当たるかで指標を確かめるとした
- チャン（『温度の発明』2004）の認識の反復。不完全な道具から出発し、道具どうしや感覚とのずれを手がかりに少しずつ直す（沸点より湯気の温度が安定していた例）。すき間は測り方が育つ場所

## 対話で出た論点

（この対話は 2026-10-31 の試し実行の A-02 について交わしたもの。今朝の本番の本文とは例が一部ちがう）

- 著者の受け止め。この領域は、サイエンスをサイエンスするために相当苦労している。検証を成り立たせるために無理な操作をするので、結局その実証に何の意味があるのか、という研究が量産されてしまう
- 問題は操作そのものより、選ぶ順番にあることが多い。本来は測りたいものが先で、それを捉える手続きを選ぶ。実際には検証しやすい手続きが先に決まり、「不安」「知能」のような大きな名前だけを借りてくる。明るい街灯の下だけで落とした鍵を探す形（街灯効果）
- 心理学の内側にも自覚はある。フレイクとフリード（2020）は、尺度をどう作りどう選んだかが報告されない状態を「疑わしい測定の実践」と呼び、まず測定の決定をすべて報告することを求めた。同じ名前で別のものを測る、別の名前で同じものを測る、という混乱も古くから指摘されている
- 温度の歴史と比べると違いが見える。温度にも出発点の堂々めぐりはあったが、互いに独立した測り方がいくつもあり、蒸気機関や化学の実験で、測った結果が役に立つかどうかが外からはっきり返ってきた。だから反復が揃っていった。心理学の多くの構成概念は、独立した手がかりと外からの手応えが乏しく、反復しても揃いにくい。論文は増えてもすき間が詰まらない。B-01 で出たカーネマンとクラインの二条件（規則性とフィードバック）がここでも効いている
- AIの評価も同じ道をたどりかけている。採点しやすい数学やコードの問題が先に選ばれ、「推論力」の名前が付く。ホリスティックな評価はこの街灯癖への抵抗と読める。ただ暗い場所では、見つけたものが鍵かどうか確かめにくい。A-01 の帯域幅と忠実度のジレンマを別の角度から見たもの

## 概念表

| 概念 | 一言で |
|---|---|
| 操作主義 | 概念の意味をそれを確かめる手続きと同じものとみなす立場 |
| 操作的定義 | 構成概念を手続きとその結果で定めること |
| 概念の増殖 | 手続きごとに別の概念になってしまう操作主義の帰結 |
| 法則論的ネットワーク | 構成概念をほかの概念や観察と結ぶ予想の網 |
| 認識の反復 | 不確かな出発点から、ずれを手がかりに体系を直していく進み方 |
| 定点 | 温度計の目盛りを決める基準の状態。それ自体も揺れていた |
| 街灯効果 | 確かめやすい場所で、確かめやすいことだけを確かめてしまう傾向 |
| 疑わしい測定の実践 | 尺度の作り方や選び方を報告せず、測定の妥当性を疑わせる研究上の決定（フレイクとフリード） |
| 名前の借用 | 検証しやすい手続きに、大きな構成概念の名前だけを付けること |
| 外からの手応え | 測った結果が役に立つかどうかが、測定の外からはっきり返ってくること |

## 復習用の問い

1. ブリッジマンが長さを手続きごとに別の概念とみなしたのはなぜか
2. 操作主義の立場をとると、なぜ測定が「間違える」ことができなくなるのか
3. ベンチマークの漏れを問題にできるのは、どんな想定があるからか
4. クロンバックとミールは、外に基準のない構成概念の指標をどう確かめるとしたか
5. チャンの認識の反復を、温度計の定点の例で説明できるか
6. 手続きと結びつかない構成概念の何が困るのか、日常の例で言えるか

## 開いたままの問い

- 自分の評価で、街灯の下に戻りそうになるのはどんなときか。モデルの判定と自分の読みが揃いやすい種類の出力ばかりを、無意識に評価の対象に選んでいないか（→A-19 LLMを評価者として測定論で見る、A-17 アンカー事例）
- 外からの手応えが乏しい構成概念で、反復が揃っていくための条件は何か。観想的エージェントの振る舞いに、外から返ってくる手応えはあるか（→A-15 直観はいつ信頼できるか、B-14 較正）
- 「推論力」のような名前の借用は、言葉の争いとして扱うべきか、測定の欠陥として扱うべきか（→C-10 言葉の争い、C-17 AIが概念を割る）
