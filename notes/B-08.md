# B-08 ベイズ更新の連鎖と事前分布の役割

## 本編の要点

- 仮説の並び全体に配った見込みが事前分布。仮説ごとに事前と尤度を掛け、その合計 P(D) で割ると事後分布になる。P(H|D) ＝ P(H)×P(D|H)÷P(D)。合計で割るのは、証拠が出た場合だけに世界を狭める一手（B-04）。玉2個の袋で赤を一つ見ると、平らな事前 3分の1ずつから事後 0、3分の1、3分の2
- 事後の比は事前の比×尤度比（B-03 の事後オッズの形を分布で）。事前を 4分の1、2分の1、4分の1 に変えると、同じ赤一つでも赤2個の袋は2分の1。尤度の頂上がいちばんありそうな仮説とは限らないことが数になる
- 昨日の事後を今日の事前にし、尤度は新しい一回について出し直す。袋が決まれば一回ごとの取り出しが互いに影響しないなら、一つずつ更新しても、まとめても、順番を入れ替えても同じ事後に着く（赤、赤で 0、5分の1、5分の4）。掛け算は順番によらず、合計で割るのは仮説どうしの比を変えないから。ラプラス『確率の哲学的試論』（1814）に同じ袋の例がある
- 次の一回の予測は、仮説ごとの次の見込みを事後の重みで足したもの（B-05 の期待値と同じ形）。赤、赤のあと次も赤は10分の9。いちばんありそうな袋の見込みとも、その袋での予測とも違う
- 見込みが0から1のどれも同じくらいと置くと、n 回続けて起きたあと次も起きる見込みは (n＋1)÷(n＋2)（ラプラスの継起の規則）。猫が3日続けて来たら5分の4で、最尤推定の1に届かない。日の出の例でラプラス自身、仕組みを知る人の見込みはずっと大きいと書き添えた。等しく置く置き方には疑いがあり、考え方は割れている

## 概念表

| 概念 | 一言で |
|---|---|
| 事前分布 | 見る前に、仮説の並び全体に配った見込み。P(H) の並び |
| 事後分布 | 見たあとの、仮説の並び全体の見込み。P(H|D) の並び |
| P(D) | 仮説を分けずに見たとき、見た結果が出る見込み。すべての仮説の P(H)×P(D|H) の和で、割る数 |
| 事後の比＝事前の比×尤度比 | 二つの仮説の見込みの比は、見る前の比に、どれだけよく言い当てたかの比を掛けたもの |
| 更新の連鎖 | 昨日の事後を今日の事前にし、尤度は新しい一回について出し直して更新を続けること |
| 順番によらない更新 | 一回ごとの観測が袋のもとで互いに影響しないなら、一つずつでもまとめてでも順番を変えても同じ事後に着くこと |
| 予測分布 | 次の一回の見込みを、仮説ごとの見込みを事後で重みづけて足したもの |
| 三行の手順 | 仮説ごとに一行で事前、尤度、掛けたものを書き、掛けたものの合計で割る。行の数は仮説の数で決まり、並びの書き出しは要らない |
| 事後と次の見込みの区別 | 予測では、(a) その仮説である見込み（事後）と (b) その仮説なら次に起きる見込みを分けて掛ける |
| 継起の規則 | n 回続けて起きたあと次も起きる見込みを (n＋1)÷(n＋2) とするラプラスの規則。回数のほかに何も知らない人の出発点 |

- 練習の場面で、事前と説の中身（尤度のもと）に同じ数を使わない。同じ数があると、どの欄の数かの区別がつかなくなる（B-08 の対話）
- 「仮説」の語を、著者は誰かが唱える説として読みうる。「候補」「実際はどうなっているかの候補」と言い換え、事前と尤度を同じ候補に付く二つの欄として見せる（カードの絵）。B-09 以降で「仮説」が出るときに一度断る（→B-09）
- 説の中身が確率（毎日4分の3で来る）の場面は、事前と尤度の二か所の偶然がどちらも分数になり、著者には通りにくい。自然頻度（12の朝のうち何回）に直すと数えられる。テーマBの練習では、袋のように数えられる場面か、自然頻度の形を先に置く（仕込みで見直す印）
- 自然頻度で一つの事実（どちらの猫か）を「12の朝」として並べると、候補の朝と結果の朝が言葉の上で混ざる。並べるのは朝でなく、袋の棚や12軒の家のような、候補ごとに別々の物にする（仕込みで見直す印）
- 二つの候補を名前のある二匹の猫にすると、著者は二匹が同じ窓を分け合う場面として読んだ。候補が「どちらか一方だけが本当」であることを、場面の最初の一行で言い切る。袋のように、手元に一つしかないことが目に見える場面のほうが通る（仕込みで見直す印）
- 猫の場面（説の中身が来る見込み、二つの名前の候補、来なかったという結果）は、著者には何度言い換えても通らず、やめてほしいと言われた。袋の場面は通る。B-09 以降の練習は袋か、物を数える場面で始める（→B-09）
- 練習でも本文でも、事前を置くときは前提を一行で書く（「渡す人は四つの袋を同じ見込みで選ぶとする」）。「目をつぶって」「手がかりがないので」で済ませると、著者には自明でない数が黙って入ってくるように見える。B-08 の回の大半の引っかかりはここにあった（→B-09。仕込みで見直す印）
