# C-15 哲学とは概念の創造である

## 本編の要点

- ドゥルーズとガタリは『哲学とは何か』（1991年）で、哲学を新しい概念を作る営みとした。概念は空の星のように出来上がって待っておらず、作られねばならず、作った人の署名を帯びる。眺めること、振り返ること、話し合って意見を合わせることは哲学の仕事から外れる。広告や販売促進が「コンセプト」の語を手にし、吟味が売り込みに置き換わる流れを嘆いた
- 単純な概念は無い。どの概念もいくつかの成分を一つにまとめたもので、成分が一つだけの概念も、あらゆる成分を持つ概念（ただの混沌）も無い。どの成分を選ぶかは、その概念が応じる問題が決める
- デカルトの「我思う」の成分は、疑う、考える、在る。よく知られた読みでは、何一つ確かでないところから最初の足場を見つける問題に応じた。カントが時間を持ち込むと組み替わる。問えるのは正しかったかより、よく組まれているか。洗濯物の「干し日和」は、困りごとが変われば成分も重みも入れ替わる
- 受け継いだ概念をそのまま信じない出発点は概念工学と同じ（カペレンとプランケットの2020年の序章は同じニーチェの一節で始まり、ドゥルーズを哲学史を読み直す相手に挙げる）。違いは二つ（この講義の整理）。何を相手にするか（共同体で共有された語の意味か、署名のある一つ一つの概念か）と、何で測るか（その語を使う人たちが求める役目か、作る人の問題に照らしてよく組まれているか）
- 吹奏楽団の「少し速く」を団の決まりとして直すのは直す工学に近く、皆がそろうかで確かめる。曲順のために作った「息の借金」は作る仕事に近く、最後まで息が続いたかで確かめる。チャーマーズの新規設計（C-09）は作ることに近い所にある

- 講義のあとの対話。著者「うーん、今回のドゥルーズ•ガタリがこれまでと違うオリジナリティーは何？確かに一見世俗諦的と言うかポストモダン的と言う感じはするが。署名というのはどう言った事態を想定していたのだろう？何か制度的な回収を考えたのか？そういうタイプには思えない」。応答は独自さを三つにまとめた。(1) 概念を何として扱うか。これまでの回は概念を共同体の語の意味として扱い、欠陥を直して広める枠だった。二人の概念は語の意味でも命題でもなく、科学の関数や論理の命題と分けられ、真偽では測らない。立つ条件は、成分どうしが分けられないほど重なった内側のまとまりと、同じ平面（内在平面）の上でほかの概念とつながっていること。直す相手になる共有の語が出発点に無い。(2) 問題を立て直すところから始まる。概念はまずく立てられた問題、まだ分かられていない問題に応じて作られ、問題をどう立てるかまでが哲学の仕事に入る。(3) 合意を目指さない。コミュニケーションと合意を哲学の外に置き、C-08 の実装の問題を解いたのでなく問いの立て方ごと外した
- 同じ問いの、世俗諦的、ポストモダン的という印象について。応答は、二人は何でもありの相対主義ではない、と答え、記憶として、結論の章で意見（ドクサ）を混沌から身を守る傘のように描き、哲学や芸術はその傘を裂く側にいる、と書いていたはずだ、と述べた（本文で確かめていないと断った）。この読みが当たっていれば、皆で合わせた約束ごととしての世俗に近いのは二人の図では意見の側で、一方で普遍はそれ自体は何も説明せず説明されるべきもの（序論の抜粋で確かめた点）なので、概念は勝義の主張にもならない。概念は、勝義の普遍でも合意としての世俗でもない、日付と場所を持った組み立てとして置かれている、と読める、と応答の当てはめとして示した
- 同じ問いの、署名について。応答は、制度に回収する考えではないという著者の読みは当たっていると思う、と答えた。作られ、作った人の署名を帯びる、までは仕込みで確かめた点。そこからは記憶で本文を確かめていないと断ったうえで、二人が概念に作り手の名前が付いている例（アリストテレスの実体、デカルトのコギト、ライプニッツのモナド、ベルクソンの持続）を並べ、言葉の選び方（古い語を掘り起こす、奇妙な新語を作る、ふだんの語に別の響きを持たせる）も署名の一部としていたこと、署名は第3章の概念的人物（デカルトなら自分の頭だけで考えようとする素人、ニーチェならツァラトゥストラやディオニュソス）と結びつき、哲学者の名前はそうした人物たちを包む仮の名前のようなものと扱われていることを挙げた。署名が指すのは経歴を持った著者が持ち主になることでなく、この問題にこの人物を通してこの組み方で応じた、という作られ方の一回きりさ。制度の側では、広告や販売促進が概念を作る者を名乗る流れを嘆いていた（確かめた点）ので、署名には、概念が普遍に溶けないようにする働きと、ブランドの名前に置き換えられないようにする働きの両方がある、と読める（後半は講義の読み）。本体の英訳は、この実行の通信の設定で開けなかった
- 教案の備えを使った場面は、署名の答えのうち、署名を作った人が持ち主になることと読まない、という点（節1のつまずきの手当て）と、合意を外に置いたことを仕事の種類の線引きと読む点（根拠の割れている論点）。教案は内在平面と概念的人物を下書きに出さないと決めていて、対話ではじめて出た。その場で作った場面は、独自さの三つのまとめ、世俗と勝義への当てはめ、署名の二つの働き

## 概念表

| 概念 | 一言で |
|---|---|
| 概念の創造 | 概念は出来上がって待っておらず、作られ、作った人の署名を帯びる。哲学の仕事はこれを作ること |
| 観照、反省、コミュニケーション | 眺めること、振り返ること、話し合って意見を合わせること。二人はどれも哲学の仕事から外した |
| 成分 | 概念を形づくる要素。概念はいくつかの成分を重ね合わせて一つにまとめたもの |
| 問題が成分を決める | どの成分を選ぶかは、その概念が応じる問題による。困りごとが変われば成分も入れ替わる |
| よく組まれているか | 概念を正しいかでなく、問題に照らして組み方の出来で測る見方 |
| 作る哲学と直す工学 | 出発点は同じで、相手（共有された語か署名のある概念か）と物差し（皆の役目か作る人の問題か）が違う（この講義の整理） |
| 内在平面 | 概念がその上でほかの概念とつながる平面。概念は成分の内側のまとまりと、この平面の上のつながりで立つ（対話で出た。本文では出さなかった） |
| 概念的人物 | 哲学者の概念を考えている人物（デカルトの、自分の頭だけで考えようとする素人など）。哲学者の名前はそれらを包む仮の名前のようなもの（対話で記憶として出た。本文で確かめていない） |
| 意見（ドクサ）の傘 | 混沌から身を守るために人が差しかける傘としての意見。哲学や芸術はそれを裂く側にいる（対話で記憶として出た。本文で確かめていない） |

2. 夕方までに乾かしたい人の「干し日和」の成分は、晴れていること、風があること、空気が乾いていることの三つです。日に当てると色があせる服を干したい人の「干し日和」で、重く見る手がかりはどちらでしょうか。1 日差しが強すぎないこと、2 日差しが強いこと。答え　1（困りごとが変わると、同じ日差しが逆の向きに効く）
3. ある人が「よい散歩道」を「信号が少ないこと」の一つだけで決めました。この決め方で起きやすいのはどちらでしょうか。1 信号は少ないが、歩道が狭くて歩きにくい道まで「よい散歩道」に入る、2 どの道も迷わず正しく決まる。答え　1（成分が一つだけの概念は無い。それは目印の一つ）
4. 料理教室で、レシピの「ひとつまみ」がまちまちだったので、教室の決まりとして「指三本でつまんだ量」と決め直し、皆に使ってもらうことにしました。うまくいったかを確かめるとき、まず問うのはどちらでしょうか。1 教室の皆が、同じくらいの量を入れるようになったか、2 決め直した人が、塩加減について新しいことを考えやすくなったか。答え　1（直す工学に近い）
5. 旅行の荷造りでいつも迷う人が、重さ、旅先で手に入るか、なくしたときの困り方の三つをまとめて「置いていける度」と考え、持ち物の選び方を組み直しました。この考えがうまく組めたかを確かめるとき、まず問うのはどちらでしょうか。1 旅行好きの友人たちが、この言葉を同じ意味で使うようになったか、2 それで持ち物を選びやすくなったか。答え　2（作る仕事に近い）
