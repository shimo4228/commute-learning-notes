# B-18 自由エネルギー原理の式を読む

## 本編の要点

- F は一行で、F ＝ Σ q(s) × log2(1 ÷ p(o, s)) − Σ q(s) × log2(1 ÷ q(s)) と書ける。q を重みにした「観測で、しかも s」の驚きの平均から、q のエントロピーを引いた数。フリストン（2010年の総説）の F ＝ −⟨ln p(s̃, ϑ|m)⟩q ＋ ⟨ln q(ϑ|μ)⟩q と、底と文字が違うだけで同じもの（s̃ が観測 o、ϑ が隠れた原因 s）
- 新しい資料を開いたら、F が小さいほどよい量か符号を逆にした量か、観測と隠れたものがどの文字か、平均の重みをどの分布から取っているか、の三つをまず確かめる
- p(o, s) ＝ p(o) × p(s|o) と、掛け算の対数は足し算になる性質から、組の驚きは観測の驚きと観測したあとの驚きの和に分かれる。どの行にも同じ観測の驚きが入るので q で平均しても変わらず、F ＝ 観測の驚き ＋ KL(q||p(s|o)) がどんな q でも成り立つ
- KL は0より小さくならないので F ≧ 観測の驚き（上界）。観測の驚きは足しきれない p(o) が要るが、F は手元の q と p(o, s) だけで計算できる。q を動かして下がるのは KL の分だけで、その先は o か p が変わる必要がある
- 二つの式は計算のきまりで観測では外れない。自由エネルギー原理はそこに、q を生き物の内側の状態、p をその生き物のモデルと読む読み方を足す。p を後から選べるなら何でも説明できてしまい、前もって置けば外れうる（磯村ら 2023）。原理そのものの位置づけは、数学の推論とする側（ラムステッド 2024）と、予測は足した仮定から出るとする側（ガーシュマン 2019）で割れている

## 概念表

| 概念 | 一言で |
|---|---|
| F の一行の式 | q で重みを付けた組の驚きの平均から、q のエントロピーを引いた数 |
| 記号の対応 | 論文ごとに観測と隠れたものの文字が違う。q の括弧の中が隠れたもの |
| 組の驚きの分かれ方 | 「観測で、しかも s」の驚き ＝ 観測の驚き ＋ 観測したあとで s だった驚き |
| 上界 | いつもその上にある値。F は観測の驚きより小さくならない |
| q で下がる分 | q を動かして下がるのは KL だけ。観測の驚きは o と p で決まる |
| 式の話と生き物についての話 | どんな q と p でも成り立つ計算のきまりと、ある生き物の q と p を置いたうえでの主張 |
| F を出す四つの手順 | 組の確率を棚の全部で出す、驚きに直す、q の重みで平均する、q のエントロピーを引く（対話） |
| 0 × log の約束 | q が0を置いた行は、重みが0なので足し算に入れない。確率0の驚きそのものは限りなく大きい（対話） |
