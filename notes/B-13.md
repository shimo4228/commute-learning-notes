# B-13 相互情報量

## 本編の要点

- 条件付きエントロピー H(X|Y) ＝ Σ P(y) × H(X|y)。知らせ y ごとに、聞いたあとに残る色のエントロピーを出し、その知らせが何回に1回来るかを掛けて足す。聞く前に見積もる、聞いたあとに残る読めなさの平均。縦棒は given で、右が聞いた側。B-10 の 1.75 ＝ 1 ＋ 2分の1 × 1.5 の右の項がこの例の H(X|Y)
- 相互情報量 I(X;Y) ＝ H(X) − H(X|Y)。知らせを聞くことで、色の読めなさが平均でどれだけ減るか。I(X;Y) ＝ H(Y) − H(Y|X) とも書け、どちらの側から測っても同じ。セミコロンは二つの事柄の区切りで given ではない。シャノン（1948年）は、片方を知ってももう片方の読めなさが平均で増えることはないと示し、この量を雑音のある通信で伝わる情報の速さとして書いた。呼び名は後から付いた
- 実際の大きさ。シャノン（1951年）の英語の印刷文で、1文字の読めなさは出やすさだけでおよそ4.03ビット、直前の1文字を知るとおよそ3.32ビット。差のおよそ0.7ビットを直前の文字と次の文字の相互情報量と読むのは講義のための計算
- 相互情報量は当たる割合とは別のもの。いつも逆の色を言う友人ウは一度も当たらないが1ビット教え、のぞかずに硬貨で言う友人イは半分当たるが0ビット。計算に入るのは、聞いたあとに残る読めなさと、知らせが何回に1回来るかだけ
- 相互情報量は、色と知らせの組の実際の出方を左、関係が無いとした出方（掛け算の出方）を右に置いた KL ダイバージェンスに等しい。そこから、0より小さくならず、0になるのは色と知らせが独立なときだけ

## 概念表

| 概念 | 一言で |
|---|---|
| 条件付きエントロピー | 知らせを聞いたあとに残る読めなさの平均。知らせごとの残りに、その知らせが何回に1回来るかを掛けて足す |
| 相互情報量 | 聞く前のエントロピーから、聞いたあとの条件付きエントロピーを引いた値。どちらの側から測っても同じ |
| 当たる割合との違い | 言った色が合っているかは計算に入らない。言い方の癖が決まっていれば、一度も当たらなくても色を全部教える |
| 掛け算の出方 | 二つが関係なく決まるとしたときの組の見込み。P(x) × P(y) |
| KL で読む相互情報量 | 組の実際の出方を左、掛け算の出方を右に置いた KL。0は独立なときだけ |
| 知らせのエントロピー | 友人の言葉そのものが次に何になるかの読めなさ H(Y)。言葉が色で決まるときだけ相互情報量と同じ値になる |
| 減った分と残った分 | 聞く前のエントロピー ＝ 相互情報量（減った分） ＋ 条件付きエントロピー（残った分） |
| 二段の平均 | 知らせごとに残りを出し、それを知らせの来る回数でもう一度平均する。知らせの種類の数では割らない |
| 事後と事前の KL の平均 | 言葉ごとに事後 P(x|y) を左、事前 P(x) を右に置いた KL を出し、言葉の来る回数 P(y) で平均したもの。相互情報量と同じ値になる |
| 外側の重み P(y) | H(X|Y) ＝ Σ P(y) × H(X|y) の P(y) は縦棒の無いふつうの確率で、単位は無い。ビットは H(X|y) の側から来る |
| 二本の縦棒 | KL の D(P||Q) で二つの分布を区切る記号。given でも引き算でもない |
| KL の左と右 | この講義の呼び方。左（一つ目）は何回に1回出るかを取る平均の側、右（二つ目）は驚きを取る比べる相手 |
