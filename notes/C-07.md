# C-07 話題の連続性の問題

## 本編の要点

- 持ち帰る見分けは一つ。「それは同じ話か」と問われたら、元の問いがいまの意味のまま答えを求めていたのか、意味の見直しを含んで問われていたのかを先に確かめる。C-06 の付け足し（既存の語を借りるなら同じ話と言える理由が要る）とソール（2006）の心配（働いている概念が一つあると示しにくいなら、言い当てでなく意味を変える提案になる）を受けた問い
- ストローソン（1963）の心配。日常の概念について見通しを求める人に科学の用語の形式的な説明を差し出すのは、心臓の働きが分かればとため息をつく人に生理学の教科書を渡すようなもの。語 w を含む問い Q(w) に、意味を変えた w* で組んだ答えを返すと、それは Q(w*) への答えで、Q(w) への答えだと言うには別の理由が要る（記法は講義の整理）。鍋の「辛い?」に唐辛子の量で答える例
- カペレンの応答。意味の中身が少し違っても「二人とも同じことを言った」と報告できる関係（比べる相手の違う「大きい」）を手がかりに、概念を直して当てはまる範囲が変わっても同じ話題について話していると言える場合がある、とした（話題の保存）。話題は意味より粗く数える。「家族」の例。ベッレーリは、同じことを言ったかの判断が伝える場の目的で揺れるので、事例ごとに争えると指摘した
- ベッレーリ（2021）の区別。探究は、意味を変えないことを前提に始めることも、初めから意味の変化を許すものとして始めることもできる。許す探究では話題が動くことは予定のうちで欠陥ではなく、拠りどころは最初の問いに込めた目的の連続。子どもの「魚は卵を産むの?」は前者、天文学者の「惑星とは何か」は後者
- この区別で読むと、カルナップのポケットナイフと専用の道具の応答は許す探究に、ストローソンの心配は変えない探究に向いていて、二人は別々の始め方の問いを見ていた（講義の整理）。困りごとが出るのは、許す探究で得た答えを、変えたことを伝えずに変えない探究の場へ持ち出すとき（→C-08）

## 対話で出た論点

- 復習1（町内の「歩きやすい道」の地図二枚）への著者の答え。(ア)は「意図がよくわからない、事実は書いてあることそのままでは」。「目的に直接結びつく事実」という言い方が伝わらなかった。(イ)にベビーカーは歩道の整備と幅員、夜の一人歩きは街灯と防犯カメラと、目的に結びつく性質を挙げ、C-06 の乗り物の種類のような目印で定める形は出なかった。ただし (イ) は各地図の選び方を述べただけで、一本の道が一方に入り一方に入らない例は出なかった（C-06 の小問2と同じく、二つの基準を一つの物に当てる段が抜ける）。答え合わせで商店街と川沿いの遊歩道の例を示した
- 復習2（四つの場面の直し方）への著者の答え。適量は30〜35グラムと幅を決める、ゲームの二つの決まりを一つに書き直す、野草と雑草のリストを作る、家事の定義を広げる。四つとも直し方が分かれ、四条件の名前で答える形が初めて出なかった（台帳の弱点「欠陥の型」は、直し方を問う形で通った）。リストは外延を並べる分け方で、呼び名を分ければ口に出して区別できる、と添えた
- 復習3（C-04 問い5の場面版、料理教室の8人）への著者の答え。「使い方のデータなら隠し味を入れると美味しくなるという結論に寄与し、手がかりなら隠し味とおいしさの因果まで範囲に入る」。二つとも皿の側の読み方になっていて、語の当てはめ方の記録という読みが出なかった。著者の指摘「事実の手がかりという日本語は不自然で、どういう事態か分かりにくい」。皿についての証拠と、言葉についての記録と言い直し、10人が味の濃いものなら何でもおいしいと言う人たちなら分かるのは言葉の癖、という例を添えた。因果を言うには隠し味のない皿との比較が要ることも添えた
- 著者の「本文へ進んで」で、冒頭の三段落（ソールの心配からの受け、持ち帰る見分けの一行）と節1（別の問いに答えてしまう）と小問1（旅行の荷物の「軽い」）を出した

- 小問1（旅行の荷物の「軽い」）への著者の答え。(ア)「答えていない。現象学的な質感を聞いているのに測定された値を答えている」、(イ)「この荷物何キロ?」。両方正解。機内持ち込みの重さや前の旅行との比較も添えた
- 著者の見方「Thompson らの The Blind Spot のテーマそのもの」。Frank、Gleiser、Thompson の共著（著者は WebSearch で確認）。形は重なるが、ストローソンは問いに答えたかを問い、The Blind Spot は言い換えたことが忘れられ言い換えた側が本物と見なされる見えなさを問う、と違いを置いた。フッサールのすり替え批判を引き継ぐというのは講義側の理解で、本での扱いは未確認と断った。取り替えに気づいていれば Q(w*) への答えとして使え、困るのは忘れたとき。A-02 の構成概念と操作的定義のすき間と同じ場所、とつないだ
- 節2（話題は意味より粗く数える）と小問2（祖父と孫の「散歩」）を出した

- 小問2（祖父と孫の「散歩」）への著者の答え。(ア)「孫の自転車は普通は散歩とは言わない。サイクリングなら通るだろうが」、(イ)「歩いているかと聞かれた時」。(ア) は教案の答え（ふだんの会話なら伝えてよい）と逆で、例の作りが悪かったと認めた。柴犬の「大きい」は比べる相手のずれだけだが、自転車を散歩に含めるのはいまの使い方から外れる。カペレンの物差しは報告してよいという私たちの感じに頼り、どこまでの変化を許すかは物差しの外で決まる、判断が割れたことがベッレーリの「事例ごとに争える」の実例、と結んだ。著者の判断はいまの意味を基準にしていて、節3への橋にした。(イ) は正解
- 節3（連続を守らなくてよい問い）と小問3（卵のスープと時短料理）を出した
- 教案の小問2の例は、意味の変化が大きすぎて「ふだんの会話なら報告が通る」が成り立たなかった。比べる相手のずれ程度の小さな変化で作り直す必要がある（その場で答えを組み替えた場面）

- 小問3（卵のスープと時短料理）への著者の答え。(ア) 意味を変えない探究、(イ) 意味の変化を許す探究で、両方正解。店の人が卵の意味を決め直したら何が起きるかには答えがなく、答えを示した（話題の取り替えで、この場面では危険）。(イ) でもレシピ集の読み手に決め方を伝えないと行き違いが起きる、と添えた
- 三つの節を終え、今日の引っかかり（研究ハブの定義語を、宣言を知らずに検索や引用で出会った読み手はどちらの探究で読むか）と参考文献を出して講義を終えた。残った節はなし


- 著者の見方「達成を、昭和マインドなら苦しさを耐え忍んだ物語で、最近は楽しかった物語で語る。マインドの違いがある」。今日の道具で読んだ。「二人とも頑張ってやり遂げた話をしていた」と報告でき話題は続くが、何をもって頑張ったと言うかが違う。復習1の言葉で、やり遂げる目的に直接結びつく事実（続けた、手を入れた、戻ってきた）を、昭和は苦しさ、最近は楽しさという目印で測っていると読み、どちらの目印も事実とずれうるとした。目印が変わると「頑張った」の当てはまる範囲が動き、どちらの語りも誰かの働きを見えなくする向きを持つ（C-01 の欠陥の型）。世代差のデータは持っていないこと、語りは後から選ばれ空気に左右されることを断った。著者自身のサイクリングや研究はどちらで数えているか、と問いを返した（答えはまだ）

- 著者の見方「物事の達成をどう語るかは権力の誇示かもしれない。その時々に勢力のある物語にどれだけ貢献したかという」。二つの主張に分けた。(1) どの語りが通るかは勢いのある物語が決める。「頑張った」の目印は周りが受け取ってくれるかで決まり、C-08 の実装と制御の欠如で、通りやすさを誰が握るかを扱う。(2) 個人が達成を語ることは貢献の誇示である。人前の語りには当たるが、自分に言い聞かせる語りもあり、時代の言葉を借りて経験に形を与えていると見ることもできる。あわせて、権力で説明する読み方は C-06 で出た著者の否定の形の異議（代わりの基準を立てない）と同じ形で、なぜそう語られるかは説明するが、どう語るのがよいかは出てこない、ハスランガーならそこで誰の働きを見えるようにすべきかという目的を立てる、と添えた

## 概念表

| 概念 | 一言の説明 |
|---|---|
| 話題の取り替え | 語の意味を変えて答えると、元の問いでなく変えたあとの意味で読んだ問いに答えてしまうこと |
| 話題の連続性の問題 | 定義を直したあとも同じ話をしていると言えるか、という概念工学への心配 |
| 話題の保存（カペレン） | 意味の中身が少し変わっても「同じことを言った」と報告できるなら、同じ話題が続いているとする見方 |
| 話題は意味より粗く数える | 話題の同じさは、意味の中身の同じさより緩い基準で決まるということ |
| 報告の揺れ（ベッレーリ） | 「同じことを言った」と言えるかが伝える場の目的で変わり、話題の連続も事例ごとに争えること |
| 意味を変えない探究 | 語のいまの意味のまま答えを求める問いの始め方 |
| 意味の変化を許す探究 | 語の意味を見直すことを初めから含めて始める問いの始め方。話題の変化は欠陥にならない |
| 目的の連続 | 意味が動いても、最初の問いに込めた目的がつながっていること。許す探究の拠りどころ |
| ポケットナイフと専用の道具 | 日常の言葉は何にでも使える粗い道具で、決まった用途には専用の道具がよいというカルナップの応答 |

## 復習用の問い

1. 語の意味を変えて答えると、なぜ元の問いに答えたとは限らないのか。日常の例を一つ挙げて言えるか
2. カペレンは、意味が変わっても同じ話題が続いていると言える根拠を、ふだんのどんなやり方に求めたか
3. ベッレーリは、カペレンの数え方のどこが弱いと見たか。散歩や買い物の場面で、報告が通ったり通らなかったりする例を作れるか
4. 意味を変えない探究と意味の変化を許す探究を、場面を一つずつ挙げて見分けられるか。許す探究で話題が動いても欠陥にならない拠りどころは何か
5. カルナップのポケットナイフの応答とストローソンの心配は、二つの探究の区別で読むとどう食い違っているか
6. 許す探究で決め直した語を、そのことを伝えずに変えない探究の場へ持ち出すと何が起きるか

## 開いたままの問い

- 語りの通りやすさを誰が握るか。達成の語りの目印の移り変わりを、実装の問題（誰も意味の広まりを制御しきれない）の例として読めるか（→C-08、C-14）
- 権力で暴く読み方は、なぜそう語られるかを説明するが、どう語るべきかを出さない。C-06 の否定の形の異議と同じ型か（→C-14）
- 達成を苦しさで語るか楽しさで語るかは、「頑張った」の目印の取り替えと読めるか。著者自身はどちらで数えているか（返した問い、答えはまだ）
- 「直観の二つの読み方」は、問いの言い方（事実の手がかり）が不自然で、二つの読みが両方とも対象の側に寄った。次に出すときは「〜についての証拠」と「語の当てはめ方の記録」と言い、記録の読みでは対象について何も言えない場面（言葉の癖）で出す（台帳の弱点に残る）
- 二つの目的の定義を作れても、一つの物に二つの定義を当てて分かれるところを示す段が抜ける（C-06 の小問2、C-07 の復習1）
- 話題の取り替えが問題になるのは取り替えたことを忘れたときではないか。The Blind Spot の経験の忘却とストローソンの心配はどこまで同じ形か（→C-13 の科学の中の概念変化、A-02）
- 研究ハブの定義語を、宣言を知らないまま検索や引用で出会った読み手は、どちらの探究の中で読むのか（今日の引っかかり、→C-08、C-18、C-19）
