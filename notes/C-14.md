# C-14 概念の倫理

## 本編の要点

- どの概念を使うべきかという問いを、バージェスとプランケットは概念の倫理と呼ぶ。チャーマーズ（2011年）は冥王星の争いを、「惑星」をどう使うべきかを問う用語の倫理の争いとして読むのがいちばんよいとした
- 概念の倫理の「べき」には、何に照らしてという但し書きがいつも付く（バージェスとプランケット 2013年。原文は index と書く。この講義では C-10 の添え字の手と紛れないよう但し書きと呼ぶ）。カペレンとプランケット（2020年）は、主張の多くが「ある人々は、ある場面で、ある目的のために、ある概念の代わりに別の概念を使うべきだ」の形だとまとめた。誰が、どんな場面で、何のために、の三つの欄。但し書きの違う二つの評価はどちらも正しくありうるが、但し書きをそろえれば評価は決まりうる
- ブリガントの知ることの目的は「何のために」の欄に入る一つの値と見られる（この講義の整理）。ブリガントとロサリオ（2020年）は、目的ごとに概念を使い分ける構えを社会の目的にも広げた
- 目的は人が実際に追っているもの、善は追っていなくても大事なもの（この講義の言い方）。善には道徳と政治の善のほか、知ることの善も入る。カールの思考実験で、二人は目的だけで決める考えを退け、善のほうが基礎にあるかもしれないとしたが、目的がどれほどどのように大事かは開いた問いとして置いた。すべての善を考え合わせた一つの評価がありうるかは割れている
- 変えたい古い意味を理由の中で使って、その意味を手放すよう説く議論は、偽善と責められうるが、相手の言葉で語る美徳とも言え、二人はあとで蹴り倒すはしごを登る比喩を挙げた。退けたい側に責めがある一方、自分の足場を崩す心配は決着していない。勧めたい新しい意味を理由の中で使う議論を、バージェス（2020年）は論点先取に見えるとした（はしごを登る議論、輪の議論という一組の名前はこの講義の整理）

## 概念表

| 概念 | 一言で |
|---|---|
| 概念の倫理 | どの概念を使うべきかを問う営み。「倫理」は道徳に限らない（バージェスとプランケット） |
| 用語の倫理 | 語が何を意味すべきかという問い。チャーマーズはパースの言葉を借り、冥王星の争いをこれとして読んだ |
| 但し書き | 概念の「べき」にいつも付く、何に照らしての部分。原文の index（この講義の呼び方） |
| 三つの欄 | 誰が、どんな場面で、何のために。カペレンとプランケットの主張の形から取った |
| 但し書きの違う評価 | 同じ決め方へのよいとよくないは、但し書きが違えばどちらも正しくありうる。何でもありとは違う |
| 戦略的な概念工学 | 目的ごとに一つの概念を使い、別の目的には別の概念を使うことに開かれた構え（ブリガントとロサリオ） |
| 目的と善 | 目的は実際に追っているもの、善は追っていなくても大事なもの（この講義の言い方） |
| カール | 当選だけが目的の政治家の思考実験。目的と社会の正しさという善が分かれる場面 |
| 知ることの善 | 考えの整合や、正当な理由のある信念を助けること。道徳の善と並ぶ善の一つ |
| はしごを登る議論 | 理由の中で変えたい古い意味を使い、その意味を手放すよう説く議論（この講義の呼び方） |
| 輪の議論 | 理由の中で勧めたい新しい意味を使う議論。論点先取に見える（バージェス 2020年） |
| 論点先取 | 示したい結論を、理由の中にすでに入れてしまうこと |
