# B-17 変分推論の直感

## 本編の要点

- 事後分布 p(s|o) ＝ p(o, s) ÷ p(o) の分母 p(o)（エビデンス、観測そのものの見込み）は、候補すべての p(o, s) を足したもの。候補一つの p(o, s) は掛け算一つで出るが、隠れたものが何個もあると候補は組み合わせの全部になり（硬貨20枚で100万通り超）、切れ目なく続くと積分になって、足しきれなくなる。o は observation（観測）、s は state（状態）
- 変分推論は、こちらで選んで動かせる分布 q(s)（近似分布）を事後分布の代わりに置き、KL(q||p(s|o)) で近さを測って近づけるやり方。左に q を置くので、平均の重みは q から取る。棚の例（事後 2分の1、4分の1、4分の1）で、袋アだけの q は1ビット、袋アと袋イに半分ずつの q は0.5ビット。ただしこの KL も分母がないと計算できない
- ELBO（evidence lower bound）は E[log2(p(o, s) ÷ q(s))]（重みは q から）で、分母を使わずに計算できる。log2 p(o) ＝ ELBO(q) ＋ KL(q||p(s|o)) が成り立ち、KL は0以上なので ELBO は log2 p(o) を超えない。log2 p(o) は q によらないので、ELBO を上げることがそのまま KL を下げることになる。棚の例で袋アだけの q は ELBO −2、事後分布そのものの q は −1（log2 p(o) と同じ）
- ELBO の符号を逆にした量が変分自由エネルギー F で、B-18 の主役
- 大きな世界では q も扱いやすい形の集まり（族）から選ぶ。よく使う族は硬貨ごとの見込みを掛ける独立な形で、つながりを書けない。この向きの KL は、q が0を置いた所は足さず（取りこぼしに甘い）、事後分布が0を置いた所に q が見込みを置くと限りなく大きい（はみ出しに厳しい）。そのため q は事後分布の一部に縮こまり、狭く自信のありそうな形になりやすい。「同じ面」と分かった2枚の硬貨では、独立な q は片方の山（2枚とも表）に寄る。どちらの向きの物差しがすぐれているかは、残したい性質で決まり、割れている

## 概念表

| 概念 | 一言で |
|---|---|
| エビデンス p(o) | 観測そのものの見込み。候補すべての p(o, s) の合計で、事後分布の分母 |
| 分母が重い | 候補が組み合わせで増えたり切れ目なく続いたりすると、エビデンスの足し算が手に負えなくなること |
| 近似分布 q(s) | 事後分布の代わりに置く、こちらで選んで動かせる分布 |
| 変分推論 | q を KL で測って事後分布に近づけるやり方 |
| KL(q‖p(s\|o)) | q を左に置いた KL。重みは q から取り、q が0を置いた候補は足さない |
| ELBO | E[log2(p(o, s) ÷ q(s))]。分母なしで計算でき、log2 p(o) を超えない下界 |
| log2 p(o) ＝ ELBO ＋ KL | q によらない左辺が、ELBO と KL に分かれる。ELBO を上げることは KL を下げること |
| 変分自由エネルギー F | ELBO の符号を逆にした量（B-18） |
| 族と独立な形 | q を選ぶ扱いやすい分布の集まり。独立な形は見込みを掛け算で出し、つながりを書けない |
| 近似が狭くまとまる癖 | この向きの KL は取りこぼしに甘く、はみ出しに厳しいので、q は事後分布の一部に縮こまりやすい |
| 逆向きと前向きの KL | 今日の KL(q‖p) を逆向き、入れ替えた KL(p‖q) を前向きと呼ぶことが多い。呼び名は資料で違う |
| 変分自由エネルギー F ＝ 観測の驚き ＋ KL | KL と同じ手順で、右に手元の p(o, s) を置いた数。正の数で小さいほどよい。観測の驚きは q によらないので、F が小さい q ほど KL も小さい |
| 二つの表のずれとしての KL | 重みは左の表、驚きは右の表から取る。左が0の行は見ない。右が0で左に重みがある行は限りなく大きい |
| 入れ替えた向きの KL(正しい答え‖q) | 重みを正しい答えから取るので、落としたものを厳しく数える。正しい答えが無い本番では計算できない |
| F を下げる手続き | q を少し動かしては F を出し、下がるほうへ進む。近くの谷底で止まり、ほかの谷があるかは F からは分からない |
| LLM の学習との違い | 隠れた s を立てず、実際の次の語が答えとして手元にあるので、KL(データ‖モデル) の向きを損失として直接下げる |

4. F ＝ 観測の驚き ＋ KL で、観測の驚きは q によらない決まった数ですが、値は分かりません。同じ観測について二つの代わりの分布の F を計算すると、q1 が8ビット、q2 が6ビットでした。正しい答えに近いのはどちらでしょうか。1 q1、2 q2、3 観測の驚きが分からないので言えない。答え　2（差の2ビットは、そのまま KL の差）
5. 赤が出たこと自体の驚きが2ビットの場面で、ある代わりの分布の F を計算したら1.5ビットになったと友人が言いました。この計算はありうるでしょうか。1 ありうる、2 ありえない。答え　2（KL は0より小さくならないので、F は2ビットを下回らない）
6. 事後分布が、同じ重さの離れた二つの山を持っています。一つの山しか表せない形の代わりの分布を、q を左に置いた KL で近づけると、q はどうなりやすいでしょうか。1 片方の山に寄る、2 二つの山のあいだに広がる。答え　1（事後分布が0に近い谷に見込みを置くと KL が大きくなり、取りこぼしは安くしか数えない）

## 開いたままの問い

- F ＝ 観測の驚き ＋ KL がいつも成り立つことは、棚の数で確かめただけで、式ではまだ開いていない。補強で符号を F にそろえたので、次は F を既習として始められる →B-18
- 二つの表が並ぶと、右が0の行で、重みに確率の0をそのまま掛ける形が二度出た。確率を驚きに直してから掛ける一手を、表が並んだ場面で確かめたい →B-18
- F や KL を、見る行を絞ってもらわずに自分で組み立てられるかは、まだ確かめていない →B-18
- 広く持ったまま動いて、入ってきた観測で絞る、という形は、行動で観測を取りに行く話につながる。期待自由エネルギーは今日の F と別の量 →B-19
- 言い切って外れたときの痛みは、今日の向きの KL には映らない。Contemplative Agentが憲法の修正のたびに何かを言い切る形へ寄るとしたら、落とした山があったことをどこで見分けられるか。B-12 の引っかかり（新しい版と古い版のどちらを左に置くか）の続き
- 白黒をはっきりさせる人、なかなか決めない人を、物差しの向きと q の書き方の広さで読むたとえは、どこまで当たっているか。同じ材料から出発点の違う人が別々の結論に強い自信で着く、という印は、実際に見分けに使えるか
- 答えの付かない環境に置かれた主体の更新に F の枠を足すとき、隠れた状態の一つ一つに確率としての数をどう置くのか。較正された確率を返す小さな判定器を外した経験と同じ継ぎ目 →テーマDへ
- LLM の学習が KL(データ‖モデル) の向きで、広く覆う側に寄る、という読みは、LLM のふるまいの何を説明し、何を説明しないか →テーマDへ
- 新しい資料を開いたら、まず記号の対応（F は正の数か、KL の左はどちらか、重みはどの分布から取るか）を取る。自由エネルギー原理の文献の式と、今日の F ＝ 観測の驚き ＋ KL との対応を、B-18 の最初に一度取る →B-18
- 自由エネルギー原理は何でも説明できて外れる予測を出さないのではないか、という批判は、式が読めたあとにどう見えるか。式の話と、生き物はこうしているという解釈の話を分けて読む →B-18、B-19
- 物理の言葉で心や社会を語る記事を読むときの三つの問い（手で回せる小さな例があるか、何が起きたら外れか、借りた概念が元の分野の意味のまま使われているか）。三つ目は、借りた概念の話題の連続性の問い（C-07）にあたるのか →テーマC
- Laukkonen の記事「Misaligned agents will lose」（2026年）の、局所の最適化と全体の同期の釣り合い（臨界）が整合と能力の共通の条件だ、という主張は、手で回せる小さな例と、外れる観測を持つか。著者が聞いた「今のモデルは局所最適」という言い方の出どころは確かめられていない →テーマE
