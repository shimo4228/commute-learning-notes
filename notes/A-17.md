# A-17 事例で基準を共有する

## 本編の要点

- 段階の言葉だけでは、どこからがその段階かがぼやける。言葉の横に置いて、言葉が指すところを具体的な作品で示す見本をアンカー事例と呼ぶ。サドラー（1987年）は、言葉と注釈を付けた見本を組み合わせて基準を示すことを勧め、典型の見本に加えて、段階にぎりぎり届いた境目の見本に触れた。判断が割れやすいのは境目だから
- 評定者の較正は、評価する人の判断を、点の決まった見本や仲間の判断に照らして、集まりの基準に合わせること。サドラー（2013年）は、較正されるのは作品の束でなく評価する人だとした。確かめるのは、練習の見本でなく、新しい見本への判断。ウェイグル（1998年）では、訓練のあとも評定者どうしの厳しさの違いが残った。テーマBの第14回の確率の較正とは、照らす相手が違う
- 中の一致だけでは、皆がそろってずれていることは見えない（第10回の古い相場の本と同じ形）。モデレーションは、ある集まりの付けた点を、外の評定者が見本を付け直して確かめ、許容幅を超えるずれがそろっていれば、全員の点をまとめて直す手続き。イングランドの課題作品の例では、直された生徒の8割あまりが点を下げられた
- 評定者のドリフトは、時がたつにつれて評定者の厳しさが少しずつ変わること。同じ場で同じ作品を見る人たちは一緒に動くことがあり、そうなると揃ったまま全体が動く。厳しさが短い期間に動くとする研究と、かなり安定した癖とする研究があり、見方は割れている
- アメリカの全国学力調査は、前の回の答案を点を伏せて今回の答案に混ぜて採点させ、今の目が前の目と同じかを確かめる。食い違ったとき、どちらの目が正しいかはこれだけでは決まらない。前回の判断の一致を、見本で作り、外の目と前の年の見本に照らして確かめる、とまとめた（この講義の整理）

- 復習2（B-15 から、計算。毎朝の雨の見込みを一つの数で言い、失点は言った数と「降ったら1、降らなければ0」の差の2乗。10日のうち8日降ると思っている友人が毎朝「8割」なら10日の失点の合計は1.6。毎朝「7割」なら）に、著者「8割の計算どうだったっけ？」。応答は「8割」の1.6を、降った8日と降らなかった2日に分けて数えて見せ、同じ数え方で「7割」を問い直した。著者「0.3^2*8+0.7^2*2=0.09*8+0.49*2=0.17」、続けて「1.7」で通った（式の立て方は合い、0.17 は桁の打ち間違いですぐ直した）
  - 応答は、数え方を見てから同じ手順をなぞったので、思っているとおりがいちばん得、までは読み取れないとして、確かめを一往復足した（同じ友人が毎朝「9割」と言ったら、10日の失点の合計は1.6と比べて。1 大きい、2 小さい）。「2」で外れた（答えは1。9割も1.7）。応答は同じ手順で数えて見せ、高く言うと降った日の失点は8日分で0.24減るが、降らなかった日の失点が2日分で0.34増える、2乗は大きく外したときほど急に重くなる、と添え、低く言っても高く言っても思っているとおりより失点が増える、テーマBの第15回の適正な採点、とまとめた。講評で、降る日が多いのだから1に近く言うほうが得そう、という感覚は自然で、この採点はその感覚がちょうど釣り合うところに思っているとおりの数が来るように組まれている、と述べた
  - 見立て　理解の側。一日の失点の数え方（降った日と降らなかった日に分けて2乗して足す）を名前と場面から呼び戻せなかったことと、思っているとおりがいちばん得になることを、高く言う側で持てていなかったこと（降る日が多いなら1に近いほど得、という感覚に引かれた）。手順は、示されたあとは「7割」で通った。確かめは教案に無く、その場で作った

## 概念表

| 概念 | 一言で |
|---|---|
| アンカー事例 | 段階の言葉の横に置いて、その言葉が指すところを具体的な作品で示す見本 |
| 境目の見本 | その段階にぎりぎり届いていると見なされる見本。判断が割れやすいところで見比べる相手になる |
| 評定者の較正 | 評価する人の判断を、点の決まった見本や仲間の判断に照らして、集まりの基準に合わせること |
| モデレーション | 集まりの付けた点を、外の評定者が見本を付け直して確かめ、ずれていれば全体を直すこと |
| 評定者のドリフト | 時がたつにつれて、評定者の厳しさが少しずつ変わっていくこと。皆で一緒に動くと中の一致からは見えない |
| 前の回の答案を混ぜる | 点を伏せた前の回の答案を今回の採点に混ぜ、今の目が前の目と同じかを確かめる手立て |

## 復習用の問い

1. 料理教室で、卵焼きを「合格」と「もう一歩」に分けていますが、生徒によって判定が違います。言葉の横に見本を一つ足すなら、効きやすいのはどちらでしょうか。1 これまででいちばん上手に焼けた卵焼き、2 合格の中で、もう一歩にいちばん近い卵焼き（答え　2。アンカー事例のうち境目の見本。A-17 の小問1の「いちばん出来の低かった」は悪い見本に聞こえ、出し直しの「分かれ目のあたり」は問いの「割れ」と重なったので、どちらも使わない）
2. 盆栽の品評会に新しい審査員が加わり、点の決まった過去の鉢で練習しました。目が会の基準に合ってきたかを確かめるのに、よいのはどちらでしょうか。1 練習した鉢で、決まった点との差が縮んだかを見る、2 点の決まった別の鉢を採点してもらい、決まった点に近いかを見る（答え　2。評定者の較正）
3. あるパン教室の先生たちが、生徒のパンに付けた点はよく揃っていました。外の審査員が何個かを付け直すと、どれも教室の点より1点低くなりました。付け直していないパンの点は、どうするのが近いでしょうか。1 そのまま認める、2 同じように下げる（答え　2。モデレーション）
4. 三十年続く町の写真展で、審査員の目が皆そろって昔より甘くなっていないかを確かめたいと思います。よいのはどちらでしょうか。1 今年の審査員どうしの点が揃っているかを見る、2 昔に点を付けた写真を、点を伏せて今年の写真に混ぜて付けてもらう（答え　2。評定者のドリフト）
5. 町の写真展の審査員五人の点は、毎年とてもよく揃っています。外の審査員に何枚か付け直してもらうことは、要るでしょうか。1 揃っているので要らない、2 揃っていても要る（答え　2。中の一致は皆がそろってずれていることを見せない。「揃っている」と「当たっている」を並べた二択は、ふだんの感覚で答えが透けるので使わない）
