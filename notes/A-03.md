# A-03 信頼性

## 本編の要点

- 古典的な測定理論では、観測値 = 真の値 + 誤差 と置き、信頼性を観測値のばらつきのうち真の値のばらつきが占める割合とする。真の値は同じ手続きを繰り返したときの平均で、構成概念そのものとは限らない
- 信頼性は道具だけの性質ではなく、何を並べて測るか（区別したい違いの大きさ）にも依存する。確かめ方には再テスト、内部一貫性、評定者間の一致がある
- コーエン（1960）のカッパ係数は、偶然の一致を差し引いて一致を測る。カッパ =（一致率 − 偶然の一致率）÷（1 − 偶然の一致率）。一致率0.8でも、判定が半々なら0.6、ほとんど合格なら0を下回る
- ファインスタインとチケッティ（1990）は、一致率が高いのにカッパが低く出る逆説を整理し、合格側と不合格側の一致を別々に報告することを勧めた。欠点か当然の帰結かは意見が分かれる。一致（同じ点数を付ける）と相関（順位が揃う）は別の性質
- スピアマン（1904）は、測定誤差が二つのものの関係を薄めて見せることと、信頼性による補正を示した。信頼性が低いと網の予想（A-02）も確かめられない。一方、いつも同じ向きにずれる測り方は信頼性が高く出るので、信頼性は狙いに当たっているかを教えない
- 観点を狭めれば揃うので、信頼性を通じて街灯効果が入り込む。言語モデルの評価者では、同じ文面・温度を下げての再判定は揺れを表に出しにくくするだけかもしれず、判断に関わらないはずの条件（言い回し、並び順、前置き）を変えて揃うかを見る方が、測定の意味での信頼性に近い

## 対話で出た論点

- 復習（操作主義で測定が間違えられなくなる理由）への著者の答えは「間違えないような測定基準を操作できてしまうから」。基準を都合よく動かせる、という読みはグッドハートの入口としては当たっているが、問いの芯は定義の形にある。意味が手続きそのものなら、手続きの外に照らす相手がないので、測り損ねを言う言葉がそもそも無い。操作できるかどうか以前に、ずれを言える場所が消える
- 復習（再現性と広さ）への著者の答えは「対象を狭く厳密にすると広さとトレードオフ」。要点は合っている。補うなら、狭めることで消えるのは判断の余地で、揃いにくいけれど価値のある部分から先に落ちる（本文の第3節につながる）
- 著者の問い。「雨」0.6、「雨でない」0.6 は合計1.2で、それ自体が矛盾ではないのか。答えは、合計が1を超えること自体が確率の公理に反しているが、それを「矛盾」として感じられる形にしたのがダッチブックの議論。信念0.6を「1000円券に600円まで払ってよい」と読むと、二枚で1200円払って必ず1000円しか戻らず、どちらの天気でも200円失う。信念の数字が賭けの値段として振る舞うとき、公理違反は確実な損として表に出る。論理的に両立しない文を二つ信じているわけではないので、論理の矛盾とは違う種類の不整合
- 著者の受け止め。操作主義で比較対象が消えるのは、公理系の話と同じに聞こえる。けれど人間の知性は何かを定めないと始まらない。以前読んだ『仏教哲学序説』に、四諦はトートロジーになっているという主張があった。自分は、何か一つを疑いようもなく信じること、つまり賭けがないと始まらないと思っている
- 公理系との違い。公理は体系の内側では疑われないが、その体系が世界に当てはまるかという別の問いは外に残る（ユークリッド幾何と物理空間）。操作主義は定義と当てはめを一つにしてしまうので、その外の問いが消える。始点を置くこと自体は問題ではなく、始点の当否を問える場所を残すかどうかが分かれ目
- 四諦がトートロジーに見えるのも同じ形かもしれない。苦と渇愛を互いで定めれば、命題としては定義上正しくなる。それでも道諦の実践の側から手応えが返るなら、体系の外に照らす相手があることになる（A-02 の外からの手応え）
- 「疑いようもなく信じる」と「賭け」は少し向きが違う。賭けは負けうることを認めたうえで張るもので、負けのない賭けは賭けにならない。ウィトゲンシュタインの『確実性の問題』の蝶番のように、疑いの前提として疑わずに使うものと、チャンの認識の反復やノイラートの船のように、仮の出発点として張り、ずれが出たら直すものとがある。操作主義は負けようのない賭けを張る形と読める
- 著者の答え。始点は賭けに近い。大谷翔平のようになりたい子どもが、大谷のしてきた練習を自分なりにアレンジしながらやってみて近づこうとする。仏教はここに「真理である」という観点が入るのでややこしくなるが、構造としてはこういうことだと思う
- この例では、目標が定義でなく一人の人物（手本）として外に立っている。練習を全部まねても近づけないことがありうるので、賭けは負けうる。操作主義と違って比べる相手が消えていない。アレンジは、手本とのずれを手がかりに練習を直す認識の反復の手つき。手本で基準を共有する点は A-17 のアンカー事例や、クーンが『科学革命の構造』の後記でパラダイムの中身として挙げた範例に近い
- 測定の問いも残る。「大谷に近づいた」を何で見るかは子どもが選ぶ構成概念で、見えやすい練習の形だけをまねると街灯効果になる。手本を成り立たせたもののうち見えないもの（体の条件、判断の速さなど）は写せない
- 仏教で「真理である」が入ると何が変わるか。手本が真理だと言われると、近づけなかったときの負けが手本や道の側でなく、実践者の側に帰されやすくなる。賭けの負けがどこに付くかが固定されるので、構造は同じでも賭けの性質が変わるのかもしれない（未決）
- 著者の問い。操作主義の「内と外が一緒になる」が分からない。自分は定義した基準を常に自明視しないから、同じ問題に見えるだけか
- 答えは後者に近い。「内と外」は言い方が悪かった。言い直すと、操作的定義を使うことと、操作主義という立場をとることは別。操作的定義は「いまはこの手続きで測ることにする」という道具で、手続きが狙っている相手が別にいるので、手続きが外れることを言える。操作主義は「意味はその手続きそのもので、狙っている相手は別にいない」という意味についての主張。体重計で言えば、前者なら別の体重計と食い違ったときに「この体重計が狂っている」と言え、後者なら「体重計ごとに別の体重がある」としか言えない
- 著者のやり方は、操作的定義は使うが操作主義はとらない側。基準を自明視しないというのは、手続きの向こうに狙っている相手を残しているということ。公理系や四諦と同じ問題に見えたのは、どれも「何かを始点に置く」点で共通しているからで、違いは始点を置いたあとでそれが外れうると考えるかどうか
- 小問（いつも1点低いBさん）への著者の答えは「得点の一致では信頼できないが、正規化すれば極めて信頼できる」。正解。正規化は差を評定者の厳しさという癖として取り除く操作で、ラッシュモデル系統で評定者の厳しさを推定する広げ方（A-01）と同じ発想
- 補足三つ。決まった線（4点以上の店に行く）で使うなら一致が要り、正規化では済まない。一点の差が癖でなく情報（外の基準から見てどこもそこそこというBさんの見立て）なら、正規化はそれも消し、どちらかは二人の点数の中からは決まらない。5段階でいつも一点低いならAさんは1点を付けていないはずで、目盛りの端ではずれが一定とは限らない
- 著者の受け止め（今日の引っかかりについて）。試行を繰り返して平準化し、つまらないものになるより、一回限りの評価で終わらせたい。だがそれだと再現性がない。口コミの例も、そもそも数値化にそぐわない気がする。宿の良し悪しが体験を決めるという文脈の貧しさにも同意できない。体験を数値に丸めることに抵抗がある。数学とアートの対立のようなもので、『The Blind Spot』でトンプソンらが議論していた話
- 繰り返しの目的は平均に限らない。結論は一回目の判断のまま残し、並び順や言い回しだけ変えた再判定は、その判断がどれだけ揺れうるかを知る点検にだけ使う（平均しない）という分け方がある。並び順で結論が裏返るなら、一回目に読んでいたものの一部は作品でなく並び順だったという知らせになる。それを受け取らないと決めるのも筋の通った選択だが、何を受け取らないのかを知ったうえで決める方がよい
- 口コミの例は、良し悪しが宿の側にあり泊まり手ごとのばらつきは誤差という古典的な測定理論の置き方をそのまま持ち込んでいた。エナクティヴな見方では体験は宿と泊まり手の関係で生まれ、誤差とされる部分の多くは関係そのもの。一般化可能性理論（クロンバックら 1972）は評定者と対象の組み合わせに固有の分を別の成分として取り出せるが、関係を成分として切り分けられるとみる点で外からの分解であることは変わらない
- 『The Blind Spot』（フランク、グレイザー、トンプソン 2024）はフッサールの「ひそかなすり替え」を出発点にする。体験から抽象した量を体験より実在的とみなし、元の体験を忘れること。著者の抵抗は数字そのものより、このすり替えに向いているのかもしれない。チャンの温度計も出発点は触れた温かさで、目盛りの改良は問題でなく、目盛りを本物の温度とし、触れた温かさを不正確な近似とみなしはじめたところですり替えが起きる
- 土地評価も最後は価格に丸めるのに、著者はそこに同じ抵抗を感じていないように見える。数字が体験の代わりを名乗らず、取引という別の実践に渡す形として置かれているからか（未決）
- 著者の答え。土地評価は直接税という形で不利益を与えるので、アートでは済まない
- 数値化にそぐうかは対象の性質だけでなく、判断で誰が不利益を受けるかで決まる。課税評価の再現性は公平の要求そのもので、同じ条件の土地に評価者ごとに違う税が付くなら、そのばらつきは誤差でなく不公平。審査の申出のような不服の道も、評価のたびに結論が変わるなら争う対象が定まらないので、再現性を前提にしている
- 信頼性がどれだけ要るかは判断の使われ方から決まる。メシックの結果的妥当性（→A-05）を信頼性の側から言い直した形
- llm-as-judge への当てはめ。結果を引き受けるのが著者自身だけなら一回限りのアートでよい。判断が観想的エージェントの憲法修正を通すかを決め、その修正が誰かに影響するなら、課税の側に寄る。結論に異議を唱えられる形にするには、ある程度の再現性が要る（AAP の責任帰属につながる）
- 著者の受け止め。難しい。口コミ（体験の質）は宿泊料金を決めもする。ただ、少なくともそれを決めるのは宿泊客ではない
- 書く行為と、集計して使う行為を分ける。一回限りの体験を星や言葉にするのはアートのままでよく、不利益が生まれるのは多くの口コミを平均して順位や料金に使う段階。そこを担うのは集計する側と値段を決める宿の側で、再現性の要求と責任はそこにかかる。ばらつきを平均して宿の性質として扱うところで、ひそかなすり替えも起きる
- B-02 のシンプソンが一回の判定の中でなく集めて比べる段階で起きる、という話と同じ形。llm-as-judge でも、一つひとつの判定は一回限りのアートとし、集めて何かを決める段階に再現性と責任を置く分け方がありうる
- 口コミが料金を決めるようになると、宿は星を上げることを目標にしはじめ、体験をよくすることとずれる（→A-06 キャンベルの法則）

## 概念表

| 概念 | 一言で |
|---|---|
| 信頼性 | 同じものを測れば同じ値が出る度合い。真の値のばらつきが観測値のばらつきに占める割合 |
| 真の値 | 同じ手続きを何度も繰り返したときの平均。構成概念そのものとは限らない |
| 測定誤差 | 観測値と真の値のずれ。でたらめな向きに入る |
| 再テスト信頼性 | 時間をおいて測り直して揃うか |
| 内部一貫性 | 一つのテストの中の問いどうしが同じ方向を向いているか |
| 評定者間の一致 | 別の人が同じものを評価して揃うか |
| カッパ係数 | 偶然の一致を差し引いた一致の指標 |
| 偶然の一致率 | 二人がでたらめに判定しても揃う割合。判定の偏りで大きくなる |
| カッパの逆説 | 一致率が高いのにカッパが低く出る現象 |
| 一致と相関 | 同じ点数を付けることと、順位が揃うことは別 |
| 希薄化 | 測定誤差が二つのものの関係を弱めて見せること（スピアマン） |
| 操作的定義と操作主義 | 手続きで測ると決める道具と、意味は手続きそのものだという主張。前者は外れを言え、後者は言えない |
| 正規化 | 評定者ごとの厳しさの癖を差し引いて比べること。癖でなく情報だった差も一緒に消える |
| 揺れの点検 | 結論は一回目のまま残し、条件を変えた再判定は揺れの大きさを知るためだけに使うこと |
| ひそかなすり替え | 体験から抽象した量を体験より実在的とみなし、元の体験を忘れること（フッサール、『The Blind Spot』） |
| 一般化可能性理論 | 測定のばらつきを評定者、対象、その組み合わせなどの成分に分ける枠組み |
| 異議の前提としての再現性 | 結論に異議を唱えるには、結論がある程度再現できる必要があること |
| 書く行為と集計して使う行為 | 一回限りの判断と、それを集めて何かを決める段階。再現性と責任は後者にかかる |
| 条件を変えた再判定 | 判断に関わらないはずの条件を変えても結論が揃うかを見ること |

## 開いたままの問い

- 自分が始点として置いている賭けは、疑わずに使う蝶番か、負けうる仮の出発点か。負けうるなら、何が返ってきたら負けとみなすか（→A-16 規則は自らの適用を決めない、A-15 直観はいつ信頼できるか）
- 四諦がトートロジーに見えるとき、道諦の実践から返る手応えは、体系の外からの手応えと言えるか。それとも体系の内側で解釈されてしまうか（→C-07 話題の連続性の問題）
- 手本への賭けで、近づけなかったときの負けを手本の側に付けるか、自分の側に付けるかは、何で決まるか。「真理である」という主張は、その付け先を固定してしまうのか（→A-17 事例で基準を共有する、C-11 本質的に論争的な概念）
- 評定者どうしの差を、正規化して消す癖とみるか、残すべき情報とみるかは、何で決まるか。自分の eval でモデルどうしの判定がずれたとき、どちらとして扱っているか（→A-10 ノイズ、A-17 事例で基準を共有する）
- 体験を数値に丸めることへの抵抗は、数字そのものへの抵抗か、すり替えへの抵抗か。土地評価の価格には抵抗を感じないなら、その違いは何から来るのか（→A-08 全体的評価と分析的評価、A-20 統合回、B-18 自由エネルギー原理の式を読む）
- llm-as-judge で、一回限りの結論を残しつつ揺れを点検する手順は、結論の鋭さを損なわずに置けるか。点検で揺れが大きかった項目を、結論にどう添えるか（→A-19 LLMを評価者として測定論で見る）
- 自分の判断の結果を引き受けるのは誰か。観想的エージェントの憲法修正の判定は、アートの側か課税の側か。どこからが他者に不利益を与える判断になり、どれだけの再現性が要るか（→A-05 メシックの統一的妥当性論、A-20 統合回）
- 自分の eval で、一回限りの判定を集めて何かを決めている段階はどこか。そこで再現性と責任を誰が持っているか（→A-06 グッドハートの法則とキャンベルの法則、A-19 LLMを評価者として測定論で見る）
