# B-03 ベイズの定理

## 本編の要点

- ベイズの定理は条件付き確率の向きを入れ替える道具。掛け算の形を二通りに書いて P(H|E) = P(H) × P(E|H) ÷ P(E)。事前に尤度を掛け、証拠が出た場合だけに世界を狭める（全体で割る）操作で、前回の「狭めてから数える」の組み直し
- ベイズの遺稿はプライスが整えて1763年に王立協会で読まれた。ラプラスは1774年に独立に原因の確率の理論を出し、一般的な形に育てた
- 尤度 P(E|H) は仮説の確率ではなく、仮説がその証拠をどれだけ予想していたか。仮説どうしで足しても1にならない。オッズの形では 事後オッズ = 事前オッズ × 尤度比 で、P(E) は消える。尤度比1の証拠は何も動かさず、目立つかどうかは尤度比と関係がない
- 独立と見なせる証拠は尤度比を掛け続けられる（自転車のパンクの例で 1対4 → 3対4 → 3対1）。対数をとると足し算になり、チューリングとグッドは尤度比の対数を証拠の重みとして積んだ（デシバン、グッド 1950）
- 事前の出どころ（記録の割合、無差別の原理、信念の度合い）は割れている。意見の違いは事前の違いと尤度比の違いに分けられ、前者は証拠を重ねれば近づくが後者は近づかない。事前0は動かない（クロムウェルの指針）
- 較正された判定器の確率は事前を含んだ事後確率。尤度比4の判定器は、事前1対1の集まりなら0.8、1対4の集まりなら0.5が正しい。別の集まりに移すと見分ける力は同じでも数字が当てにならなくなる（→B-04 基準率の無視）

## 対話で出た論点

- 復習（B-02 の餌皿）への著者の答えは P(鳴く|空)=0.8、P(空|鳴く)=2.5。前者は正解。後者は1を超えていて確率になっていない。空の日10を空でない日に鳴いた4で割るような向きの取り違えの可能性。正しくは鳴いた日12に狭めて 8÷12 ≒ 0.67。分子は同じ8で、分母が条件の側に当てはまる日の数（10か12か）で変わるのが条件の逆転の形
- 復習（C-01 の概念の欠陥の型）は著者が忘れていたので答えを示した。曖昧さ（大盛り）、内部の矛盾、説明に役立たない、人を見えなくする・傷つける（無償労働）。ペットロスは言葉が経験に形を与える例
- 著者の確認「P(空|鳴く) は分母が鳴くという意味ではないか」。そのとおりで、縦棒の右が条件で分母になる。読み方の向きは合っていて、つまずきは分母の数え方。鳴いた日は空の日の8日と空でない日の4日を足した12日で、空でない日の4日を落とさないこと
- 著者の頼みで同じ形の問いを出し直した。散歩40日、雨10日のうち傘9日、雨でない30日のうち傘6日。著者の答えは P(傘|雨)=0.9（正解）、P(雨|傘)=0.67（正しくは 9÷15=0.6）。分母に条件の側の日をすべて入れる手順はまだ揺れている。分子は同じ9で、分母が10か15かで値が分かれる
- 著者の頼みで、小問の前に分からないところを一つずつ潰すことにした。最初は事前オッズ。確率は全体と比べ、オッズは二つのグループどうしを比べる（20日中、雨5日なら確率0.25、オッズ5対15で1対3）。変換は a対b → a÷(a+b)、p → p対(1−p)。「事前」は証拠を見る前というだけの意味。オッズにすると証拠の取り込みが掛け算一回で済み、自転車の例を日数（パンク10回、自然40回、砂利道で6回と8回、3対4）で数えると、事前オッズ×尤度比が「狭めてから数える」の近道になっていると確かめられる
- 著者の問い「尤度はどこから出てきたか」。本文は数字の出どころを説明していなかった。尤度は仮説ごとのグループの中で証拠がどれだけ出ていたかを数えた条件付き確率（パンク10回中6回で0.6、自然40回中8回で0.2）。縦棒の右が仮説で分母になる。復習で出した P(鳴く|空)=0.8 は仮説「空」、証拠「鳴く」の尤度そのもので、逆向きの P(空|鳴く) が求めたい事後。記録がないときは経験や仕組みの知識から見積もるので見立てが入るが、「その仮説の世界で何が起きやすいか」という問いなので事前より揃いやすいことが多い
- 著者の問い「尤度は条件付き確率とイコールか」。値としては同じ P(E|H)。違いは何を固定し何を動かすか。条件付き確率は仮説を固定して証拠を動かす（P(砂利|パンク)=0.6 と P(砂利でない|パンク)=0.4 で足して1）。尤度は起きた証拠を固定して仮説を動かす（パンク0.6、自然0.2、足した0.8に意味はなく、比の3倍が要点）。連続量では尤度が1を超えることもあり、違いがよりはっきりする（→B-07）
- 確認の問いへの著者の答え。確率0.2はオッズ1対4、オッズ2対3は確率0.4。どちらも正解で、オッズと確率の行き来は掴めた
- 著者の頼みで練習問題をもう一問。事前オッズ1対2、空の朝に9割鳴く、空でない朝に3割鳴く。著者の答えは尤度比3、事後オッズ3対2、確率0.6で、すべて正解。事前オッズ×尤度比の一回の更新は掴めた
- 小問への著者の答え。一人目は0.57（尤度比4、4対3）、二人目は0.4（尤度比2、2対3）で、二問とも正解。理由として「降らない日が4割だから」と書いたのを、こちらが「答えが4割と一致しただけ」と読み違えて偶然の一致と講評したが、著者の指摘どおり、それは二人目で変わった点（降らない日の尤度が0.2から0.4に上がった）を示した正しい理由だった。言い足すなら「それで尤度比が4から2に半分になる」まで
- 著者の受け止め。尤度とオッズは計算は分かったが、概念としてしっくりきていない
- 絵で置き直した。オッズは二つの仮説を載せた天秤の傾きで、証拠は全体を測り直すのでなく傾きを変えるので、傾きだけを追うオッズが証拠の取り込みと相性がよい。オッズは賭けの言葉でもあり B-01 のダッチブックにつながる。尤度は仮説を予言者と見たときの、起きた出来事をどれだけ言い当てていたかの採点で、予言者が正しいかは直接言わない。事後オッズ=事前オッズ×尤度比は、よく予想していた側の皿に予想の差の分だけ重りが足される動き
- しっくりこない理由の候補。知りたいのは仮説の側なのに尤度は証拠の側を向いていて、この向きの食い違いは B-02 の条件の逆転と同じ根。別の入り口として、自由エネルギー原理の驚きは観測の尤度の対数にマイナスを付けたもので、尤度は仮説がその観測にどれだけ驚かずにいられたかと読める（→B-09、B-18）
- 著者の問い。オッズは競馬のイメージで2.5のような数なので、1対4の形に違和感がある。答え。競馬の2.5は払い戻しの倍率（100円で当たれば元手込み250円）。公平なら 100=250×p で p=1÷2.5=0.4、オッズにすると2対3で、同じ見込みの別の書き方。ベイズでは比に尤度比を掛けるだけで済む「対」の形が使いやすい
- 競馬のオッズは控除率（JRA は券種によりおよそ2〜3割、2019年時点の一覧）を引いた残りを分けるので、全馬の 1÷倍率 を足すと1を超える（単勝ならおよそ1.25）。B-01 の0.6と0.6の人と同じ形で、全部買えば必ず損をする。買い手がダッチブックを組まれている側で、胴元はその差を取る。倍率から出した確率はそのままでは整合的な信念ではない
- 著者の問い「競馬のオッズは対数か」。違う。「2対3」の対は比、競馬の2.5は確率の逆数の倍率、対数は証拠の重み（尤度比の対数で掛け算を足し算にする）にだけ出てきた。確率0.4、オッズ2対3、倍率2.5は四則演算で移り合う
- 著者の問い「事後オッズが事前オッズ×尤度比になる理屈」。数える見方では、事前オッズはグループの大きさの比（10対40）、尤度は証拠に絞ったときの縮み方（0.6と0.2）で、(10×0.6)対(40×0.2) は 10対40 に 0.6÷0.2 を掛けたものと同じ。比の両側を違う割合で縮めると比は縮め方の比だけずれる。式の見方では、二つの仮説のベイズの定理を割り算すると共通の ÷P(E) が消え、事後オッズ=事前オッズ×尤度比が残る。天秤の傾きを比べるのに天秤全体の重さは要らない
- 著者の受け止め。これがベイズの定理で、脳はこの事後オッズの更新を繰り返している
- 「脳はベイズ更新をしている」は仮説で、強さの段で支えが違う。(1) 振る舞いがベイズに合う段は厚い。アーンストとバンクス（2002）は目と手の手がかりを当てになり具合で重み付けしてまとめる様子が最適な合わせ方とよく一致すると示した。(2) 脳内で尤度比のようなものが積み上がる段。ヤンとシャドレン（2007）はサルの LIP のニューロンが手がかりごとの対数尤度比の積み重ねに沿って変わることを示し、チューリングとグッドの証拠の重みが神経活動として見えた例。限られた課題での結果。(3) 脳は本質的にベイズの機械だという段は割れている。バウアーズとデイヴィス（2012）は事前や尤度を後から選べるので柔らかすぎ、後付けの話になると批判し、グリフィスらが同号で反論。正確な更新は手に負えないので近似と考えられ、自由エネルギー原理はその近似を変分自由エネルギーで書いたもの（→B-17、B-18）
- 知覚ではベイズ的なのに、言葉で確率を考えると基準率を無視しやすい、というねじれ（→B-04）。脳全体の原理としてはまだ賭けの段階
- 著者の受け止め。だいぶ基礎が分かったが、定着させるには繰り返しの計算問題が要るのではないか。応答。間を空けた繰り返しや型を混ぜた練習は手続きの定着によく効くという知見は確か。ただ APPROACH.md は「自分で手を動かすほうが効く」に戻るのを古い物差しのしるしとする。問題を作って差し込む側を AI が持ち、本人は朝の問いに答えるだけなら、その考え方の内側に収まる。計算は目的でなく、ベイズで自分の問題を考えるための足場
- 著者の問い。計算できることと、理解して道具や物の見方として身につけることは違うのか。応答。スケンプ（1976）の道具的な理解（手順を回せる）と関係的な理解（なぜ働くか分かる）の区別に当たり、今日の「計算は分かったがしっくりこない」はその境目。物の見方としてのベイズは、外れの側でどれだけ起きるか、出発点はどこか、食い違いはどちらの側か、という問いの立て方。それでも大きさの感覚（尤度比2と10の差、事前1対9の引き戻し）は数を回さないと育たない。計算は直観の較正で、A-03 で出たチャンの指の感覚と目盛りの突き合わせと同じ形。手順と概念は交互に押し上げ合って育つという見方が有力で、今日も三問解いて天秤の絵が入り、絵が入って小問の理由が書けた
- 著者の頼みで、今日の概念を要素に分けるため事前オッズの問題を三つ出した（散歩と柴犬）。問1 記録60回中20回から事前オッズ1対2（正解。確率約0.33は未回答）。問2 尤度比3で、事前1対2なら0.6、1対8なら11分の3（どちらも正解。同じ証拠で0.6と0.27まで開く）。問3 朝の20回中12回から3対2（正解）
- 問3の講評。著者は「朝で切り取ると、それ以外の要素による変化を捨象する」と答えた。当たっていて、どの参照クラスでも絞らなかった軸（曜日、天気）は中で平均されたまま残る。もう一つの大きな引き換えは数が60から20に減ること。絞るほど明日に似た日だけを使えるが、たまたまの偏りが出やすい（晴れの朝で3回中3回など）。B-01 のライヘンバッハの指針（信頼できる統計のある範囲で一番狭い参照クラス）はこの釣り合い
- 復習の問いを、数を変えた計算一問と、数を出さずに見方を使う問い一問の組で出す案を出した（著者の了承を得て CLAUDE.md の朝の実行の5とノートの書式、APPROACH.md の仕組みの形に足した）

## 概念表

| 概念 | 一言で |
|---|---|
| ベイズの定理 | 事前と尤度から事後を求め、条件付き確率の向きを入れ替える式 |
| 事前確率 | 証拠を見る前の仮説の確率 |
| 尤度 | 仮説が正しいとしたときの、その証拠の出やすさ |
| 尤度と条件付き確率の向き | 同じ P(E|H) を、仮説を固定して見るか（条件付き確率）、証拠を固定して仮説ごとに比べるか（尤度） |
| 天秤としてのオッズ | 二つの仮説の傾きだけを追う見方。証拠は傾きを変える |
| 予言の採点としての尤度 | 各仮説が起きた出来事をどれだけ予想していたかの点。仮説の正しさそのものではない |
| 払い戻しの倍率 | 競馬のオッズの書き方。確率に戻すと 1÷倍率。対の形のオッズと同じ見込みを別に書いたもの |
| ベイズ脳仮説の三つの段 | 振る舞いが合う、脳内で尤度比が積み上がる、脳が本質的にベイズの機械、の順に支えが薄くなる |
| 道具的な理解と関係的な理解 | 手順を回せることと、なぜ働くか分かること（スケンプ 1976） |
| 直観の較正としての計算 | 数を回して、見方に大きさの感覚を合わせること |
| 絞り残しと数の減り | 参照クラスを絞っても絞らなかった軸は混ざったまま残り、絞るほど数える回数が減ること |
| 事後確率 | 証拠を見たあとの仮説の確率 |
| オッズ | ありそうとなさそうの比。確率0.2なら1対4 |
| 確率とオッズの変換 | オッズ a対b は確率 a÷(a+b)、確率 p はオッズ p対(1−p) |
| 尤度比 | 証拠が二つの仮説のもとでどれだけ出やすさが違うかの比。証拠の強さ |
| 証拠の重み | 尤度比の対数。独立な証拠なら足し合わせられる（チューリング、グッド） |
| 事前の違いと尤度比の違い | 意見の食い違いの二つの源。前者は証拠で近づき、後者は近づかない |
| 事前を含んだ較正 | 較正された確率は、較正した集まりの当たりの割合を中に含んでいること |

3. 尤度が仮説の確率でないとは、どういうことか。尤度を足しても1にならないのはなぜか

## 開いたままの問い

- 較正された小さな判定器が返していた確率は、どの集まりの事前を背負っていたか。大きなモデルが品質で上回ったのは、尤度比の鋭さの差か、事前の当て方の差か、確率という一つの数で答えさせる形そのものの差か（今日の引っかかり。→B-04 基準率の無視、B-14 較正、B-16 言語モデルの確率）
- 尤度の見積もりは事前より揃いやすいと言ったが、評価のように仮説の世界そのものが定義しにくい場面でも揃うのか（→A-03 の評定者間の一致、A-19 LLMを評価者として）
- 知覚ではベイズに近く、言葉の確率推論では基準率を無視する。同じ人の中のこのずれは、別の仕組みが働いているからか、同じ仕組みに与える問題の形が違うからか（→B-04 基準率の無視、B-18 自由エネルギー原理の式を読む）
- ベイズが物の見方として身についたことは、何で分かるか。計算の正しさでなく、自分の問題に尤度比や事前の問いを立てられるかで見るなら、それをルーブリックに落とさずにどう確かめるか（APPROACH.md の新しい物差し、→A-20 統合回）
