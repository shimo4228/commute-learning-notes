# B-09 驚きの量

## 本編の要点

- 底2の対数 log2 N は、N を2で何回割ると1になるかの回数（1に2を何回掛けると N になるか）。候補を毎回半分に割る、はいかいいえの問いで N 個から1個を当てる回数にあたる。log2 8＝3、log2 16＝4、log2 1＝0。log は logarithm（ギリシア語の「比」と「数」）、小さな2は底（base）
- 驚きの量（情報量、surprisal）は I(x)＝log2(1/P(x))。1/P(x) は「何回に1回か」。単位はビットで、シャノンは1948年の論文で底2の対数の単位をこう呼び、語はテューキーの提案と書いた。対数で情報を測る考えは1928年のハートレーにある。確率1なら0ビット、確率0なら限りなく大きい。意味の側面は入らない（シャノンの断り。意味を含む情報の理論は議論が続いている）
- 互いに影響しない（独立な）二つの出来事が両方起きたときの驚きは、それぞれの驚きの和。I(x かつ y)＝I(x)＋I(y)。確率の掛け算が、半分にした回数の足し算になる。8分の1と4分の1で 3＋2＝5 ビット、32分の1と合う
- 候補 H のもとでの観測 D の驚き log2(1/P(D|H)) は、尤度 P(D|H) を驚きの物差しで読み直したもの。最尤推定の候補は驚きがいちばん小さい候補。二つの候補の驚きの差 k ビットは尤度比 2の k 乗倍で、証拠の重みをビットで数えたもの（MacKay 18.3節の言い直し）
- 驚きは尤度だけで決まり事前を見ない。袋から結果への向きの数で、いちばんありそうな袋を言うには事前が要る。驚き0の袋がいちばんありそうとは限らない。自由エネルギー原理の驚きも、生成モデルのもとでの観測の確率に同じ形で測ったもの（底は e が多い）→B-18

## 対話で出た論点

- 復習の1（計算、棚の五つの袋で赤、赤のあと赤2個の袋である見込み）。最初「1」と答えた。見立て　理由は言っていないので確かではない。赤2個の袋で赤、赤が出る見込み P(赤赤|赤2個)＝1、つまり尤度を、見たあとの袋の見込みと取り違えた疑い（台帳の推定の向き）
- 教案の手当て（赤1個の袋一つで、2回の並びが何通りか、そのうち赤、赤が何通りか）を一往復ずつ出した。前に、袋に戻すので2回とも赤が出ることはあるか、をその場で一つ足した。「ある」「4」「1」で通った
- 続けて、五つの袋で合わせて20通りのうち赤、赤は何通りか、をその場で出した。「5通り」と答えた。講評では外れの元を赤2個の袋の数え方と読み、「色の並び方」と書いた問いの足りなさのせいにして、赤2個の袋の玉をアとイに分ける問いをその場で作った。著者は「4通り。さっきのは赤1この袋を3倍にするのを忘れた」と返した。外れの元は赤1個の袋の数3を掛け落とした一手で、講評の読みが外れていた（出題の側。外れの元を確かめずに講評を書いた）。掛け落とし自体は理解の側の手順の揺れで、棚の袋の数を落とす形は B-08 でも出ている
- 最初の問いをもう一度出すと、「0*1/5+1/4*3/5+1*1/5=7/20」「1/5*20/7=4/7」と三行の手順を式で自分から回して正解。式の形では事前の 5分の3 として袋の数が自然に入った。並びの20通り中7通り、4通りとの対応を示した
- 復習の2（見方、犬が公園で何度も吠えた、「機嫌の悪い日なら、何度も吠えるのはよくあることだ」はどれか）。「P(吠|悪)」「尤度」で正解。記号も自分から書いた。事前 P(悪)、事後 P(悪|吠) を並べた
- 復習の3（C-06 から、散歩を家族の運動不足を減らす手立てとして決めたい）。「改良的な問い」で正解。続けて著者「そういえば選択肢の問題は選択肢をタップできるようにしたと思うが、この環境ではできないのか？」。スケジュールで立ち上がったクラウドの実行には選択肢のボタンの道具が渡されておらず、ボタンが使えない実行では文中に選択肢を並べる決まりなのでその形で出している、と答えた。この件は同じ日のうちに、ボタンが使えない実行では選択肢に番号を振って番号で返してもらう、という形で CLAUDE.md の一往復に入った
- 復習の4（B-02 から、偏りのない硬貨を6回投げて6回とも裏、7回目に表の確率）。著者「えっわからない」。数を小さくした一往復（1回目が裏のとき2回目に表の確率）をその場で作り「1/2」、続けて（6回とも裏のあと、2分の1から変わるか）「変わらない」で通った。見立て　出題の側の要素が大きい。直前の復習の1が、前の結果が次の見込みを動かす袋の問いで、そのすぐあとに続けた。小さくしたらすぐ通ったので、理解の側の揺れは小さい。答え合わせで、前の結果が次に効くのは何が分かっていないとき（袋が分からない）で、偏りのない硬貨と分かっていれば動かすものが無い、と分けた
- 節1の小問1（32枚のカード、半分に割る問いで何回）。「5」で正解
- 節2の小問2（16枚のうち赤い札4枚、赤を引いた驚き）。「2ビット」で正解。場面から4回に1回を切り出しているので確かめは足さなかった
- 節3の小問3（8枚から引いて戻し、2回とも「1」）。「6ビット」で正解
- 節4の小問4（赤1個の袋と仮に置いて白、白の驚き）。「尤度　1/4」「log2(4)」「2ビット」と、尤度から驚きへの道筋を式で順に書いて正解。小問5（赤、白で驚きのいちばん小さい候補）は夕方に続けて「赤1個」で正解。ほかの二つは確率0で、この観測で残る候補は赤1個の袋だけ、と添えた。今日の引っかかりと参考文献を出して講義を終えた。残った節なし
- 講義のあと、著者「驚きはIでInformationなんだろ？なんで驚きなの？」。同じ数に二つの名前がある、と答えた。情報は知らされる側からの読みで、知らされて候補がどれだけ絞れたか（シャノンは通信の工学で、メッセージで候補がどれだけ絞れるかを測りたかった。I はこちらから）。驚きは予想していた側からの読みで、予想からの外れの大きさ。同じ数になるのは、珍しいことほど起きたと知ったときに多くの候補を消すから。surprisal はあとから付いた呼び名で、誰が言い出したかは確かめられていない。節4のように候補を仮に置いて観測を見るときは驚きの読みが合い、自由エネルギー原理の論文も surprise と呼ぶ。記号も本によって I、h(x)（MacKay）、記号なしの −log P(x) に分かれる
- 著者「なんか、普通の意味での驚きとは似ているようで本質的には違う感じがするな」。ずれを三つ挙げた。(1) どの結果も等しく珍しい場面。6桁の数で 111111 と 503827 はどちらも百万回に1回でおよそ20ビット。ふだんの驚きは、ぞろ目かそれ以外か、のように自分が気にかけている分け方で見ていて、驚きの量はその分け方で変わる。(2) 見方が変わったか。驚きの量は見る前にどれだけ低く見積もっていたかだけで、見たあとに見込みがどれだけ動いたかは測らない。動きは前後の分布のずれで測り、B-12 の KL ダイバージェンスがその道具。(3) 意味と重みは入らない（シャノンの断り）。驚きの量は、ふだんの驚きのうち起きる前の見積もりの低さの一面だけを数にしたもの、という整理は講義のためのもので資料の主張ではない、と断った
- 著者「自由エネルギー理論で脳は驚きを最小にしようとするということは、常に自分の信念と実世界のずれを修正しようとしているということかな？」。半分はそのとおり、と答えた。小さくされるのは驚きの上界の変分自由エネルギーで、F ＝ −log P(o) ＋ KL[ q(s) ‖ P(s|o) ] と平文で先に示した（o は観測、s は隠れた状態、q(s) はいまの信念、KL は0以上）。道は三つ。知覚は q を動かして KL を小さくすることで、直す先は実世界そのものでなく生成モデルのもとでの事後（実世界とのずれは観測しか見えない生き物の側からは直接には見えない）。行為は世界を動かして −log P(o) そのものを小さくすること（寒ければ日なたへ移る）。学習はモデル P を作り直すこと。「信念と実世界のずれを直し続ける」は知覚の側だけの描き方。驚きは生き物のモデルのもとでの驚きで、暗い部屋の疑問もそこにかかる。経験的に確かめられる理論か、ものの見方の枠組みかは割れている、と添えた
- 教案の梯子を使った場面は、復習の1の手当て（赤1個の袋一つで並びを数える二往復）。その場で作った場面は、2回とも赤はありうるか、20通りのうち赤、赤は何通りか、赤2個の袋の玉をアとイに分ける問い、硬貨の数を小さくした二往復

## 概念表

| 概念 | 一言で |
|---|---|
| 底2の対数 log2 N | N を2で何回割ると1になるかの回数 |
| 驚きの量（情報量、surprisal） | log2(1/P(x))。起きたことが「何回に1回」かを半分にした回数で数えた量 |
| ビット | 底2で測った驚きの単位。はいかいいえが半々の問い一回ぶん |
| 独立な驚きの足し算 | 互いに影響しない出来事なら、両方の驚きはそれぞれの驚きの和 |
| 候補ごとの驚き | log2(1/P(D|H))。尤度を驚きの物差しで読み直したもの。事前は見ない |
| 驚きの差と尤度比 | 差が k ビットなら尤度比は2の k 乗倍 |
| 情報と驚き | 同じ log2(1/P) を、知らされる側（候補がどれだけ絞れたか）と予想していた側（外れの大きさ）から読んだ二つの名前 |
| 分け方への依存 | 驚きの量は、何を候補として並べ、結果をどう分けたかで変わる（ぞろ目かそれ以外か） |
| 変分自由エネルギー F | 驚き −log P(o) に、信念 q と事後のずれ（KL、0以上）を足した上界。知覚、行為、学習で小さくする（→B-18） |

## 復習用の問い

1. （計算）玉が16個入った福引の箱があり、当たりは2個です。どの玉も同じ見込みで出るとします。1個引いたら当たりでした。この驚きの量は何ビットでしょうか。（答え　3ビット。16個中2個で8分の1、8回に1回）
2. （計算）互いに影響しない二つの出来事があり、一つ目の確率は4分の1、二つ目の確率は2分の1です。両方が起きました。この驚きの量は何ビットでしょうか。（答え　3ビット。2＋1、確率では8分の1）
3. （計算）数え方の約束事。袋は最初に一度だけ渡され最後まで同じ、玉は取り出して色を見て戻しよく振り、毎回2個すべてから選び直す、出た順番を区別する。手元にビー玉2個入りの袋が一つあり、玉はそれぞれ赤か白、中身は赤0個、赤1個、赤2個のどれか。3回取り出したら、白、白、白でした。赤1個の袋だと仮に置いたとき、この結果の驚きは何ビットでしょうか。（答え　3ビット。8通りのうち1通り）
4. （見方）二つの候補のもとでの、同じ観測の驚きの差が2ビットでした。驚きの小さい候補の尤度は、もう一方の何倍でしょうか。（答え　4倍）
5. （見方）ある観測の驚きが0ビットになる候補がありました。その候補が、見たあとにいちばんありそうな候補だと言えるでしょうか。「言える」「言えるとは限らない」のどちらかで。（答え　言えるとは限らない。驚きは事前を見ないので、事前の小さい候補なら、ほかの候補のほうがありそうになりうる）

## 開いたままの問い

- 棚の袋の数（事前）を掛け落とす一手が、並びで数える形でまた出た。式の形（事前 5分の3 を掛ける）では自然に入った。次のテーマBの復習で、袋の数が平らでない棚を、並びと式で別の日に一往復ずつ確かめる（→B-10）
- 硬貨の独立（B-02）で一度止まった。前の結果が次の見込みに効くのは何が分かっていないときか、を袋の場面と硬貨の場面で、同じ日に続けずに一往復ずつ確かめる（→B-10 以降）
- 外れの講評で、外れの元を確かめずに読んでしまった（5通りを赤2個の袋の数え方と読んだ）。数を答える問いで外れたら、講評の前に、どこまで数えたかを一往復で尋ねる形があるとよい
- 驚きの量は、何を候補として並べ、結果をどう分けたかで変わる（ぞろ目かそれ以外か）。ふだんの驚きが黙って決めている分け方を、エージェントの憲法はどこで決めているか。今日の引っかかり（修正のきっかけは珍しいだけの出来事か、そのときの憲法が並べていなかった出来事か、驚きの量の側から見分けられるか）とつながる（→B-10、B-12、B-18）
- 珍しいのに見方がほとんど動かない出来事と、その逆。驚きの量と見込みの動き（KL）のずれ（→B-12）
- 自由エネルギー原理で小さくするのは F で、知覚、行為、学習の三つの道がある。暗い部屋の問題と、経験的な理論か枠組みか（→B-17、B-18、B-19）
