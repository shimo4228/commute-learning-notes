# A-08 全体的評価と分析的評価

## 本編の要点

- 全体的評価（ホリスティックな採点）は、作品のいくつもの面を読む人が頭の中で重みづけてまとめ、一つの段階で返す。その一つの数には作品のでこぼこと読む人の重みづけが畳み込まれ、数からは読み分けられない（音楽祭の二つのバンドがどちらも4）。ディードリッヒら（1961）では、観点も段階の説明も渡されない読み手53人が作文300本を9段階で評価し、94%が7通り以上の評価を受け、読み手は重く見るものでおおむね五つの群に分かれた
- 分析的評価は観点を先に決めて観点ごとに段階を付け、何をどれだけ見るかが紙の上に出る（この講義の整理）。ウェイグル（2002）の表では、診断の情報、判定のそろいやすさ、採点者の訓練に利点があり、時間と手間がかかる。重みづけは消えず、観点の選び方と段階の書き方、合計するなら埋め合わせの前提に入る。分析的な表でも全体の印象を観点へ配ると観点の数は一つの数の写しになる。ブルックハート（2018）は、分析的は練習の途中、全体的は最後の成績づけに向くとした
- ブルックハート（2018）は大学のルーブリック研究46本を見直し、全体的か分析的かと信頼性や妥当性のあいだにはっきりした関係は見えず、適切な観点こそが要だとした。課題の指示に従ったかを数える観点（出典が三つある）は努力を誤った方へ向ける。分析的のほうが判定がそろうという見方とはここで割れる
- 数えられる特徴を観点にすると観点の中に小さな指標ができ、押されれば敵対的な型でそのすき間へ圧が流れる（野菜3種類以上）。この結びつけはこの講義の整理で、ブルックハートはグッドハートに触れていない
- サドラー（2008年の講演、2009年記録）は、全体の判断と観点の和はよく食い違い、どの観点にも当てはまらない質は観点へばらまかれ、観点は組み合わさって効くと論じた。足し算は全体が部分の和に等しいと言うことになる。判断を先にし理由をあとで観点の言葉で言うことを勧めた。反対側でパナデロとヨンソン（2020）は、ルーブリック批判の多くは直接の強い証拠に支えられていないとした。学説は割れている

## 対話で出た論点

- 復習の1の前に、著者が前回の四つの型を尋ねた。答えを出さずに、四つの定義（回帰的、極端、因果的、敵対的）と、選ぶ二つ、手を入れる二つというまとめ方、見分けの手がかり二つ（ふだんの範囲で見てきた関係が変わったか、手を入れたのは選ぶ側か目的の違う相手か）を示した。教案の手当てにある問いを、答える前の手がかりとして使った

- 復習の答え。1は (ア) 回帰的、(イ) 敵対的で正解。3は (ア) 過少代表、(イ) 無関係な分散で正解。4は過少代表の側で交通ルールを守らない人が修了証を得る、スピード競争、無関係な分散の側で自転車の性能向上。正解。スピード競争は圧そのもので、手抜きされるのは取りこぼされた面と整え、コースの内側を削るを足した
- 復習の2（歩数計で偽りを封じた場面）。グッドハートは「歩数が外を楽しんだ目安として機能しなくなる」、後半は「家の周りを歩く」で正解。前半は「振って数を稼ぐこと」と、当たるならどんな形かを答え、この場面で当たるか当たらないかを言い切らなかった。封じてあるので当たらない、と示した。前半と後半を偽りの有無で分けること自体は取れている。台帳の弱点「振り分けを自分からしない」の形がまだ残る（三回目）
- 本文の導入と節1（一つの段階には何を重く見たかが畳まれる）と小問1（カレーの3と5）を出した
- 小問1の答え。審査員がどういう基準で採点したか分からず、3と5は比較できない。採点項目と点数ごとの基準があればよい。正解（重みづけが畳まれて読み分けられないことを捉え、手当てが節2の分析的評価を先取りしている）。食い違いの元は三つあると補った。重みづけの違い（同じ人なら同じ向き）、その日の揺れ（食べるたびに変わる、同じ人の再試食で見分ける）、一皿の側の割れ方（理由を書かせると見える）。採点項目と基準で手が届くのは一つ目だけ。節2と小問2（平らな数）を出した
- 小問2の答え。ホリスティックな判断を先に行い、観点ごとの配点をバイアスを持ったまま行った。正解（観点の写し）。確かめ方を答えていなかったので補った。ほかの審査員が同じバンドに付けた観点ごとの数と比べる。ほかがでこぼこならその審査員の側の事情、ほかも平らならどのバンドも本当に同じくらいだった可能性も残る。平らさだけでは写しの証拠にならない。問いの二つ目を答えない形は復習の2（当たるかを言い切らない）と同じ向き。節3と小問3（フォトブック）を出した
- 小問3の答え。写真が10枚以上ある、低品質でも数を揃えようとする。正解。作り手が講評会の見ているものを学んで押すので敵対的な型、C-06:68 の手近な目印で定める形と同じと一文で結んだ。節4（サドラー）と小問4（ゆとりの観点を足す）を出した
- 小問4の答え。ゆとりはほかの四つの観点との折り合いが悪く評価が難しくなる、全体的な印象が各観点に配分される可能性がある。二つとも当たり。折り合いの悪さは観点が組み合わさって効く（独立でない）というサドラーの三つ目の指摘そのもので、ゆとりは景色の多さや移動の速さと引っぱり合う。配分は節2の観点の写しが観点を増やしても起きうるという見方。追いかけっこの筋（次の旅は別の組み合わせで食い違い、観点を足しても足し算の前提が残る、事前に書き切れない）は答えに無かったので補い、C-03 の条件を足していく追いかけっこにつないだ
- 四つの節を終え、今日の引っかかり（例外規定の書き足しは観点の追いかけっこと同じ形か）と参考文献を出して講義を終えた。残った節なし
- 講義のあと、著者が eval のワークフロー案を出した。ルーブリックの観点ごとに複数エージェントのチームを組み（5観点なら5チーム）、観点ごとの eval ループを回し、最後にホリスティックな段で釣り合いを取る。応答（見立てを含む）。強みは、一つのエージェントが一つの観点だけを見るので観点の写しを仕組みで断てること、観点ごとの数が本当の診断の情報になること。気をつけどころは三つ。(1) ループで観点が一つずつ目標になり、観点の中の小さな指標が五つできる。観点を質そのものを指す言葉で書けるかがまず効く。(2) 観点どうしの引っぱり合い（小問4で著者が見つけた折り合いの悪さ）がループどうしの綱引きになり、組み合わせは最後の段まで誰の目にも入らない。(3) 最後の段に五つの数を先に見せると足し算に近づく（逆向きの写し）。サドラーの順に寄せ、数を見ずに作品を読んで判断し、そのあと五つの数と突き合わせ、全体と観点の和の食い違いを情報として使う。どの観点にも当てはまらない質や組み合わせに名前を付けて記録すれば次の観点の候補として育ち、例外規定の書き足しに近い（今日の引っかかりへ）。A-06 の下限と上限の分け方とも合う（観点チームは欠けの拾い出し、最後の段はよさの選択）。ループが直すのは作品かルーブリックかを著者に尋ねた
- 著者「作品かルーブリックかってどういうこと？」。スープの例で説明した。作品を直すループは観点を固定して作品を点が上がるまで直す（観点が押される目標になり、気をつけどころの1と2が効く）。ルーブリックを直すループは作品を採点するだけで、ホリスティックな判断と観点の和の食い違いを見て観点を書き直し足す（押す圧は起きないが、追いかけっこになるかが問題）。両方回すと同じ観点を目標にしつつ書き直すので、どちらで何が起きたか見分けにくい
- 著者「作品だね」。作品を直すループへの手当てを三つ示した（見立て）。(1) 観点チームには点より理由を返させ、観点は質を指す言葉で書く（数を目標にせず診断を残す）。(2) 止めどきは観点の和でなく、数を見ないホリスティックな判断で決める（和の最大化は全部5なのに欠けた作品へ行く）。(3) ループの中のホリスティックな段も何周かで学ばれ敵対的に押されるので、作り直す側が結果を見ない判定をループの外に置く（A-07 の外れ方の違う二つ目の手がかり）。zenn-content の指摘の処分と著者の最後の内容 GO がこの形に近い

## 概念表

| 概念 | 一言で |
|---|---|
| 全体的評価（ホリスティックな採点） | 作品の全体を見て一つの段階を選ぶ採点 |
| 分析的評価 | 観点を先に決め、観点ごとに段階を付ける採点 |
| ルーブリック | 観点と段階を表にしたもの。段階の説明を一列にまとめた全体的なものもある |
| 畳み込まれた重みづけ | 全体的評価の一つの数に、作品のでこぼこと読む人の重みづけが一緒に入っていること |
| 観点の写し | 分析的な表でも、全体の印象を先に決めて観点へ配ると、観点の数が一つの数の写しになること |
| 適切な観点 | 課題の指示に従ったかを数えるのでなく、学びや作品の質そのものを描く観点（ブルックハート） |
| 観点の中の小さな指標 | 数えられる特徴を観点にすると、観点の中に押せる指標ができること（この講義の整理） |
| 足し算の前提 | 観点の和で全体を決めることは、観点が独立で、全体が部分の和に等しいと言うこと（サドラー） |
| 判断が先、理由があと | 全体の判断を先に下し、その理由を観点の言葉で言い表すというサドラーの勧め |

## 復習用の問い

1. 全体的評価の一つの数には、何と何が畳み込まれているか。同じ段階の二つの作品で、数から分からないことを日常の例で言えるか
2. 分析的評価にしても重みづけが消えないのはなぜか。重みづけはどこへ移るか
3. 分析的な表を使っているのに観点ごとの数が診断の役に立たなくなるのは、どんなときか。それを確かめるには何と比べればよいか
4. 数えられる特徴を観点にすると判定はそろいやすいのに、何が起きやすいか。前回の四つの型のどれと結びつくか
5. サドラーは、観点を足し合わせることのどこに困りごとを見たか。観点を一つ足すことで解決しないのはなぜか
6. 全体的か分析的かという型の違いと、観点の書き方の違いでは、どちらが信頼性や妥当性に効くか。学説はどう割れているか

## 開いたままの問い

- グッドハートとキャンベルの区別は、中身は通ったが「それぞれ当たるか」に当たる当たらないで答えず、形の説明で答える癖が残る。次のテーマAの復習で、偽りを封じた場面をもう一度、当たるか当たらないかの二択で答えさせて確かめる（→A-09）
- 今日の引っかかり。土地評価の要領が例外規定を書き足して路線価の取りこぼしを拾うのは、観点を一つずつ足す追いかけっこと同じ形か。違うなら、例外規定の何が足し算の前提から逃れさせているのか（→A-16、A-17、A-20）
- 著者は観点どうしの引っぱり合い（折り合いの悪さ）を自分から見つけた。重なりを重なりのまま読むホリスティックな判断の妥当性はどの入口から支えられるか（A-04:73）とつながる（→A-09、A-20）
- 観点ごとのチームと最後のホリスティックな段を組む eval のワークフロー。最後の段を数を見ずに先に判断させ、観点の和との食い違いを記録して観点の候補を育てる形は、追いかけっこでなく事例から育つ要領になるか。ループが直すのは作品かルーブリックか（→A-10、A-17、A-19、A-20、記事の素材になりうる）
- 作品を直す eval ループの外に置く、作り直す側から見えない判定を何にするか。人なら手間が残り、別のモデルなら何周目から押され始めるかを見張る必要がある（→A-19、A-20、B-14）
