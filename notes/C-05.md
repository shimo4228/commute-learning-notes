# C-05 意味は頭の中にない

## 本編の要点

- パトナム「意味の意味」（1975）の双子地球。見た目も味も水と同じだが H2O でない XYZ の星で、化学以前の1750年に、頭の中が同じ二人の「水」は H2O と XYZ を指す。言葉の当てはまる範囲（外延）は心の状態だけでは決まらず、世界のあり方に依存する（意味の外在主義）。1750年にするのは、誰も見分けられなくても違いが残ることを示すため
- 言語的分業。パトナムはニレとブナを見分けられないが、その語は正しくニレとブナを指す。区別の知識は共同体の一部（専門家）に預けられ、ふつうの話し手はそのつながりで語を使う。分業は意味の変化が伝わる道筋にもなる
- バージ（1979）は社会の側の外在主義を思考の中身に広げた（太ももの関節炎）。思考実験の直観に頼るという批判もあり、評価は割れている
- 外在主義が正しいなら、意味は世界、共同体のつながり、使われてきた歴史に支えられ、一人の決定では変わらない。カペレン『Fixing Language』（2018）は外在主義を土台にした倹約的な枠組みで、意味の変わり方の見通せなさと制御の欠如を強調し、それでも試みは続けるべきとした
- 裏面として、信念が変わっても指示が保たれるなら、概念を直しても話題は保たれうる（水が H2O と分かっても「水」は水を指していた、→C-07）。ただし「エージェント」「理解」のような人が決める部分の大きい語にそのまま当てはまるかは分からない

- 著者の答えは後者（脇役が主役として問われること）。一節一問の形になる前の回なので仕方ない面もある、とも。C-01 は一節に話題がいくつも入っていた回で、欠陥の型は概念工学が何を直すかを示す脇役だった。一節一概念になってからは各節の主役がはっきりしている（C-05 なら双子地球、言語的分業、外に意味があるときの直しにくさ）ので、復習の問いを主役から作れば減るはず。規約は変えず、候補として開いたままの問いに置いた
- 小問1（金に見える指輪）への著者の答えは「外在主義では正しくない、個人の信念とは独立に真実があると考える」。結論は正解。著者は観念論と実在論の対立につながる話と受け止め、唯識からは問い自体が成立せず戯論として退けられるだろう、共有の阿頼耶識を出せば別だが、観念を離れた真にはあまり興味がない、と述べた
- 応答（見立てを含む）。意味の外在主義と実在論は近いが同じではない。外在主義が言うのは、当てはまる範囲は個人の頭の中だけで決まらない、までで、「外」が心から独立した世界か、ほかの人たちとのつながりかは決めない（言語的分業は後者）。パトナム自身も『理性・真理・歴史』（1981）で形而上学的実在論（心から独立した対象の決まった総体と、それとの対応としての真理）を退け、内的実在論をとった。その批判に使った水槽の中の脳の議論は、指示が因果的なつながりで決まるという外在主義寄りの前提に立っていた。唯識からは、「外の世界が意味を決める」は退けられるが、「意味は一人の中で閉じない」は共業による世界の共通の現れで語れるかもしれない。今日の問いの芯を「個人の外に世界があるか」から「意味は一人の中で閉じるか」へ置き直すと、観念を離れた真に関心がなくても扱える
- 小問2への著者の答えはヒラメとカレイ。漁師や卸市場の専門家が見分けて卸し、スーパーの値札に名前が付くことで多くの人は区別している。「哲学的な議論とは思えない地に足のついた話」。講評。ふつうの買い物客は自分で区別しているのでなく、値札を信頼して名前を借りている（寄りかかり）。これがパトナムの言う頼りながら使うこと。「左ヒラメに右カレイ」は専門家の知識の一部が言い伝えで降りてきたものと読めるが、ヌマガレイのような例外があり範囲そのものは決めない。地に足のついた感じは、パトナムが意味を人と人の役割分担のしくみへ引き下ろした意図と重なる。節3（外に意味があるなら誰が直せるのか）へ進んだ
- 小問3への著者の答え。研究者のレベルによるし、発表しただけでは浸透しないので、外在主義だと変わったと言えるものはないのでは。共同体に認知されて初めて意味が変わるなら概念工学の意義自体を問い直す話で、概念工学者は他のセクトに影響力を持てず、内輪で精緻にしても影響がないので学際的にならざるを得ない
- 講評。共同体での当てはまる範囲は動いていない、は正しい。小さく変わったのは、提案の記録が世に出たことと、受け入れた読み手の使い方。研究者自身の言葉も、共同体の使い方に寄りかかって使うなら社会的外在主義では共同体の意味のまま。文書内で定義を宣言して使えば通るが、同じ語の改良か同じ綴りの別の語かという話題の連続性の問題が出る（→C-07）。意義の問い直しは C-08 の実装の問題そのもの。分業の見方からは、範囲を保つ共同体の人たちが見直せば意味は実際に動く（2006年の国際天文学連合の惑星の定義、→C-13）。概念工学が効くのは区別を保つ役の共同体の中で、またはその人たちと一緒に提案したときで、著者の「学際的にならざるを得ない」はそこにしか道がないという読みにもなる。C-01 の開いたままの問い（個人の定義語は既定値に抗えるか）につながる
- 三つの節を終え、今日の引っかかりと参考文献を出して講義を終えた。残った節はなし
- 著者の見立て「今なら言葉の意味を支えているのは LLM かもしれない。北極星など LLM の影響で皆が使い出した言葉はたくさんある」。測った研究を確かめて示した。コバクら（Science Advances 2025、arXiv 2406.07016）は2010〜2024年の PubMed 要旨1500万件余りの急増語から、2024年の要旨の少なくとも13.5%が LLM を通ったと推定し、増えたのは主に文体の語。矢倉ら（arXiv 2409.01754、2024、2025改訂）は学術系 YouTube やポッドキャストで ChatGPT 的な語（delve など）が公開後に話し言葉でも増えたと報告。日本語の「北極星」の増加を測った研究は未確認
- 応答（見立てを含む）。LLM はパトナムの専門家（区別を保つ）より、抹茶の節の多くのお店（言い方を大量に流通させ使い方の分布を動かす）に近い。人の文章から学ぶ、人が言い回しを取り込む、次のモデルがまた学ぶ、という輪で、意味を支える側が人とモデルのあいだを行き来する。著者の知識の循環（AKC）はこの輪の上にある。カペレンは意味の変化は誰の手の内にもないとしたが、広く使われるモデルの言い回しを決める立場は、意図せず最も強く意味を動かしているのかもしれない。C-01 の「声の大きい使い方が既定値になる」の最大の例

## 概念表

| 概念 | 一言で |
|---|---|
| 双子地球 | 頭の中が同じでも、まわりの世界が違えば言葉の指すものが違う、という思考実験 |
| 意味の外在主義 | 言葉の当てはまる範囲は話し手の心の状態だけでは決まらず、世界や共同体に依存するという立場 |
| 内在主義（意味） | 意味は話し手の頭の中で決まりきるという立場 |
| 外延 | 言葉が当てはまるものの範囲 |
| 言語的分業 | 語の範囲を決める知識が共同体の一部に預けられ、ほかの人はそのつながりで語を使うこと |
| 寄りかかり（値札を信頼すること） | 自分で区別せず、区別を保つ人たちの判断を信頼して名前を借りること |
| 社会的外在主義 | 共同体の言葉の使い方が、個人の思いの中身まで決めるという立場（バージ） |
| 形而上学的実在論と内的実在論 | 心から独立した対象の総体と対応としての真理を認める立場と、真理を部分的に探究の仕方に依存させる後期パトナムの立場 |
| 意味の外在主義と実在論の区別 | 外在主義は意味が一人の頭の中で閉じないと言うだけで、外が心から独立した世界かどうかは決めない |
| 寄りかかる使い方と宣言する使い方 | 共同体の意味に寄りかかって語を使うか、文書の中で定義を宣言して使うか。後者は同じ語の改良か別の語かが問われる |
| 流通としての意味の支え | 区別を保つのでなく、言い方を大量に流通させて使い方の分布を動かす支え方（LLM の語彙の影響） |
| 見通せなさと制御の欠如 | 意味の変わり方は複雑で予測できず、ほぼ話し手の手の内にないこと（カペレン） |

## 復習用の問い

2. 外在主義では、言葉の当てはまる範囲を決めているのは何か。日常の例で言えるか

## 開いたままの問い

- 人とモデルのあいだで言い回しが行き来する輪の中で、意味を支えているのは誰か。モデルの言い回しを決める立場は、意図しない概念工学者になっているのか。知識の循環（AKC）の設計で、この輪のどこに人の側の区別を保つ役を置くか（→C-08 実装の問題、C-14 概念の倫理、C-17 AIが概念を割る）
- AI の用語（エージェント、理解、幻覚など）で、当てはまる範囲を保つ役を担っているのは誰か。研究者の共同体か、大きな開発元か、使う人々か。個人の研究者の定義語は、その人たちとどうつながれば範囲を動かせるのか（→C-08 実装の問題、C-17 AIが概念を割る、C-18 用語を作る技術）
- 研究ハブの定義語は、共同体の語の改良として出しているのか、宣言して使う別の語として出しているのか（→C-07 話題の連続性、C-19 自分の概念を点検する演習）
- 今日の引っかかり。言語モデルの「ニレ」は書き手たちの分業にぶら下がって指しているのか。観想的エージェントが憲法の言葉を書き換えるとき、その意味を支えているのは誰か（→C-17、D-05 特徴と線形表現仮説、テーマDの統合回）
- 唯識の共業による世界の共通の現れは、社会的外在主義（意味を共同体のつながりが支える）と同じ形に並べられるか。並べたとき、言語的分業の「専門家」にあたるものは何か（→C-08 実装の問題、テーマDの統合回）
- 規約の候補（著者と話し中、まだ変えない）。復習用の問いは各節の主役の概念から作る。一節一概念にする前の回（C-01 など）から出すときは主役にあたる問いを選び、脇役は場面を与えて見方を使わせる形にする。ほかの回のノートの復習用の問いにも同じずれが残っていないか
- 概念の欠陥の型が三回続けて出ない。次の C の回の復習では、例（大盛り、無償労働など）を示してどの型かを見分ける形にする（→C-06）
- カルナップの四条件は厳密性が抜けた。次の C の回の復習で確かめる（→C-06）
- 基準の問題が「わからん」だった。A の次の回の復習で、別の例で確かめる（→A-06）
