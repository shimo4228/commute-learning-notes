# A-18 比較判断

## 本編の要点

- 一対比較は、二つのものを並べ、決めた性質をより多く持つのはどちらかだけを判断してもらうやり方。甘さ辛さのように並べた二つに同じだけかかる違い（第10回の水準のノイズ）は、差し引きで消える。何を重く見るかの違いや、先に口にしたほうをおいしく感じる癖は消えない
- 比較判断の法則（サーストン、1927年）は、出会うたびに揺れる印象の重なりから、二つのものの隔たりを、揺れの幅を単位にして選ばれる割合から読み取る決まり。物理の大きさを持たない性質にも目盛りを当てられるようにした。いまはテーマBの第16回の softmax と同じ形で使うことが多く、1目盛りごとに2倍の数え方なら P(AがBに勝つ) ＝ 2^a ÷ (2^a ＋ 2^b)。勝つ見込みを決めるのは差だけで、ゼロの位置は決まらない。全員が同じほうを選ぶ組からは隔たりが出てこない
- 適応的比較判断（ポリット、2004年の提案、2012年の論文）は、それまでの判断から推し量った位置を使って、勝ち負けの読めない近い組を選んで出し、少ない判断で並びを作るやり方。基準表を使わず全体を見て決める。地理の作文564本の研究で信頼性0.97が報告された
- 信頼性の水増し（ブラムリー、2015年）は、組み方が結果に合わせて変わるとき、本当は差の無いところにも位置の散らばりが作られ、信頼性の数字が実際より高く出ること。判断をすべてでたらめにしても、適応的な組み方を続けると0.89まで上がった。総当たりでの比べ直しや外の手がかりとの揃い方で確かめることが勧められ、組む二つに少し隔たりを残す手直しも作られた
- 比べる判断から作る目盛りは差だけでできていて、そのおかげで評定者の甘さ辛さが消える一方、組み方しだいで差が実際より大きく見えることがある（この講義の整理）

- 著者「オンラインゲームとかのランクマッチとかは今日の観点からどのようなことが言える？」。応答は四つを挙げた。イロレーティングは二人のレートの差だけで勝つ見込みを決める比較判断の法則の形で、400点の差で見込みの比が10対1、講義の1目盛り（2対1）はおよそ120点の差。審査員がおらず対戦の勝ち負けが判断なので甘さ辛さははじめから入らず、出会うたびの揺れにあたるのはその日の調子や通信や味方。近いレートどうしを当てるマッチングは適応的比較判断と同じで、互角の試合は情報がいちばん多く、遊ぶ側にもいちばん面白い（測ることと楽しませることの向きがたまたま揃っていて、漫才の審査と違う）。試合が続くので運で上がりすぎた人はやがて戻されるが、試合数の少ない仮のランクは水増しの心配があり、最近の仕組みの多くは不確かさも一緒に持つ。レートは差だけを決めるので、遊ぶ人全体がうまくなっても数字は上がらず、昔と今の名人をレートで比べられない（トップのレートが年とともに高くなってきたのが実力か数字のずれかは見方が割れている。今日の引っかかりと前回のドリフトに重なる）。ランクが報酬や評判に結びつくと、サブアカウントや代行のような敵対的グッドハートが出て、勝率だけを追う戦い方に偏るとランクとゲームのうまさのあいだにすき間ができる、とした
- 教案の備えを使った場面は、小問2の三つの手順（教案の節2の別の表し方の手順版）。その場で作った場面は、復習6の出し直し（トマト）と因果的と敵対的を端に振った二つの場面、復習7の出し直しと確かめ、小問2の半々の端の場面と一歩だけの練習、softmax の差と比の説明、漫才とランクマッチへの当てはめ

## 概念表

|---|---|
| 一対比較 | 二つを並べ、どちらがより多く持つかだけを選んでもらうやり方。並べた二つに同じだけかかる違いが消える |
| 比較判断の法則 | 選ばれる割合から、印象の揺れの幅を単位にして二つの隔たりを読み取る決まり |
| 差だけの目盛り | 比べる判断の目盛りは差だけを決め、ゼロの位置は決めない |
| 適応的比較判断 | 推し量った位置から勝ち負けの読めない近い組を選んで出し、少ない判断で並びを作るやり方 |
| 信頼性の水増し | 結果に合わせて組み方が変わると、差の無いところにも散らばりが作られ、信頼性の数字が高く出ること |
| 点は重みの対数 | 1目盛りごとに2倍の数え方では、重みの比が点の差になる。比は重みの側で、差は点の側で見ている（対話） |
| ルースの選択公理 | AとBの選ばれやすさの比は、ほかに何が並んでも変わらない、という仮定。ここから正の重みに比例する形が出る。似た候補が加わると外れる（対話） |
