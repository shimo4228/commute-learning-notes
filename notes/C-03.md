# C-03 伝統的な概念分析とその行き詰まり

## 本編の要点

- 伝統的な概念分析は、概念の必要十分条件の組を探す。定義の案を出し、想像の中の反例で試し、直す、を繰り返す（自転車の例）。想像の場面への反応が証拠になるという前提が隠れている（→C-04）
- 知識は正当化された真なる信念（JTB）とされてきた。プラトンにさかのぼると言われるが、プラトン自身が定義として採ったかは解釈が分かれる
- ゲティア（1963、三ページ）は、三条件を満たすのに知識と言えない例を示した（硬貨十枚、フォードかバルセロナか）。崩れたのは十分性のほう。芯は、理由と真のつながりが運で切れていること。同じ形の陽炎と水の例が8世紀インドの仏教論理学の注釈にある（ダルモーッタラに帰されることが多い）
- 条件を足す修繕（偽の前提を経ない、因果、信頼性など）にはそのつど反例が出た（張りぼての納屋の村）。ザグゼブスキー（1994）は、足す条件が真を保証しない限り、不運で切って幸運で戻す手順で反例が作れると論じた
- 応じ方は分かれる。ウィリアムソン（2000）は知識を分解できないものとし、ロッシュらの1970年代の研究は人が概念を典型例を中心に持つことを示した（スズメとペンギン）。クレイグ（1990）は「なぜ知識という概念が要るのか」と問いの向きを変え、よい情報源に印をつける役目を挙げた。定義は見つからなかったが知識のまわりの区別は細かく育った。使い道から概念を考え直す向きが、解明と概念工学に重なる

## 対話で出た論点

- 復習（C-02 のカルナップの四条件）への著者の答えは「再現性、厳密性、概念の広さ、手続きの固定」。厳密性のみ正解。再現性と手続きの固定は同じ日の A-03 と A-02 の語が混ざったもの。正しくは類似性、厳密性、実り豊かさ（最も重い）、単純さ（最後）。「概念の広さ」は元の言葉の範囲を保つという意味なら類似性に近い。思い出しの手がかりは C-02 で著者が読んだ気象庁の晴れ（類似性を手放し、厳密性、実り豊かさ、単純さを得た）
- 著者の問い。いろいろな講義を日替わりでやっている弊害か、一つのテーマを連続で進めた方がよいか。応答。今日は日替わりでなく一日に三回（A-03、B-03、C-03）進め、その最中に前日の C-02 を思い出そうとしたので、直前の A-03 の語が割り込んだと読める。一日で名前が出ないのは珍しくなく、11月5日の復習日で見る。種類を混ぜた練習はその場ではつまずきやすいが長く残り、道具の見分けがつきやすいという知見があり、今日の取り違えはカルナップの条件（概念の作り直し）と測定の性質（揺れの小ささ）の境目が未だ引けていない知らせとして使える。テーマをまたぐ行き来も交互の利点。勧めは交互のまま一日に何回も進めるのを控えめにすること。取り違えやすい概念には本文で一言区別を書く手当ても候補に出した。著者は今まで通り日替わりで進めると決め、仕組みは変えなかった
- 小問（止まった時計）への著者の答え。ゲティア問題は底なし沼。正当化が欠けていると言える。偽の信念だが真であるというケースでもある。真、正当化、信念が互いに少しずつオーバーラップしていて、ゲティア問題はそれを白日の下にさらす
- 講評。「正当化が欠けている」は立場次第で、本人の手元の理由で見る立場（内在主義）なら正当化はあり、信念の作られ方で見る立場（信頼性主義などの外在主義）なら欠けている。著者の答えは後者に近く、本文の答えは前者の立場で書いていた。決着はついていない。「偽の信念だが真」は、結論「いまは3時」は真で、支えの「時計は動いている」が偽という形に言い直せ、偽の前提を経ないという条件で外せる例でもある
- オーバーラップの指摘はザグゼブスキーの論法の芯に近い。正当化を真から切り離すと運の隙間ができ、閉じようとして真を保証させると二つが一つになる。条件を独立させることも一つにまとめることもできず、三つを別々の部品として並べる設計そのものに無理があるという読み方。ウィリアムソンの分解しない立場は、この重なりを部品に分けるのを諦めたとも見える
- 著者の確認。エレノア・ロッシュはトンプソンらと『身体化された心』の共著者ではないか。そのとおりで、ヴァレラ、トンプソン、ロッシュ『The Embodied Mind』（1991、改訂版2016）。典型例のロッシュと同じ人
- つながり。ロッシュの基本レベルのカテゴリー（家具、椅子、肘掛け椅子のうち、体の関わり方が一つにまとまる「椅子」が最も速く自然に使われる）は、概念の中心が体と環境の関わりで決まると読め、身体化された認知の議論の手がかりとしてよく引かれる。必要十分条件の分析が概念を体から離れた条件の一覧として扱う前提を、経験的な側から崩した。A-03 の『The Blind Spot』のすり替え（体験から抽象した量を実在とみなす）と同じ形で、概念を条件の一覧に置き換えて体の関わりを忘れる、と読めるかもしれない
- 著者の受け止め。ゲティア問題で分かったのは、知識が論理的にできていないということ。論理式では組みきれない。どちらかというと ML 的に認知ができていることを暗に示した
- 応答。合っている部分は、必要十分条件は短い論理式の形で、知識がそこに収まらないことと、ロッシュの典型例（事例から作った典型との似かた）が、定義を持たず学んだ境界で判断する分類器に似ていること。A-13 のドレイファスの初期 AI 批判も同じ方向。言い直す部分は、ML も数学の形式なので、違いは「短く読める条件の組か、高次元で事例から学ばれた連続的な境界か」。ゲティアが直接示すのは知識の語の当てはめ方で、認知全体の仕組みは推論。手がかりとして、マシェリーら（2017）はブラジル、インド、日本、アメリカで「正当化された真なる信念なのに知識でない」判断がおおむね共有されると報告（一部に文化差を指摘する批判あり）。定義は書けないのに判断は揃うのは、学ばれた安定した分類器に似る
- ひねり（見立て）。ML 的な認知はゲティア事例を生みやすい。背景の草原で牛を見分ける分類器のように、当たっているが理由がずれている。学んだ境界は理由と真のつながりを保証しない。クレイグに引きつけると、知識という概念は「当たっているがたまたまではないか」を見分ける印として育ったのかもしれず、ML 的な認知が運に頼った当たりを出しやすいからこそ要る、と読める。ホリスティックな判断（学んだ境界）と要領（たまたまでないかを外から点検する仕組み）の関係にも同じ形がある
- 著者の補足。ML というより LLM 的にできていると思う、知識のカテゴリー分けは。推論で後から規則を説明することは可能だが、気が遠くなるようなパラメーターの重みという理解のほうがよいのではないか
- 応答。LLM 的と言うと、文脈で境目が動くこと（同じ語でも文脈で表現が変わる。おでんは鍋かが卓上コンロの話か献立の話かで分かれる）と、規則による説明が後付けになること（ニスベットとウィルソン 1977、人は判断の理由を内側から報告するより手持ちの理論で組み立てる。反論あり。B-02 の推論の忠実性、D-17 と同じ形）が見える
- 留保。重みを理解の単位にすると理解できなくなる。説明には段があり、実装（重み）、手順、何を計算しているか（目的）。後付けの規則は実装の描写としては外れても上の段の描写としては当たりうる（ケプラーの法則）。規則か重みかは二択でなく見る段の違い。解釈可能性研究は中間の段（特徴、回路）を探す営みで、ロッシュの典型例や基本レベルは人の概念の中間の段の描写かもしれない
- 人と LLM のずれ。人の概念の中心は体の関わりで決まり（基本レベル）、少ない事例から作られ、言葉のやりとりで直される。LLM 的な部分と身体化された部分の組み合わせ方は開いた問い
- 土地評価に当てはめると、評価者の判断は重み、要領は後から書かれた規則。要領を判断の中身と見るか、中ほどの段の当たっているが部分的な描写と見るかで、要領とホリスティックな感覚の関係の見え方が変わる

## 概念表

| 概念 | 一言で |
|---|---|
| 解明の条件と測定の性質の区別 | カルナップの四条件は概念をどう作り直すか、信頼性や妥当性は測ったものがどう振る舞うか |
| 内在主義と外在主義（正当化） | 正当化を本人の手元の理由で見るか、信念の作られ方の信頼性で見るか |
| 偽の支え | 真の結論を偽の背景信念が支えている形（止まった時計の「動いている」） |
| 条件の重なり | 正当化と真を独立させると運の隙間ができ、閉じると一つになるという分析のジレンマ |
| 基本レベルのカテゴリー | 体の関わり方がひとまとまりになる中ほどの段（椅子）。最も速く自然に使われる（ロッシュ） |
| 短い条件の組と学ばれた境界 | 人が読める論理式で境目を書くか、事例から学んだ高次元の連続的な境界で判断するか |
| 理由のずれた当たり | 答えは当たっているが手がかりがずれている状態。ML の近道学習に現れるゲティア事例の形 |
| 文脈で動く境目 | 同じ概念でも文脈ごとに境目が引き直されること。LLM の文脈依存の表現に似る |
| 後付けの説明 | 判断の理由を、過程の報告でなく手持ちの理論から組み立てること（ニスベットとウィルソン） |
| 説明の段 | 実装、手順、目的の段。規則は上の段の描写として当たりうる |
| 概念分析 | 概念の必要十分条件の組を探す伝統的な方法 |
| 必要条件 | 満たさないものは決してその概念に入らない条件 |
| 十分条件 | 満たせば必ずその概念に入る条件 |
| 反例 | 定義の案を満たすのに概念に入らない、またはその逆の例 |
| 正当化された真なる信念 | 知識の伝統的な分析。真であり、信じていて、十分な理由がある |
| ゲティア事例 | 三条件を満たすのに、運が介在して知識と言えない例 |
| 認識的な運 | 理由と真のつながりがたまたまで成り立っていること |
| ゲティア問題の不可避性 | 真を保証しない条件を足す限り反例が作れるという議論（ザグゼブスキー） |
| 知識第一主義 | 知識を分解できないものとみなし、ほかを知識から説明する立場（ウィリアムソン） |
| 典型例による概念 | 定義でなく典型を中心に概念を持つという見方（ロッシュら） |
| 概念の役目から問う | 何であるかの代わりに、なぜその概念が要るのかを問うこと（クレイグ） |

## 復習用の問い

1. 必要条件と十分条件の違いを、日常の例で説明できるか
2. ゲティアの例は、知識の三条件のうち必要性と十分性のどちらを崩したのか
3. ゲティア事例の芯にある「運」は、理由と真のあいだの何を切っているのか
4. ザグゼブスキーは、なぜ条件を足しても反例がなくならないと論じたのか
5. 典型例による概念の見方は、必要十分条件の探索にどんな疑いを向けるか
6. 「なぜその概念が要るのか」と問う向きは、カルナップの解明とどう重なるか

## 開いたままの問い

- ルーブリックの改訂は、反例の出力が見つかるたびに項目を足すゲティア以後の追いかけっこと同じ構造か。ザグゼブスキーの論法が評価にも当てはまるなら、条件を足しても埋まらない隙間は何で埋まるのか。クレイグのように評価が何の役に立つかから問い直すべきか（今日の引っかかり。→A-08 全体的評価と分析的評価、A-16 規則は自らの適用を決めない、A-20 統合回）
- 真、正当化、信念が重なり合っていて部品に分けられないなら、「よい出力」も同じく部品に分けられない概念か。それをホリスティックな評価の根拠にできるか（→A-20、C-19 自分の概念を点検する演習）
- 正当化を手元の理由で見るか作られ方の信頼性で見るかの分かれは、LLM の評価者の判断を信じてよい理由を、書き出された推論に置くか判定の当たり方に置くか、の分かれと同じ形か（→A-19、D-17 思考の連鎖は本当の思考か）
- 概念の中心が体と環境の関わりで決まるなら、体を持たない言語モデルの概念には基本レベルにあたる段があるのか。あるとしたら何がそれを決めているのか（→C-17 AIが概念を割る、D-05 特徴と線形表現仮説）
- ホリスティックな判断が学ばれた境界なら、それがたまたま当たっていないかを何で点検するか。要領はその点検として働いているのか、それとも境界そのものを作る教材として働いているのか（→A-13 ドレイファスの技能習得モデル、A-15 直観はいつ信頼できるか、A-20 統合回）
- LLM の正しい答えのうち、理由のずれた当たりをどう見分けるか。知識という概念は言語モデルに当てはめられるか（→D-11 プロービング、D-17 思考の連鎖は本当の思考か）
- 要領は土地評価の判断の、どの段の描写か。中ほどの段の部分的な描写なら、要領に書かれていない部分は何の段にあり、どう共有されているのか（→A-11 ポランニーの暗黙知、A-17 事例で基準を共有する、A-20 統合回）
- 人の概念の LLM 的な部分と身体化された部分は、どう組み合わさっているか。体を持たない言語モデルが人の概念をよく真似られるのは、言葉の中に体の関わりが写し込まれているからか（→C-17、D-05、B-19 能動的推論）
