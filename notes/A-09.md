# A-09 臨床判断と統計的予測

## 本編の要点

- 臨床的な判断と統計的な予測は、材料を頭の中でまとめるか、経験から確かめた関係にもとづく決めた式でまとめるかで分かれる。材料の種類や観察する人では分かれない（ドーズ、フォースト、ミール 1989）。ウェステンとワインバーガー（2004）は「臨床的」が観察する人の軸とまとめ方の軸の二つに使われてきたと指摘した。ミール（1954）は公平な比べには同じ材料が要るとした
- 同じ材料で比べると、式は頭のまとめにほとんど負けない。1989年の総説は約100の比較研究のほぼすべてで式が同じか上とまとめ、グローヴら（2000）のメタ分析では平均で式が一割ほど正確、判断する人の経験によって傾向は変わらなかった。性格検査の課題では単純な規則70%、人62%
- 式が負けない理由は、同じ材料にいつも同じ結論を返すこと（本人をまねた式が本人より当たる）と、材料を実際の予測の力に応じて重みづけること。ただし毎回同じ結論は信頼性の側の性質で、それだけでは当たる保証にならない
- 骨折した脚。式に入っていないまれな事実が結論を大きく変えるときは、人が式を覆して当たる（ミール 1957 の例としてよく紹介される）。ただ、人に覆すかを任せた研究では、覆さず式に従ったほうが全体で当たった。人は例外を見つけすぎる
- ドーズ（1979）の不適切な線形モデル。目盛りをそろえて同じ重みで足すだけの式でも人の判断を上回る（大学院入試で委員会 0.19、同じ重みの式 0.48）。人は材料を選び向きを決めるのが得意で、まとめるのが苦手。働く条件は、よい材料が選ばれていること、各材料がほかの材料の値によらず同じ向きに効くこと。ルーブリックの同じ重みの足し算をこの形で読むのはこの講義の整理

## 対話で出た論点

- 復習の1（温泉宿のアンケートで四つすべてに4を付けた客）。「まず先に全体の判断をしてから、その印象をもとに各観点の採点を行った」で正解（観点の写し）。ほかの客の答えにでこぼこがあることが、写しを疑う決め手になると補った。A-08 の小問2で答えなかった確かめ方は、比べる相手を場面の中に書いたので問わなかった
- 復習の2（冷蔵庫の読書表に読んでいない本を書き足す人に、キャンベルの法則の後半は当たるか）。「当たる」と答えた。答え合わせを保留し、教案の見どころにあった問い（書き足しをできなくしたら困った振る舞いは残るか）を場面を書き直して一往復で出したら、「消える」で正解。そこから答えは「当たらない」で、数そのものが偽られる前半の側だと示し、迷ったら「記録を正直にしたら、困りごとは残るか」と自分に聞く、と添えた。見立て　出題の側と理解の側の両方。前回の歩数計（偽りを封じたあとに営みの変化が残る）と逆向きの作りで、前回の答えの形に引かれやすかった。一方で、前半と後半を見分ける手順は示されれば通るが、場面から自分で当てていない（台帳の弱点「振り分けを自分からしない」の続き）。A-08 で残った「当たる当たらないを言い切らない」形は、今回は二択で言い切った
- 復習の3（B-06 から、猫の体重を同じ体重計で10回量る）。「体重計の癖」で正解。いつも同じ向きのずれは平均に残り、毎回同じ結論を返すことは信頼性の側で当たる保証にならない、と節2への足場にした
- 節1の小問1（飼い主が付けた「元気がない」の印と記録を獣医の表に当てはめる）。「統計的な予測」で正解。観察する人の軸とまとめ方の軸を分けて読めた
- 節2の小問2（家庭菜園の水やりで、本人をまねた式が本人より当たる）。「決定の揺れを防げるから」で正解
- 節3の小問3（乗り換えアプリ、路線が止まった朝と、ほとんど毎回変える人）。「a」で正解。小問4（毎回変えるのが得かを確かめるには何を記録するか）は「到着時間」で通った。アプリの到着予定と並べて記録すること、ときどきアプリのとおりに行く日を混ぜると比べる相手がはっきりすること、を補った
- 節4の小問5（外食の店10軒で「駅から近い」だけを2点に）。「概ね同じ」で正解。小問6（量が多くてデザートも付く店で満足が下がる）。「後者」（同じ向きに効く条件）で正解
- 四つの節を終え、今日の引っかかり（観点ごとのチームと最後のホリスティックな段で、最後の段が観点の和を覆したとき、骨折した脚か覆しすぎかをどう見分けるか）と参考文献を出して講義を終えた。残った節なし。講義のあとの対話はなかった
- 教案の梯子や別の表し方を使った場面は、復習の2の見どころの問い。その場で作った場面はない

## 概念表

| 概念 | 一言で |
|---|---|
| 臨床的な判断 | 材料を判断する人が頭の中でまとめて結論を出すやり方 |
| 統計的な予測（機械的な予測） | 材料と結果の、経験から確かめた関係だけで結論を出す、前もって決めたまとめ方 |
| まとめ方の軸と観察する人の軸 | 人が観察して付けた印でも、決めた式でまとめれば統計的な予測の側に入る |
| 判断の揺れ | 同じ材料でも日によって変わる人のまとめ方。本人をまねた式が本人より当たる理由 |
| 骨折した脚 | 式に入っていないまれな事実が結論を大きく変える場面。人が式を覆して当たる |
| 覆しすぎ | 人が例外を見つけすぎ、まちがって覆す分が正しく覆す分を上回ること |
| 不適切な線形モデル | 予測が最もよくなるようには決めていない重みの足し算。代表は目盛りをそろえて同じ重みで足す式 |
| 雑な足し算が働く二つの条件 | よい材料が選ばれていること、各材料がほかの材料の値によらず同じ向きに効くこと |

## 復習用の問い

1. 家族で行く日帰り旅の行き先を、三つの材料（移動の時間、天気予報、前に行った人の口コミ）から決める。父は三つを眺めてその場で決める。母は、三つを点にして決めた足し方で合計し、点の高い所にする。母のやり方は、臨床的な判断と統計的な予測のどちらにあたるか。選択肢は「臨床的な判断」「統計的な予測」（答え　統計的な予測）
2. パンを焼く人が、生地の膨らみと部屋の温度を見て、焼き始める時刻を決めている。この人の過去の決め方をまねて、同じ二つの材料で決める式を作ったら、式のほうがよく焼けた。式は同じ材料しか使っていないのに、なぜこうなることがあるか。短い一文で（答え　本人は同じ材料でも日によって決め方が揺れ、式はいつも同じ結論を返すから）
3. 天気アプリが「午後は晴れ」と言うので自転車で出かけるつもりだった。次の二つのうち、骨折した脚にあたるのはどちらか。(a) 窓の外を見たら、もう雷が鳴って大粒の雨が降り始めていたので、電車にした。(b) なんとなく雲が多い気がして、アプリが晴れと言う日のほとんどで電車にしている。選択肢は (a) と (b)（答え　(a)。(b) は覆しすぎの疑い）
4. 古本屋で買う本を、「状態がよい」「値段が安い」「好きな作家」の三つの印の数で選ぶ。三つのあいだに、ある印が付く本ほど別の印が付きにくいという逆向きの関係はない。印一つを1点として並べたあと、「好きな作家」だけを2点にして並べ直した。並び順はおおむね同じか、大きく変わるか。選択肢は「おおむね同じ」「大きく変わる」（答え　おおむね同じ。入れ替わるのは点の近い本どうし）
5. 散歩コースを「坂が少ない」「距離が長い」「公園を通る」の三つの印の数で選ぶ。坂の少ないコースでは、距離が長いほど満足して帰ってくる。坂の多いコースでは、距離が長いと疲れ切って満足が下がる。雑な足し算が働く二つの条件のうち、崩れているのはどちらか。選択肢は「よい材料が選ばれていること」「各材料が、ほかの材料の値によらず同じ向きに効くこと」（答え　後者。距離が長いことの効く向きが、坂の印の値で入れ替わる）
6. 雑な重みの足し算（テーマA、ドーズの不適切な線形モデル）で、材料を選び、それぞれがどちらの向きに効くかを決める仕事は、人と式のどちらに残るか。選択肢は「人」「式」（答え　人）

## 開いたままの問い

- キャンベルの法則の前半と後半の見分けは、「記録を正直にしたら困りごとは残るか」を示されれば通るが、場面から自分で当てていない。前回と逆向きの場面で、前回の答えの形に引かれた。次のテーマAの復習で、手順を示さずに、偽りだけの場面と営みが変わる場面を日をおいて一往復ずつ出す（→A-10）
- 今日の引っかかり。作品の質のように、あとで確かめられる結果が無いところで、最後のホリスティックな段が観点の和を覆したとき、それが骨折した脚を見つけた場面なのか覆しすぎなのかを、どうすれば見分けられるか（→A-10、A-15、A-17、A-20）
- 式が負けない理由の一つは、同じ材料で日によって変わる人の揺れを持たないこと。この揺れは次回のノイズの話そのもので、本人をまねた式が本人より当たる現象は、ノイズを取り除くことの効き目として読める（→A-10）
- 同じ重みの足し算で足りる場面と、組み合わせを読む判断が要る場面の分かれ目は、あとで確かめられる結果を予測するのか、作品の質そのものを判断するのか、にありそう（本文の見立て）。土地評価の要領の格差率の掛け合わせは、ほかの材料の値で効く向きが入れ替わる組み合わせをどう扱っているか（→A-16、A-20）
