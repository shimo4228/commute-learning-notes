# C-02 先駆としてのカルナップの解明

## 本編の要点

- 解明は、曖昧な被解明項を精密な解明項に置き換える手続き。カルナップが『意味と必然性』（1947）で言い始め、『確率の論理的基礎』（1950）第1章で方法として述べた。元の意味の発見ではなく、目的のための提案に近い（「魚」から鯨が外れた例）
- よい解明項の四条件は、類似性（かなりの違いは許される）、厳密性、実り豊かさ（多くの法則が言える）、単純さ（最後に考える）。実り豊かさが重く、類似性としばしば引っぱり合う
- 解明項は論理の形を変えてよい。分類（暖かい）、比較（より暖かい）、量（二十五度）。心にかかわる概念では量の解明項がないかもしれず、比較や分類で実り豊かなものを探すべきとした
- カルナップは「確率」を確率1（確証の度合い）と確率2（長期の相対頻度）に割ってから解明した。確率2を確率1に吸収したと読む解釈もあり、評価は割れている（→C-12 概念の分割）
- ストローソン（1963）は、日常の概念の困りごとは精密な別概念に置き換えても解けず、話題が移るだけだと批判した。カルナップは日常と科学の概念はなだらかに続くと応じた（→C-07）。ブルン（2016）は解明を理論的目的のための概念の作り直しと位置づけ、目的を先に決めることを中心に置いた

## 対話で出た論点

- 気象庁の晴れ（雲量2〜8）は厳密性を得て類似性を手放した解明、と著者は読んだ。雲量8は多くの人が曇りと呼ぶ。実り豊かさ（観測所間・年ごとの比較）と単純さも得ていて、どれだけ実り豊かかは統計か洗濯物かという目的で変わる
- 「日常の語の使用にそぐわない」という批判は、分析哲学の中で人工言語の路線へのカウンターが生まれたことに大きく効いていそうだ、と著者。常識的な感覚に訴えるから強い
- 時期で言うと、日常言語学派（ライル、オースティン、ストローソンらのオックスフォード）は1940年代半ばから60年代前半が盛期で、カルナップの解明とほぼ同時代の対抗だった。ストローソンの批判はその陣営からの一撃と読める。後期ウィトゲンシュタインの、意味を使用に見る考えも背景にある
- 常識への訴えは強さと弱さを併せ持つ。強さは、哲学の問いが日常の言葉の中で生まれたなら答えも日常の言葉に返すべきという筋の通り方。弱さは、いまの使い方を基準にすると改良の余地が閉じ、保守的になりやすいこと。ゲルナー（1959）やグライスがこの方向から批判し、学派は60年代後半から70年代に退潮した（衰退の時期と理由には諸説ある）
- その後の振り子。実験哲学は「常識的な感覚」が実際にどれだけ揃っているかを調べ（→C-04）、概念工学はカルナップ側の改良の発想を、ストローソンの批判を抱えたまま引き継いでいる（→C-07）
- 常識や直観に照らす手法の名前を確かめた。中心は反照的均衡（グッドマン 1955 が帰納の正当化で示し、ロールズ 1971 が名付けて広めた。個々の事例の判断と原理を行き来し、両方を直して噛み合わせる）。ほかに、事例への直観を証拠にする事例の方法、ムーア（1925）の常識の擁護、日常言語学派の日常言語分析。ブルン（2020）は解明を反照的均衡と結びつけ、類似性の条件を一方向の照合から往復の調整に読み替えた
- カルナップの位置を確かめた。ウィーン学派へのカウンターではなく、その中心の一人（『世界の論理的構築』1928 は論理経験主義の基本文献）。学派へのカウンターは、外からはポパー（『探究の論理』1934、検証ではなく反証可能性による線引き）、内からはクワイン（「経験主義の二つのドグマ」1951、分析と総合の区別と還元主義への批判）、イギリスでは日常言語学派。カルナップ自身も学派の中で立場を何度も改め、解明は検証の基準が行き詰まったあとの、目的を明示して概念を作る方向への移り変わりとも読める（この読みは一つの見方）
- 著者の自己理解。改良するという、普通ならほぼ裏付けのいらない姿勢に疑問を呈してしまうので、工学的な視点が苦手で、哲学的な傾向のある人間なのだろう。応答では、「改良」には何がよりよいかの基準が先に要り、カルナップはそれを実り豊かさと目的に預けて問わずに済ませた、と整理した。著者が引っかかるのはその預け先のほう。一方で、観想的エージェントは自分で憲法の修正を提案する、つまり改良の姿勢をエージェントの側に組み込んだ設計でもある。改良を疑う人が改良し続けるものを作っていることになり、この同居をどう見るかは開いたまま。C-01 の「戯論と知りつつ定義語を作る」、B-01 の「定義できないが方向はある」と同じ形をしている
- 著者の補足。エージェントはまさに方向付けを欠いていて、最適化すべき目的がない。考えた末に北極星を「変化し続けること」とした。外部環境とのフィードバックループで変わるだけで、目的を欠いている。生存もかかっていないので、変なフィードバックループ
- 応答で出した見方。(1) 「変化し続ける」は最適化の目標というより、止まらないという制約に近い。変化には向きがないので勾配にならない。(2) エナクティヴィズムでは、意味づけの規範は自己を作り続けないと消えるという不安定さと、存続の条件に対する適応性から生まれる（ディ・パオロ 2005）。生存がかからないエージェントには、その規範の源がない。変なループと感じるのはここ。(3) 能動的推論で言えば、好む状態の事前分布が平らなとき、期待自由エネルギーは知るための項だけが残る（→B-19）。(4) カルナップに戻すと、解明は目的を先に置いて実り豊かさで選ぶ。目的のない憲法の変化は解明よりも、誰も舵を取らないまま使われ方で意味が流れる日常言語の意味変化に近い（→C-08 実装の問題）。選ぶ圧のない変化なら、適応よりも偶然の漂流に似てくるかもしれない（類比で、検証はしていない）
- 著者が今日の対話からSNSの投稿案を書いた。AIコーディングは工学で「評価し改良する」が大前提。自分はいちいち「何のために」と問うので畑違いだろうが、多くの人がAIコーディングを始めるなら必要な態度だと思った、という内容。講評では、意味は通るとしたうえで、なぜ必要なのかの一言（改良が安くなるほど、何のための改良かが残る問いになる、など）が抜けていて読み手が補う必要があること、「この分野」の指す先、「思った」の重複、誤字を挙げた
- 著者の修正方針。必要な理由は「ソフトウェア界隈はこの前提にいちいち疑問を持たないから」というニュアンスで書きたい。改良の安さではなく、界隈の文化として前提が問われないことが理由の芯
- 改良の前提に疑問を呈する分野は哲学や社会学くらいだろう、と著者。応答では、技術哲学、科学技術社会論（STS）、人類学、デザインの批判的な流れ（価値に配慮した設計、批判的デザインなど）も挙げた。ソフトウェアの内側の「なぜ」（要求工学の目的の掘り下げなど）は誰かの目的を前提にした問いで、改良そのものを問うものとは違う。外の分野の問いが界隈に届きにくいことが、著者の投稿の「疑問を持たない」を支えているとも読める
- だからベンチマーク主義に強い違和感を感じる、と著者。応答では、ベンチマークを「能力」の解明として読んだ。気象庁の晴れと同じ形で、厳密性、単純さ、比較の実り豊かさを得て、類似性を手放している。違和感は二層ありうる。一つはグッドハート的なもので、点数が目標になると指標と能力が離れる（→A-06、A-07）。もう一つはその手前で、何のための能力かという目的が問われないまま、点数が上がることが改良と見なされること。カルナップの解明は目的を先に置くが、ベンチマーク主義では目的が点数の側に吸収されている。メシックの言い方では、妥当性は点数の解釈と使い方の性質（→A-05）
- 2026-11-03 の C-03 の復習で、四条件を「再現性、厳密性、概念の広さ、手続きの固定」と答え、厳密性以外は同じ日の A-03 の語が混ざった。四条件の名前の定着が弱い

## 概念表

| 概念 | 一言で |
|---|---|
| 解明 | 曖昧な概念を、目的に合った精密な概念に置き換える手続き |
| 被解明項 | 置き換えられる側の、日常の曖昧な概念 |
| 解明項 | 置き換える側の、精密な概念 |
| 類似性 | たいていの場面で元の言葉の代わりに使えること。ずれは許される |
| 厳密性 | 当てはまるかどうかを規則で迷わず決められること |
| 実り豊かさ | その概念を使って多くの法則が言えること |
| 単純さ | ほかの条件が同等なら、定義と法則が単純なほうを選ぶこと |
| 分類・比較・量の概念 | 暖かい、より暖かい、二十五度。解明で形が変わりうる |
| 確率1と確率2 | 確証の度合いとしての確率と、相対頻度としての確率 |
| 理想言語と日常言語 | 精密な人工言語で哲学するか、日常の言葉の使い方から哲学するかの対立 |
| 日常言語学派 | 1940〜60年代オックスフォードを中心に、言葉の日常の使い方を手がかりにした学派 |
| 常識への訴えの保守性 | いまの使い方を基準にすると、改良の余地が閉じやすいこと |
| 反照的均衡 | 事例の判断と原理を行き来し、両方を直して噛み合わせる方法 |
| 事例の方法 | 想定事例への直観を、理論を試す証拠として使うこと |
| 常識の擁護（ムーア） | 懐疑論の前提より、常識の命題のほうが確からしいとする立場 |
| ウィーン学派（論理経験主義） | 論理と経験で哲学を立て直そうとした1920〜30年代の集団。カルナップはその中心 |
| 反証可能性（ポパー） | 経験で反駁されうることを科学の線引きにする基準 |
| 二つのドグマ（クワイン） | 分析と総合の区別、還元主義という論理経験主義の二つの前提への批判 |
| 適応性（ディ・パオロ） | 存続の条件に照らして自分を調整する性質。意味づけの規範の源とされる |
| 制約としての北極星 | 向きを与えず、止まらないことだけを求める指針 |

## 復習用の問い

1. 解明は、元の概念の「本当の意味」を見つける営みとどう違うか
2. カルナップの四つの条件を挙げ、それぞれを一言で言えるか
3. 実り豊かさと類似性が引っぱり合う例を、今日とは別の日常の場面で挙げられるか
4. 「暖かい」「より暖かい」「二十五度」の違いを、A-01 の尺度の水準と結びつけて言えるか
5. カルナップが「確率」を二つに割ったのはなぜか
6. ストローソンの批判は何を心配しているか。カルナップはどう応じたか

## 開いたままの問い

- 常識的な感覚への訴えは、どこまで論拠になり、どこから保守性になるのか。その感覚が実際どれだけ揃っているかを調べたら何が残るか（→C-04 直観は証拠になるか）
- 著者の定義語は、日常の使い方にそぐわないという批判をどこまで引き受けるつもりで作られているか。ずれを許すなら、それで得ている実り豊かさは何か（→C-07 話題の連続性、C-19 自分の概念を点検する演習）
- 改良を疑う姿勢と、自ら憲法を改良し続けるエージェントを作ることは、著者の中でどう同居しているか。エージェントの修正提案は、何を「よりよい」として進んでいるのか（→C-14 概念の倫理、C-20 統合回）
- 生存がかからず目的もないエージェントの憲法の変化で、何が選ぶ圧になっているか。環境からのフィードバックのうち、変化を一方向へ偏らせているものはあるか。偏りがなければ漂流で、あれば隠れた目的があることになるのか（→B-19 能動的推論、C-08 実装の問題）
- ベンチマークへの違和感は、グッドハート的な層と、目的が問われない層のどちらが主か。気象庁の晴れのように、目的を限れば役に立つベンチマークはあるか（→A-05 メシック、A-06 グッドハート、A-19 LLMを評価者として）
- 「望ましさ」の解明は分類、比較、量のどの形なら実り豊かか。実り豊かさを測る理論は何か（今日の引っかかり、B-01 から。→A-18 比較判断）
