# B-05 確率分布

## 本編の要点

- 確率分布は、確率1を起こりうる値のすべてに配り分けたもの。出来事に数を付ける決まりを確率変数 X とよび、P(X=x) を並べる。どれも0以上で足すと1（散歩で会う犬の数 0匹0.2、1匹0.4、2匹0.3、3匹0.1）。とびとびの値なら離散分布。分布にも頻度と信念の二つの読み方があり、仮説が三つ以上なら事前は分布になる（→B-08）
- 期待値 E[X] は値に確率を掛けて足したもの（犬の例で1.3匹）。分布の重心で、長い目で見た平均。一回の予言ではなく、1.3匹の日は来ない。掛けて足す計算は数の間隔が等しいことを前提にしていて、順序尺度の段階に当てると名前の付け替えで値が動く（A-01 の期待値スコア）。早い時期の説明としてホイヘンスの1657年の賭けの論考がある
- 分散は期待値からのずれの二乗の平均で、ばらつきの大きさ。ずれをそのまま平均すると上下が打ち消して0になるので二乗する。平方根で元の単位に戻したものが標準偏差。待ち時間が毎回10分のパン屋と、半々で0分か20分のパン屋は期待値が同じで分散が0と100。統計の言葉としての分散はフィッシャーの1918年の論文からとされる
- 裾の重い分布では分散や平均さえ定まらないことがあり、記録を増やしても平均が落ち着かない（B-01 の果ての国、→B-06）
- 連続な値では一点ちょうどの確率は0で、幅に確率を付ける。確率密度は幅1あたりの確率で、密度×幅の面積が確率、全体の面積は1。密度そのものは確率ではないので1を超えてよく、単位を変えると数字が変わる。連続量で尤度が1を超えうるのはこのため（→B-07）

## 概念表

| 概念 | 一言で |
|---|---|
| 確率変数 | 出来事に数を対応させる決まり |
| 大文字の X と小文字の x | X は出来事に数を付ける決まり、x はその決まりがとる一つの値。P(X＝x) はその値の確率 |
| 確率分布 | 確率1を、とりうる値のすべてに配り分けたもの |
| 離散分布 | とびとびの値をとる分布 |
| 事前分布 | 三つ以上の仮説の並び全体に配り分けた事前 |
| 期待値 | 値に確率を掛けて足したもの。分布の重心 |
| 期待値の間隔の前提 | 掛けて足す計算は値の間隔が等しいことを黙って仮定する |
| 分散 | 期待値からのずれの二乗の平均 |
| ずれの確率変数 | X − E[X]。同じ出来事に、値から期待値を引いた数を付ける新しい確率変数。期待値は必ず0 |
| 標準偏差 | 分散の平方根。元の単位でのばらつきの目安 |
| 連続分布 | 値がいくらでも細かく刻める分布。一点の確率は0 |
| 重み付き平均としての全体の割合 | 全体の割合はグループの割合を数で重み付けした平均で、配分が違えば逆転しうる |
| 記述と因果の読みの区別 | 数字は記録を正しく描くが、どの比較を因果の問いへの答えとするかは数字の外で決まる |
| 量と濃さ（ジャムの量と厚さ） | 確率は量で合計1まで、密度は詰まり具合で単位により値が変わり、1を超えてよい |
| ペースとしての密度 | 時速のように「単位幅ぶん続いたらどれだけか」を言う数。実際の量は密度×幅 |
| 短い窓で見る密度 | 短い幅をとったときの確率がその幅の何倍かを言う数。場所ごとの来やすさを比べられる |
| いる範囲と問いの範囲 | 全体はとりうる値の範囲そのもの。問いの範囲は全体ではなく、重なりを部分として切り出す物差し |
| 何の中の割合か | 割合が出たら、先に分母の集まりを書き、その数に掛ける。全体の数に掛けるずれを防ぐ |
| 確率密度 | 幅1あたりの確率。面積が確率になり、密度自体は1を超えてよい |
