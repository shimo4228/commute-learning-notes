# C-17 AIが概念を割る

## 本編の要点

- AI をめぐる言葉の言い争いは、調べれば答えに近づく部分と、何のためにその言葉を使うかで選ぶ部分に分かれる（この講義の整理）
- 「理解」。ベンダーとコラー（2020年）はタコの思考実験で、文字の並びだけから学ぶ仕組みは意味にたどり着けないと論じた。ミリエールとバックナー（2024年の概説）は、マルコーニ（1997年）にならって、言葉を言い換え説明する力と、言葉を世界の物につなぐ力を分け、言語モデルは前者をはっきり示し、後者は割れているとした。人ではふだん一緒にある二つが言語モデルでは離れて見え、第13回の部分的な指示の形で読める（この講義の整理）。争いは、それぞれの力を持つかという試せる問いと、どちらに「理解」の名を付けるかという選ぶ問いに分かれる
- 「幻覚」。名前は物事を指すだけでなく、なぜ起きたかの見立てと次の手当てを運ぶ。ヒックス、ハンフリーズ、スレイター（2024年）は、言語モデルは知覚しないので見誤りもないとして、フランクファートのブルシット（本当かどうかに関心を持たずに話すこと）を勧めた。2025年の OpenAI などの研究者の論文は名前を残し、見立てを当て推量（誤りも「分かりません」も0点の採点が育てる）に、手当てを採点の作り直しに移した。名前を保ったまま中身が動いた形で、困るのは名前に引かれて古い見立ての手当てを続けるとき
- 「エージェント」。Anthropic（2024年12月）は、手順が前もって決まったワークフローと、モデル自身が手順を決めるエージェントを呼び分けた。カシルザデとガブリエル（2025年）は一つの定義の代わりに、自律、周りへの効き目、目標の込み入り方、幅広さの四つの目盛りと段階を立てた。ある・ないの争いは目盛りごとの確かめられる問いに分かれ、どの目盛りを重く見るか、どの段からその名で呼ぶかは、何のために使うかで選ぶ（第10回の添え字の手、第15回の困りごとが成分を選ぶ、と同じ向き。この講義の整理）

## 概念表

| 概念 | 一言で |
|---|---|
| 調べる部分と選ぶ部分 | 言い争いのうち、試せば答えに近づく部分と、何のためにその言葉を使うかで選ぶ部分（この講義の整理） |
| 説明する力と物を指す力 | 言葉を別の言葉で言い換え説明する力と、言葉を世界の物につなぐ力。マルコーニの分け方 |
| タコの思考実験 | 電信線を盗み聞きして返事を書くタコは、熊の場面で役に立つ返事ができない。ベンダーとコラーの例 |
| 名前が運ぶ見立てと手当て | 名前は、なぜそれが起きたかの見立てと、次にすることを一緒に運ぶ |
| ブルシット | 本当かどうかに関心を持たずに話すこと。フランクファートの言葉で、ヒックスらが「幻覚」の代わりに勧めた |
| 当て推量を報いる採点 | 誤りも「分かりません」も0点の採点では、自信がなくても答えたほうが点が上がる |
| 目盛りで言い直す | ある・ないの一語の代わりに、いくつかの目盛りを立てて、それぞれのどの段にいるかで言う |

## 復習用の問い

1. 子どもが、図鑑で覚えた鳥の名前を全部言えます。公園では実物を見分けられないことを、家族の二人とも確かめてあります。それでも二人は「この子は鳥が分かっているか」で言い合っています。まだ割れているのはどちらでしょうか。1 子どもの力について、2 「分かる」をどちらの力に当てるか。答え　2（説明する力と物を指す力が別れた場面で、残るのは選ぶ部分）
2. 外国語の歌をきれいな発音で歌える友人について、家族の二人が「意味は言えないはずだ」「言えるはずだ」と言い合っています。歌詞の意味を言えるかは、まだ誰も聞いていません。まずできることはどちらでしょうか。1 歌詞の意味を言ってもらう、2 「歌が分かる」の意味を二人で決め直す。答え　1（調べれば答えに近づく部分）
3. 猫が餌を残すのを、家族は「わがまま」と呼んでいます。この呼び名のままだと後回しになりやすいのはどれでしょうか。1 別の餌を出さずに様子を見る、2 歯や体の具合を獣医に見てもらう。答え　2（名前が運ぶ見立てが、確かめを飛ばさせる）
4. 自転車のブレーキがキーキー鳴るのを、家族は「ブレーキの悲鳴」と呼んでいます。この呼び名から思い浮かびやすい手当てはどれでしょうか。1 ブレーキを新しいものに取り替える、2 当たる面の汚れを拭く、3 ゆっくり走る。答え　1（傷んで苦しがっている、という見立てを運ぶ）
5. 二つの機械のうち、人に言われなくても動き続ける度合いでは A が上、こなせる用事の幅では B が上でした。「どちらがエージェントらしいか」は、この二つの目盛りを並べただけで決まるでしょうか。1 決まる、2 何のためにその言葉を使うかを決めるまで決まらない。答え　2（目盛りで言い直したあとに残る、選ぶ部分）

- 今日の引っかかり。AI の意識をめぐる言い争いを、調べれば答えに近づく部分と、何のためにその言葉を使うかで選ぶ部分に分けてみる。そのとき、調べる側に残る部分があるとしたら、それはどこか。著者の答えはまだ無い（C-12 のあとで著者が話した、他者が苦しんでいるかは外からは分からず社会的な合意の話にならざるを得ない、の続き。→C-19、C-20、テーマD）
