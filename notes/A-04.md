# A-04 妥当性の古典的な三分類

## 本編の要点

- 妥当性は狙ったものに当たっているかの問い。入口は三つ。中身を見る内容的妥当性、外の答え（基準）と突き合わせる基準関連妥当性（予測的、併存的）、考えの網の予想が当たるかを見る構成概念妥当性
- 1954年のアメリカ心理学会の技術的勧告（クロンバック中心）は内容、予測、併存、構成概念の四つに分けた。1955年のクロンバックとミールが構成概念妥当性を論じ、のちに予測と併存がまとめられて三分類として広まった
- 内容的妥当性は道具の作りについての主張で、点の読みまでは保証しない。見た目の妥当性（モジャー 1947 が批判的に整理）は証拠にならない。基準関連妥当性は、基準そのものの当否を誰が確かめるかという基準の問題を抱える
- キャンベルとフィスク（1959）は、同じ性質を別の方法で測ると揃う（収束）ことと、別の性質を同じ方法で測ると揃いすぎない（弁別）ことを両方見るとした。方法の分散が点を揃えてしまうことがある
- ギオン（1980）は三分類を三位一体の教義になぞらえ、三つを別の種類とみなして一つの証拠で済ませる扱いを批判した。流れは構成概念を中心に置く方向へ進み、メシック（A-05）に至る
- LLM評価では、ベンチマークの問題の偏りは内容の欠け、人との一致は人を基準にした基準関連妥当性（基準の問題が戻る）、長さや丁寧さとの揃いすぎは方法の分散の疑い

## 対話で出た論点

- 復習（信頼性が高いのに妥当でない例）への著者の答えは、犬が朝食を食べる割合を、全体と前の晩に夕食を食べなかった日で比べるというもの。これは条件で絞る比較（B-02）で、問いとはずれていた。組み直すなら、朝食の割合で食欲を測るつもりが、実際には前の晩の食事でほぼ決まっているなら、記録は毎週揃うが測れているのは食欲でない、という形になる
- 復習（クロンバックとミールの確かめ方）は著者が答えられなかった。法則論的ネットワークの予想が指標で当たるかを見る、という答えを示した。今日の構成概念妥当性の入口と同じ考えなので、本文と合わせて定着させたい
- 復習（P(空|鳴く)）で著者は 0.5 と答えた。正しくは 6÷16 で 0.375。最初は分母の数え損ねと推測したが、著者の計算は空だった8日を鳴いた16日で割ったもので、分母は合っていて分子がずれていた。分子は「空で、しかも鳴いた」6日だけで、空で鳴かなかった2日は分母の世界（鳴いた日）の外にあるので入らない。P(鳴く|空) と P(空|鳴く) は分子が同じ「両方を満たす日」で、絞る先の分母だけが違う
- 分子は分母の世界の中に収まっていなければならない。収まっていないと確率が1を超えることもありうる
- 小問（散歩の楽しさの点が歩数ととても強く揃う）への著者の答えは、構成概念妥当性の観点から楽しさとの関連は言いにくい、というもの。疑わせる方に傾くという結論は正解で、揃いすぎは弁別の失敗の印
- 著者は揃いすぎの理由として、これだけ手間を注いだのだから楽しくないといけない、という心理を挙げた。費やした手間をあとから正当化する働きで、記録する人の意味づけが点を揃える方法の癖の候補として筋が通っている
- 著者の案は「大変だったか」という指標を足して、楽しさに押し込められていた手間の分を切り分けること。キャンベルとフィスクの、別の性質を測って弁別を確かめる発想とほぼ同じ
- 補足二つ。大変さも同じ本人が同じアプリで付けるなら方法が同じままで、正当化の癖は大変さの点にも入りうる。方法の分散を分けるには、楽しさを別の方法（後で書いたメモの調子、同じ道をまた歩きたくなったか）でも測り、点が歩数よりそちらと揃うかを見る要がある
- もう一つ、大変さの分を差し引くと、山歩きのように大変さそのものが楽しさの一部である場合に本物の楽しさまで消える。差し引く分が癖か中身かは点の中からは決まらない。A-03 の正規化と同じ形
- 著者の受け止め。難しい。どうしても重なる部分はあるので、それだけを取り出すのは難しい
- キャンベルとフィスクも純粋な性質を取り出せるとは考えておらず、見たのは並び方。同じ性質を別の方法で測った揃いが、別の性質を同じ方法で測った揃いより強いか。切り出すより、どちらの重なりが大きいかを比べる控えめな確かめ方
- 残る難しさの一つ目。重なりが方法の癖でなく、ものの側にある場合（山歩きで大変さが楽しさの中身になる）。楽しさが道と歩く人の関係で生まれるなら（A-03 のエナクティヴな見方）、切り分けられないのは道具の粗さでなく、切り分けられるという前提がものに合っていないから
- 二つ目。それでも切り分けたくなるのは、点を何かに使うとき。観点ごとに点を付けて足すルーブリックは観点の独立と取り替えを前提にする（A-01 埋め合わせの前提）。ホリスティックな判断は重なりを重なりのまま一度に読む形。どこまで切り分けるべきかは使い方で決まり、A-05 メシックの入口になる
- 重なりが大きいときのもう一つの道は、一つの言葉が二つのものを指していると疑うこと（楽でうれしい楽しさと、手応えのある楽しさ）。C-12 概念の分割へ

## 概念表

| 概念 | 一言で |
|---|---|
| 妥当性 | 測り方が狙ったものに当たっているか |
| 内容的妥当性 | 測り方の中身が、測りたい領域を偏りなく代表しているか |
| 基準関連妥当性 | 外にある答え（基準）と点が揃うか |
| 予測的妥当性 | あとで集めた基準と揃うか |
| 併存的妥当性 | 同じ時期に集めた基準と揃うか |
| 構成概念妥当性 | 考えの網から出る予想が、指標で当たるか |
| 見た目の妥当性 | それらしく見えるか。当たっている証拠にはならない |
| 基準の問題 | 基準そのものが当たっているかを確かめる手段がない堂々めぐり |
| 収束 | 同じ性質を別の方法で測ると揃うこと |
| 弁別 | 別の性質を同じ方法で測っても揃いすぎないこと |
| 方法の分散 | 性質でなく測り方の癖が点を揃えてしまう分 |
| 三位一体の教義 | 三分類を別々の種類とみなし、一つの証拠で済ませる扱い（ギオンの批判） |
| 手間の正当化 | 費やした手間をあとから意味づけ、結果をよく評価してしまう心の動き |
| 揃いすぎ | 別の性質のはずの指標どうしが強く揃うこと。弁別の失敗の印になる |
| 重なりの比較 | 純粋な性質を取り出すのでなく、性質の側と方法の側のどちらの重なりが大きいかを比べること |

## 復習用の問い

1. 妥当性を確かめる三つの入口を、日常の例で一つずつ言えるか
2. 内容的妥当性が高くても、点の読みが保証されないのはなぜか
3. 基準の問題とは何か。LLMの評価者を人の判定と比べるときに、どう現れるか
4. 収束と弁別を両方見なければならないのはなぜか。方法の分散の例を挙げられるか
5. ギオンが三分類を三位一体の教義と呼んで批判したのは、どんな使われ方か
6. 見た目の妥当性は、何の役に立ち、何の役に立たないか
7. P(A|B) を数えるとき、分子に入れてよいのはどの日（どの人）か。分子が分母の世界からはみ出すとどうなるか

## 開いたままの問い

- 自分のホリスティックな評価で、基準になっているのが自分の読みなら、その読みが当たっているかを確かめる役はどこに置かれているか。どこにも置かれていないなら、それは賭けとして置いた始点（A-03）か（→A-17 事例で基準を共有する、A-19 LLMを評価者として測定論で見る）
- 自分の読みにも、手間をかけた出力ほど良く見える、という正当化の癖が入り込んでいないか。それを見分けるには、どんな別の方法の手がかりが要るか（→A-10 ノイズ、A-19）
- 差し引くべき癖と、残すべき中身を分ける決め手は、点の外のどこにあるか。正規化（A-03）と弁別の確かめに共通するこの問いは、妥当性を解釈の性質とみるメシックでどう扱われるか（→A-05 メシックの統一的妥当性論）
- 重なりがものの側にあるとき、切り分けを求めるのは使い方の都合か。重なりを重なりのまま読むホリスティックな判断の妥当性は、どの入口から支えられるか（→A-05、A-08 全体的評価と分析的評価）
- 自分の評価で重なって切り分けられない観点は、一つの言葉が二つのものを指している印か（→C-12 概念の分割）
