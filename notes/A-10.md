# A-10 ノイズ

## 本編の要点

- 判断の誤りは、決まった向きへのずれ（バイアス）と、本来は同じになるはずの判断の望ましくない散らばり（ノイズ）に分かれる（カーネマン、シボニー、サンスティーン『Noise』2021）。判断はふつう一つの事例を一人が一度だけ行うので、散らばりが平均されずにそのまま結果になる
- 誤りの式。ずれの二乗の平均（平均二乗誤差）＝ バイアス × バイアス ＋ ノイズ × ノイズ。犬の体重の例（本当6キロ、見積もり7、9、7、9）でバイアス2、ノイズ1、平均二乗誤差5。ノイズもバイアスと同じ重さで誤りに入る。本人をまねた式が本人より当たるのは、ノイズを取り除いた効き目と読める
- ノイズ監査。同じ事例を、入れ替えのきくはずの何人かに相談させずに判断してもらい、散らばりを測る。正しい答えは要らない。連邦判事208人の研究（1981）、保険会社で予想1割に対して実際5割ほどの差。正しい値の無い判断の散らばりを誤りと呼べるかは割れている（ブラストランドの書評）
- ノイズの出どころは三つ。水準のノイズ（どの事例にも甘め辛め）、安定したパターンのノイズ（事例ごとの長続きする独特の応じ方）、機会のノイズ（同じ人でも時によって変わる分）。正規化で消えるのは水準のノイズだけ。同じ人に繰り返させて取り出せるのは機会のノイズだけで、残りには判断する人の癖と作品の側の割れが同じ形で入る（講義の整理）
- 媒介評価プロトコル（カーネマン、ロヴァロ、シボニー 2019）。見る観点を前もって決め、一つずつ事実にもとづいて切り離して、ほかと比べる目盛りで付け、全部そろってから人が全体を決める。直観をなくさずに遅らせる。サドラーの順（全体を先に）とは逆で、どちらの写りを先に防ぐかで分かれると読める（講義の整理）

## 対話で出た論点

- 復習の1（A-09 から、洗濯機の「おまかせ」コースで骨折した脚にあたるのはどちらか）。著者はまず「骨折した脚ってなんだった？」と尋ねた。ミールのたとえ（金曜の夜はたいてい映画に行くと出す式と、今朝脚を骨折したという事実）と、三つの条件（式の材料に入っていない、まれ、起きれば結論を大きく変える）、覆しすぎを示して出し直すと「2」で正解。見立て　出題の側。講義で作った言い回しを言い換えなしで問いに入れ、名前を思い出させる形になった
- 続けて著者「つまりブラックスワンってこと？」。似ているのは、まれ、影響が大きい、手元のモデルの外にある、の三点で、違いは二つと答えた。骨折した脚は判断する時点で目の前にある事実で、タレブのブラックスワンは起きる前は誰にも見えず、起きてから後付けで説明される出来事。骨折した脚は人が式に勝てる正当な場面はどこかという問いの言葉で、ブラックスワンは記録から作ったモデルが記録に無かった種類の出来事に弱いという警告で、式にも人の頭にも向く。「手元にある例外の事実をどう使うか」と「手元に無い例外にどう備えるか」と分けた
- 復習の2（A-06 から、パンの個数の表を増やそうと食パンをやめて小さな丸パンを毎朝焼く人に、キャンベルの法則の後半は当たるか）。著者「うーん、2　というかちょっと微妙なグレーゾーンを突くような出題だね。概念の理解を問うなら極端な事例で概念の正確をはっきりさせた方が有効じゃない？どう思う？」。受け入れた。見立て　出題の側。家族が個数で見たかったのが「楽しんでいるか」で、丸パンに変えても楽しんでいるかもしれず、営みが目的から外れたかが場面から決まらなかった。概念を初めてつかむ段階では典型のはっきりした場面で芯を作り、境目の場面は芯ができたあとに当てはまる範囲を確かめるときに使う、と答えた。場面の事実をはっきり書くことと、答えの名前に寄った言葉を書き込むこと（C-09 の「急に半分」）は分ける、と添えた。犬の散歩の回数（毎夕の30分の散歩をやめて2分の散歩を一日に何度も、表は本当に出かけた回数、犬が外を歩く時間は短くなった）で出し直し、「1」で正解。前半は記録を正直にすれば困りごとが消える側、後半は記録が正直でも困りごとが残る側、と分けた
- 復習の3（B-07 から、8個の袋で赤、白、赤、赤のときの最尤推定）。著者「最尤推定のやり方忘れた」。尤度 P(D|H) は D を固定して H を動かして比べるもの、最尤推定はそれがいちばん大きい H を選ぶこと、と示して出し直すと、著者「これ、出すとしたら計算コスト高くない？8個だろ？」。受け入れ、3個の袋に小さくして出し直したところ、著者「いや、近道を教えてくれ」。近道（赤の割合の推定は赤の回数÷取り出した回数で、袋の個数を掛ける）と、その理由（p × p × (1−p) × p で、p を上げると赤の分は増え白の分は減る引っぱり合い。log をとって微分すると 3/p ＝ 1/(1−p) で p ＝ 4分の3）、整数の候補の比べ（4096分の 375、432、343 で赤6個）を示した。掛けて整数にならないときは両隣を比べる、と添えた。見立て　候補が九つある8個の袋の計算は暗算に収まらず、出題の側。やり方を忘れていたのは理解の側の思い出しの揺れ。練習（12個の袋、白、赤、赤、白、赤、赤）は「4/6=2/3」「2/3*12=8」「8個」で正解。並びから赤4回と白2回を自分で数えている

- 復習のあと、著者「最尤推定の問題何個か出して」。四問を一往復ずつ出した。練習1（10個の袋、赤、赤、白、赤、白）は「6」で正解、続けて「取り出した割合に全体かけるだけじゃん。なんかこんな教わり方した覚えないけどな」。B-07 では袋ごとに見た並びが何通り出るかを手で数える形で入り、公式は著者が「こんなまどろっこしい計算をせずに公式はないのか」と聞いたときに近道として示したもので、p と微分の説明は今日がはじめて、と答えた
- 練習2（5個の袋、白、赤、白、公式で約1.67）は「2」で正解。125通りのうち赤1個の袋で16通り、赤2個の袋で18通り、と示した。練習3（6個の袋、白、赤、白、白、公式で1.5のちょうど真ん中、二つの袋で並びの数を数えて比べる）は「125 128」「2個」で正解。尤度の山 p × (1−p) × (1−p) × (1−p) が左右対称でないので、真ん中でも引き分けにならない。公式の値にいちばん近い候補は目安で、近い候補どうしが競るときは数えて比べる、とした。練習4（近所の雑貨屋で赤ばかりの袋はめったに売っていない、4個の袋で赤、赤、最尤推定は赤4個、これを取り出したあとのいちばんありそうな袋と言ってよいか）は「2」で正解。尤度比は16対9で2倍弱にすぎず、事前の側が効く場面で、復習の4と同じ形、と示した
- 節1の小問1（当番の一人が抱き上げた目分量の体重でごはんの量を決める。四人の見積もりの真ん中は本当の体重に合っている。量が日によってぶれるのはなぜか）は「ノイズがあるから」で正解。バイアスが0なので残る誤りはノイズの分だけで、一人一回で決めると打ち消す相手がいない、と補った
- 節2の小問2（四人が同じ古い相場の本を見て付けた値段がよく揃った。当たっていると言えるか）は「言えない」で正解。揃いはノイズの小ささで、本の相場が今とずれていれば四人とも同じ向きにずれ、それはバイアスとして並べても見えない（A-03 の、信頼性が高いのに妥当でない形）。小問3（一人目の値段を先に教えてから二人目に聞いたら近かった。ノイズが小さいと言えるか）は「2」で正解
- 節3の小問4（同じ5杯のラーメンを日を変えて二回ずつ付け、一人は二回ともこってりを高く付ける）と小問5（一人は空腹の一回目と満腹の二回目で高く付ける杯が入れ替わる）は、どちらも正解（答えの文は記録に残っていない。小問4は安定したパターンのノイズ、小問5は機会のノイズ）。同じ人にもう一度付けてもらってはじめて二つの違いが見える、と補った
- 節4の小問6（中古の楽器店で最初に手に取ったギターへの一目ぼれを、媒介評価プロトコルのどの段で使うか）は「3」で正解。今日の引っかかりと参考文献を出して講義を終えた。残った節なし
- 講義のあと、著者「じゃあ媒介評価プロトコルに従うなら、観点ごとの評価をサブエージェントにラウンド数を多めにさせた後、ホリスティックサブエージェントが行うという形にすればいいんじゃない？これまでの議論を総合できている気がするな」。筋は通るとしたうえで三つを詰めた。(1) 同じモデルに繰り返させて減るのは機会のノイズだけで、同じモデルの癖（安定したパターンのノイズ）とバイアスは平均でも残る（B-07 の対話の、試行の平均は上振れの手当てになるが同じ向きのずれは残る、と同じ）。減らすには回数より系統の違う判定者を並べる。ノイズ監査で入れ替えのきくはずの別の人を使うのと同じ理屈。(2) 観点のサブエージェントも作品全体を読むので、全体の印象が観点の点に乗り移る余地がある。観点の段に点だけでなく根拠の事実を書かせる形は、著者の llm-as-judge のスキル（二値の確認を証拠として集める）と相性がよい。(3) 最後の段が観点の点を見てから判断すると、点に引っぱられるか足すだけになり、点を軽く見すぎると A-09 の覆しすぎになる。A-08 の対話で著者が考えていた、最後の段に数を見せずに先に判断させる形（サドラーの順）と、二つの順は防ぐ写りの向きが逆。一案として、最後の段にまず点を見ずに全体の判断を書かせてから最終判断を出させ、食い違いを記録する形を示した
- 著者「1つ目はじゃあClaude2モデル、Codex2も出るくらいでいいんじゃないの？　というかあれかな、LLMってEvalから生まれたようなもんじゃん。今のOpus5.5とかならこんなこと言わなくても上手くEvalするんじゃないの？」。系統を混ぜれば安定したパターンのノイズと、自分の系統の文章を高く付ける自己優遇は薄まる。ただ学習に使った文章や人の好みに合わせる調整の方法は系統をまたいで重なり、共通する癖は混ぜても平均しても残る。それは判定者全員に同じ向きに乗るバイアスの側で、ノイズ監査では見えず外の手応えでしか見えない、と答えた。「eval から生まれた」には、評価役の点を押し上げるように育てられたことは A-06、A-07 のグッドハートの形で、長い答えや自信のある言い回しを好む癖はその名残と考えられている、と答えた。強いモデルがうまく評価するかは前提に置かず、並び順や言い回しを変えて付けさせ、散らばりと順番の効き方を測るほうが早い、とした
- 著者「いや、聞きたかったのはOpus5.5にEvalをするようにプロンプトを与えたら、これ以上によく考えられたEvalフローを組むのではと聞きたかった。なぜならこの手順をスキル化する必要があるかどうか検討したかったから」。スキルにする意味はあり、手順を細かく書くより著者の判断だけを薄く書く形がよい、と答えた。何も言わなければ観点に点を付けて重みづけて足す形に落ち着きやすく、それは能力でなく何を良しとするかの選び方の問題。著者がここまでに決めたこと（ルーブリックの合計を結論にしない、全体の判断を最後に置き観点の段は根拠の事実を書く、回数より系統を混ぜる、点を見る前の判断と最終判断の食い違いを記録する）は、モデルが賢くなれば自然に出てくるものではない。もう一つ、スキルが無いと評価のたびに流れが組み直され、手順の側に機会のノイズが入るので、手順を固定することが決定の衛生にあたる。回数、根拠の書かせ方、モデルの組み合わせのような細部はそのときのモデルに任せる、とした
- 著者「ふーむ、ではちょっと案を考えて。Fableセッションで仕上げるわ。」。新しいスキルにせず llm-as-judge に足す案を書いた。判断の順（封をした全体の判断、一つの観点だけを見て二値の確認と根拠の箇所を返す観点の段、作品と観点の証拠だけを見る新しい文脈の最終判断、突き合わせ。最終判断が観点の証拠と逆なら観点に入っていない事実を一行で名指しさせ、名指しできない覆しは覆しすぎの疑いとして記録する）、判定者の組み方（観点の段は系統を混ぜた合議で、食い違いは平均せず割れとして残す。最終判断は一つの目に残す。作品を作った系統と最終判断の系統はできれば分ける）、ときどきの点検（結論は一回目のまま残し、揺れの大きかった項目を添える）、スキルに書かないもの（回数、言い回し、モデル名、証拠の書式の細部）。封をした全体の判断を最終判断に見せないのは講義の整理から出た選び方で、媒介評価プロトコルの元の形は最後の判断者が途中の評価を見て決めるところまで、と断った
- 著者「いや、というよりLLm-as-judgeスキルだけじゃなく他にもEval系スキルはたくさんあるからちょっと全体の整理もするわ。」。どの eval スキルにも効く原則（ノイズとバイアスを分ける、系統を混ぜる、下限を守る判定は合議で上限を選ぶ判定は一つの目、全体と観点が写り合わない順を決める、押すループと評価する判定を分ける、点検は揺れを知るためで結論は一回目のまま、手順の固定がノイズ対策）と、判定の手順に固有のもの（四段、覆しへの名指し、揺れの大きい項目を添える）に分けた
- 著者「けど、この講義今後ももっと精度の高い説が出てくるのか？全部終わってからの方がいいか？」。置き換える説より、埋まっていない部品が残っている、と答えた。eval に直接効く残りとして A-15（直観を信頼できる条件）、A-17（事例で基準を共有する）、A-18（比較判断）、A-19（LLM を評価者として測る）、A-20（統合回）と、B-14〜B-16（較正、適正スコアリングルール、言語モデルの確率）を挙げた。今は器の整理までにし、最後の段の置き方、目盛りの形、基準の渡し方は仮の決めとして薄く書き、A-20 でまとめて見直す、とした
- 著者「じゃあFableが全体の整理ができるような足がかりのプロンプト考えて」。著者の一人称で、棚卸し、重なりの洗い出し、構成の案、確認待ちの四段と、共通の土台に置く原則、llm-as-judge に足す候補、仮の決めとして薄く書くところ、未解決の問いを書いたプロンプトを渡した
- 著者「しかし、この講義シリーズは本当に有用だ。私のEvalに対する解像度もかなり上がったし、確率論にも強くなってきて世界の見え方が徐々に変わってきた。LLmを活用した学習としてはかなりいい線をついている気がする」。うまく回っている理由として、一往復ずつ問うのでどこで分かっていないかがその場で見えること、外れたら問いの形を先に疑うので理解の側の揺れだけが残ること、テーマどうしが支え合ってきたこと（誤りの式は B-05 の標準偏差に乗り、事前と尤度比は eval の覆しの読み方と同じ形）を挙げた
- 教案の梯子を使った場面は無い。その場で作った場面は、復習の2の出し直し（犬の散歩の回数）、復習の3の出し直し（3個の袋）と練習（12個の袋）、最尤推定の練習1〜4

## 概念表

| 概念 | 一言で |
|---|---|
| ノイズ | 本来は同じになるはずの判断の、望ましくない散らばり |
| バイアス | 判断が決まった向きへずれていること。日本語の「偏り」はこちら |
| 誤りの式 | 平均二乗誤差 ＝ バイアスの二乗 ＋ ノイズの二乗 |
| ノイズ監査 | 同じ事例を相談させずに何人かに判断させ、散らばりを測ること。正しい答えは要らない |
| 水準のノイズ | ある人がどの事例にも甘めか辛めかで出る散らばり。正規化で消える |
| 安定したパターンのノイズ | ある人の、事例ごとの独特の応じ方で、別の日にも同じ形で出る分 |
| 機会のノイズ | 同じ人でも、その日の具合や時によって変わる分 |
| 決定の衛生 | どのノイズを消したかは見えなくても、手順を前もって整えて散らばりを減らす考え |
| 媒介評価プロトコル | 観点を決め、切り離して付け、全部そろってから全体を決める手順。直観を遅らせる |
| 繰り返しで減るノイズ | 同じ判定者に繰り返させて平均すると減るのは機会のノイズだけ。癖とバイアスは残る |
| 系統を混ぜた判定者 | 回数より系統の違う判定者を並べると、安定したパターンのノイズと自己優遇が薄まる。系統をまたいで共通する癖は残る |
| 手順の固定 | 評価の流れを毎回組み直すと手順の側に機会のノイズが入る。固定することが決定の衛生になる |
| 上流のノイズと下流のバイアス | 手順どおりに降りてくる評価では、上流の一点のたまたまが、下流ではそろった同じ向きのずれになる |

## 復習用の問い

1. 家族四人が、飼い猫を抱き上げて、目分量で体重を見積もりました。猫の本当の体重は、体重計で量って4キロです。四人の見積もりは、5、7、5、7キロでした。四人の見積もりのバイアス（真ん中が本当の値からどれだけずれているか）は何キロでしょうか。（答え　2キロ。真ん中は6キロ）
2. 家族四人が、飼い猫を抱き上げて、目分量で体重を見積もりました。猫の本当の体重は4キロで、四人の見積もりは5、7、5、7キロでした。真ん中は6キロで、バイアスは2キロ、ノイズは1キロです。本当の4キロからのずれを二乗して平均すると、いくつになるでしょうか。（答え　5。1、9、1、9 の平均。バイアスの二乗4とノイズの二乗1の和と同じ）
