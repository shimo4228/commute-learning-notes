# A-01 測るとは何か

## 本編の要点

- 測定には三つの層がある。感じている何か、それに名前を付けた構成概念、手続きに結びつけた操作的定義
- 構成概念と操作のあいだには必ずすき間がある（スコヴィル値の味見法と化学分析のずれ）
- スティーヴンス（1946）は、許される変換の違いで名義・順序・間隔・比率の四水準を分け、水準ごとに意味を持つ統計が決まるとした
- 順序尺度の平均は目盛りの付け方で動く
- 四分類は二方向から批判されている。ヴェルマンとウィルキンソン（1993）は「水準は問いによって変わる、硬すぎる」、別の流れは「量的構造を確かめずに数を付けている、ゆるすぎる」

## 対話で出た論点

- ルーブリックの各段階は作りからして順序尺度。合計点には「段階が等間隔」「観点どうしが同じ単位で足せる（埋め合わせ）」という二つの前提が隠れている。埋め合わせはグッドハート的な歪みの入口
- ラッシュモデル系統は順序データから等間隔の目盛りを推定する。間隔性の主張には、作品と評定者にわたる並びの不変性の確認が要る（それでも賛否あり）
- LLMのロジットはトークン選択の対数オッズで、段階どうしの距離ではない。期待値スコア（3×0.6+4×0.4=3.4）は等間隔を前提に置いている。細かいことと等間隔であることは別
- 累積確率 P(段階≧k) の対数オッズから段階の境目の距離を推定する方向（順序回帰、段階反応モデル）なら、LLMの分布は材料になる。ただし得られる等間隔は「モデルの選びやすさ」におけるもので、構成概念との対応は別途検証が要る（プロンプトや並び順を変えても境目が保たれるか）
- 較正と妥当性は別の性質。小さな判定器を外して大きなモデルに戻した経験はこの線で読める
- ホリスティックは判断の仕方の名前で、尺度の水準は出力の形で決まる（可否、A〜C、一対比較、金額）
- 土地評価の最終出力は価格。ホリスティックな判断が、外部の目盛り（取引価格）に支えられた比率尺度の数字を出している例。要領の格差率の掛け合わせも価格という単位を借りている
- スティーヴンスのマグニチュード推定法も、人が比率で直接答えられるという想定に立つ（これも疑問あり）
- evalは価値論と測定論が重なる場所。何に価値があるかは測定では決まらない。再現性（信頼性）は測るものを狭めれば簡単に上がる（帯域幅と忠実度のジレンマ）。問いは「価値の広さを保ったまま再現性を上げるには」
- 正常価格は制度と実践によって定められた仮定の価格。価値は共同体の実践の中で形作られ、事例の共有と目合わせで再現性が保たれる（→A-16 規則のパラドックス、A-17 アンカー事例、テーマC 概念工学へ）

## 概念表

| 概念 | 一言で |
|---|---|
| 構成概念 | 直接は見えないが、観察をまとめるために立てる概念 |
| 操作的定義 | 構成概念を具体的な手続きとその結果で定めること |
| 名義尺度 | 区別だけに意味がある数 |
| 順序尺度 | 順番だけに意味がある数 |
| 間隔尺度 | 目盛りの間隔が等しいが、ゼロは任意 |
| 比率尺度 | 本当のゼロがあり、何倍と言える |
| 許される変換 | 情報を失わずに付け替えられる範囲。尺度の水準を決める |
| 埋め合わせの前提 | 観点の合計は、観点どうしを取り替え可能とみなすこと |
| ラッシュモデル | 順序データから等間隔の目盛りを推定する方法 |
| 期待値スコア | 確率で重み付けした点数。等間隔を前提に置く |
| 外部の目盛り | 数字に単位の意味を与える外の基準（価格など） |
| 帯域幅と忠実度のジレンマ | 広く捉えると精度が落ち、精度を上げると狭くなる |

## 復習用の問い

1. 構成概念と操作的定義のすき間を、今日とは別の日常の例で一つ挙げられるか
2. 順序尺度の平均が目盛りの付け方で動くことを、数値例で示せるか
3. ルーブリックの合計点に隠れている二つの前提は何か
4. LLMの期待値スコアは、なぜそれだけでは間隔尺度と言えないのか
5. 土地評価の価格は、なぜ比率尺度として読むことに支えがあるのか
6. 再現性を上げることと、価値の広さを保つことは、なぜぶつかるのか
