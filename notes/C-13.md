# C-13 科学の中の概念変化

## 本編の要点

- 物について知っていることが増える変化（信念を足す変化）と、物の分け方が変わる変化（分類の組み替え）は別の種類の変化（この講義の呼び方）。サガード（1992年）は概念の変化を軽い段から重い段へ並べ、新しい種類を足す、分類の木の別の枝へ移す、木を組み直す、を重い段に置き、ふつうの信念の改め方で扱えるのは軽い二つの段までとした
- 2006年8月24日、プラハの国際天文学連合の総会は惑星を、太陽のまわりを回り、自分の重力で丸くなるほど重く、軌道の近くを掃き払った天体と定義し、三つ目を満たさない天体に準惑星の区分を作った。冥王星は準惑星とされた。決議は冥王星について新しい事実を述べず、区分の組み方を変えた。2005年のエリスの発見はそのきっかけ。スターンらは「掃き払った」がはっきりしないと批判し、丸さで決める定義を支持する。C-07 のベッレーリの例、C-08 の制度の範囲の中の定義にあたる（この講義の当てはめ）
- フィールド（1973年）は、ニュートンの「質量」は、特殊相対性理論で分かれる相対論的質量と固有質量（静止質量）のどちらか一方でなく、両方を少しずつ指していたとした（部分的な指示）。この講義の当てはめでは、そうした語の文は、どちらの候補で読んでも正しければ正しく、どちらでも誤りなら誤りで、分かれればどちらとも決めきれない。例はリンゴの「重さ」（詰まった物の量と量りを押す強さ）と宇宙船の中のリンゴ
- 分かる前の語が何を指していたかは、二つの候補が後の理論で名前を持つので、言えるようになるのは分かったあと。ただし言われている中身は、前の語がそのときすでにそうなっていたこと（言える時と中身の時を分ける、この講義の整理）。C-12 の二つの読み（はじめから一方を指していたと見つかる、まだ決まっていなかったので決める）に、フィールドが三つ目を足した
- 「遺伝子」はヨハンセンが1909年に、何でできているかを決めずにおく語として作った。20世紀半ばから DNA の並びとして調べられ、1960〜70年代に分子の遺伝子の考えが固まったが、それまでの遺伝子とぴったりは重ならず、指すものの範囲が気づかれないまま動いた。ブリガント（2010年）は概念の中身を、指すもの、推論の中での役目、認識上の目的に分け、前の二つの変化が筋の通ったものかは目的に照らして決まるとした。目的が動いたときは、一歩ごとにその直前の目的に照らして評価する（目的を中身に数えることには異論もある）

## 概念表

| 概念 | 一言で |
|---|---|
| 信念を足す変化 | 物について知っていることが増える変化。分け方は変わらない（この講義の呼び方） |
| 分類の組み替え | 新しい種類を足す、物を別の枝へ移す、分類の木を組み直すなど、物の分け方が変わる変化（サガードの重い段） |
| 準惑星 | 太陽のまわりを回り丸くなるほど重いが、軌道の近くを掃き払っていない、衛星でない天体。2006年の決議で作られた区分 |
| きっかけと組み替えは別の変化 | エリスの発見は事例を足す変化で、区分を組み替えたのは翌年の決議 |
| 部分的な指示 | あとの理論で二つに分かれる量の、両方を少しずつ指していた語（フィールドがニュートンの「質量」について言った） |
| 決めきれない文 | 部分的に指す語を含み、二つの候補のどちらで読むかで正しいか誤りかが分かれる文（この講義の当てはめ） |
| 言える時と中身の時 | 前の語が二つを少しずつ指していたと言えるのは後だが、言われている中身は前の時点のこと（この講義の整理） |
| 認識上の目的 | その概念を使って何を知ろうとしているか。ブリガントが、指すものと推論の役目に並べて概念の中身に数えたもの |
| 一歩ずつ、直前の目的で評価する | 目的が動いたとき、各変化をその一歩の直前の目的に照らして評価し、後の目的で前の一歩を裁かないこと |
