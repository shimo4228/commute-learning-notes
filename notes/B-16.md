# B-16 言語モデルの確率

## 本編の要点

- 言語モデルは候補の語ごとに点数（ロジット）を付け、softmax で確率に直す。点数1点ごとに重みを決まった倍率で大きくし（本物は e、講義は暗算のため2）、重みの合計で割る。P(語) ＝ 2^s(語) ÷（すべての候補の 2^s の合計）。散歩3点、昼寝2点、買い物2点なら重み8、4、4で、2分の1、4分の1、4分の1。全部の点数に同じ数を足しても引いても確率は変わらず、決めるのは点数の差だけ
- 確率の対数を対数確率と呼ぶ（log2 P）。確率は1以下なのでいつも0以下で、B-09 の驚き log2(1/P) の符号を逆にした数。2分の1は −1、4分の1は −2。−5 なら32回に1回
- 温度 T は点数を割ってから softmax にかける数。P(語) ＝ 2^(s ÷ T) ÷ 合計。T が1より小さいと尖り、1より大きいと平らになり、どの語が上かの順は変わらない。散歩2点、昼寝0点で、T ＝ 1 なら5分の4、T ＝ 2 なら3分の2、T ＝ 2分の1 なら17分の16。B-14 の友人セの読み替えを一つのつまみで行うものと見られる（講義の整理）
- 2023年の GPT-4 の技術報告では、事前学習を終えたモデルの選択肢の確率は信頼性図の斜めの線にほぼ乗り、人の評価による調整のあと大きく外れた（ずれをまとめた値で 0.007 から 0.074）。2022年の研究は、調整したモデルの数字を温度2.5で平らにするだけで、いくつかの評価でおおむね戻した
- 言葉で述べる確信度（「9割です」と文で答えさせた数）を書く語も softmax で選ばれた語だが、その語が選ばれる確率と答えが当たる確率は別。素直に尋ねると8割から10割の5刻みに集まり高めに出やすいという報告（2024年）と、調整したモデルでは言葉の確信度のほうが数字どおりのことが多いという報告（2023年）があり、割れている。どちらの道の数字も、同じ数字を言った問いを集めて数えるまで当たり方は分からない

- 著者「なるほど、無数の外れた賭けのうちの一つだったとも言えるな」。応答は、B-15 の最後の、一番だけが報われる競争では極端な数字で散らばりを大きくしたほうが一番になりやすい、という形につないだ。研究や事業の賭けも勝った一つだけが大きく残って語られる場で、大きく張った人が勝ち残るのは見通しが正しかったからとも散らばりが大きかったからとも言え、勝った一つを見ただけでは分けられない。テーマA第15回の言い方では、直観が当てになるのは規則性のある場で当たり外れの知らせを何度も受け取ってきた人の場合で、「規模を大きくすれば知能が生まれる」という賭けは一度きりで知らせが返るのに何年もかかる種類のものなので、その判断の仕方が次も当たるかはこの一回からは言いにくい、と答えた（講義の整理）

## 概念表

| 概念 | 一言で |
|---|---|
| ロジット（点数） | softmax にかける前の、候補の語ごとの点数。足して1にならず、マイナスもある |
| softmax | 点数を、1点ごとに決まった倍率で増える重みに直し、重みの合計で割って足して1の確率にする手順 |
| 点数の差だけが効く | 全部の点数に同じ数を足しても引いても、softmax の確率は変わらない |
| 対数確率 | 確率の対数 log2 P。0以下で、驚き log2(1/P) の符号を逆にした数 |
| 温度 T | 点数を割る数。1より小さいと尖り、大きいと平らになる。並びは変えず、数字の大きさだけを動かす |
| 調整による較正の崩れ | 事前学習を終えたモデルの確率は数字どおりに近く、人の評価による調整のあとずれることがある |
| 言葉で述べる確信度 | 文で答えさせた確信の数。語が選ばれる確率とも記号の確率とも別で、集めて数えるまで当たり方は分からない |
| 予測と圧縮 | 交差エントロピーは一語あたり何ビットで書けるかなので、よく予測することと短く書くことは同じことになる（対話） |
| 規模を大きくすると損失が規則正しく下がる | 2020年の OpenAI の研究者たちの報告。モデル、データ、計算の量を増やすと学習の損失がかなり規則正しく下がる。損失の下がり方とできることの増え方は別（対話） |
| 生存者バイアス | 生き残った例だけを集めると、張り方と結果の関係が実際より強く見えること（対話） |

## 復習用の問い

1. 「雨の日は」のあとに続く語に、読書5点、昼寝3点、映画3点が付きました。点数が1点高いごとに重みを2倍にする数え方で、読書の確率はいくつでしょうか。答え　3分の2（3点ずつ引いて2、0、0、重み4、1、1）
2. あるモデルが、ある語の対数確率を底2で −3 と返しました。モデルは、この語が何回に1回来ると見ていたでしょうか。答え　8回に1回
3. 散歩1点、昼寝0点の二つの語があります。点数を温度 T（temperature）で割ってから、1点ごとに重みを2倍にする数え方で確率に直します。T が2分の1のとき、散歩の確率はいくつでしょうか。答え　5分の4（差1を2分の1で割って2、重み4と1）
4. あるモデルが選択式の問いで、選んだ答えの記号に置いた確率が6割と出た問いを集めると、実際に当たったのは9割でした。温度をどちら向きに動かすと、数字どおりに近づくでしょうか。1 上げる、2 下げる。答え　2（数字が実際より低く、平らすぎる。下げると尖る）
5. 温度を上げて確率の山を平らにすると、選択式の問いでモデルが選ぶ答えはどうなるでしょうか。1 変わらない、2 変わることがある。答え　1（温度はどの答えが上かの順を変えない）
6. あるモデルに確信の強さを文で言わせたところ、「9割」と書いた問いを集めると20問あり、そのうち当たっていたのは14問でした。この「9割」は、実際の当たり方と比べてどう言っていたでしょうか。1 高めに言っていた、2 実際どおりに言っていた、3 低めに言っていた。答え　1（実際は7割）

## 開いたままの問い

- 今日の引っかかり。作品の良し悪しの当たり外れが返ってこない eval で、判定器の確信の数をブライアースコアで採点するとしたら、o（outcome、結果）の欄には何を入れることになるのか（B-15 の引っかかりの続き）。この日は答えが無い（→A-17、A-19）
- 著者「なんでこんな次の語を予測するだけのシステムがLLMになるのか、大いなる謎だな」。損失を床とずれた分（KL）に分けると、ずれを詰めるには文章の続き方を決めているものを写し取るしかない、という読み（応答の整理）は、中に何ができているかについてどこまで言え、どこから言えないのか（→B-17、テーマD）
- 応答の問い返し。生き物は行動で世界を変えて驚きを下げられ、事前学習のモデルは渡された文章を読むだけ。この違いは著者の目に大きく見えるか。この日は答えが無い（→B-19）
- 著者「無数の外れた賭けのうちの一つだったとも言える」。一度きりで、知らせが返るのに何年もかかる賭けの判断の良し悪しは、勝った一つの例からは分けられない。分母ごと残す記録（事前登録）が無い場で、判断の仕方そのものを確かめる手はあるのか（→A-15 の二つ目の条件、A-20）
