# B-07 尤度と最尤推定

## 本編の要点

- 尤度関数　起きたデータを固定して仮説を一つずつ動かし、仮説ごとの尤度を並べたもの。ビー玉4個の袋で赤、白と出たら、赤0〜4個の順に16分の0、3、4、3、0。足して1にならなくてよく、意味は仮説どうしの比にある。出方の数（組み合わせ）はどの仮説にも同じだけ掛かるので比では消える
- 最尤推定　尤度のいちばん大きい仮説を答えにする方法。割合の推定では、候補が細かく並んでいれば観測した割合がそのまま答えになる。フィッシャー（1922）が名付け、尤度を確率と分け、尤度は確率の決まりに従わないとした。1912年の手順の説明は事前を等しく置く考えに頼っていたと自分で認めている
- 連続量の尤度　一点の確率はどの説でも0なので、同じ幅の区切りの確率で比べる。幅はどの説にも同じだけ掛かり比で消えるので、観測した点での密度の値を尤度として使う。密度は詰まり具合なので尤度が1を超えてよい（座布団説の2）
- 尤度の頂上は、いちばんありそうな仮説とは限らない。最尤推定はデータをいちばん起こりやすくする仮説を選ぶだけで、データを見たあとの確からしさを言うには事前が要る。尤度の比だけで証拠の強さを言う立場と、事前と合わせるベイズの立場で割れていて、決着していない
- 少ない回数での最尤推定は極端な値（赤、赤から赤4個、3日続けて来たから割合1）を出しやすい。見込みを1に置くと動かなくなる（B-01 のクロムウェルの指針）。事前をどう入れるかは B-08

## 概念表

| 概念 | 一言で |
|---|---|
| 偶然誤差と系統誤差 | ばらばらな向きのずれ（平均で縮む）と、全員に同じ向きで乗るずれ（平均で消えない、偏り） |
| 真度と精度 | 系統誤差の小ささと偶然誤差の小ささ。両方で正確さ |
| 割合の最尤推定の公式 | 赤の個数の推定＝袋の個数×（赤の回数÷取り出した回数） |
| 戻す袋と戻さない袋 | 戻すなら毎回同じ確率で掛け算だけ（尽きない源からの観測に近い）、戻さないなら回ごとに確率と通り数が変わる |
| 記号の由来 | P は probability（確率）、| は given、H は hypothesis、D は data、L は likelihood、E は expectation、μ は mean、σ は standard deviation |
| 尤度関数 | データを固定して、仮説ごとの尤度を並べたもの。足して1にならなくてよい |
| 最尤推定 | 尤度がいちばん大きい仮説を推定の答えにする方法 |
| 尤度は確率でない | 尤度は仮説の確率ではなく、仮説のもとでデータが出る見込み。確率の決まりに従わない（フィッシャー 1922） |
| 共通の掛け算は比で消える | 出方の数や区切りの幅のように、どの仮説にも同じだけ掛かるものは比べるときに消える |
| 尤度は定数倍してよい | 全部の説に同じ数を掛けても、尤度としての比べ方は変わらない（確率に比例するもの） |
| 単位は比で消える | 密度をメートルあたりで測ってもセンチあたりで測っても、説どうしの比は同じ。密度の値そのものは単位しだい |
| 密度としての尤度 | 連続量では観測した点での密度の値を尤度として使う。1を超えてよい |
| 尤度の頂上と事後の頂上 | データをいちばん起こりやすくする仮説と、データを見たあといちばん確からしい仮説は、事前しだいで違う |
