# A-16 規則は自らの適用を決めない

## 本編の要点

- ウィトゲンシュタイン『哲学探究』（1953年）の規則に従うことの議論。1000までの練習で「2を足す」を覚えた生徒が、1000の先で1004、1008と続けても、それまでの練習のどれとも食い違わない。規則の言葉と有限の例は無数の続け方と両立し、どれも何かの読み方で合わせられるなら合う、反するの区別が無くなる（規則のパラドックス）。あいまいな言葉の揺れとは別で、はっきりした規則でも起きる
- 読み方を言葉で足しても、足した言葉にまた読み方が要り、解釈は後退する（道しるべの矢印）。規則の把握には解釈でないものがあり、それは一つ一つの場面で「従う」「反する」と呼ぶことの中に現れる。「解釈」は規則の一つの言い方を別の言い方に置き換えることに限る。理由は尽き、鋤は岩盤で曲がり、私は選ばず盲目的に従う
- 規則に従うことは実践で、従っていると思うことと従うことは別。道しるべに従えるのは、いつもの使い方（慣習）があるかぎり。正誤は人が言うことだが、その一致は意見の一致でなく生活の形の一致。通じ合うには定義の一致だけでなく判断の一致も要り、「測る」は結果のある程度の安定にも支えられる（第3回の信頼性との対応はこの講義の整理）
- クリプキ（1982年）はクワスの例で逆説を鋭くし、意味を決める事実は無いと受け入れたうえで、どんなときに「足し算を意味している」と言ってよいかを周りとの一致から見る懐疑的な解決を示した。マクダウェル（1984年）は、逆説は理解をいつも解釈とみなす思い込みから出るとし、解釈の後退と先まで敷かれたレールの二択そのものを捨てさせるのが狙いだったと読んだ。正しさを周りとの一致だけに置くと共同体そのものに物差しが無くなる、とライトの共同体の見方も疑った。読みは決着していない
- どちらの読みでも、規則が当てはめ方を決めないことは、どう当てはめてもよいことを意味しない。書き切れないことと基準が無いことは別（A-06 の対話）

## 概念表

| 概念 | 一言で |
|---|---|
| 規則のパラドックス | 規則の言葉と有限の例は無数の続け方と両立し、合う、反するの区別が無くなるという逆説 |
| 解釈の後退 | 読み方を言葉で足しても、足した言葉にまた読み方が要り、きりがないこと |
| 解釈でない把握 | 規則の把握は、置き換えの言葉でなく、一つ一つの場面で従う、反すると呼ぶことに現れる |
| 規則に従うことは実践 | 従っていると思うことと従うことは別で、いつもの使い方の中で従うことが成り立つ |
| 判断の一致と生活の形 | 定義の一致だけでなく、同じ場面で同じように当てはめる一致が言葉を支える。意見の一致とは別 |
| 懐疑的な解決（クリプキ） | 意味を決める事実は無いとし、周りとの一致から「意味している」と言ってよい条件を見る読み |
| マクダウェルの批判 | 理解はいつも解釈だという思い込みを捨てれば逆説は出ない。共同体の一致だけでは物差しが無くなる |
| 蝶番の文（『確実性の問題』） | 疑いが回るために動かずにいる文。川床のたとえでは、同じ文が確かめられる側と確かめるための規則の側を行き来する（今日の引っかかりで出した） |

3. 毎朝同じ道しるべに従って山道を歩いてきた人に、なぜ矢の先の方へ歩くのかを尋ねました。理由を二つ三つ答えたあと、「ただこうするんです」と言いました。ウィトゲンシュタインの見方で、この人の言葉について言えるのはどちらでしょうか。1 理由が尽きたところで、ふだんの従い方に行き着いている、2 規則に従っていないことを認めている。答え　1
4. 家族でトランプのゲームをするとき、説明書に無い場面でも、皆が迷わず同じようにやってきた決まりがあります。ある日、一人が違うやり方をして「自分ではそれで合っていると思った」と言いました。この人が規則に従っていたかを決めるのに近いのはどちらでしょうか。1 本人がそう思ったかどうか、2 家族が積み重ねてきたいつものやり方。答え　2（従っていると思うことと従うことは別）
5. クリプキの読みで、ある人を「足し算が分かる人」として受け入れるのは、どんなときでしょうか。1 その人の頭の中を調べて、足し算を意味している事実が見つかったとき、2 その人の答えが、十分多くの場面でまわりの人たちの答えと一致するとき。答え　2（懐疑的な解決）
6. 近所の囲碁の会では、何十年も皆が同じ数え方をしてきましたが、よその会の人から「その数え方はおかしい」と言われました。正しさを会の皆の一致だけに置く読み方で困るのはどちらでしょうか。1 会の皆がそろって外れている、と言えなくなる、2 一人が会の数え方から外れている、と言えなくなる。答え　1（マクダウェルがライトの共同体の見方に向けた疑い）
