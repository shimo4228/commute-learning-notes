# C-04 直観は証拠になるか

## 本編の要点

- 実験哲学は、哲学の想定事例を訓練を受けていない人に読ませ、判断（直観）を調べる。概念分析が暗に頼っていた「誰が読んでもそう感じるはず」という前提を確かめる営み
- ワインバーグ、ニコルズ、スティッチ（2001）はゲティア事例への判断に文化差があると報告したが、キムとユアン（2015）の追試では東アジア85%、西洋系86%が知識を否定し差は出なかった。マシェリーら（2017）も四か国でおおむね共有と報告
- 消極的プログラム。判断が事例の中身と関係のない要因（読む順番、言い回し）で動くなら、証拠としての力は弱まる。スウェインら（2008）はトゥルーテンプ事例（レーラー 1990）で順序効果を報告したが、その後の追試では頑健に再現されなかった。実験哲学40件の追試では約70%が再現（コーヴァら 2021）
- 専門家の擁護（哲学者の直観は揺れにくい）に対し、シュヴィッツゲーベルとクッシュマン（2012）は道徳の事例で哲学者にも同程度の順序効果を見出した（2015年には言い回しの効果も）。ほかの領域への一般化や、往復の過程に専門性があるという反論もあり、評価は割れている
- 直観は世界の事実の手がかりか、概念のいまの使い方についてのデータか。調査がまっすぐ教えるのは後者で、どう使うべきかは調査では決まらない。そこを引き受けるのが概念工学。カペレン（2012）は哲学者はそもそも直観を証拠に使っていないと論じ、これも割れている

## 対話で出た論点

- 復習の1（C-03 の運は何を切るか）への著者の答えは「正当化」。半分正解。切れているのは正当化そのものより、正当化と真のつながり（理由のおかげで真に当たった、の「おかげで」）
- 復習の2（A-03 のカッパ、10皿、各8皿合格、一致8皿）で著者はカッパの中身を忘れていた。偶然の一致を差し引いて一致を測る数と説明し直し、偶然の一致率0.68、カッパ0.12÷0.32でおよそ0.38と示した
- 復習の3（B-03、事前オッズ1対6、尤度比3）の著者の答えは0.5。3対6を3÷6としたと見られる。オッズから確率へ直すときは当たりを全体（3＋6）で割り、1/3。この一手が揺れているので、オッズ1対3と2対3を確率に直す練習を出した（→B-05 以降の復習でも確かめる）
- 練習の答えは 0.25 と 0.4 で、二問とも正解。当たりを全体で割る一手はその場では通った
- 小問1（ゲティア判断が文化で割れていたら論文は何を失うか）への著者の答え。普遍性を失い、西洋知識人の認知的偏りを論じただけになる。失うものは正解。講評では「偏り」の語を直した。偏りと呼ぶと正しい普遍の概念がどこかにある図になるが、判断が割れているなら物差しがなく、西洋の判断も使い方の一つになる。失わずに済むものとして、一つの共同体ではJTBが足りないという事実と、運が理由と真のつながりを切るという構造の分析を補った
- 小問2（順番で揺れる判断は何の証拠として弱くなるか、追試で再現されなかったら何が言えるか）への著者の答え。論理的に導かれる判断としての証拠、つまり真であることの証拠が弱くなる。再現されなければバイアスに左右されずに真と言えるが、ある判断が真かは変わらず振り出しに戻っただけ。講評では、直観は論理で導かれた判断でなく事例を読んですぐ出る判断で、弱くなるのは事例の中身についての証拠としての力と直した。「左右されずに真と言える」は言い過ぎで、言えるのはこの順序効果を根拠に不安定とは言えなくなったところまで。「振り出しに戻った」はよい指摘で、揺れないことは証拠の必要条件で十分条件ではない
- つながり。A-03 の信頼性と妥当性の区別と同じ形。順序効果は信頼性の側を突いただけで、判断が真に当たっているかという妥当性の側は手つかず。振り出しはその問いのこと
- 小問3（調律師の耳が当てになる条件は哲学者にもそろっているか）への著者の答え。試行ごとにフィードバックがあり、正解ラベルを専門家は知っていると言える。哲学者の議論にはフィードバックがなく、哲学の性質上正解ラベルがないか、あっても議論中。芯は正解。講評では、正解は専門家の頭の中にあらかじめあるより外の側（うなり、計器）から毎回返ってくると言い直し、条件を三つに整理した（外から当たり外れが返る、繰り返される、対象が安定している。→A-15）。反照的均衡を返しの役と見る人と、内側の辻褄にすぎないと見る人がいて、著者の答えは後者に近い
- つながり。「正解ラベルがない」は節4の問いへの橋になった。知識の正解が音の高さのように外にあるのか、「知っている」の使い方で半分作られているのか。後者なら直観は使い方のデータ
- 小問4（コンビニ往復を10人中9人が散歩でないとした結果は何を教え、何を教えないか）への著者の答え。用事でない歩行を散歩と捉える傾向があるかもしれないが、どの程度の用事まで許されるかは分からない。前半は正解で留保もよい。後半は、一つの事例からは境目の上の一点しか分からず、境目は事例を少しずつ変えて探るという鋭い指摘。補ったのは、その線を引くのが正しいか（どの使い方を採るべきか）は調査で決まらないこと。節2の聞き方や並び順の揺れもありうる
- 今日の引っかかり（土地評価の熟練者の感覚と哲学者の直観の異同、取引価格の手応えは揺れを減らすか見えにくくするか）を出して講義を終えた。全4節を消化
- 講義後の著者の受け止め。並行する講義（B の判定器、A-03 の評価者の信頼性）や AI の議論では eval のために判定器を作るのに、哲学の分野にはこの視点がなさすぎる、と今回の講義で浮き彫りになった
- 応答。二つに分けた。(1) 判定器の揺れを調べる視点（信頼性）は実験哲学として外から入ってきているが、専門家の擁護で押し返されてきた。視点の欠如より取り入れへの抵抗に近い。(2) 判定器の当たりを確かめる正解ラベル（妥当性）は本当に欠けていて、概念の問いでは正解ラベルを決めることが争点の答えを先に置くことになる。(2) は AI の eval にも返る。判定器と人の評価の一致は主に信頼性の確認で、「よい出力」「理解」のように中身が争われる概念では人の評価が正解ラベルとして当てになるかは決着していない。哲学は判定器の点検が手薄、AI の eval は正解ラベルの危うさを問わずに済ませがち、と逆の側が手薄という見方を出した
- 著者の受け止め。Eval は極めて難しいと分かってきた。人類はずっと考えてきたが確立した答えに辿り着けていない。というより変化し続けるから厄介なのか
- 応答。確立している部分（正解ラベルがあり当たり外れが返る領域。カッパ、較正と適正スコアリング、天気予報の降水確率はよく例に出される）と、確立していない部分（外の基準がない構成概念。クロンバックとミールの網、メシックの妥当性確認は終わらない過程という見方）に分けた。後者は未到達というより閉じない性質かもしれない。変化の二つの源として、測られる側が変わる（グッドハート、概念の流れ）と、測る目的が変わる（結果的妥当性）を挙げた。人類が持っているのは確立した答えより点検し直し続けるやり方、という見方。憲法を書き換え続けるエージェントは測られる側が動き続けるので、この厄介さが最も強く出る対象
- 著者の頼みで、これまでの講義で理解が浅い点をノートから拾って復習した。(1) 証拠が出た場合だけに狭めて数える手順（B-02 の2.5、B-03 の0.67、B-04 の1.8%、今朝のオッズ換算の0.5。外れの側を分母に落とす）、(2) 尤度とオッズのしっくりこなさ（尤度は証拠の側を向く、オッズは天秤の傾き）、(3) 名前の定着（尺度の水準、カルナップの四条件、概念の欠陥の型、カッパ）、(4) クロンバックとミールの法則論的ネットワーク（A-04 で答えられず）、(5) 操作主義で測定が間違えられなくなる理由（定義の形、照らす相手が消える）。確認の問いを5問出した（傘30日、オッズ1対4と尤度比6、尺度の水準三つ、四条件の名前、よい出力の確かめ方）
- 確認1（30日、雨6日のうち傘5日、雨でない24日のうち傘3日、P(雨|傘)）の著者の答えは0.625で正解。外れの側の3日を分母に入れられた。以後は確認の問いを一問ずつ出す
- 確認2（事前オッズ1対4、尤度比6）の著者の答えは0.6で正解。6対4を全体10で割る換算が通った
- 確認3（炊飯の水の量、好きな季節、料理コンテストの順位）の著者の答えは比率、名義、順序で三つとも正解。B-04 で迷った比率（本当のゼロ）も通った
- 確認4（カルナップの四条件）の著者の答えは「厳密性。より少ないことで説明できるオッカムの剃刀的なやつ。忘れた」。厳密性は正解、単純さは中身が合っていて名前が出なかった。類似性と実り豊かさは出なかった（C-03 の復習に続き二度目）。気象庁の晴れで四つを結び直し、「似ているか、厳密か、実りがあるか、単純か」と問いの形で並べる覚え方を出した
- 確認5（外に正解のないよい出力を指標で測るとき、クロンバックとミールでは何を確かめるか）の著者の答えは「構成概念なんちゃら」。名前（構成概念妥当性、1955）は合っていて、中身の法則論的ネットワーク（関係するはず、しないはずの予想の網を張り、指標が予想どおり振る舞うかを見る）が抜けた。よい出力の例で予想を三つ示した（手直しなしで使える割合とは関係、長さとはあまり関係しない、熟練者の順位とは揃う）。総復習の確認は五問とも終えた
- 確認6（C-01 の概念の欠陥の型）は著者が忘れていた（B-03 の復習に続き二度目）。直し方とセットで並べ直した（曖昧すぎる/大盛り/精密化、内部の矛盾/嘘つき/置き換えや分割、説明の役に立たない/虫・鯨/分け直し、見えなくする・傷つける/無償労働・ペットロス/意味の拡張や新語）。「ぼやけている、ぶつかっている、役に立たない、人を害する」とまとめ、型を当てる練習を出した（ひと煮立ち、竹やバナナも入る「草」）
- 欠陥の型の練習の著者の答えは、ひと煮立ち＝曖昧すぎる、草＝説明の役に立たないで、二つとも正解
- 確認7（操作主義で測定が間違えられなくなる理由）の著者の答えは「外部に較正する基準を持たないから」。ほぼ正解で、A-03 の「基準を操作できる」から定義の形の芯に近づいた。補ったのは、較正の道具がないより手前で、意味が測定値そのものなので「測り損ねた」が言葉の上で成り立たない、ずれを言える場所が定義で消えること
- 確認8（尤度は何を表すか、足して1にならない理由）の著者の答えは「仮説を分母にした証拠。別々の条件下なので足しても意味がない」で正解。補ったのは、1になるのは同じ分母の中で足したとき（P(E|H)+P(Eでない|H)）。縦棒の右が分母という読みが身についてきた
- 確認9（同じ証拠で食い違う二人の源と、どちらが近づくか）の著者の答えは「仮説と基準率。仮説」。基準率（事前）は正解、もう一つは仮説でなく尤度比（証拠の読み方）、近づくのは事前の違いのほうで、ここが揺れている。B-04 の雨マークの例で説明し直し、パン屋の行列で事前の違いと尤度比の違いを見分ける練習を出した
- パン屋の練習の著者の答えは、ア＝事前、イ＝尤度比で二つとも正解。続けて、行列を何度も見て近づくのはどちらかを尋ねた
- 続きへの著者の答えは「ア」で正解。事前の違いだけが証拠で近づくことが通った
- 著者の頼みで、事前の違いが洗い流され尤度比の違いは残る仕組みを、比喩を交えて高校生向けに説明した。オッズが2倍で1段の階段に直す（対数で掛け算が足し算、チューリングとグッドの証拠の重み）。アの二人（地下2階と2階、尤度比2）は見るたびに1段ずつ上がり、段差は4段のまま変わらないが、8階（0.996）と12階（0.9998）で確率は1に張りつき区別がつかなくなる（高い塔の展望台の景色）。イの二人（尤度比2と1）は見るたびに差が1段ずつ開き、尤度比1/2なら2段ずつ開く（同じエスカレーターと、上りのエスカレーターと止まった階段）。近づく条件は、尤度比が同じ、証拠が独立、事前が0でない（クロムウェルの指針）。確認として、事前0の人が行列を見続けたらどうなるかを尋ねた
- 確認（事前0の人は行列を見続けたらどうなるか）への著者の答えは「考えは変わらない？」で正解。0に何を掛けても0、底のない地下
- 著者の頼みで、パン屋の例で更新の連鎖を一歩ずつ式で示した。証拠は行列（尤度比2）、友人の「また行きたい」（4）、夕方の売れ残り（1/2、逆らう証拠）、口コミの星（3）。Aさん 1対4（0.2）→1対2（0.33）→2対1（0.67）→1対1（0.5）→3対1（0.75）。Bさん 4対1（0.8）→8対1（0.89）→32対1（0.97）→16対1（0.94）→48対1（0.98）。Cさん 0対1 は動かない。確率の差は0.6→0.56→0.30→0.44→0.23と全体では縮むが、逆らう証拠で一時広がる（0.5付近が最も動きやすく、1付近は張りつく）。オッズの比は16倍のまま。事後オッズ＝事前オッズ×尤度比の積で、積が共通なら事前の違いは相対的に小さくなる。確認としてAさんに尤度比4の五つ目の証拠を出した
- 著者の問い。正しい科学的知識を教えれば、それで解釈できる事象を繰り返し見ることで、よほど反知性主義でない限り皆同じ結論に近づくのか（確認のAさん五つ目の証拠は答えずに進んだので、12対1、約0.92を示した）
- 応答。骨組みとしてはそのとおりで、科学を教えることは尤度比を揃えることに当たる。ブラックウェルとデュビンズ（1962）の意見の融合の定理。崩れやすい条件を四つ挙げた。(1) 誰も0を置かない（定理の条件の芯。反知性主義に限らず疑わない前提一般）、(2) 証拠の独立（同じ情報源の話の重複）、(3) 読み方が本当に揃っていること。尤度比は情報源への信頼という別の信念に支えられ、「専門家が言った」の尤度比は信頼で変わる。ジャーンとチャンとケンプ（2014）は、別の信念の違いだけで合理的なベイズ更新者が同じ証拠で逆向きに強まりうることを示した（分極は必ずしも非合理でない）、(4) 十分な回数。加えて「正しい」の正解ラベルの問題。現実の割れは出発点より読み方、特に情報源への信頼の違いから来ることが多いという見方を出し、人がどこまでベイズ的かには異論ありと留めた
- 著者の受け止め。朝に太陽が昇り沈むことに異を唱える人がほぼいないのも説明できる。ブラックスワンと絡めるとなお面白い
- 応答。日の出は条件がそろった理想に近い場合（自分の目で見られ信頼に頼らない、回数が多い、0を置く人がいない）。ひねりとして、天動説と地動説はどちらも日の出を同じく予想するので尤度比1で、日の出をいくら見ても割れは縮まず、フーコーの振り子（1851）やベッセルの年周視差（1838）のような仮説を見分ける証拠が要った。ブラックスワンは三層で読んだ。(1) 確証と反証の非対称（黒い白鳥一羽で尤度比0、ポパー、ゲティアの反例と同じ形）、(2) ラッセルの鶏（1912。餌は親切説でも太らせて食べる説でも出るので尤度比が1に近いのに確証を積んだつもりになる）、(3) タレブ（2007）の要点、仮説の一覧に無い可能性には黙って0が置かれている。融合した意見の固さと、考えに入っていない一羽で崩れうることの対比（→B-08 でラプラスの日の出の問題と扱う）
- 著者の受け止め。だいぶ分かってきた。ヒューム的な帰納の基礎になりそうな考え方。ループ量子重力などと絡め、今の物理法則はたまたま安定した場だからそうなっているだけで、スケールの問題だという話と相性がよい
- 応答。ベイズは帰納を基礎づけず、帰納の前提（過去の観測が未来の証拠になる）を尤度と事前の形の中にしまい、置き場所を見えるようにする。疑いは解消しないが疑いの置き場所を指せる。グッドマン（1955）のグルーは、これまでの観測が緑とグルーを同じく予想する尤度比1の証拠で、緑に段を上るのは概念の選択から来る（テーマCの話題）。物理は慎重に。ループ量子重力自体は法則がたまたまと主張しない。有効な法則という見方は広くあるが、小さなスケールの細部が違っても大きなスケールで同じ振る舞いになりやすいという安定の理由も与える。スモーリン『Time Reborn』（2013）は法則が時間とともに変わる仮説で少数派。ベイズに寄せると、観測は狭い条件の範囲に偏り、範囲の外で読み方が通じる保証はない。B-03 の判定器を別の集まりに移す話と同じで、法則は観測範囲で較正された判定器のようなものかもしれず、範囲の外はブラックスワンの居場所。物理法則が本当にそうかは未決着

## 概念表

| 概念 | 一言で |
|---|---|
| 直観（哲学での） | 想定事例を読んで、理由を組み立てる前にすぐ出てくる判断 |
| 実験哲学 | 想定事例への人々の判断を、調査や実験で調べる研究の流れ |
| 文化差の主張と追試 | ゲティア判断の文化差は、標本を増やした追試で見られなかった |
| 消極的プログラム | 関係のない要因で揺れる直観を、哲学の証拠とすることに慎重であるべきとする立場 |
| 順序効果 | 事例を読む順番で判断が変わること |
| トゥルーテンプ事例 | 本人の知らない装置で正しい気温を信じる人は知っているか、を問う事例（レーラー） |
| 専門家の擁護 | 訓練を積んだ哲学者の直観は揺れにくいので証拠にしてよい、という応答 |
| 揺れないことは必要条件 | 安定は証拠の前提だが、真に当たっていることまでは保証しない（信頼性と妥当性の区別） |
| 外から返る当たり外れ | 熟練の感覚が育つ条件。外からの返し、繰り返し、安定した対象 |
| 境目を事例を変えて探る | 一つの事例は境目の一点しか教えないので、事例を少しずつ変えて境目を描く |
| 判定器の信頼性と正解ラベル | 判定器が揺れないかの点検と、当たっているかを確かめる正解の用意は別の仕事 |
| 閉じない妥当性確認 | 外の基準がない構成概念では、評価の確かめは終わらず点検し直し続けるものだという見方 |
| 対数の階段 | オッズ2倍を1段とみると、尤度比の掛け算が段の足し算になる |
| 事前の洗い流し | 同じ読み方で証拠を重ねると、段差は残っても確率が1や0に張りついて差が見えなくなること |
| 意見の融合 | 誰も0を置かず同じ情報で更新を続けると、二人の予測は一致していくという定理（ブラックウェルとデュビンズ） |
| 合理的な分極 | 情報源への信頼などの別の信念が違うと、同じ証拠で意見が逆向きに強まりうること（ジャーンら） |
| 見分ける力のない証拠 | 二つの仮説で起こりやすさが同じ証拠（尤度比1）。いくら積んでも割れは縮まない（日の出と天動説・地動説、ラッセルの鶏） |
| 一覧に無い仮説の0 | 考えに入っていない可能性には黙って確率0が置かれ、ブラックスワンで崩れる |
| 帰納の前提の置き場所 | ベイズは帰納を基礎づけず、過去が未来の証拠になるという前提を尤度と事前にしまって見えるようにする |
| グルー（グッドマン） | これまでの観測が緑とも「ある時点から青」とも同じく合う述語。どちらに上るかは概念の選択で決まる |
| 観測範囲で較正された法則 | 法則を、観測してきた条件の範囲で較正された判定器のように見る見方。範囲の外の保証はない |
| 使い方のデータとしての直観 | 直観を世界の事実でなく、概念のいまの使い方についての証拠と読むこと |

## 復習用の問い

1. 実験哲学は、伝統的な概念分析のどの前提を確かめようとしたのか
2. ゲティア判断の文化差の報告は、追試でどうなったか。標本の大きさはなぜ効くのか
3. 判断が読む順番で揺れると、その判断は何の証拠として弱くなるのか
4. 専門家の擁護とは何か。シュヴィッツゲーベルとクッシュマンの結果はそれに何を突きつけたか
5. 直観を「世界の手がかり」と読むのと「使い方のデータ」と読むのとでは何が違うか。概念工学はどちらの先に来るか
6. 熟練した人の感覚が当てになるために必要そうな条件を挙げ、哲学者の想定事例への判断にそれがそろっているかを言えるか

## 開いたままの問い

- 事例への直観の妥当性、つまり判断が真に当たっているかは何と突き合わせれば確かめられるのか。外の基準がない構成概念と同じ困りごとか（→A-02 見えないものを測る、A-04 妥当性、A-15）
- 概念の問いの「正解ラベル」は、使い方で半分作られているのか、外にあるのか。半分作られているなら、熟練者の直観は正解を写すのか作るのか（→C-05 意味の外在主義、A-16 規則は自らの適用を決めない）
- 判断が割れたとき、どれかを「偏り」と呼べるのはどんな物差しがあるときか。概念の使い方に正誤を言う基準はどこから来るか（→C-05 意味の外在主義、C-14 概念の倫理）
- 土地評価の熟練者の感覚は、哲学者の直観とどこが同じでどこが違うか。のちの取引価格のような外の手応えは、感覚を揺れにくくするのか、揺れを見えにくくするだけか（今日の引っかかり。→A-10 ノイズ、A-15、A-20 統合回）
- 概念の境目の形は、事例を少しずつ変えて聞けば描けるか。描けた境目は、典型例を中心にした広がり（C-03 のロッシュ）と同じ形か（→A-18 比較判断、C-12 概念の分割）
- 哲学は判定器の点検が手薄、AI の eval は正解ラベルの危うさを問わずに済ませがち、という見方は当たっているか。較正された小さな判定器を戻した経験は、信頼性と正解ラベルのどちらの側の問題だったか（→A-19 LLMを評価者として、B-14 較正、A-20 統合回）
