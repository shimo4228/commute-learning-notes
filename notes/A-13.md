# A-13 ドレイファスの技能習得モデル

## 本編の要点

- ヒューバートとスチュアートのドレイファス兄弟は、1980年の報告で大人が教わりながら技能を身につける道筋を段階に分け、1986年の本『Mind over Machine』で、初心者、上級の初心者、一人前、習熟者、熟達者の五段階に整えた（1980年の報告には上級の初心者の段が無く、最後に達人の段があった）。ヒューバートは規則と記号で知を組む初期の人工知能の批判者でもあった
- 初心者は、経験がなくても見分けられる、場面から切り離された手がかりにもとづく規則に従う（玉ねぎを中火で3分）。上級の初心者は、何度か経験して見分けるしかない場面の相も使い、相を指す格言に従える（透き通って甘い匂いがしたら）。格言は、その領域の理解をすでにある程度持つ人にしか使えない
- 一人前は、見える相が多すぎるので、計画や見方を自分で選び、大事なものとそうでないものを分ける。選び方を教える規則は無く、選んだ見方の成功と失敗を自分のこととして引き受ける（ハウゲランドの、勝つことを気にかけない機械との対比）。関わりと危うさを避けて規則の安全を求める人は伸びが止まりやすい
- 習熟者は、何が大事かが選ばなくても見えるが、どう応じるかはまだ考えて決める。熟達者は、同じ見え方の場面を、経験で、一つの応じ方を共有する小さな集まりに細かく分けていて、見えたときにはもう応じている。慣れない場面では熟達者も考える、と二人は書く
- ゴベとチャシー（2009年）は、熟達者はほとんど考えずに動けるという描き方を批判した。カプランの試しは細部が書かれず評価できず、統制した実験では同時の課題で手の質が落ち、考える時間を減らすと腕前が下がる。熟達者もふつうの対局で、見て、読み、また見る行き来をしている。直観を本物の働きと認める点は共通で、割れているのは、ふだんの振る舞いの中に分析がどれだけ残るか。2018年にスチュアート・ドレイファスとルースが応答し、モンテロ（2016年）も議論を続けている

- 著者「結局考え抜いてもがいた結果ブレークスルーが生まれるんだと思うんだよな。四六時中感げないことが理想の禅師だというような主張には全く同意できない」（「感げない」は「考えない」と読んだ）。応答は、臨済の公案の修行の「大疑」（公案を解けないところまで抱え込み、疑いの塊になってもがき抜く）を挙げ、求められているのは考える働きを一点に集めて押し切ることで、四六時中考えない禅師の像はこの面を落としている、とした。兄弟の段階でも伸びる力は一人前の段のもがき（自分で見方を選び、外れたら悔しく思う）に置かれていて、著者が同意できないのは、もがき終えて考えなくなった状態を最終的な理想に置くところだ、とした。ウォーラスが1926年に準備、あたため、ひらめき、検証の四段を描き、ひらめきは意識して取り組み続けた準備のあとに来る、と添えた
- 著者「割と暗黙知の領域は瞑想との絡みで語るべきことがたくさんあるんだよな。それこそ大乗はこれを死ぬほど気にした伝統な気がするし」。応答は対応を三つ並べた（応答の側の並べ方）。熏習（繰り返した行いが種子として阿頼耶識に積もり、気づかれないまま次の見え方と振る舞いを形づくる。兄弟の経験がしみこむ話やブルデューの構えと同じ形で、唯識はそれを転じる転識得智まで論じ、暗黙の層を自分で組み替えられるかという、暗黙知の論者があまり扱っていない問いに入っている）。根本無分別智と後得智（区別を離れた智のあとに、区別をもう一度使って世界の中で働く智が来るので、考えないことを到達点とする主張に対し、大乗はその先に分ける働きが戻ることを置いている）。方便（相手や場面に応じた説き方と振る舞いは規則に書き切れず、集合的な暗黙知や熟達者の細かい見分けと重なる。世俗の言葉に頼らなければ勝義は説けないという中観の立場も同じ向き）
- 著者「うーん、どっちもかな。どっちかというと維摩や、禅のように語ることで壊れるものを気にしてきたことが気になるかな」。応答は維摩の一黙（入不二法門の章で、菩薩たちが順に不二を言葉で語り、文殊が言葉も説明も離れることが不二に入ることだと語ったあとで、維摩は黙る）を挙げ、これまでの講義に出た「語ると壊れる」の形を三つに並べた（応答の側の並べ方）。ポランニーの形（従属的な手がかりを言葉にすると、いまここの働きが崩れる）、A-12 の禅と系譜の対話の形（外からの記述を修行する側が取り込むと、伝わっていく中身が変わる）、維摩や中観の形（言葉そのものが分ける働きを持つので、分けられないものを語ると語った時点で別のものになる）。この伝統は語ると壊れると知りながら膨大に語り続け、公案は語ることで語りを壊す使い方の言葉と読める、著者の要領とホリスティックな感覚をどう結びつけるかという問いもこの形をしている（全体の感覚を観点の一覧に書き出すと何かが壊れるが、書かなければ共有できない）、と添えて、三つのどれに近いかを尋ねた。記録はここで終わっていて、著者の答えはまだ無い
- 教案の備えのうち使ったのは、節4のつまずきの予測（小問5で1を選ぶ）とその手当て（慣れない場面は争点でないと戻し、一本の線とジグザグの線に戻す）。その場で作った場面は、復習3の確かめ（写真がないと書けない表）と後半の側の例（ミニトマト一粒）、小問4の出し直し（初めて聞く曲の伴奏）、小問5の言い換えと確かめ（いつもの道を走る自転車）、講義の前後の対話の材料（コリンズとクッシュ、ブルデューのゲームの感覚と履歴効果、無念と黙照禅、ベイロック、大疑とウォーラス、熏習と後得智と方便、維摩の一黙）

## 概念表

| 概念 | 一言で |
|---|---|
| ドレイファスの技能習得モデル | 初心者、上級の初心者、一人前、習熟者、熟達者の五段階で、規則に頼るやり方から、場面が見えてそのまま応じるやり方へ移る道筋 |
| 場面から切り離された手がかり | 経験がなくても誰でも同じように見分けられる手がかり。初心者の規則はこれにもとづく |
| 場面の相（aspect） | その場の様子のうち、何度か見て覚えるしかないもの。上級の初心者が使い、格言はこれを指す |
| 見方を選び結果を引き受ける | 一人前の段。何を大事にするかを自分で選び、その成功と失敗を自分のこととして受け止める |
| 何が見えるかと、どう応じるか | 習熟者は何が大事かは見えるが応じ方は考えて決め、熟達者は応じ方まで見えている |
| 場面の細かい見分け | 熟達者を習熟者から分けるもの。同じ見え方の場面を、一つの応じ方を共有する小さな集まりに分ける |
| 熟達者も考えているのではないか | ゴベとチャシーの批判。熟達者のふだんの振る舞いにも、見て、読み、また見る行き来が残る |
| 格言は相を共有する人どうしの合図 | 選手のこつの言葉が経験の無い人に理論に聞こえないのは、指す相を見分けられないから（小問1の対話） |
| ゲームの感覚 | その場で何がふさわしいかを考えずに分かる感覚（ブルデュー）。地位を得た人のやり方が、ふさわしさの手本になる逆向きの流れもある |
| 履歴効果（ヒステリシス） | ある環境で育った構えが、環境が変わったあとも前の形のまま残り、いまの場とずれること（ブルデュー） |
| 出来ばえの主張と価値の主張 | 考えないほうがうまくいくという主張と、考えないことそのものに価値があるという主張。前者から後者へ滑り込みやすい |
| 語ると壊れる三つの形 | いまここの働きが崩れる（ポランニー）、伝わる中身が変わる（記述の取り込み）、語った時点で別のものになる（維摩、中観）。この講義の並べ方 |

## 開いたままの問い

- 今日の引っかかり。観点の一覧は、最後の全体の判断と突き合わせる手すりの役のほかに、判定するモデルの目が場面に入るための入口の役もどこかでしているのか。講義のあとの対話は別の方へ進み、まだ扱っていない（→A-17、A-19、A-20）
- 「上手さ」を「その場でうまくいったこと」で決める、一周して空っぽに聞こえる説明（著者がブルデューを嫌う理由）。何がうまくいくかを場の側が決めているなら、熟達者の描き方にも同じしょうもなさが入るのか。熟達を、場でうまくいくことと切り離して言い表す手立てはあるのか（→A-15、A-20）
- 著者「私は物事の上達において暗黙知を重視するが、そうなることだけが価値のあることだという主張を激しく嫌う」。考えないほうがうまくいくという出来ばえの主張は、どこで考えないことそのものの価値の主張へ滑るのか（→A-14、A-15）
- 「考える」の解像度。内観では考えない瞬間はほとんどない（著者）。熟達者の論争の「考える」を、言葉になるつぶやき、先を読むこと、注意が動くことに分けると、ドレイファス兄弟とゴベとチャシーはどこで割れ、どこで割れていないのか（→A-14、C-17、テーマD）
- 語ることで壊れるもの（著者、維摩と禅）。応答が並べた三つの形（いまここの働きが崩れる、伝わる中身が変わる、語った時点で別のものになる）のどれに近いかを尋ねたところで記録が終わっている。要領とホリスティックな感覚をどう結びつけるかという問いは、どの形の壊れ方を相手にしているのか（→A-16、A-17、A-20）
- 暗黙の層を自分で組み替えられるか（応答が熏習と転識得智で並べた問い）。暗黙知の論者があまり扱っていないところ（→A-20）
