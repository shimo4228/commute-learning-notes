# C-10 言葉の争い

## 本編の要点

- チャーマーズ（2011年の論文「言葉の争い」）は、二人が関わる事実では一致していて、ある語の意味の割れ方だけから起きている争いを言葉の争いと呼んだ。語の割れ方が片づけば、事柄についての争いは消えるはず。典型はジェイムズ（1907年）のリスの話で、「回る」の二つの意味を分ければ争うことは残らない
- 同じ文でも、二人のあいだの一致の背景しだいで、言葉の争いにも事実の争いにもなる（七分の曲を「長い」と言うか、四分だと思い込んでいるか）
- 消去法。鍵の語とほぼ同じ意味の語を禁じ、残った言葉で、二人がまだ割れていて、もとの争いの一部になる文を探す。見つかればまるごと言葉の争いとは言えない。「X とは何か」の争いには、X1、X2 と添え字を付けて、それぞれについて割れているかを確かめる添え字の手が使える（その場で別の語の設計を行う手に近い、はこの講義の整理）
- 言葉が何も左右しないときの、ただの言葉の争いと、ある語に何が入るかで暮らしが変わるときの、言葉が大事な言葉の争い。チャーマーズは、語が何を意味すべきかを、もとの争いから切り離した別の問い（概念の倫理、C-14）として扱う。プランケットとサンデルは、同じ場面をメタ言語的交渉として、争いの中身そのものと読む。どちらがよいかは割れている
- 岩盤の争い。関わる事実では一致していて、これ以上基礎的な言葉で明らかにできない概念をめぐる実質のある争い。道徳の「べき」、意識、存在が難しい場合として挙がる。消去法で鍵の語を禁じても、ほぼ同じ意味の語でしか言い表せなくなる。ただし岩盤の札はめったに切れず、どこを岩盤と見るかも論者で割れている

- 一つ目、Eval の広さ。添え字の手で Eval1（課題の結果に点を付ける、ベンチマークの意味）と Eval2（良し悪しを判断して使うか決めること全般）に分けると、事実で割れる文は残らない（8月の記事の組み直しは Eval2）。言葉の争いだが、どちらを取るかで問いの立て方が変わる（記事の言う「引力」）ので、言葉が大事なほう。語が何を意味すべきかは、チャーマーズの扱いでは切り離した別の問い（→C-14）
- 二つ目、Eval の問いが責任の問いに置き換わってしまう、という記事の心配。岩盤というより話題の取り替え（C-07）の心配に近い。「Eval」「評価」を禁じると「誰かに渡す前に、聞かれたら答えられるところまで自分で確かめる」が残り、基礎の言葉で言えている。注の「説明は判断の前か後か」も手順と判断の順番の話として言い直せる
- 岩盤の候補として示したのは「結局、説明をするのは人間です」の「人間がしなければならない」。実用の意味なら言い直せ、道徳の意味（エージェントが説明できても人が引き受けるべき）なら岩盤の候補になる、と分けて尋ねた。著者「1かな。結局責任引受が現在の社会だと人間しかできないから」。実用で、根拠は今の制度についての事実なので、記事に岩盤の争いは無いと見た。割れるとしたら、今の社会が本当にそうなっているかという事実の争いになる
- そこから出たこと（応答の側の読み）。「どこで」が今の制度で決まるなら、記事の答えの候補は今の社会という条件付きの答えになり、エージェントが責任を引き受けられる仕組みができれば人間が Eval する場所も動く。記事の心配は半分当たっていて、「どこで」は責任の割り振りで決まり、Eval の問いとして残るのは「どう確かめれば説明に耐えるか」（注の前か後か）。著者はこの読みが記事の引っかかりに「合っている」と答えた
- 8月の記事で前半を組み直したとき、足りないところは読む前に言えたか、読んで初めて分かったか、と尋ねた。著者は「2」読んで初めて分かった。著者自身の記事の Eval も、説明が判断の後にある形だった。LLM の Eval に向けていた引っかかり（判断のあとから理由を添える）と同じ形が、著者自身の Eval にもある
- 最後に、その組み直しの理由を今誰かに説明したら、LLM が判定のあとに添える理由と同じ種類か、と尋ねたところで、著者「掘り下げはこれくらいにして」。答えは出ていない
- 記録を頼んだあと、著者「しかし、チャーマーズは仕事の幅が広いな。哲学的ゾンビの議論で有名だが、このような概念工学の議論までしているのだな」。応答は、意識の難しい問題とゾンビの議論のほかに、アンディ・クラークとの拡張された心の論文、二次元意味論、仮想現実の哲学、大規模言語モデルに意識がありうるかの議論がある、と答えた。そのうえで、言葉の争いの論文はゾンビの議論と無関係でなく、ごく少ない基礎的な概念からすべての真理を組み立てられるかを探す2012年の『Constructing the World』の中で、どの概念がこれ以上言い直せない基礎かを見分ける道具の役も持つ、岩盤の例に意識が挙がるのはそのため、とした
- 同じ応答で、著者の懐疑の立場を消去法の言葉で言い直した（応答の側の読み）。「意識」を禁じても注意や報告やアクセスの言葉で言い直せて割れている文は残らない、と見る立場で、そう見るならゾンビをめぐる争いの多くは、チャーマーズが岩盤と見る場所でじつは言葉の争いになっている。どちらに寄るかは論者のあいだで割れている
- 著者「彼の元々のテーマってなんなの？意識について探求している哲学者ではないの？」。出発点は意識で、もともとは数学の人（アデレード大学で数学、インディアナ大学で哲学と認知科学の博士号、1993年。ホフスタッターの人工知能の研究グループに在籍し、博士論文の題は「意識の理論に向けて」）、その後アンディ・クラークのいる研究プログラムで博士研究員、いまはニューヨーク大学の教授で心と脳と意識の研究センターの共同所長、と答えた。仕事の幅が広く見えるのは、意識の議論を支える道具（ある事実から別の事実が導けるとはどういうことか、どの概念が基礎か）を言葉と知識の側から自分で作ってきたからで、概念工学の2020年の論文はそこから外へ伸ばした枝、とした
- 著者「おや？人工知能の研究者なの？なんだか時流が味方をするタイプの人間だな。めちゃくちゃ経歴が強いな」。肩書きは哲学者で、若いころに類推や知覚を計算機で組む研究グループで神経回路網の小さな実験や類推の計算の論文に関わった、自分で手を動かした経験のある哲学者、と答えた。時流については、意識と計算機の関係は30年前から一貫して扱ってきた問いで、大規模言語モデルが出て世の中がその問いに追いついた形、とした。哲学論文の索引サイト PhilPapers を共同で立ち上げたことも挙げた
- 著者「やば、現在の哲学者の中では指折りと見て間違いなさそうだな」。心の哲学で、いま生きている人の中で最も影響力のある一人と見るのは多くの人が同意する、「難しい問題」は賛成する人も反対する人も使う共通の言葉になった、と答えた。ただ影響力が大きいことと主張が通っていることは別で、デネットの長い批判、キース・フランキッシュらの錯覚主義（言い直せない何かがあるという感じそのものを説明すべき錯覚として扱う）を挙げ、著者の懐疑の立場はこちらの側に近いはず、とした。消去法で言えば、チャーマーズは「意識」を岩盤に置き、錯覚主義は岩盤に見えるもの自体を言い直そうとしている、どちらが通るかは決着していない
- 著者「しかし、消去法はかなり実用性が高い概念な気がするな」。応答は理由を三つ挙げた。道具が小さく、言い合う二人のあいだや自分一人の頭の中でも使えること。次に何をすればよいかを四つに振り分けること（事実の争いなら事実を確かめる、ただの言葉の争いなら本題に戻る、言葉が大事なら目的から語の使い方を決める C-06 の改良的分析へ、岩盤なら言い直せないところまで来たと分かる）。添え字の手が決着を急がずに済む形になっていること。判断が入る所も残り（ほぼ同じ意味の語をどこまで禁じるか、言い直した文がもとの争いの一部と言えるか）、言い直しのふりをして同じ争いを持ち込むこともできるので、機械的な判定法というより見通しをよくする手順と見るのがよい、とした。応答の思いつきとして、AKC のエージェントと人の意図のずれや、エージェントが憲法の修正を提案する場面にも、同じ語を違う意味で読む言葉の争いとして添え字の手を組み込める余地がある、と添えた
- 著者「うーん、なかなか面白いな。グローバルスキルにしてもいいな。叩き作れる？」。消去法を六つの段にしたスキルの叩き（verbal-dispute-check）を作って送った。段は、争いを一文にする（相手のいない記事なら決めずに残した点を言い合う二人の立場に置き直す）、事実が一致しているかを確かめる、鍵の語と近い語を禁じる、禁じた語を使わずに言い直す（「X とは何か」には添え字の手）、四つに振り分ける、岩盤と言う前に実用の「べき」として目的、制度、手順の言葉で二度言い直してみる。例には本文の「休む」を使い、著者の記事は入れていない。このリポジトリには入れず、置くなら著者が手元の ~/.claude/skills/ に置く、とした。決めていないことは、AKC や憲法修正の場面に当てる段を足すかと、禁じる語に英語の同義語を含めるか

## 概念表

| 概念 | 一言で |
|---|---|
| 言葉の争い | 関わる事実では一致していて、語の意味の割れ方だけから起きる争い |
| 事実の争い | 事柄そのものについて二人の見ていることが割れている争い |
| 消去法 | 鍵の語と近い語を禁じて言い直し、まだ割れている文が残るかを見る手順 |
| 添え字の手 | 「X とは何か」の争いで、X を禁じて X1、X2 と名前を付け、それぞれについて割れているかを確かめる手 |
| ただの言葉の争い | 言葉が何も左右しないときの言葉の争い。乗り越えて本題に向かえばよい |
| 言葉が大事な言葉の争い | ある語に何が入るかで暮らしや決まりの結果が変わる言葉の争い。語が何を意味すべきかの問いが残る |
| 岩盤の争い | 事実では一致し、これ以上基礎的な言葉で言い直せない概念をめぐる、実質のある争い |
| 実用の「ねばならない」の言い直し | 目的と事実（今の制度など）で言い直せる「ねばならない」は岩盤にならない。割れるなら事実の争いになる |

## 復習用の問い

1. 二人が、庭の木について「この木は大きいか」と言い合っています。高さが3メートルであることも、隣の家の木より低いことも、二人とも知っています。テーマC（概念工学）のチャーマーズの区別で、この言い合いは事実の争いと言葉の争いのどちらでしょうか。1 事実の争い、2 言葉の争い、から番号で一つ選んでください。答え　言葉の争い
2. 二人が「このスープは辛いか」と言い合っています。一人は、唐辛子が入っていることを知りません。もう一人は、唐辛子を入れたところを見ていました。テーマC（概念工学）のチャーマーズの区別で、この言い合いは事実の争いと言葉の争いのどちらでしょうか。1 事実の争い、2 言葉の争い、から番号で一つ選んでください。答え　事実の争い（唐辛子が入っているかで割れている）
3. 二人が「この猫は太っているか」と言い合っています。体重が6キロであることも、ごはんの量も、動き回る量も、二人とも知っています。テーマC（概念工学）のチャーマーズの消去法で、「太っている」と、それに近い「太め」「ぽっちゃり」を禁じて言い直したとき、二人がまだ割れている文は残るでしょうか。1 残る、2 残らない、から番号で一つ選んでください。答え　残らない（言葉の争い）
4. 図書館の決まりに「静かな本読みの部屋では、おしゃべりは禁止」とあります。親子が小声で絵本を読み聞かせている声を「おしゃべり」に入れるかで、二人の利用者が言い合っています。声の大きさも、読み聞かせであることも、二人とも分かっています。どちらで数えるかで、親子がその部屋に居られるかが変わります。テーマC（概念工学）のチャーマーズの区別で、この言い合いは次のどちらでしょうか。1 ただの言葉の争い、2 言葉が大事な言葉の争い、から番号で一つ選んでください。答え　言葉が大事な言葉の争い
5. 二人が「誕生日のプレゼントが気に入らなかったとき、くれた人に正直に言うべきか」と言い合っています。くれた人の気持ちも、正直に言えば少しがっかりすることも、二人とも分かっています。それでも割れていて、「べき」を禁じると「そうするのが正しい」のような近い言い方しか残りません。テーマC（概念工学）のチャーマーズの考え方で、こうした争いは何と呼ばれるでしょうか。1 ただの言葉の争い、2 岩盤の争い、から番号で一つ選んでください。答え　岩盤の争い（ただしチャーマーズは、この札はめったに切れないと念を押す）

## 開いたままの問い

- 今日の引っかかり。「このモデルには推論力がある」「いや、ない」と言い合う二人に、「推論力」「推論」「考える力」を禁じた消去法を当てたとき、まだ割れている文が残るとしたら、それはどんな文か（A-02:60 から。→C-17）
- 8月の記事を組み直した理由を今誰かに説明したら、それは LLM が判定のあとに添える理由と同じ種類か、違うなら何が違うか。後から付けた説明が当てになる条件（規則性のある環境と、当たり外れが返ってくること）として受ける（→A-15）
- 記事「人間が Eval するのは、どこなのか」で残った問いは、責任の割り振りで「どこで」が決まったあとの「どう確かめれば説明に耐えるか」、言い換えると説明を判断の前に置くか後に置くか。要領とホリスティックな感覚をどう結ぶかと同じ形（→A-17、A-20）
- Eval の語が何を意味すべきか（Eval1 の点数か、Eval2 の判断全般か）は、言葉が大事な言葉の争いのあとに残る問い。どちらの語の設計（同じ語を広げるか、別の語を当てるか、C-09）で扱うかも含めて（→C-14、C-18）
- 「人間が説明を引き受けなければならない」を今の制度についての事実に置いたので、エージェントが責任を引き受けられる仕組みができたとき、人間が Eval する場所がどう動くか（AAP の責任帰属の設計と重なる。→C-17）
- 著者の意識への懐疑を消去法で言うと、「意識」を禁じても注意や報告やアクセスの言葉で言い直せて割れている文は残らない、と見る立場になる（応答の側の読み）。チャーマーズが「意識」を岩盤に置くのと錯覚主義が岩盤に見えるもの自体を言い直すのと、どちらに寄るかを、消去法のどの段で決めることになるか（→C-17、D-16、D-20）
- 消去法を、AKC のエージェントと人の意図のずれや、Contemplative Agent が憲法の修正を提案する場面に、同じ語を違う意味で読む言葉の争いを見つける手順として組み込めるか。スキルの叩き verbal-dispute-check で決めていない二点（その場面に当てる段を足すか、禁じる語に英語の同義語を含めるか）とあわせて（→C-18、C-19）
