# 確率と情報理論　第6回　正規分布と中心極限定理

2026年11月7日

## 復習

前回の思い出しの問いです。二つで一組です。

1. 15メートルの廊下で、飼っている猫は、入口から3メートルの地点と9メートルの地点のあいだのどこかで、どこも同じくらいの見込みで昼寝をします。(ア) 入口から7メートルまでのところで寝ている確率はいくつでしょうか。(イ) 問いの範囲を入口から12メートルまでに変えると、確率はいくつになるでしょうか。答えの前に、猫のいる範囲と、問いの範囲と、その重なりを書いてみてください。

2. 二つの散歩コース A と B で、飼い犬が途中で座り込んで動かなくなった日の割合を比べます。晴れの日だけ見ても、雨の日だけ見ても、A の方が座り込みが少ないのに、全部まとめると B の方が少なく見えます。A を雨の日によく使っていたからです。(ア) 天気が、どちらのコースを選ぶかと、犬が座り込むかの両方に効いているなら、分けた数字とまとめた数字のどちらで比べるのがよいでしょうか。(イ) 分ける軸が天気でなく「その日に犬が疲れていたか」で、疲れは A を選んだ結果として生じるもの（A には日陰がない）だとしたら、どちらで比べるのがよいでしょうか。

今日が復習日にあたる問いはありません。

## 本文

前回は、確率を値の全体に配った姿を分布と呼び、その重心を期待値、散らばりを分散と標準偏差で測りました。今日は、ある一つの分布の形が、なぜこれほどあちこちに現れるのかを考えます。

### 釣鐘型の分布

八百屋の店先に、きゅうりがたくさん並んでいるところを思い浮かべてください。長さを測って短い順に並べると、20センチ前後のものがいちばん多く、18センチや22センチのものはそれより少なく、15センチや25センチのものはごくわずかです。しかも、長い側と短い側の減り方がほぼ同じに見えます。

この、真ん中が高く、左右に同じ形でなだらかに下がっていく山の形を、釣鐘型と呼びます。釣鐘型の代表が正規分布です。

正確に言うと、正規分布は、左右対称で山が一つの連続分布で、平均と標準偏差の二つの数で形が決まります。平均は山の真ん中の位置を決め、標準偏差は山の幅を決めます。標準偏差が小さければ細く高い山に、大きければ低く広い山になります。

前回の言葉で言えば、この山の線は密度を描いたものです。山の高さそのものは確率ではなく、ある範囲の下の面積が、その範囲に入る確率になります。曲線を表す式もありますが、今日は使いません。

正規分布には、覚えておくと便利な目安があります。平均から標準偏差一つぶんの範囲に、全体のおよそ68%が入ります。標準偏差二つぶんの範囲には、およそ95%が入ります。三つぶんなら99.7%で、ほぼ全部です。

きゅうりで言えば、平均20センチ、標準偏差2センチなら、100本のうちおよそ68本が18センチから22センチのあいだに、およそ95本が16センチから24センチのあいだに入ります。24センチを超えるものや16センチに届かないものは、合わせても5本ほどです。

ただし、ちょうど正規分布に従うものは、実際にはまずありません。きゅうりの長さはマイナスになりませんし、極端に長い品種が混ざれば形は崩れます。正規分布は、多くの量がおおよそこの形をしている、と言うときの、よくできた近似の形です。

**小問1**　同じきゅうりの山（平均20センチ、標準偏差2センチ）で、22センチより長いきゅうりは、100本のうちおよそ何本でしょうか。

### 足し合わせると釣鐘型になる

では、なぜ釣鐘型があちこちに現れるのでしょうか。手がかりは、足し算にあります。

硬貨を使うすごろくを考えます。硬貨を投げて、表なら2マス、裏なら0マス進みます。1回だけなら、0マスか2マスが半々で、分布は二本の同じ高さの棒です。山はありません。

2回投げると、表裏の出方は、表表、表裏、裏表、裏裏の4通りです。合計は4マス、2マス、2マス、0マスで、2マスになる出方が二つあります。分布は0マスが4分の1、2マスが2分の1、4マスが4分の1になり、真ん中が高くなりました。

4回投げると、出方は16通りです。合計が0マスになるのは全部裏の1通り、2マスは4通り、4マスは6通り、6マスは4通り、8マスは全部表の1通りです。1、4、6、4、1と並べると、もう山の形が見えています。真ん中が多いのは、真ん中の合計にたどり着く出方の組み合わせがいちばん多いからです。

回数を増やしていくと、この棒の並びは、どんどん正規分布の釣鐘型に近づいていきます。もとの1回の分布が、山のない二本の棒だったことを思い出してください。

これが中心極限定理の中身です。正確に言うと、互いに関係なく決まる（独立な）量を、たくさん足し合わせると、もとの一つ一つの分布がどんな形であっても、その合計の分布は正規分布に近づきます。合計を個数で割った平均でも同じです。ただし、成り立つための条件があります。それは次の二つの節で扱います。

この形を最初に見つけたのは、ド・モアブルで、1733年に、硬貨を何度も投げたときの表の回数の分布を、釣鐘型の曲線で近似しました。ラプラスは1810年に、これを独立な誤差の和の話へ広げました。

ここから、釣鐘型がよく現れる理由について、一つの説明が出てきます。19世紀の前半、ハーゲンは、一つの観測の誤差は、ごく小さな独立な誤差がたくさん足されたものだ、という仮説を立てました。たとえば空気の揺らぎや器械のわずかな傾きのような小さなずれの合計なら、中心極限定理によって、誤差は釣鐘型になるはずです。

きゅうりの長さも、日当たりや水やりや土の具合といった小さな要因の積み重ねと見れば、同じ説明が当てはまります。ただし、この説明がどこまで通用するかは意見が分かれています。19世紀の終わりに統計が生物や社会のデータに使われるようになると、正規分布から遠い、左右が非対称な分布がたくさん見つかりました。足し合わせとして読める量かどうかは、量ごとに確かめることになります。

**小問2**　硬貨のすごろくで4回投げたとき、合計が4マスになる見込みは、0マスになる見込みの何倍でしょうか。また、その理由を、出方の数を使って言えるでしょうか。

### 平均は落ち着いていく

足し合わせると釣鐘型になることが分かりました。今度は、その釣鐘の幅に目を向けます。

同じすごろくで、1回あたりの平均の進みを考えます。1回だけなら、進みは0マスか2マスで、期待値の1マスからは必ず1マスずれています。前回の計算と同じ手順で、標準偏差は1マスです。

4回投げて、合計を4で割った平均を見ます。平均がとる値は0、0.5、1、1.5、2マスで、16通りの出方が1、4、6、4、1と分かれます。1回のときは両端の0と2にしか立たなかったのに、4回の平均は真ん中の1の近くに集まっています。表と裏のずれが、互いにいくらか打ち消し合うからです。

どれくらい縮むかには、決まった割合があります。独立なものを n 個平均すると、平均の標準偏差は、1個のときの標準偏差の √n 分の1になります。4個なら2分の1、9個なら3分の1、100個なら10分の1です。統計では、この平均の散らばりを標準誤差と呼びます。

n 分の1まで縮まないのは、ずれが全部は打ち消し合わないからです。散らばりを半分にしたければ、数を2倍でなく4倍にしなければなりません。読める人のために書くと、独立なら合計の分散は1回の分散の n 倍になり、合計の標準偏差は √n 倍になります。平均はそれを n で割るので、√n 分の1が残ります。

前の節の目安と組み合わせると、こう言えます。すごろくで100回投げると、1回あたりの平均の進みは、およそ68%の見込みで0.9マスから1.1マスのあいだに、およそ95%の見込みで0.8マスから1.2マスのあいだに入ります。1回ごとには0か2しか出ないのに、100回の平均は1のすぐそばにほとんど収まります。

料理の味見を思い出すと、感覚がつかめます。鍋のスープをひとさじだけ味見すると、たまたま濃いところをすくうこともあります。四さじすくって平均すると、さじごとの偏りは半分ほどにならされます。三分の一にしたければ、九さじ要ります。

この縮み方には、中心極限定理の条件の一つ目が効いています。ずれが独立であることです。もし、使うスプーンにいつも少し塩がついていたら、何さじ味見しても、その塩の分の濃さはすべてのさじに同じ向きに乗ります。さじごとのばらばらな偏りは平均で縮みますが、全部のさじに共通するずれには打ち消す相手がいないので、何さじ平均しても同じだけ残ります。

**小問3**　(ア) すごろくの1回あたりの平均の進みについて、散らばり（標準偏差）を3分の1にするには、何回分を平均すればよいでしょうか。(イ) 4人の友人が同じきゅうりの長さを測り、平均を取ります。4人が同じ一本の、目盛りが少しずれた巻尺を順に使った場合、平均で小さくなるずれと、小さくならないずれは何でしょうか。

### 平均が落ち着かないとき

中心極限定理の条件の二つ目は、散らばり（分散）が有限であることです。これが崩れるのは、裾の重い分布です。

すごろくに「ワープ」のマスがあり、ごくまれに、桁違いの数のマスを一気に進むとします。100回の平均を取っているところに、一度だけ1万マスのワープが出たら、それだけで平均はおよそ100マス跳ね上がります。一回の出来事が、平均全体を決めてしまいます。

ワープの大きさに上限がなく、大きなワープほど少しずつしか珍しくならない場合を考えます。ワープの散らばりが限りなく大きいと、合計や平均の分布は釣鐘型に近づきません。さらに裾が重く、平均そのものが定まらない分布では、回数を増やしても、そのうちさらに大きなワープが出て、また平均が跳びます。平均は、いつまでも一番大きな一回に引きずられます。

前回の分散の節の終わりに、ごくまれな桁違いの値が出る分布では、分散や平均さえ定まらないことがある、と書きました。ワープのすごろくは、その世界の例です。極端な例として知られるのがコーシー分布で、この分布に従う値は、何個平均しても、平均の散らばり具合が1個のときと変わりません。B-01 で話した果ての国で中心極限定理が使えないというのは、この崩れ方のことです。

正規分布にも、まれな外れはあります。ただ、標準偏差二つぶんの外は5%、三つぶんの外は0.3%と、遠くへ行くほど急に減っていきます。

裾が重い分布では、遠くへ行ってもその減り方がゆるく、桁違いの値が無視できない頻度で出てきます。数を集めて平均を取る前に、どちらの分布に近いかを確かめておく必要があります。

**小問4**　ワープのあるすごろくで、ワープの大きさに上限がなく、大きなワープほど少しずつしか珍しくならないとします。1万回投げた平均は、100回投げた平均より当てになると言えるでしょうか。数を使わずに、理由とあわせて答えてください。

## 今日の引っかかり

同じ判定器に同じ作品を何度も判定させて平均すると、ばらばらな揺れは、回数の平方根に応じて小さくなります。けれども、すべての回に共通する癖は、何度平均しても残ります。そして、作品そのものが見る角度によって本当に評価の割れる作品なら、平均はその割れを、釣鐘の真ん中の一つの数に畳んでしまいます。

自分の eval で回数を重ねて平均を取るとき、縮んでいるのは判定器の揺れなのか、作品の割れなのでしょうか。その二つを分けて見るには、何を平均せずに残しておけばよいのでしょうか。

## 答え合わせ

復習の1について。猫のいる範囲は3メートルから9メートルで、全体は6メートルです。(ア) 問いの範囲は入口から7メートルまでで、いる範囲との重なりは3メートルから7メートルの4メートルです。部分4を全体6で割って、3分の2です。全体を問いの範囲の7メートルや、廊下の15メートルにすると、ずれてしまいます。(イ) 問いの範囲が入口から12メートルまでなら、猫のいる3メートルから9メートルを丸ごと含みます。重なりは全体と同じ6メートルなので、確率は1です。猫は必ずその範囲のどこかにいます。

復習の2について。(ア) は分けた数字です。天気は、コースの選ばれ方と座り込みの両方に効いている共通の原因なので、天気をそろえて比べないと、A が雨の日に多く使われていた分だけ不利に見えます。(イ) はまとめた数字です。疲れは A を選んだことの結果の一部なので、疲れで分けて比べると、A の日陰のなさという欠点を消してしまいます。どちらで比べるかを決めたのは、どちらの場合も、軸がどこから来たかという見立てでした。

小問1について。18センチから22センチに68本が入るので、その外は32本です。正規分布は左右対称なので、32本は短い側と長い側に16本ずつ分かれます。22センチより長いのは、長い側の16本です。32本と答えたら、短い側まで数えています。

小問2について。6倍です。4回投げたときの出方16通りのうち、合計が4マスになるのは、表が2回と裏が2回の並び方で6通りあります。0マスになるのは全部裏の1通りだけです。真ん中の合計には、たどり着く出方の組み合わせが多いので、出やすくなります。

小問3について。(ア) は9回です。平均の標準偏差は回数の平方根分の1になるので、3分の1にするには、平方根が3になる9回分を平均します。3回分では、およそ1.7分の1にしかなりません。(イ) 一人一人の読み取りのばらばらな揺れは、互いに打ち消し合って、4人の平均では半分ほどに縮みます。巻尺の目盛りのずれは4人全員に同じ向きに乗っているので、平均しても同じだけ残ります。

小問4について。当てになるとは言えません。大きなワープほど少しずつしか珍しくならないので、回数を増やすと、それまでより大きなワープに出会う見込みも増えます。そのたびに平均が大きく跳ぶので、1万回の平均も、たまたまその中で一番大きかったワープに引きずられたままです。回数を増やすと平均が落ち着くのは、ずれが互いに打ち消し合える場合に限られます。
