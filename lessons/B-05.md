# 確率と情報理論　第5回　確率分布

2026年11月7日（土）

## 復習

前回の思い出しの問いです。二つで一組です。

2. 二人が公園で、同じ鳥の声を聞きました。二人とも「あの鳥らしい声だ」と同じくらいに聞き取っています。一人は「この公園にはあの鳥がよく来る」と思っていて、もう一人は「この季節にはまず来ない」と思っています。二人の見込みの食い違いは、事前と証拠の読み方のどちらの側にあるでしょうか。この先、別々の日に何度も同じ声を聞いたら、二人の見込みは近づくでしょうか。

今日が復習日にあたる問いです。

3. （A-02 から）操作主義の立場をとると、なぜ測定が「間違える」ことができなくなるのでしょうか。

4. （B-02 から）分けた数字とまとめた数字が逆の結論を示すとき、どちらを使うべきかは何で決まるのでしょうか。

## 本文

これまでの回は、「雨が降るか」「病気か」のように、起きるか起きないかの二つに一つを扱ってきました。今日は、起こりうる値がいくつもある場合に進みます。

### 確率を値の全体に配る

散歩のたびに、道で出会う犬の数を数えるとします。0匹の日もあれば、3匹の日もあります。何十日も記録をつけたら、こんな割合になったとしましょう。

0匹が0.2、1匹が0.4、2匹が0.3、3匹が0.1。

これまでは一つの出来事に一つの確率を付けていました。ここでは、起こりうる値の一つ一つに確率を付け、その並び全体を見ています。足すと0.2＋0.4＋0.3＋0.1でちょうど1です。手持ちの確率1を、起こりうる値に残らず配り分けた姿、と考えると分かりやすいと思います。この配り方を確率分布と呼びます。

もう少し正確に言います。出来事に数を対応させる決まりを確率変数と呼び、よく X と書きます。「今日出会う犬の数」が X で、P(X=2)=0.3 は「出会う犬が2匹である確率は0.3」と読みます。確率分布は、X のとりうる値すべてについて P(X=x) を並べたものです。どの値も0以上で、全部足すと1になる。B-01 で見たコルモゴロフの決まりが、値の並びの上でも守られています。

確率変数という名前は少し紛らわしく、確率でも、ふつうの意味の変数でもありません。出来事に数を付ける決まりそのものです。数を付けるという点では、A-01 で見た測定と同じ手つきで、どの尺度の水準で数を付けたかが、次の節で効いてきます。

犬の数のように、とびとびの値をとる分布を離散分布と呼びます。サイコロの目、一日に届く手紙の数、ゲームで一回に引くカードの枚数などがそうです。

分布も、B-01 の二つの顔をそのまま持っています。犬の数の分布は記録の割合から作ったので頻度の読み方ですが、「明日は何匹に会うと思うか」を自分の見込みとして0匹から3匹に配り分ければ、信念の度合いの分布になります。B-03 では事前を「雨か、雨でないか」の二つに置きましたが、仮説が三つ以上あれば、事前は仮説の並び全体への配り分け、つまり分布になります。証拠が来るたびにその分布の形が変わっていく様子は、B-08 のベイズ更新の連鎖で扱います。

分布を眺めると、一つの確率だけを見ていたときには見えなかったことが見えます。0匹の日が2割あることも、3匹に会う日がたまにしかないことも、並び全体の形として目に入ります。この形をどう要約するかが、次の二つの節の話です。

**小問1**　飼っている猫が、一日に窓辺へ来る回数の分布を考えます。0回が0.1、1回が0.3、3回が0.2で、ほかには2回しかありません。2回の確率はいくつでしょうか。また、1回以下の確率はいくつでしょうか。

### 期待値は分布の重心

分布全体を一つの数で言うとしたら、まず思い浮かぶのは「平均するとどのくらいか」でしょう。

先ほどの犬の例で計算します。それぞれの値に、その確率を掛けて足します。0×0.2＋1×0.4＋2×0.3＋3×0.1 で、0＋0.4＋0.6＋0.3、合わせて1.3匹です。これを期待値と呼び、E[X] と書きます。式では、E[X] は x × P(X=x) をすべての値について足したもの、となります。

直感としては、分布の重心です。0から3までの目盛りの付いた棒に、確率の大きさに応じた重りを置いたとき、棒が釣り合う点が1.3にあります。頻度の見方では、長く散歩を続けたときの一日あたりの平均に近づいていく値です。

ここで二つのことに気をつけます。

一つは、1.3匹の日は一度も来ないことです。期待値は、一回の散歩の予言ではありません。明日出会う犬の数を一つだけ当てるなら、いちばん確率の高い1匹と言うほうが当たりやすいくらいです。

もう一つは、期待値が数の間隔を信じていることです。掛けて足す計算は、1匹と2匹の差と、2匹と3匹の差が等しいものとして扱います。犬の数なら問題ありません。けれども A-01 で見たように、評定の段階を「3」「4」と呼んでいるだけなら話が違います。LLM の判定器の確率から 3×0.6＋4×0.4＝3.4 を出す期待値スコアは、段階の間隔が等しいという仮定を黙って入れています。同じ順序のまま最上段の名前を5から10に書き換えると、期待値は動いてしまいます。

期待値の考え方は古く、1657年に出たホイヘンスの賭けの計算についての小さな論考が、早い時期の印刷された説明として知られています。そこでは、同じくらいの見込みで a か b がもらえる賭けの値打ちは (a＋b)÷2 だ、というところから話が始まります。

日常の例では、くじ引きを考えると感覚がつかめます。商店街のくじで、1等が当たる見込みは小さくても賞品が大きいとき、期待値は「一枚あたり平均でいくら戻ってくるか」を教えてくれます。ただ、一枚しか引かない人にとっては、ほとんどの場合は外れです。

**小問2**　お祭りの屋台で、一回100円のくじがあります。1割の見込みで500円分の景品、3割の見込みで100円分の景品が当たり、残りは何も当たりません。一回あたりの景品の期待値はいくらでしょうか。

### 分散はばらつきの大きさ

期待値が同じでも、まったく違う分布があります。

近所のパン屋が二軒あるとします。一軒目は、焼き上がりを待つ時間が毎回ちょうど10分です。二軒目は、半々の見込みで、すぐ買えるか20分待つかのどちらかです。どちらも待ち時間の期待値は10分です。けれども、次の予定まで12分しかない日には、二軒目は半分の日で間に合いません。

このばらつきの大きさを測るのが分散です。考え方は、「期待値からどれくらい離れるか」の平均をとることです。

ところが、離れ方をそのまま平均すると困ったことになります。二軒目の待ち時間は、期待値の10分から見て、マイナス10分かプラス10分ずれます。これを半々で平均すると0になってしまいます。上と下のずれが打ち消し合うのです。そこで、ずれを二乗してから平均します。二乗すれば符号が消えて、どちら向きのずれも大きさとして数えられます。

正確には、分散 Var(X) は、(X − E[X]) の二乗の期待値です。二軒目なら、ずれの二乗はどちらも100なので、分散は100です。一軒目はずれがないので0です。

二乗したせいで、単位は「分の二乗」になってしまいます。そこで分散の平方根をとって元の単位に戻したものを、標準偏差と呼びます。二軒目の標準偏差は10分で、「だいたい10分くらい上下する」と読めます。分散という名前を統計の言葉として使い始めたのは、1918年のフィッシャーの遺伝の論文とされています。

一つ付け加えます。分散はいつでも計算できるとは限りません。B-01 で話した果ての国のように、ごくまれな桁違いの値が出る分布では、分散が定まらないことがあります。極端な例では、平均すら定まらない分布も知られています。そういう世界では、記録を増やしても平均が落ち着かず、分散で「だいたいこのくらいの幅」と言うこと自体ができません。これは次回の中心極限定理の前提に関わります。

**小問3**　駅へ向かうバスが二路線あります。路線Aは毎回ちょうど5分遅れます。路線Bは半々の見込みで、遅れなしか10分遅れのどちらかです。それぞれの遅れの期待値と分散はいくつでしょうか。乗り換えに7分の余裕しかない日は、どちらを選ぶでしょうか。

### 連続な値と確率の密度

最後に、値がとびとびでない場合を考えます。

バスが7時から7時10分のあいだのどこかに、どの時刻も同じくらいの見込みで来るとします。到着時刻は7時2分ちょうどかもしれないし、7時2分3秒かもしれず、さらに細かく刻めます。

ここで、「ちょうど7時2分0秒に来る確率」はいくつでしょうか。刻みはいくらでも細かくできるので、一点ちょうどに来る確率は0になってしまいます。それでも、「7時2分から7時5分のあいだに来る確率」なら意味があります。10分のうち3分なので0.3です。値が連続のときは、一点ではなく幅に確率を付けます。

そこで使うのが確率密度です。直感としては、「その辺りに、幅1あたりどれだけの確率が詰まっているか」です。バスの例では、確率1が10分に均等に広がっているので、密度は1分あたり0.1です。幅3分なら 0.1×3 で0.3。グラフにすれば、密度の高さに幅を掛けた面積が確率になります。全体の面積は、必ず1です。

犬の数の分布を棒グラフにしたときを思い出すと、つながりが見えます。到着時刻を1分刻みの棒にすれば、棒は10本で、それぞれの高さは0.1です。30秒刻み、10秒刻みと細かくしていくと、棒の一本あたりの確率はどんどん小さくなりますが、「幅あたりの確率」で高さを描けば、棒の上端は同じ高さのまま、なめらかな線に近づいていきます。その線が密度です。

正確に言えば、連続分布では P(a ≦ X ≦ b) が、密度の曲線の a から b までの面積で与えられます。密度そのものは確率ではありません。

このことから、少し意外な性質が出てきます。密度は1を超えてもかまいません。もしバスが7時から7時30秒の、半分の分のあいだに必ず来るなら、確率1を幅0.5分に詰め込むので、密度は1分あたり2になります。それでも面積は 2×0.5 で1のままです。B-03 の対話で「連続量では尤度が1を超えることもある」という話が出ましたが、その理由がこれです。尤度として使うのが確率でなく密度の値だからで、B-07 で改めて扱います。

連続分布でも、期待値は重心、分散はばらつきという読み方は変わりません。バスの例なら、期待値は真ん中の7時5分です。身長、気温、料理の焼き時間、音の高さなど、測って得る量の多くはこちらの形で考えます。

**小問4**　飼っている猫が、夜の19時から19時20分のあいだに、どの時刻も同じくらいの見込みで帰ってくるとします。19時から19時5分のあいだに帰る確率はいくつでしょうか。また、時間の単位を「分」でなく「時間」にとると、密度の数字はいくつになるでしょうか。その数字が1を超えても困らないのはなぜでしょうか。

## 今日の引っかかり

LLM の判定器が、ある作品について「3に0.6、4に0.4」と返すときと、「1に0.5、5に0.5」と返すとき、期待値は3.4と3でほとんど変わらないのに、分布の形はまったく違います。

後者の大きなばらつきは、判定器がその作品について迷っていることを表しているのでしょうか。それとも、作品そのものが見る角度によって評価の割れる作品だということを表しているのでしょうか。分布を期待値という一つの数に折り畳むとき、捨てているのはどちらの情報なのでしょうか。

## 答え合わせ

復習の1について。1000匹で数えます。病気の猫は50匹で、その8割の40匹が陽性です。病気でない猫は950匹で、その1割の95匹が陽性です。陽性は合わせて135匹、そのうち病気は40匹なので、40÷135でおよそ0.3です。オッズでは、事前1対19に尤度比8を掛けて8対19。確率に直すときは当たりを全体の 8＋19＝27 で割り、8÷27でおよそ0.3です。8÷19（約0.42）としてしまうのは、オッズをそのまま割り算にした形です。外れの側の95匹を分母に入れ忘れると、0.8に近い答えになります。

復習の2について。二人は声を同じくらい「あの鳥らしい」と聞いているので、証拠の読み方、つまり尤度比はそろっています。違うのは、声を聞く前にその鳥がいると思っていた度合いで、食い違いは事前の側です。事前の違いは、独立な証拠が重なるほど小さくなります。同じ尤度比を二人が掛け続ければ、二人ともその鳥である見込みが高い方へ寄っていき、確率としての差は縮まります。ただし、片方が事前0、「絶対に来ない」と置いていれば、何度聞いても動きません（クロムウェルの指針）。

復習の3について。操作主義では、概念はその測り方の手続きと同じものだとみなします。すると、手続きが出した値は、定義によってそのまま概念の値になります。指標と概念のあいだにすき間がないので、「この指標は狙ったものから外れている」と言う場所がなくなります。ベンチマークに問題が漏れていても、「そのテストの得点」としては正しく測れていることになってしまいます。

復習の4について。データの外にある、因果の見立てで決まります。自転車のルートと天気の例のように、分ける軸（天気）が、選ばれ方（どのルートを選ぶか）と結果（かかる時間）の両方に影響しているなら、分けた数字を使います。反対に、分ける軸が比べたいものの結果として生じるものなら、分けるとかえってゆがみます。数字の側だけを見ても、どちらを使うべきかは決まりません。

小問1について。全部足して1になるので、2回の確率は 1 − 0.1 − 0.3 − 0.2 で0.4です。1回以下は0回と1回を足して0.4です。

小問2について。500×0.1＋100×0.3＋0×0.6 で、50＋30＋0、期待値は80円です。一回100円なので、平均すると一回につき20円分戻ってこない計算になります。それでもお祭りでくじを引く楽しさは、期待値の外にあります。

小問3について。路線Aは遅れが毎回5分なので、期待値5分、分散0です。路線Bは0分か10分が半々なので、期待値は5分で同じです。ずれはどちらもプラスマイナス5分、二乗して25なので、分散は25、標準偏差は5分です。余裕が7分の日、路線Aなら必ず間に合い、路線Bでは半分の日で10分遅れて乗り換えに失敗します。期待値が同じでも、ばらつきが選び方を分けます。

小問4について。20分のうち5分なので、確率は0.25です。密度は1分あたり 1÷20 で0.05です。単位を時間にとると、20分は3分の1時間なので、確率1を3分の1時間に詰めることになり、密度は1時間あたり3になります。密度は「幅1あたり」の量なので、幅の単位を変えれば数字も変わります。確率は密度に幅を掛けた面積で、19時から19時5分なら 3×(12分の1時間) で0.25と、単位を変えても同じです。密度が1を超えてもかまわないのは、密度そのものは確率ではなく、面積が1を超えないかぎり確率の決まりは守られているからです。
