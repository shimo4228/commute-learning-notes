# 判断と測定　第8回　全体的評価と分析的評価

2026年11月10日

## 復習

前回の思い出しの問いです。

1. 料理のレシピサイトで、レシピが保存された数の多い順に並んでいます。(ア) いちばん保存数の多いレシピを作ってみたら、思ったほどではありませんでした。(イ) 保存数で並ぶと知った投稿者たちが、料理の写真を豪華に撮るようになりました。(ア) と (イ) は、前回の四つの型のどれに近いでしょうか。

前回のノートから申し送られた問いです。

2. （A-07 から）家族で毎日の歩数を記録し、月末にいちばん多かった人が好きな夕食を選べることにしました。家族は歩数を、どれだけ外の空気を楽しんだかの目安として見ていました。歩数計は腕に付けたまま外せず、振って数を稼ぐこともできないようにしてあります。それでも一人が、いつもの川沿いの寄り道をやめて、家のまわりを早足で何周も回るようになりました。グッドハートの法則、キャンベルの法則の前半（数そのものが偽られる）、キャンベルの法則の後半（数は正直なまま営みが形を変える）は、それぞれ当たるでしょうか。

今日が復習日にあたる問いです。

3. （A-05 から）近所の自転車教室で、上達の具合を「決められたコースを何秒で走れたか」で測っています。(ア) 止まり方や、曲がる前の合図の出し方がうまくなっても、秒数には表れません。(イ) 軽い自転車を持ってきた人は、腕前が同じでも秒数がよくなります。(ア) と (イ) は、構成概念の過少代表と、構成概念に無関係な分散の、どちらにあたるでしょうか。

4. （A-06 から）同じ教室で、秒数の上位三人に修了証を出すことにしました。秒数を目標にしたことで生まれる圧は、どこへ流れ込むでしょうか。過少代表と無関係な分散の言葉で言ってみてください。

## 本文

前回は、指標が押されて崩れる四つの型を見ました。ここまでの数回は、測られる側から見てきたことになります。今日は判断する側に目を移します。

同じ作品を採点するのに、大きく二つのやり方があります。一つは、作品の全体を見て、一つの段階を選ぶやり方です。これを全体的評価、英語ではホリスティックな採点と呼びます。もう一つは、観点を先に決め、観点ごとに段階を付けるやり方で、分析的評価と呼びます。

観点と段階を表にしたものをルーブリックと言います。ルーブリックは分析的評価の道具と思われがちですが、段階ごとの説明を一列にまとめた全体的なルーブリックもあります。今日は、二つのやり方がそれぞれ何を見せて何を隠すのかを、四つの節で一つずつ見ていきます。

### 一つの段階には、何を重く見たかが畳まれる

町の音楽祭で、バンドの演奏を五段階で審査するとします。審査員は一曲を聞き終えて、全体の印象から一つの段階を選びます。

Aバンドは、歌が見事でしたが、リズムがときどき崩れました。Bバンドは、どこも崩れず、それなりにまとまっていました。どちらも五段階の4でした。同じ4ですが、二つのバンドが次に練習すべきところはまるで違います。一つの段階からは、それが見えません。

言葉を決めて言うと、全体的評価では、読む人が作品のいくつもの面を頭の中で重みづけてまとめ、一つの段階で返します。その一つの数には、作品の側のでこぼこと、読む人がどの面をどれだけ重く見たかの両方が畳み込まれています。数だけを見ても、二つを読み分けることはできません。

書く力の評価をまとめたサラ・ウェイグルの2002年の本には、二つのやり方を比べた表があります。全体的評価は速く手軽で、全体で読むほうが自然だという論者の見方も載っています。一方で、一つの点数ではでこぼこのある書き手の姿が隠れること、点数が文章の長さや字のきれいさのような表面の特徴とそろいやすいことも挙がっています。

一つの数が読む人によってどれほど動きうるかを示した古い研究があります。1961年、アメリカの教育試験の研究機関で、ポール・ディードリッヒらが、いくつかの分野の読み手53人に、大学一年生の作文300本を、観点を決めずに9段階で評価してもらいました。94%の作文が、9段階のうち7通り以上の違う評価を受けました。読み手は、何を重く見るかで、おおむね五つの見方の群に分かれていました。

ただ、この読み手たちは、観点も段階の説明も渡されずに評価していました。この結果が示すのは、重みづけをそろえる手立てが無いときに、一つの数が人によってどれほど動くか、ということです。

**小問1**　カレーのコンテストで、二人の審査員が同じ一皿に、五段階の3と5を付けました。この二つの数だけからは分からないことは何でしょうか。それを見分けるには、何があればよいでしょうか。

### 分けると、重みが紙の上に出る

同じ音楽祭で、今度は観点を四つ決めます。歌、演奏の正確さ、まとまり、選曲です。観点ごとに五段階を付けると、Aバンドは歌5、正確さ2、まとまり4、選曲4のようになります。次に練習すべきなのがリズムの正確さだと、数から読めるようになりました。

分析的評価では、観点を先に決め、観点ごとに段階を付けます。何をどれだけ見るかが、読む人の頭の中から紙の上に移ります。この言い方はこの講義の整理ですが、ウェイグルの表が挙げる分析的評価のよいところは、ここから読めます。どの観点で弱いかという診断の情報が出ること、採点者どうしの判定がそろいやすいこと、新しい採点者の訓練に役立つことです。代わりに、時間と手間がかかります。

第6回の対話で、ホリスティックな判断にしても、すき間は判断する側の好みへ引っ越すという見立てが出ました。分析的評価は、その好みを紙の上へ引き出す形です。ただ、重みづけが消えるわけではありません。何を観点にし、段階の説明をどう書くかに、表を作った人の重みづけが入ります。合計で順位を決めるなら、観点どうしが埋め合わせられるという、第1回で見た前提も入ってきます。

ウェイグルの表には、もう一つ大事な指摘があります。分析的な表を使っていても、採点者が全体で読んで印象を決め、それに合わせて観点ごとの段階を付けることがある、というものです。そうなると、観点ごとの数は一つの数の写しになり、診断の情報が消えてしまいます。

二つのやり方の使い分けについて、スーザン・ブルックハートは2018年の総説で、分析的なものは観点ごとに手応えを返せるので練習の途中に向き、全体的なものは一回の判断で済むので最後の成績づけに向く、と書いています。

**小問2**　審査員の一人が、どのバンドにも、観点ごとに4、4、4、4や2、2、2、2のように、平らな数を付けていました。何が起きているかもしれないでしょうか。それを確かめるには、何と比べればよいでしょうか。

### 観点をどう書くかが効く

料理教室の講評表に、二つの書き方の観点があるとします。一つは「野菜を3種類以上使っている」。もう一つは「季節の野菜の味が生きている」です。

前者は、先生が二人で判定しても、すぐにそろいます。ところが、しばらくすると、生徒は付け合わせに三つ目の野菜を足すようになります。数は満たされても、料理の味は前と変わりません。後者は判定が割れやすいものの、料理のよさそのものを指しています。

ブルックハートはその総説で、大学でルーブリックを調べた研究46本を見直しました。全体的か分析的かを含むルーブリックの種類と、報告された信頼性や妥当性のあいだには、はっきりした関係が見えなかったと書いています。ただ、見たルーブリックのうち全体的なものは少数でした。よい結果の出た研究ほど公表されやすい偏りもありうると、本人も断っています。

なお、分析的評価のほうが判定がそろいやすいという見方はよく語られ、ウェイグルの表もそう書いています。型よりも観点の書き方が効くというブルックハートの見方と、ここは割れています。

そのうえでブルックハートがしっかり言えるとした結論は、適切な観点こそが要だ、ということでした。レポートの観点を例にとると、「出典が三つある」のように課題の指示に従ったかを数えるだけの観点は、「関わりがあり信頼できる出典をいろいろ使っている」のように学びの質を描く観点と違って、学ぶ人の努力を誤った方へ向け、学びを測り損なう、と書いています。

まとめると、観点は、作品の質そのものを指す言葉で書く必要があります。数えられる特徴を観点にすると、判定はそろいやすくなりますが、観点の中に小さな指標が一つできます。生徒がその数を押せば、前回の言葉で言う敵対的な型になり、圧はその指標と質のすき間へ流れます。この結びつけはこの講義の整理で、ブルックハートはグッドハートには触れていません。

**小問3**　旅のフォトブックの講評会で、「写真が10枚以上ある」と「旅の流れが伝わる並びになっている」という二つの観点を考えました。数を数える観点はどちらでしょうか。それを観点にすると、どんなことが起きやすいでしょうか。

### 全体は、観点の足し算で決まらない

旅の振り返りを、宿、食事、景色、移動の四つの観点で付けたとします。ある旅は、四つとも五段階の5でした。景色の名所をたくさん回り、移動も手早く済ませました。それなのに、気ぜわしく、どこも味わえなかった感じが残りました。景色の多さと移動の速さは、一つずつなら申し分ありません。二つが重なったところで、ゆっくり味わう時間が消えていました。

別の旅は、雨で予定が崩れ、宿でゆっくり過ごすことになりました。その時間が、いちばんの思い出になっています。けれども、このよさは四つの観点のどこにも当てはまりません。振り返りの表に書くと、宿や食事の段階を少し上げるという形で、なんとなくばらまかれてしまいます。

評価の研究者ロイス・サドラーは、2008年の講演（2009年に記録が出ました）で、複雑な作品を事前に決めた観点で採点することの困りごとを、こうした形で論じました。全体の判断と、観点ごとの判断を足したものは、よく食い違うこと。優れているのにどの観点にも当てはまらない質があると、採点者はその分を一覧にある観点へばらまくこと。そして、観点はたがいに組み合わさって効くこと。観点を足し合わせるのは、全体がちょうど部分の和に等しいと言うことになる、とサドラーは述べています。

観点を足すルーブリックが観点の独立を前提にしていることは、第4回の対話で触れました。サドラーの議論は、その前提が崩れる形を具体的に示したものと読めます。サドラーは、よさは観点の組み合わせの中で現れ、どの観点が効くかは作品ごとに違うので、観点を事前に書き切ることはできない、と考えました。

サドラーが勧めたのは、判断を先にし、理由をあとで言うことです。まともな理由の説明はかならず観点の言葉に触れるけれど、どの観点が目立つかは作品ごとに違う、と言います。本人も、まず全体の判断を下し、そのあとでそれを観点の言葉で言い表すと述べています。

全体的な判断にも、読む順番や関係のない手がかりに引きずられる落とし穴があります。サドラーはそれを認めたうえで、その実験のほとんどが訓練も擦り合わせもしていない採点者を使っている、と指摘しています。

反対側では、エルネスト・パナデロとアンデシュ・ヨンソンが2020年に、ルーブリックへの批判の多くは直接の強い証拠に支えられていない、と結論しています。学説は割れていて、どちらの側にも決め手になる実験は多くありません。

**小問4**　四つの観点がすべて5なのに気ぜわしかった旅を拾えるように、五つ目の観点として「ゆとり」を足すことにしました。これで、次の旅からの振り返りはうまくいくようになるでしょうか。

## 今日の引っかかり

土地評価の要領は、路線価が取りこぼす個々の事情を、例外規定として書き足しながら拾ってきました。その書き足しは、今日の小問4で見た、観点を一つずつ足していく追いかけっこと同じ形でしょうか。もし違うとしたら、例外規定の何が、観点の足し算の前提から逃れさせているのでしょうか。

## 答え合わせ

復習の1について。(ア) は回帰的グッドハートに近いと考えられます。保存数には、味のよさに加えて、写真の映えや載った時期といった外れが入っています。いちばんを選ぶと、外れが上に振れたレシピも一緒に選ばれます。誰も世界に手を入れていません。(イ) は敵対的グッドハートです。投稿者には保存されたいという自分の目的があり、サイトが何を見ているかを学んで、味を通らずに保存数を上げる道を押しています。

復習の2について。グッドハートの法則は当たります。歩数が、外の空気を楽しんだかの手がかりとして働かなくなりました。キャンベルの法則の前半は当たりません。歩数計は外せず、振ることもできないので、記録は正直なままです。後半は当たります。散歩そのものが、歩数に合わせて寄り道のない周回へと形を変えました。前回の対話で出た「記録を正直にしたら、困りごとは残るか」を当てると、残ります。それが後半だけの指摘です。月末の夕食の決まりをやめても周回の癖が残るなら、それも後半の印です。

復習の3について。(ア) は過少代表です。教室が育てたいのは自転車に安全に乗る力で、止まり方や合図はその大事な面ですが、秒数はそれを取りこぼしています。(イ) は無関係な分散です。乗る力とは関係のない自転車の重さが、点数を同じ向きに動かしています。見分けの問いは逆向きの二つでした。「中身がよくなっても点数が動かない面はないか」が取りこぼし、「中身は変わらないのに点数だけを動かす要因はないか」が混ざりものです。

復習の4について。過少代表の側では、秒数に表れない止まり方や合図の練習がおろそかになります。中身のうち拾われていない面が手抜きされる形です。無関係な分散の側では、軽い自転車を借りてくる、角を小さく回ってコースの内側を削る、といった、乗る力を通らずに秒数を上げる要因が押されます。どちらも、指標と構成概念のすき間へ圧が流れた形です。

小問1について。二つの数からは、食い違いがどこから来たのかが分かりません。二人が重く見たものが違う（片方は香り、片方は辛さの釣り合い）のかもしれません。同じものを見ていて、片方がその日たまたま揺れたのかもしれません。あるいは、そのカレーが見る角度によって本当に評価の割れる一皿なのかもしれません。重みづけの違いは、同じ人が何度食べても同じ向きに出ます。揺れは、食べるたびに変わります。見分けるには、二人に理由を書いてもらう、観点ごとに付けてもらう、同じ人に別の日にもう一度食べてもらう、といった手がかりが要ります。第6回の対話で出た揺れと作品の割れ方の見分けに、重みづけの違いが加わった形です。

小問2について。その審査員は、全体の印象で先に段階を決め、それを観点に配っているのかもしれません。ウェイグルの表が挙げていた形です。確かめるには、ほかの審査員が同じバンドに付けた観点ごとの数と比べます。ほかの人がでこぼこのある数を付けているなら、平らなのはその審査員の側の事情です。全部のバンドが本当にどこも同じくらいだった、という可能性も残ります。

小問3について。数を数える観点は「写真が10枚以上ある」です。判定はすぐにそろいますが、似た写真を足して枚数を満たす、旅の流れと関係なく枚数だけを増やす、といったことが起きやすくなります。観点の中に小さな指標ができ、旅の伝わり方とのすき間へ圧が流れる形です。旅の流れという目的に直接つながる事実でなく、手近な目印で観点を定めた形とも言えます。

小問4について。その旅の食い違いは拾えるようになります。ただ、次の旅は別の組み合わせで食い違うかもしれません。ゆとりがありすぎて退屈だった旅や、移動そのものが楽しみだった旅です。そのたびに観点を足していくと、一覧は長くなり、足し算の前提は残ったままです。サドラーの言う、観点を事前に書き切ることはできない、という指摘の形です。テーマCで見た、反例が出るたびに条件を足していく追いかけっこにも似ています。
