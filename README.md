# commute-learning-notes

毎朝の通勤電車（乗車約30分、スマホで読む）で一つの回を学び、その記録を置いています。

- `CURRICULUM.md`　テーマと回の一覧です。A は判断と測定、B は確率と情報理論、C は概念工学、D は解釈可能性研究です
- `lessons/`　その朝に読んだ本文です。Claude が書いています
- `notes/`　回ごとのノートです。本文の要点、本文を読んだあとの Claude との対話で出た論点、概念表、復習用の問いがあります
- `figures/`　回ごとの図（PNG と SVG）と、投稿に添えた説明文です

本文やノートの「著者」は、この学習をしている本人を指します。個人的な名前は伏せています。
